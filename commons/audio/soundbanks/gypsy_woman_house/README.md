# Gypsy Woman House Soundbank

Procedural sound scripts for soulful house — piano stabs, organ, warm pads, classic house percussion.

## Sounds

`kick.gd`, `snare.gd`, `clap.gd`, `hihat.gd`, `bass.gd`, `pad.gd`, `piano.gd`, `organ.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("gypsy_woman_house")`. Configuration in `brief.json`.
