# Boards of Canada Soundbank

Procedural sound scripts inspired by Boards of Canada — warm lo-fi textures, detuned synths, nostalgic pads.

## Sounds

`kick.gd`, `snare.gd`, `hihat.gd`, `bass.gd`, `pad.gd`, `sequence.gd`, `texture.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("boards_of_canada")`. Configuration in `brief.json`.
