# Chromatic Story Soundbank

Procedural sound scripts for chromatic, narrative-driven music — piano, harmonic sequences, clean percussion.

## Sounds

`kick.gd`, `snare.gd`, `hihat.gd`, `rimshot.gd`, `bass.gd`, `pad.gd`, `piano.gd`, `sequence.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("chromatic_story")`. Configuration in `brief.json`.
