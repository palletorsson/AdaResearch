# K-Bass Soundbank

Procedural sound scripts for UK bass music — deep subs, breaks, atmospheric textures, stabs.

## Sounds

`kick.gd`, `snare.gd`, `hihat.gd`, `sub.gd`, `stab.gd`, `break.gd`, `atmosphere.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("k_bass")`. Configuration in `brief.json`.
