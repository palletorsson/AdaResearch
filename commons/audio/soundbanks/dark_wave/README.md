# Dark Wave Soundbank

Procedural sound scripts for dark wave — cold synths, driving bass, atmospheric pads, post-punk percussion.

## Sounds

`kick.gd`, `snare.gd`, `clap.gd`, `hihat.gd`, `bass.gd`, `pad.gd`, `lead.gd`, `arp.gd`, `atmosphere.gd`

## Reference

- `DRUM_PATTERNS.md` — Drum pattern documentation
- `TOP_LINE.md` — Melody and lead line notes

## Usage

Loaded by `SoundbankLoader.load_genre("dark_wave")`. Configuration in `brief.json`.
