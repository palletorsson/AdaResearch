# Vangelis CS-80 Soundbank

Procedural sound scripts emulating Vangelis's Yamaha CS-80 and supporting instruments — brass, strings, choir, Jupiter arpeggio, Prophet pad.

## Sounds

- `cs80_brass.gd`, `cs80_lead.gd`, `cs80_strings.gd` — CS-80 patches
- `vp330_choir.gd` — Roland VP-330 choir
- `prophet_pad.gd` — Sequential Prophet pad
- `jupiter_arp.gd` — Jupiter arpeggio
- `singing_voice.gd` — Vocal synthesis
- `cr5000_kick.gd`, `cr5000_snare.gd`, `cr5000_hihat.gd` — CompuRhythm CR-5000 drums

## Usage

Loaded by `SoundbankLoader.load_genre("vangelis_cs80")`. Configuration in `brief.json`.
