# Synthwave Soundbank

Procedural sound scripts for synthwave — supersaw leads, arpeggiated sequences, retro pads, punchy drums.

## Sounds

`kick.gd`, `snare.gd`, `hihat.gd`, `bass.gd`, `pad.gd`, `arp.gd`, `supersaw.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("synthwave")`. Configuration in `brief.json`.
