# K-Pop Prog Soundbank

Procedural sound scripts blending K-pop production with progressive rock — supersaws, Mellotron pads, 808 subs, Kraftwerk sequences.

## Sounds

`kick.gd`, `snare.gd`, `clap.gd`, `hihat.gd`, `hihat_open.gd`, `808_sub.gd`, `supersaw_pad.gd`, `mellotron_pad.gd`, `neomoog_lead.gd`, `kraftwerk_seq.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("kpop_prog")`. Configuration in `brief.json`.
