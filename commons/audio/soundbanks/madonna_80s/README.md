# Madonna 80s Soundbank

Procedural sound scripts inspired by 1980s pop production — gated reverb, synth stabs, classic drum machine sounds.

## Sounds

`kick.gd`, `snare.gd`, `clap.gd`, `hihat.gd`, `bass.gd`, `pad.gd`, `arp.gd`, `stab.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("madonna_80s")`. Configuration in `brief.json`.
