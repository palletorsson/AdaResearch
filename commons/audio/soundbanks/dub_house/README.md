# Dub House Soundbank

Procedural sound scripts for dub house — deep bass, dub delays, siren effects, rimshots.

## Sounds

`kick.gd`, `snare.gd`, `clap.gd`, `hihat.gd`, `rimshot.gd`, `bass.gd`, `pad.gd`, `stab.gd`, `siren.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("dub_house")`. Configuration in `brief.json`.
