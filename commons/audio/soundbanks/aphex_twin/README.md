# Aphex Twin Soundbank

Procedural sound scripts inspired by Aphex Twin's production style — complex rhythms, modular textures.

## Sounds

`kick.gd`, `snare.gd`, `hihat.gd`, `bass.gd`, `pad.gd`, `sequence.gd`, `texture.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("aphex_twin")`. Configuration in `brief.json`.
