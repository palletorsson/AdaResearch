# Moroder Disco Soundbank

Procedural sound scripts inspired by Giorgio Moroder's electronic disco production — driving sequencers, synth pads, singing voice synthesis.

## Sounds

`kick.gd`, `snare.gd`, `hihat.gd`, `bass.gd`, `pad.gd`, `sequencer.gd`, `singing_voice.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("moroder_disco")`. Configuration in `brief.json`.
