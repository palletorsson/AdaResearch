# Burial Soundbank

Procedural sound scripts inspired by Burial — vinyl crackle, chopped vocals, sub bass, haunted atmospheres.

## Sounds

`kick.gd`, `snare.gd`, `hihat.gd`, `sub.gd`, `vocal.gd`, `crackle.gd`, `atmosphere.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("burial")`. Configuration in `brief.json`.
