# EMD House Recreation Soundbank

Reference video:
- https://www.youtube.com/watch?v=TSx1w2G0m98

Chapter mapping:
- `sine_arp.gd` -> "Beautiful sine arp" (02:39-06:20)
- `wub_synth.gd` -> "Wub synth" (06:43-07:49)
- `vowel_wub.gd` -> "Vowel effect" (07:49-09:30)
- `gritty_lead.gd` -> "Unique gritty lead" (09:30-10:42)
- `aggressive_bass_house_bass.gd` -> "Aggressive bass house preset" (12:43-15:12)

Extensions in the same sound language:
- `razor_formant_bass.gd` -> modern formant/razor bass extension
- `metallic_yoi_lead.gd` -> yoi-style metallic FM lead extension
- `hyper_pluck_lead.gd` -> bright pluck lead extension

These scripts are practical recreations tuned for AdaResearch's stateless
`generate(...)` soundbank model. They aim for the same behavior and character,
not a binary-identical clone of the source patches.
