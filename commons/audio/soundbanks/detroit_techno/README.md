# Detroit Techno Soundbank

Procedural sound scripts for Detroit techno — driving kicks, claps, stabs, analogue pads.

## Sounds

`kick.gd`, `snare.gd`, `clap.gd`, `hihat.gd`, `bass.gd`, `pad.gd`, `stab.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("detroit_techno")`. Configuration in `brief.json`.
