# 90s R&B Soundbank

Procedural sound scripts for 1990s R&B — Rhodes piano, choir pads, finger snaps, smooth leads.

## Sounds

`kick.gd`, `snare.gd`, `clap.gd`, `fingersnap.gd`, `hihat.gd`, `bass.gd`, `pad.gd`, `lead.gd`, `organ.gd`, `choir.gd`, `rhodes.gd`

## Usage

Loaded by `SoundbankLoader.load_genre("nineties_rnb")`. Configuration in `brief.json`.
