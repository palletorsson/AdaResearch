# Kraftwerk Soundbank

Procedural sound scripts emulating Kraftwerk's electronic music — sequenced patterns, electronic percussion, synthetic vocals.

## Sounds

`kick.gd`, `hihat.gd`, `electronic_perc.gd`, `bass.gd`, `pad.gd`, `kraftwerk_bass.gd`, `kraftwerk_lead.gd`, `kraftwerk_pad.gd`, `kraftwerk_arp.gd`

## Subdirectories

- `songs/` — Song-specific configurations (e.g., `computer_love.json`)

## Reference

- `COMPUTER_LOVE_RESEARCH.md` — Research notes on Computer Love synthesis
- `computer_love_harmony.md` — Harmonic analysis

## Usage

Loaded by `SoundbankLoader.load_genre("kraftwerk")`. Configuration in `brief.json`.
