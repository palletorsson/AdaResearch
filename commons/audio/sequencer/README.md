# Step Sequencer

This folder provides an interactive step sequencer artifact for rhythm-driven maps.

## Files
- `step_sequencer.tscn` / `step_sequencer.gd`: Main sequencer artifact spawned from map interactables.
- `sequencer_ui.tscn` / `sequencer_ui.gd`: UI layer used by the sequencer.
- `SoundSuiteSequencer.gd`: Sequencer engine and playback logic.

## Used By
- `Tutorial_Disco` via `step_sequencer`.
