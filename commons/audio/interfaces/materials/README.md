# Interface Materials

Shared Godot material resources (`.tres`) for audio rack and display surfaces.

## Files

- `te_rack_material.tres` — Base rack panel material
- `te_slot_dark.tres` — Dark slot background
- `te_accent_blue.tres` — Blue accent highlight
- `te_accent_green.tres` — Green accent highlight
- `te_accent_orange.tres` — Orange accent highlight
- `te_accent_yellow.tres` — Yellow accent highlight

## Usage

Used by VR display scenes in `../` and rack controls in `../../rack_controls/` for consistent visual styling across the modular synth interface.
