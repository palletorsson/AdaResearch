# Soundscape Presets

Extended multi-layer soundscape presets for immersive environments.

## Files

- `abandoned_factory.json` — Industrial decay atmosphere
- `space_station_isolation.json` — Deep space isolation ambience

## Usage

These presets define richer, multi-layered ambient configurations compared to the single-layer presets in the parent directory. Loaded by `AmbientSoundController` the same way as standard presets.
