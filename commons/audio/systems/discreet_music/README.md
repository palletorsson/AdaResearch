# Discreet Music

Generative music system inspired by Brian Eno's "Discreet Music" — tape delay loops with gradual transformation.

## Files

| Script | Purpose |
|--------|---------|
| `DiscreetMusicLooper.gd` | Core looper — records, plays back, and gradually transforms audio loops |
| `DiscreetSynth.gd` | Synthesis engine for the discreet music system |
| `DiscreetVisualizer.gd` | Visual representation of loop states and transformations |
| `DiscreetMusicTest.gd` | Test driver script |

## Scenes

- `DiscreetMusicTest.tscn` — Test scene for the discreet music system

## Concept

Two or more melodic lines are fed through a long tape delay, creating slowly evolving textures. The loops drift and interact over time, producing non-repeating ambient music from simple initial material.
