# Audio Debug

Debug playback scenes for testing audio systems.

## Files

| Script | Scene | Purpose |
|--------|-------|---------|
| `AmbientWorksPlayer.gd` | `AmbientWorksPlayer.tscn` | Test ambient sound generation and crossfading |
| `ProgSynthPlayer.gd` | `ProgSynthPlayer.tscn` | Test progressive synthesis playback |

## Usage

Drop these scenes into the editor to manually test audio generation without loading a full map. Useful for iterating on synthesis parameters and verifying bus routing.
