# Audio Testing

Test scenes and scripts for validating audio systems.

## Files

- `AudioTestScene.gd` — General audio system test driver

## Subdirectories

- `test_scenes/` — Individual test scene files (currently empty — test scenes are co-located with their systems, e.g., `systems/air_points/AirPointAudioTest.tscn`)

## Usage

Use `AudioTestScene` as a sandbox for verifying synthesis, bus routing, and playback. For system-specific tests, see the test scenes within each system directory.
