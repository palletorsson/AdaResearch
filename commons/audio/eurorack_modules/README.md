# Eurorack Modules

Experimental eurorack module emulation system.

## Files

- `module_library.json` — Module definitions and specifications for the eurorack emulation.

## Status

Under active development. Supports `EurorackModule.gd` and `EurorackRack.gd` at the audio root level. The module library defines available modules that can be instantiated and patched together using the cable system in `../cables/`.
