# Composition Scenes

Ready-to-use Godot scenes for track playback.

## Files

- `dark_game_track.tscn` — Dark ambient game track
- `polymeter_track.tscn` — Polymetric rhythm composition
- `structured_track.tscn` — Standard structured track
- `syncopated_track.tscn` — Syncopated rhythm track

Each scene pairs with a player script from `../players/` and uses the composition systems from `../systems/`.
