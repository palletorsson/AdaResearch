# Runtime Presets

Pre-built Godot audio stream resources (`.tres`) for common game sounds.

## Files

- `pickup_mario.tres` — Item pickup sound
- `teleport_drone.tres` — Teleportation audio
- `ghost_drone.tres` — Ambient ghost drone
- `lift_bass_pulse.tres` — Elevator/lift bass pulse
- `melodic_drone.tres` — Background melodic drone

## Usage

These are pre-synthesized audio resources loaded by `LeanAudioRuntime` for instant playback without runtime generation overhead. They correspond to parameter files in `../../parameters/basic/`.
