# Drum Parameters

JSON synthesis parameters for procedural drum sounds.

## Files

- `dark_808_kick.json` — 808-style kick drum
- `tr909_kick.json` — TR-909 kick
- `linn_drum_kick.json` — LinnDrum kick
- `909_house_kit.json` — Full 909 house drum kit
- `acid_606_hihat.json` — 606 acid hi-hat
- `synare_3_disco_tom.json` — Synare 3 disco tom
- `synare_3_cosmic_fx.json` — Synare 3 cosmic effects

## Usage

Used by `HouseDrumGenerator`, `TrapBeatsGenerator`, and soundbank scripts for procedural drum synthesis.
