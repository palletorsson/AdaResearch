# Basic Parameters

JSON synthesis parameters for fundamental game sounds — pickups, teleportation, UI feedback.

## Files

- `pickup_mario.json` — Item pickup jingle
- `teleport_drone.json` — Teleportation sound
- `ghost_drone.json` — Ambient ghost drone
- `lift_bass_pulse.json` — Elevator bass pulse
- `basic_sine_wave.json` — Simple sine wave
- `ambient_wind.json` — Wind atmosphere
- `artifact_reveal_shimmer.json` — Artifact reveal effect
- `explosion.json` — Explosion sound
- `laser_shot.json` — Laser weapon
- `retro_jump.json` — Retro jump sound
- `shield_hit.json` — Shield impact
- `power_up_jingle.json` — Power-up jingle

## Usage

These are the most commonly used parameters. Several have pre-built `.tres` counterparts in `../../runtime/presets/` for instant playback via `LeanAudioRuntime`.
