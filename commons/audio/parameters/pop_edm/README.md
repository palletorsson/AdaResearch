# Pop/EDM Parameters

JSON synthesis parameters for pop and EDM genres.

## Files

- `detroit_techno.json` — Detroit techno sounds
- `electro_808.json` — Electro 808 elements
- `house_bounce_bass.json` — House bounce bass
- `house_organ.json` — Classic house organ
- `house_piano_stab.json` — House piano stab
- `moroder_disco_bass.json` — Moroder-style disco bass
- `prince_sync_lead.json` — Prince-style synth lead
- `prophet_pad.json` — Prophet synthesizer pad
- `rave_stab.json` — Rave stab hit
- `supersaw_progressive.json` — Progressive supersaw
- `synthwave_lead.json` — Synthwave lead
- `vocal_chop_house.json` — Vocal chop house element
- `warm_strings_pad.json` — Warm string pad
- `wobble_bass.json` — Wobble bass (dubstep-influenced)

## Usage

Used by various genre generators and soundbank scripts for pop and electronic dance music production.
