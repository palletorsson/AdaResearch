# Educational Parameters

JSON synthesis parameters designed for teaching audio synthesis concepts.

## Files

- `beat_frequencies_eerie.json` — Beat frequency demonstration
- `harmonic_brass_lead.json` — Harmonic series brass
- `harmonic_flute_soft.json` — Harmonic series flute
- `harmonic_square_wave.json` — Square wave harmonics

## Usage

Used in educational maps that teach Fourier analysis, harmonic series, and wave interference. These parameters are tuned for clarity of the underlying concept rather than musical polish.
