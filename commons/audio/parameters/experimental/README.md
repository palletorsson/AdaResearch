# Experimental Parameters

JSON synthesis parameters inspired by experimental electronic music artists and techniques.

## Files

- `aphex_twin_modular.json` — Aphex Twin modular synthesis style
- `autechre_flutter.json` — Autechre-style glitch flutter
- `cellular_automata.json` — Cellular automata sonification
- `eccojam_drift.json` — Eccojam/vaporwave drift
- `flying_lotus_sampler.json` — Flying Lotus sampler style
- `herbie_hancock_moog_fusion.json` — Hancock Moog fusion
- `ikeda_dataplex.json` — Ryoji Ikeda data-driven audio
- `radiophonic_workshop.json` — BBC Radiophonic Workshop style
- `spiegel_intelligent.json` — Laurie Spiegel intelligent instruments
- `xenakis_stochastic.json` — Xenakis stochastic composition
- `synthetic_presets.json` — Mixed experimental presets

## Usage

Used for avant-garde ambient presets and experimental soundscapes in maps that explore unconventional audio.
