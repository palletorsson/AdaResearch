# Space Dystopia Parameters

JSON synthesis parameters for the space dystopia theme — dark, cinematic, world-music-infused soundscapes.

## Files

- `blade_runner_brass.json` — Blade Runner brass lead
- `choir_pad.json` — Ethereal choir pad
- `ethnic_tabla.json` — Tabla percussion
- `gamelan_bell.json` — Gamelan bell tones
- `industrial_anvil.json` — Industrial anvil hit
- `noir_sax.json` — Noir saxophone
- `organ_swell.json` — Pipe organ swell
- `processed_vocal_pad.json` — Processed vocal texture
- `reversed_swell.json` — Reversed swell effect
- `trip_hop_beat.json` — Trip hop drum pattern

## Usage

Used by `SpaceDystopiaGenerator` and the space dystopia track collections in `../../collections/`. These parameters define the palette for a specific album-like collection of tracks.
