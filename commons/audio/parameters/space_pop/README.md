# Space Pop Parameters

JSON synthesis parameters for space pop — dreamy, atmospheric pop-influenced soundscapes.

## Files

- `cinematic_strings.json` — Cinematic string section
- `space_choir_pad.json` — Space choir pad
- `space_sub_drone.json` — Sub-frequency space drone
- `pedal_steel_swell.json` — Pedal steel guitar swell
- `noir_sax_breath.json` — Breathy noir saxophone
- `rain_atmosphere.json` — Rain atmosphere layer
- `wavetable_morph.json` — Wavetable morphing synth
- `glitch_chaos.json` — Glitch chaos texture
- `industrial_clank.json` — Industrial clank percussion

## Usage

Used for space pop-themed ambient presets and tracks.
