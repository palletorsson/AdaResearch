# Retro Parameters

JSON synthesis parameters for retro computing and vintage game audio.

## Files

- `c64_sid_lead.json` — Commodore 64 SID chip lead
- `gameboy_dmg_wav.json` — Game Boy DMG wave channel
- `amiga_mod_sample.json` — Amiga MOD tracker sample
- `ambient_amiga_drone.json` — Ambient Amiga drone
- `game_world_presets.json` — Retro game world sound collection

## Usage

Used for maps with retro computing themes, chiptune ambiences, and vintage hardware emulation.
