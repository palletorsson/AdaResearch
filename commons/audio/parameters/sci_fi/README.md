# Sci-Fi Parameters

JSON synthesis parameters for science fiction soundscapes.

## Files

- `space_ambience.json` — Deep space atmosphere
- `dystopian_alarm.json` — Dystopian alarm sound
- `lab_presets.json` — Science lab ambient collection
- `space_dystopia_presets.json` — Space dystopia theme collection

## Usage

Used for sci-fi themed maps and laboratory environments. Pairs with the space dystopia tracks in `../../collections/`.
