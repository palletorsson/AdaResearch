# Trap Beats Parameters

JSON synthesis parameters for trap percussion and elements.

## Files

- `808_kick.json` — 808 kick drum
- `808_cowbell.json` — 808 cowbell
- `808_rim.json` — 808 rimshot
- `trap_snare.json` — Trap snare
- `trap_tom.json` — Trap tom
- `clap.json` — Clap hit
- `hihat_closed.json` — Closed hi-hat
- `hihat_open.json` — Open hi-hat

## Usage

Used by `TrapBeatsGenerator` and the trap beats soundbank. See `../../TRAP_BEATS_INTEGRATION.md` for integration notes.
