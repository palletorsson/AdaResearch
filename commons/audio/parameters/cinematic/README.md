# Cinematic Parameters

JSON synthesis parameters for film score and cinematic audio.

## Files

- `blade_runner_pad.json` — Vangelis-style atmospheric pad
- `deep_dark_cello_drone.json` — Dark cello drone
- `vangelis_brass_lead.json` — CS-80 brass lead
- `weather_presets.json` — Weather-themed cinematic sounds

## Usage

Used by `CinematicMusicGenerator` and the catalog tools for producing cinematic ambient tracks.
