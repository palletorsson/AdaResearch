# Synthesizer Parameters

JSON synthesis parameters emulating classic hardware synthesizers.

## Files

Includes emulations of iconic instruments:

- **Moog**: `minimoog_bass.json`, `moog_bass_lead.json`, `moog_kraftwerk_sequencer.json`
- **Roland**: `juno_bass.json`, `jupiter_8_strings.json`
- **Yamaha**: `dx7_electric_piano.json`, `korg_m1_piano.json`
- **Sequential**: `prophet_pad.json` (via pop_edm)
- **Yamaha CS-80**: `cs80_brass_lead.json`
- **ARP**: `arp_2600_lead.json`
- **Generic**: `fm_bell.json`, `glass_lead.json`, `brass_stab.json`, `pluck_bass.json`, `pluck_lead.json`, `picked_bass.json`, `distorted_bass.json`, `distorted_lead.json`, `bitcrushed_lead.json`, `cinematic_432hz_pad.json`, `wavetable_morph.json`
- **Pop**: `pop_dx7_ballad_keys.json`

## Usage

Used across all generators for synth patches. The catalog tools (`GenreSynthBrowser`, `SynthElementBrowser`) browse these as building blocks for sound design.
