# Tech Noir Parameters

JSON synthesis parameters for tech noir atmosphere — urban, dark, mechanized soundscapes.

## Files

- `city_ambience.json` — Urban city atmosphere
- `distant_siren.json` — Far-off siren
- `electric_hum.json` — Electrical hum
- `endless_drone.json` — Continuous drone
- `mechanical_whir.json` — Mechanical whirring
- `rain_segment.json` — Rain atmosphere
- `static_burst.json` — Static burst effect
- `heartbeat_segment.json` — Heartbeat pulse
- `typing_segment.json` — Keyboard typing sounds
- `industrial_presets.json` — Industrial preset collection

## Usage

Used by `TechnoNoirGenerator` and tech noir ambient presets for dark urban map environments.
