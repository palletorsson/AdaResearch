# EMD House Parameters

JSON synthesis parameters for EMD (Electronic Music Dance) house genre.

## Files

- `emd_house_aggressive_bass_house_bass.json` — Aggressive bass house bass
- `emd_house_razor_formant_bass.json` — Razor formant bass
- `emd_house_vowel_wub.json` — Vowel-modulated wub
- `emd_house_wub_synth.json` — Wub synth
- `emd_house_gritty_lead.json` — Gritty lead
- `emd_house_hyper_pluck_lead.json` — Hyper pluck lead
- `emd_house_metallic_yoi_lead.json` — Metallic yoi lead
- `emd_house_sine_arp.json` — Sine wave arpeggio

## Usage

Used by the EMD house soundbank and genre generators. Pairs with the `soundbanks/emd_house/` scripts.
