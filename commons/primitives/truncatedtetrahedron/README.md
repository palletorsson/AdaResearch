# Truncated Tetrahedron

Tetrahedron with corners cut off, creating a mix of triangular and hexagonal faces.

## Files

- `truncatedtetrahedron.gd`: 8-vertex truncated tetrahedron
- `truncatedtetrahedron.tscn`: scene wrapper

## Behavior

- 8 vertices: original 4 tetrahedron vertices plus 4 cut-corner points.
- 4 triangular + 2 mixed faces.
