# Folded Paper

Interactive folded paper structure with draggable vertex points.

## Files

- `foldedpaper.gd`: multi-segment paper with DragPointSet interaction
- `foldedpaper.tscn`: scene wrapper

## Behavior

- 5+ segments with alternating fold directions.
- Vertices are draggable for geometry exploration.
- Uses MeshInstance3D with procedural mesh updates.
