# Icosahedron

Regular icosahedron (20 triangular faces) using golden ratio vertices.

## Files

- `icosahedron.gd`: procedural mesh via PrimitiveMeshBuilder with PHI constant
- `icosahedron.tscn`: default scene
- `grab_icosahedron.gd` / `grab_icosahedron.tscn`: grabbable VR variant

## Behavior

- Vertices derived from golden ratio (PHI = 1.618...).
- GridMaterialFactory applied for edge visualization.
