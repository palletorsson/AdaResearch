# Pythagorean Proof

Interactive visualization of the Pythagorean theorem.

## Files

- `pythagorean_proof.gd`: main proof visualization with draggable vertices
- `SplitQuadTriangles.gd`: quad splitting helper
- `simple_split_quad.gd`: simplified split quad
- `fill.gdshader`: area fill shader
- Matching `.tscn` scene files

## Behavior

- Draggable vertex points animate square area relationships.
- Demonstrates a² + b² = c² visually with colored areas.
- Uses DragPointSet for interactive geometry manipulation.
