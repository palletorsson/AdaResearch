# Torus

Configurable torus with adjustable rings and tube segments.

## Files

- `torus_radials_rings.gd`: grid-configurable torus via metadata strings
- `torus.tscn`: default torus scene
- `noisetorus_ex_1.tscn`: noise-deformed torus variant

## Behavior

- Parses config metadata for ring/tube segment parameters.
- Supports dynamic parameter adjustment via grid config.
