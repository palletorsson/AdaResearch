# Octahedron

Regular octahedron (8 triangular faces, 6 vertices).

## Files

- `octahedron.gd` / `octahedron.tscn`: procedural octahedron
- `grab_octahedron.gd` / `grab_octahedron.tscn`: grabbable VR variant

## Behavior

- Optional material alternation between faces.
- Grabbable variant extends XRToolsPickable with snap support.
