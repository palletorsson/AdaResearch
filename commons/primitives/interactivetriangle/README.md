# Interactive Triangle

Split quad/triangle system with draggable vertices for geometry exploration.

## Files

- `interactivetriangle.gd`: main interactive triangle with DragPointSet
- `SplitQuadTriangles.gd`: quad-to-triangle splitting helper
- `simple_split_quad.gd`: simplified split quad variant
- `.tscn` scene files for each variant

## Behavior

- Two-triangle color split visualization (pink/black).
- Draggable vertices update mesh in real time.
- Demonstrates how quads decompose into triangles.
