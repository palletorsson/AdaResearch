# Slanted Cube

Thin parallelogram-shaped cube for VR menu elements.

## Files

- `slantedcube.gd`: VRMenuElement with text label and hover color
- `slantedcube.tscn`: scene wrapper

## Behavior

- Creates parallelogram (slanted) shape for menu items.
- Includes Label3D for text display.
- Hover color change for VR interaction feedback.
- Used by the menu system for item rendering.
