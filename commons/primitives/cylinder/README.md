# Cylinder

Cylinder primitives with configurable radial segments, rings, and caps.

## Files

- `cylinder_radials_rings.gd`: grid-configurable cylinder (metadata e.g. "4:3")
- `cylinder_radials_rings.tscn`: configurable variant
- `cylinder.tscn`: default cylinder
- `cone.tscn`: cone variant
- `cylinder_low.tscn`: low-poly variant
- `grab_disc.tscn`: grabbable disc
- `grab_cylinder.tscn`: grabbable cylinder

## Behavior

- Parses grid config metadata for radial/ring parameters.
- Optional cap rendering.
