# Bipyramid

Double pyramid with square base and top/bottom apex points (8 triangular faces).

## Files

- `bipyramid.gd`: procedural mesh via PrimitiveMeshBuilder and GridMaterialFactory
- `bipyramid.tscn`: scene wrapper

## Behavior

- Generates 8-faced polyhedron at runtime.
- Uses shared builder utilities for consistent grid material look.
