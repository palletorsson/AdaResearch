# Unit Cube

Standard unit cube (0.5 scale) with grid material and collision.

## Files

- `unitcube.gd`: cube via PrimitiveMeshBuilder and GridMaterialFactory
- `unitcube.tscn`: scene wrapper

## Behavior

- Light blue color with edge visualization.
- Includes StaticBody3D collision.
- Uses shared builder utilities from `commons/primitives/shared/`.
