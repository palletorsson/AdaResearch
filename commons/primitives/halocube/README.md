# Halo Cube

Hollow cube frame (4 sides, open top/bottom) with collision body.

## Files

- `halocube.gd`: procedural SurfaceTool mesh with configurable size/thickness
- `halocube.tscn`: scene wrapper

## Behavior

- Pink/queer material applied.
- Configurable size, thickness, and height.
- Includes collision for physics interaction.
