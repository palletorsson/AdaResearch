# Laser Measure

Interactive distance measurement tool with laser beam and LCD display.

## Files

- `laser_measure.gd`: raycast-based distance measurement
- `grab_laser_measure.tscn`: grabbable VR tool scene

## Behavior

- Uses RayCast3D for hit detection.
- Renders laser beam and hit dot visuals.
- Displays distance reading and target label.
- Configurable colors for laser and display.
