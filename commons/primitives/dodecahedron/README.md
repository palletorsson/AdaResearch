# Dodecahedron

Regular dodecahedron (12 pentagonal faces) using golden ratio geometry.

## Files

- `dodecahedron.gd`: procedural mesh using PHI constant (1.618) with GridMaterialFactory
- `dodecahedron.tscn`: default scene
- `grab_dodecahedron.gd` / `grab_dodecahedron.tscn`: grabbable VR variant

## Behavior

- Vertices computed from golden ratio relationships.
- Edge-visualized grid material for wireframe appearance.
