# Capsule

Capsule primitives with configurable radial segments and ring divisions.

## Files

- `capsule_radials_rings.gd`: grid-configurable capsule (metadata string e.g. "8:4")
- `capsule_radials_rings.tscn`: configurable variant
- `capsule.tscn`: default capsule
- `capsules.tscn`: multi-capsule scene

## Behavior

- Parses grid config metadata for radial/ring parameters.
- Useful for demonstrating mesh tessellation levels.
