# Stepped Pyramid

Stepped pyramid/ziggurat with configurable parameters.

## Files

- `steppedpyramid.gd`: parameterized stepped pyramid generator
- `steppedpyramid.tscn`: scene wrapper

## Behavior

- Extends MeshInstance3D.
- Configurable: number of sides, steps, base width.
- Vertex data derived from Blender export.
