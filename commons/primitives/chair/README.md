# Chair

Multiple procedural chair variants fitting within a 1x1x1 unit cube.

## Files

- `chair.gd` / `chair.tscn`: basic side-view chair profile
- `chair_modern.gd` / `chair_modern.tscn`: modern style
- `chair_throne.gd` / `chair_throne.tscn`: throne style
- `lab_chair.gd` / `lab_chair.tscn`: lab/office style

## Behavior

- Each variant uses SurfaceTool for procedural mesh generation.
- Configurable seat height, back height, and proportions.
