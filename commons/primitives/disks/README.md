# Disks

Small grabbable color disks for additive/subtractive color mixing.

## Files

- `grab_disk.gd`: color-configurable pickable disk
- `grab_disk.tscn`: grabbable disk scene

## Behavior

- Extends XRToolsPickable for VR grab interaction.
- Supports visual color blending when disks overlap.
- Works as @tool script for editor color preview.
- Snaps to shelf positions.
