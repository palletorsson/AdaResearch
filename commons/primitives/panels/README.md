# Panels

Sci-fi panel walls and digital paper display surfaces.

## Files

- `SciFiPanelWall.gd` / `scifi_panel_wall.tscn`: configurable panel wall
- `scifi_panel_tile.tscn`: individual panel tile

## Subfolders

- `DigitalPaper/`: scrollable text/code display with grab mechanics (see `TOUCH_SCROLL_README.md`)

## Behavior

- SciFiPanelWall generates tiled walls with dimension and material variation.
