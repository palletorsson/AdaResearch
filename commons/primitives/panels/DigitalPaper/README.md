# Digital Paper

Scrollable text and code display surfaces for VR.

## Files

- `TouchScrollContainer.gd`: scrollable container control
- `grab_paper.tscn`: basic grabbable paper
- `grab_paper_hand.tscn`: hand-held paper variant
- `grab_paper_text.tscn`: text-displaying paper
- `wikiCodeDisplay.tscn`: code display surface
- `TextUIControl.tscn`: text UI layout

## Behavior

- Touch-scrollable content via TouchScrollContainer.
- Multiple paper variants for different display needs.
- See `TOUCH_SCROLL_README.md` for scroll implementation details.
