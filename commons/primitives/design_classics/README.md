# Design Classics

Procedurally generated classic design objects.

## Files

- `aalto_vase.gd` / `aalto_vase.tscn`: Alvar Aalto's 1936 Savoy vase with harmonic cross-sections
- `alessi_tree.gd` / `alessi_tree.tscn`: Alessi tree ornament
- `grab_aalto_vase.tscn`: grabbable vase variant
- `grab_alessi_tree.tscn`: grabbable tree variant

## Behavior

- Aalto vase uses harmonic cross-sections with configurable base/rim radius.
- Both work as @tool scripts for editor preview.
