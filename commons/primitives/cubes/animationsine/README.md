# Animation Sine

Cube animator with rotation, oscillation, and scale pulse effects.

## Files

- `CubeAnimator.gd`: per-animation enable/disable controls
- `animated_cube.tscn`: animated cube scene
- `animated_cube_edit.gd`: editor variant

## Behavior

- Rotation speed as Vector3 (degrees/sec per axis).
- Vertical oscillation with configurable height and speed.
- Scale pulse effect with configurable amount and speed.
- Used in Chapter 3 teaching modules.
