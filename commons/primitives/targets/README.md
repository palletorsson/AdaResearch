# Targets

Target practice objects with pride-colored concentric rings.

## Files

- `queer_cylinder_target.gd`: target with 8-color pride palette
- `queer_cylinder_target.tscn`: scene wrapper

## Behavior

- Extends StaticBody3D for hit detection.
- Concentric rings with pride flag colors.
- Breathing animation for visual presence.
- Reports hits for scoring.
