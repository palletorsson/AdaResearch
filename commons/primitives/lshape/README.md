# L-Shape

Upside-down L-shaped geometry with configurable dimensions.

## Files

- `lshape.gd` / `lshape.tscn`: L-shape variant 1
- `l_shape.gd` / `l_shape.tscn`: L-shape variant 2

## Behavior

- Cyan/queer material applied.
- Configurable vertical/horizontal dimensions and thickness.
- Procedural SurfaceTool mesh with collision support.
