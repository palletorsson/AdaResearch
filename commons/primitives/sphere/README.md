# Sphere Primitives

This folder contains sphere variants used as ambient volumes and grab objects.

## Key Scene in Point Maps

- `dark_sphere.tscn`: large inward-facing black sphere used as enclosure/contrast backdrop.

## Other Scenes

- `sphere.tscn`
- `light_sphere.tscn`
- `grab_sphere.tscn`
- `grab_sphere_wood.tscn`

## Usage

Registry key in maps: `dark_sphere`

Use sparingly: large enclosing spheres can dominate composition if overused.
