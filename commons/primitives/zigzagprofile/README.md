# Zigzag Profile

Standing zigzag profile with alternating peaks and valleys.

## Files

- `zigzagprofile.gd`: interactive zigzag with DragPointSet
- `zigzagprofile.tscn`: scene wrapper

## Behavior

- Green marble color.
- Draggable vertex points for interactive deformation.
- Supports freeze modes for locking geometry.
- Connects to `point_picked_up` and `point_dropped` signals.
