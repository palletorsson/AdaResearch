# Cube

Regular hexahedron (6 square faces) using shared builder utilities.

## Files

- `cube.gd`: procedural cube via PrimitiveMeshBuilder and GridMaterialFactory
- `cube.tscn`: default cube scene
- `grab_cube_show.tscn`: grabbable display variant

## Behavior

- Uses shared GridMaterialFactory for consistent edge-visualized material.
- Standard 1-unit cube built at runtime.
