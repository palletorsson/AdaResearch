# Hollow Rock

Procedural hollow rock using torus base with noise deformation.

## Files

- `hollowrock.gd`: torus-based rock with noise displacement
- `hollowrock.tscn`: scene wrapper

## Behavior

- Exports: major/minor radius, deformation, roughness, scale/skew per axis.
- Extends MeshInstance3D with procedural mesh generation.
- Creates organic rocky shapes with hollow interior.
