# Johnson Solids

Convex polyhedra from the Johnson solids classification, built via PolyhedronFactory.

## Files

- `square_pyramid.gd` / `square_pyramid.tscn`: J1 square pyramid
- `triangular_cupola.gd` / `triangular_cupola.tscn`: triangular cupola

## Behavior

- Generated through `PolyhedronFactory.create_square_pyramid()` and `create_cupola()`.
- Uses shared polyhedron builder for consistent mesh quality.
