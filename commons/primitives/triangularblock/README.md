# Triangular Block

Pyramid base with apex, built from 4 triangular faces.

## Files

- `triangularblock.gd`: SurfaceTool-based triangular block
- `triangularblock.tscn`: scene wrapper

## Behavior

- Orange accent color.
- 4 triangular faces (base triangle + 3 side triangles).
- Built via `create_triangle_block()` and `add_triangle()` helpers.
