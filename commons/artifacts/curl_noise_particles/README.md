# Curl Noise Particles

Drives 300 particles through a divergence-free velocity field generated by curl noise, producing smooth, swirling flow ribbons. Teaches the concept of curl (rotational component of a vector field) and why incompressible flow fields are useful in procedural animation and fluid simulation.

## How It Works

Two independent 3D noise potential fields are sampled at each particle position. The curl (cross product of their gradients) produces a velocity vector that is guaranteed to be divergence-free -- meaning particles neither accumulate nor disperse, mimicking incompressible fluid. Particles are advected by this velocity field each frame, with trail lines drawn behind every third particle for flow visualization. Color shifts from deep blue (slow) through cyan to near-white (fast) based on local speed. Particles that exit the bounding box are respawned at random interior positions.

## Parameters

| Export | Type | Default |
|--------|------|---------|
| `particle_count` | int | `300` |
| `bounds` | Vector3 | `(0.7, 0.5, 0.7)` |
| `noise_scale` | float | `2.5` |
| `flow_speed` | float | `0.3` |
| `time_scale` | float | `0.15` |

## Features

- Curl noise velocity field guaranteeing divergence-free (incompressible) flow
- 300 particles rendered via MultiMesh with speed-based color ramp
- Flow-trail ribbons drawn with ImmediateMesh for every third particle
- Wireframe bounding box for spatial reference
- Three-octave sin-based noise for smooth turbulence without Godot noise textures
- Grid config integration for dynamic parameter adjustment
