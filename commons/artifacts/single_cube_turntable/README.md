# One cube / one turn

A 1.10-metre black-steel plate carries one outlined off-white cube centered on
its axis. Turning the plate rotates the cube in place. The cube has no independent
animation or scale change.

This reuses the zoetrope drive, production desktop pointer rim, XRTools crank grip
and shared machine finish. RPM selects 0–30 revolutions per minute. ANGLE pauses
automatic motion and chooses a phase. RUN resumes; REVERSE changes direction.
The hand overrides the motor, which resumes 0.65 seconds after release.

The transmission is ideal kinematic gearing. The source is a demonstration of an
attached body, not a force-based gearbox. Its plate top is 1.05 metres above the
floor; crank and controls retain the other machines' hand heights.

`DiskAndCrank` and `PlaybackControls` are separate editable source groups. The
shared catalogue places the same scene in desktop, VR, the tree and the live editor.
The floor59 path develops from the hand-driven sine yoke, through this single
body, into the 24 fixed-frame zoetrope.
