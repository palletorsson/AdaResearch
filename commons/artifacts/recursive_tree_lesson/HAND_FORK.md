# One fork in the hand

The primary `recursive_tree_2` placement with `#lesson:true#room:canopy` installs the hand model beside its existing rule desk. The source still owns the queue, branches and generation count. No new registry entry or map token is needed.

- GROW reveals the first two controls, then adds one whole generation. Four binary generations give 31 segments, including the trunk.
- Hold the rose or black point. Its position is converted into model-local direction, bounded to 12–65 degrees from up. The selected existing branch, its descendants and queued tips turn around the attachment; lengths and other subtrees stay.
- The hand remains free. Release parks the point at the represented fixed-length endpoint. Desktop pickup/drop uses the existing pointer hooks.
- GROW/RESET/ANGLE/LENGTH/FORKS wait while either point is held. Global rule controls rebuild the tree and discard local edits. RULE remains readable.
- The miniature and large solid canopy receive the same source data. Pose changes update existing meshes/colliders at up to 20 Hz; topology changes rebuild the bounded receivers. The original tree still caps allocation at 512 segments; this desk allows at most 121.
- The enlarged trunk is offset one metre from its former position to clear the central walking line. Existing route and other exhibits remain.

This is a geometric edit, not a spring or a living tree responding to forces. The large canopy is solid; the small model is a visual receiver with two pickable points. No new player motion is imposed. Physical headset feel and Quest performance remain untested.

Tests: `tools/probes/fractal_hand_fork.gd`, `tools/probes/fractal_hand_fork_museum.gd`. Printed lessons: `python tools/test_fractal_opening_lessons.py` extracts actual tutorial.md code and runs it. Review: `doc/book/iterations/2026-10-08-fractal-fork-in-the-hand/index.html`.

## Two readings and a return — 8 October 2026

The same canopy placement now installs `tree_readings.gd` beside the desk. Four batched drawings show plan (X/Z) and side (X/Y), with live black segments over one kept rose snapshot. Both use a fixed 0.075 scale. Segments aligned with the omitted axis become small marks rather than disappearing. The 10 Hz receiver refreshes on a geometry revision, changed root or changed segment count; it never calls the generator to alter the tree.

KEEP copies endpoint records and the current generation/ratio/fork/angle settings. CLEAR removes only that comparison. The endpoint records retain local hand edits; the four rule settings alone would not reconstruct them. This is one comparison in memory, not an undo command or a cross-visit save. The drawings have no collision. The station's narrow support, base and control shelf do; a standing approach is tested against the actual museum floor and collisions.

The encounter asks the visitor to keep a view, turn a branch, walk under the canopy and return with a changed description. It is a supporting research instrument, not a new required programming subject. Method and editorial placement: `doc/book/course/fractals-scale-and-return.md`.
