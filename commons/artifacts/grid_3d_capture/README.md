# Grid 3D Capture

Scene-only artifact used for capturing 3D grid screenshots. Provides the scene setup needed by the Godot capture pipeline to render grid-based content for documentation and preview images.

## How It Works

This is a scene-only artifact (no script) that serves as a capture target for the multi-angle screenshot pipeline. It provides the camera and lighting configuration needed to render grid 3D content.

## Files

- `grid_3d_capture.tscn` -- Capture scene configuration
