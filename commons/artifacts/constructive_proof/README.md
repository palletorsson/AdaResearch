# Constructive Proof

A simple visual artifact contrasting constructive and classical proof styles. Teaches the fundamental distinction in mathematical logic: a classical proof can show something exists by contradiction, while a constructive proof must explicitly exhibit a witness.

## How It Works

A colored box is displayed as the "constructed witness" with an arrow labeled "Must BUILD it," embodying the constructive approach. A text label below explains the difference: classical existence proofs assert that some x satisfying P(x) exists (possibly via contradiction), whereas constructive proofs require producing the actual x. The artifact serves as a visual anchor for discussions about intuitionism and computability.

## Features

- Visual representation of the constructive proof concept
- Configurable box color and size via grid config
- Explanatory label comparing classical vs constructive existence proofs
