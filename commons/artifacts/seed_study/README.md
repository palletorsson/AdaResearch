# Seed study

Registered as `seed_study` in Random_Definition, the first randomness hall.
The current placement is map cell (10,17), facing west (270 degrees), near the
far-right end of the room. Refresh the web editor or reload the desktop room
after changing its map.

The five trays use the same 48 retained values: flat RGB colour, neutral bars,
colour plus height, uniform size and yaw. The rectangular board controls
reset, keep, replay, export, import and the next seed. Desktop F1–F8 work at
the board while facing it; they do not affect the study from another room.

`seed_record.gd`, `seed_board.gd` and `seed_study.gd` are the promoted,
byte-identical build of the experiment's printed implementation at installation.
The research companion retains that reproducible version. Future changes to
these scripts should return to the tutorial and experiment record with new
evidence. `museum_seed_study.gd` adds only local keyboard ownership. Production
resources live here because exports exclude `doc/`.
