# Book / Notes Display

3D text display objects for reading content in VR.

## Key Files
- `ada_notes.tscn` — Node3D with UINoiseBlobControl; multi-layer display (Screen MeshInstance3D, Viewport2Din3D with TextUIControl, HandPoseArea, SpotLight3D) for interactive markdown/text
- `booktext.tscn` — Text/book display variant
- `text_display.tscn` — Generic text display container
