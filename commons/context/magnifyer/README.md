# Magnifying Glass

Optical distortion lens effect for VR inspection.

## Key Files
- `magnifying_glass.tscn` — SphereMesh with `magnifyingLens.gdshader` material for optical distortion
- `magnifying_glass_red.tscn` — Red-tinted variant
- `magnifying_glass_tool.tscn` — Interactive variant with full VR interaction setup
