# Tutorial Text - .gd File Format

## Why Use .gd Files?

Using `.gd` (GDScript) files for tutorial content is **the recommended approach** because:

✅ **Automatically imported** by Godot as resources
✅ **No filesystem path issues** - `load()` works perfectly
✅ **Works in exported builds** without special configuration
✅ **Syntax highlighting** in Godot's script editor
✅ **Version control friendly** - easy to diff and track changes
✅ **Faster loading** - uses Godot's resource cache

## Format

Create a GDScript file that extends `Node` and stores content in a `text` variable:

```gdscript
extends Node

# Tutorial: Your Tutorial Name
# BBCode formatted content

var text = '''[b][color=cyan]Tutorial Title[/color][/b]

Your tutorial content here with BBCode formatting.

[color=yellow]Section 1:[/color]
Explanation text...

[code]
# Code examples
func example():
    print("Code with syntax")
[/code]

[i]Tips and additional notes...[/i]
'''
```

## Key Points

1. **Use triple-quoted strings** (`'''...'`) for multi-line content
2. **Store in `var text`** - the loader looks for this variable
3. **Full BBCode support** - colors, bold, italic, code blocks, etc.
4. **Keep it simple** - just a data container, no complex logic needed

## Alternative: Function-based

If you need dynamic content, you can also use a function:

```gdscript
extends Node

func get_content() -> String:
    return """[b]Dynamic Content[/b]

    This content is generated by a function.
    You could even do string interpolation here!
    """
```

The loader will call `get_content()` if it exists.

## Usage in JSON

Reference the `.gd` file in `tutorial_text.json`:

```json
{
  "tutorials": {
    "my_tutorial": {
      "content_file": "res://commons/context/clipboard/tutorial_text/my_tutorial.gd"
    }
  }
}
```

## Migration from .txt

To convert existing `.txt` files to `.gd`:

1. Create new `.gd` file
2. Add the boilerplate:
   ```gdscript
   extends Node
   var text = '''
   ```
3. Paste your BBCode content
4. Close with `'''`
5. Update JSON to point to `.gd` file
6. Done!

## Editing

You can edit `.gd` tutorial files:

1. **In Script Editor**: Open the `.gd` file directly
2. **In Tutorial Editor Plugin**: Load from file chooser dropdown
3. **Externally**: Edit with any text editor

The content is just a string, so it's easy to work with!

## Best Practices

- ✅ Use descriptive file names (e.g., `vector_math_basics.gd`)
- ✅ Add a comment header with the tutorial name
- ✅ Format your BBCode nicely for readability
- ✅ Test in the preview before saving
- ✅ Keep each tutorial focused on one topic
- ✅ Use `_template.gd` as a starting point

## Loading Flow

```
1. JSON references: "content_file": "res://.../tutorial.gd"
2. TutorialTextLibrary detects .gd extension
3. Uses load() to get script resource
4. Instantiates script
5. Reads .text variable
6. Returns content string
7. Displays in codeDisplay with BBCode rendering
```

No filesystem access needed - pure Godot resource system! 🎉
