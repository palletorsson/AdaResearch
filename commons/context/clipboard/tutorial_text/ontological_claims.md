# Ontological Claims Registry

## Method

Every theoretical claim is tested in code. The test is not illustration — it is experiment. The code must be capable of falsifying the claim. Verdicts are: **Confirmed** (code behaves as theory predicts), **Refined** (theory holds but requires conditions the theorist didn't specify), **Broken** (code contradicts the claim in this domain).

The cross-domain verdict table is the contribution. One confirmation is an example. Confirmations across seven computational domains is evidence. Breakdowns are as valuable as confirmations — they reveal the scope conditions of the theory.

## Claim 1: Thrownness

**Source:** Martin Heidegger, *Being and Time* (1927). Geworfenheit.

**Claim:** Initial conditions are given, not chosen. The trajectory of an entity follows from its state at instantiation, not from any decision procedure within it.

**Confirmed means:** The entity has no self-initialization logic. Varying initial state produces divergent trajectories. The initial state is imposed externally.

**Broken means:** The entity self-seeds through internal logic, or the system converges to the same attractor regardless of initial state (the thrown condition is forgotten).

**Test protocol:**
1. Identify initialization code — is there conditional logic governing initial state from within the entity?
2. Write a function that varies initial conditions and measures trajectory divergence
3. If divergence: thrownness confirmed (the given state matters)
4. If convergence: thrownness broken (initial conditions are irrelevant)
5. Check for the collapsed thrown/projected distinction (CA_11 found both happen in one tick)

## Claim 2: Agential Realism

**Source:** Karen Barad, *Meeting the Universe Halfway* (2007). Intra-action.

**Claim:** Properties are enacted through interaction, not possessed intrinsically. An entity's behavior depends on its relational configuration, not on internal attributes alone.

**Confirmed means:** Same entity in same internal state produces different outcomes when context varies. The function signature requires context parameters (neighbors, environment, field values).

**Broken means:** Entity behavior determined entirely by internal state. A function `f(entity_state) -> outcome` suffices with no context input.

**Test protocol:**
1. Identify the core update function — does it take context parameters?
2. Hold entity state constant, vary context, observe output
3. If outputs differ: agency is relational (confirmed)
4. If outputs identical: agency is intrinsic (broken)
5. Then test whether the UPDATE RULE ITSELF is relational or fixed (the Baradian limit from CA_11)

## Claim 3: Performativity

**Source:** Judith Butler, *Gender Trouble* (1990). Performative constitution.

**Claim:** Identity is produced through constrained repetition. The act of performing produces the category being performed. Prior iterations constrain future iterations.

**Confirmed means:** The algorithm contains a repeated operation whose accumulated execution creates constraints on future repetitions. History affects what the entity can do next. Feedback loop from output to next iteration's conditions.

**Broken means:** Each iteration is independent (memoryless). Constraints precede repetition entirely (imposed from outside, not generated by the process).

**Test protocol:**
1. Identify the main loop or iterative process
2. Check whether iteration N's output constrains iteration N+1's input
3. Test: does removing history (resetting state mid-execution) change subsequent behavior?
4. If yes: performativity confirmed (repetition produces its own constraints)
5. If no: identity is given, not performed (broken)
6. Check whether spatial structure is required (CA_11 found the diode)

## Claim 4: Boundary as Politics

**Source:** Composite (critical theory, Ahmed, Foucault).

**Claim:** Every threshold, boundary, or classification criterion is a political choice. Changing the boundary changes the physics of the system.

**Confirmed means:** The algorithm contains at least one threshold. Changing that threshold to different values produces qualitatively different system behavior. The threshold is not derivable from first principles.

**Broken means:** The threshold is mathematically necessary (derivable from conservation laws), or changing it produces only quantitative differences (same behavior, different magnitude).

**Test protocol:**
1. Identify thresholds, cutoffs, `if` conditions with numeric comparisons
2. Replace the threshold with alternatives (higher, lower, removed)
3. If qualitatively different behaviors emerge: boundary is political (confirmed)
4. If behavior scales smoothly: boundary is parametric, not political (refined)
5. If only one value produces coherent behavior: boundary is structural (necessary infrastructure)

## Claim 5: Negation Requires Infrastructure

**Source:** Jacques Derrida, *Of Grammatology* (1967).

**Claim:** NOT operations depend on prior presence. You can only negate what is already posited. Negation requires institutional infrastructure to operate.

**Confirmed means:** The algorithm's exclusion/rejection/filtering operations depend on a ground signal — a prior positive state that the negation subtracts from.

**Broken means:** The algorithm generates absence from nothing — it has a NOT operation that requires no prior signal, no clock, no ground state.

**Test protocol:**
1. Identify negation operations: `not`, boolean inversion, exclusion filters, clamping, boundary rejection
2. Trace each negation to its dependencies: what must exist for negation to operate?
3. Remove the prerequisite infrastructure — does negation still work?
4. If fails without infrastructure: confirmed
5. If negation is primitive: broken
6. In unconditional systems (noise, waves): negation may be entirely absent — report as N/A

## Claim 6: Finitude as Constitutive

**Source:** Heidegger (*Being and Time*), M. Chirimuuta (*Outside Color*).

**Claim:** Limits are not defects but conditions of possibility. Removing limits destroys function rather than improving it.

**Confirmed means:** Removing a limit (grid size → infinite, speed → unlimited, iterations → unlimited) causes degenerate output — uniform fields, trivial convergence, computational explosion, or loss of interesting behavior.

**Broken means:** Removing the limit produces strictly better results. The finite case was merely a performance compromise.

**Test protocol:**
1. Identify all finite limits: grid bounds, max velocity, perception radii, iteration counts, timestep sizes
2. For each limit, test the algorithm with the limit dramatically increased or removed
3. If interesting behavior collapses: finitude is constitutive (confirmed)
4. If behavior improves: finitude is merely practical (broken)
5. Distinguish constitutive limits from computational limits

## Claim 7: QFEP Location

**Source:** Ada Research QFEP framework. QFE = F − λE(S) + φΔE(S,t).

**Claim:** Every algorithm has effective (λ, φ) coordinates derivable from its code structure. These coordinates predict behavior class.

**Confirmed means:** Lambda and phi can be extracted from code properties AND correctly predict observed behavior. Systems with similar (λ, φ) behave similarly across domains.

**Broken means:** Different extraction methods produce contradictory values, or values don't predict behavior.

**Test protocol:**
1. Lambda indicators: presence of randomness, conditional vs unconditional transitions, sensitivity to initial conditions, accessible state space
2. Phi indicators: damping (φ < 0), amplification (φ > 0), feedback loops, memory/memorylessness
3. Assign (λ, φ) with explicit justification from code
4. Test: does the assignment predict behavior class?
5. Cross-domain comparison IS the test — individual assignments are hypotheses, the pattern is evidence

**Lambda reference points:**
- λ ≈ 0.0: Deterministic, no randomness, fixed paths (Wireworld)
- λ ≈ 0.3: Edge of chaos, structured emergence (Game of Life, Rule 110)
- λ ≈ 0.5: Mid-entropy, balanced exploration
- λ ≈ 1.0: Pure chaos, maximum randomness

**Phi reference points:**
- φ ≈ -1.0: Maximum resistance to change (refractory states, damping)
- φ ≈ 0.0: Neutral (no amplification or damping)
- φ ≈ +1.0: Maximum embrace of change (positive feedback, amplification)

## Claim 8: Emergence Requires Both Rules and Geometry

**Source:** Systems theory, complexity science.

**Claim:** Complex behavior requires both fixed rules (the algorithm) and intentional geometry (initial configuration or spatial structure). Neither alone suffices.

**Confirmed means:** Behavior vanishes when either rules are replaced with trivial rules (identity, random) while geometry is preserved, OR geometry is replaced with trivial geometry (uniform, degenerate) while rules are preserved.

**Broken means:** Interesting behavior persists from rules alone (any geometry works) or from geometry alone (any rules work).

**Test protocol:**
1. Identify the algorithm's rules (update function) and geometry (initial conditions, spatial layout, connectivity)
2. Hold rules constant, replace geometry with uniform/random → does behavior persist?
3. Hold geometry constant, replace rules with trivial rules → does behavior persist?
4. If both destroy behavior: confirmed (both required)
5. If one preserves: that component is sufficient (claim too strong)

### Key Findings

**Agential realism has a formal boundary.** It holds if and only if the update function includes a context parameter: `f(state, context) → outcome`. Systems without context parameters (noise, waves, CF L-Systems) break the claim. Systems with context parameters (boids, cloth, CS L-Systems, CA_11) confirm it. The boundary corresponds exactly to the CF→CS transition in the Chomsky hierarchy.

**Performativity requires state-dependent iteration.** Mere repetition is insufficient (waves repeat without performing). What Butler requires is that iteration N's output constrains iteration N+1's input. Systems with accumulating state (forces/velocity, L-Systems/string, cloth/position-history) confirm it. Stateless systems (noise, waves) break it.

**Thrownness is the most universal claim.** It holds everywhere — in every system tested, initial conditions are externally given. But thrownness has strengths: it can be weak (wave phase shifts timing only), strong (force velocity determines trajectory), or absolute (L-System axiom determines exponentially divergent futures). It can also decay (boids forget initial scatter) or persist forever (wave phase never converges).

**Finitude splits into constitutive and practical.** Constitutive limits (CFL condition, Nyquist aliasing) destroy the simulation when removed. Practical limits (grid resolution, amplitude) produce strictly better results at higher values. The constitutive limits are always temporal/frequency constraints. The practical limits are always spatial/magnitude constraints.

**The QFEP correctly discriminates.** Systems with similar (λ, φ) behave similarly. Forces and cloth share (0, -0.3) — both are conservative, dissipative physics. Boids at (0.35, +0.2) are uniquely self-organizing. Waves and CF L-Systems share (0, 0) — deterministic, neutral, rigid. The coordinates predict behavior class across domains.

**Emergence is graded in multi-force systems.** Both boids (3 steering rules) and cloth (3 spring types) show the same pattern: one force produces degenerate behavior, two produce partial behavior, three produce the full phenomenon. Emergence is not binary (present/absent) but a function of how many independent forces operate simultaneously.
