## The Unit Circle: Where Waves Are Born

A point rotating around a circle traces **sine and cosine simultaneously**.

**Code: Circle as Dual Waves**

```
var angle = 0.0

func _process(delta):
    angle += delta  # Rotation over time

    # Position on unit circle (radius = 1)
    var x = cos(angle)  # Horizontal position
    var y = sin(angle)  # Vertical position

    # This point rotates around circle
    draw_point(Vector2(x, y))

    # Project to axes:
    draw_point(Vector2(x, 0))  # Cosine wave on X axis
    draw_point(Vector2(0, y))  # Sine wave on Y axis
```

**What this reveals:**
- **Circular motion = two waves perpendicular**
- X-coordinate oscillates as **cosine**
- Y-coordinate oscillates as **sine**
- Circle is sine and cosine **united in rotation**

**The circle IS the wavefunction.**

## From Circle to Spiral: Adding Time

If rotation happens while moving forward → **spiral**.

**Code: Helix (3D Spiral)**

```
var time = 0.0
var frequency = 2.0
var radius = 1.0
var rise_rate = 0.5

func _process(delta):
    time += delta

    # Rotate in XY plane (circle)
    var x = cos(time * frequency) * radius
    var y = sin(time * frequency) * radius

    # Move forward in Z (time progression)
    var z = time * rise_rate

    # This creates helix (spiral staircase)
    var position = Vector3(x, y, z)
    draw_point(position)
```

**The helix = sine + cosine + linear progression**

Examples in nature:
- **DNA double helix** - two spirals intertwined
- **Spiral galaxies** - rotation + radial movement
- **Seashell spirals** - growth while rotating
- **Climbing vines** - seeking light while growing

**Spiral = wave extended through space.**

## Superposition: Multiple Waves Create Complex Form

Add multiple sine waves at different frequencies → **complex patterns emerge**.

**Code: Lissajous Figures**

```
var time = 0.0
var freq_x = 3.0  # X frequency
var freq_y = 2.0  # Y frequency
var phase = 0.0   # Phase offset

func _process(delta):
    time += delta

    # Two independent oscillations
    var x = sin(freq_x * time)
    var y = sin(freq_y * time + phase)

    # Creates Lissajous curve
    draw_point(Vector2(x, y))

# freq_x / freq_y = rational number → closed curve
# freq_x / freq_y = irrational → never closes (dense spiral)
# phase changes → curve rotates/transforms
```

**Frequency ratios create patterns:**
- 1:1 → diagonal line (same frequency)
- 2:1 → figure-8
- 3:2 → three-lobed flower
- 4:3 → complex knot

**These are pure geometry generated by wave interference.**

Used in:
- **Oscilloscope patterns** (audio phase visualization)
- **Harmonograph drawings** (mechanical art from pendulums)
- **Planetary orbital resonances** (3:2 = Mercury
