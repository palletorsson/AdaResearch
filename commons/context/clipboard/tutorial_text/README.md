# Tutorial Text Library

~433 GDScript axiom/tutorial files covering the full breadth of Ada Research topics.

## Purpose
Each file contains structured learning content (axioms, explanations, code examples) for a specific algorithm or concept. Files are loaded by `TutorialTextLibrary` using the `tt:name` syntax from clipboard artifacts.

## File Pattern
- `<topic>_axioms.gd` — Algorithm/concept axiom content
- `_template.gd` — Template for creating new entries
- `_TEMPLATE_*.md` — Templates for different content styles (critical reflection, map summary, technical tutorial)
- `README_GD_FORMAT.md` — Format specification for .gd tutorial files
- `AUDIO_TUTORIALS_INDEX.md` — Index of audio-related tutorials

## Coverage
Algorithms, audio synthesis, data structures, computational geometry, machine learning, physics, VR interaction, UI patterns, and more.
