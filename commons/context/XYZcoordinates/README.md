# XYZ Coordinates Gadget

This folder contains a coordinate-reference artifact used to teach axis orientation in VR spaces.

## Files
- `xyz_gadget.tscn`: The visible coordinate gadget scene.
- `pickable_xyz.gd`: Pick/grab behavior for the gadget interaction node.

## Used By
- `Tutorial_Single`, `Tutorial_Row`, and `Tutorial_2D_Build` via `xyz_coordinates`.
