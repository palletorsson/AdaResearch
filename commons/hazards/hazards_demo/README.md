# Hazards Demo

Test scene for previewing hazard behaviors. Spawns Plasma Critter, Stick Tool, Octapod Crawler, and Force Fields in a simple environment.

## Behavior

Extends `Node3D`. Development/testing harness.

- Builds ground, walls, and labels
- Spawns sample hazards for interactive testing
- Works in both VR and desktop (WASD + mouse look)

## Files

| File | Purpose |
|------|---------|
| `hazards_demo.gd` | Main script — environment setup, hazard spawning |
| `hazards_demo.tscn` | Scene |
