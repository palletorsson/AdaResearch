# Index Sentinel

Walking 4x4 grid creature that fires projectiles by array index pattern — teaches array indexing and traversal.

## Behavior

Extends `HazardCreatureBase`. Array tutorial hazard.

- 16 cells arranged in a 4x4 grid on the creature's body
- Fires projectiles by [i][j] index patterns during attack
- Cells are color-coded with emission for visual feedback
- Walking locomotion with left/right legs
