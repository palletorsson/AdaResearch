# Mushroom

Edible mushroom with an effect system — pickup item that applies buffs or debuffs.

## Files

| File | Purpose |
|------|---------|
| `edible_mushroom.gd` | Main script — pickup interaction |
| `edible_mushroom.tscn` | Mushroom scene |
| `mushroom_effect.gd` | Effect application logic |
| `mushroom_effect.tscn` | Effect scene |
| `effect_demo.gd` | Demo/test script |
| `effect_demo.tscn` | Demo scene |
