# Kaleidocycle

Ring-pattern enemy based on kaleidocycle origami — procedurally generated rotating symmetry geometry.

## Behavior

Extends `HazardCreatureBase`. Origami-themed hazard.

- Procedurally generated kaleidocycle ring geometry
- Rotating symmetry patterns during movement
- Uses `KaleidocycleGeometry` helper for mesh generation

## Files

| File | Purpose |
|------|---------|
| `kaleidocycle_enemy.gd` | Main script — state machine, combat |
| `kaleidocycle_geometry.gd` | Geometry helper — ring mesh generation |
| `kaleidocycle_enemy.tscn` | Scene |
