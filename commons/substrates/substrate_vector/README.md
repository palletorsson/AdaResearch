# Substrate Vector System

**Every artifact is a point in 8-dimensional substrate space.**

This system decomposes every AdaResearch artifact into the implementation primitives that compose it — not *what* it teaches, but *how* the engine produces it. When you describe artifacts this way, clusters and trajectories emerge that reveal the deep structure of the project.

## The 8 Dimensions

| Dimension | Question | Example Values |
|-----------|----------|----------------|
| **Geometry** | How is shape made? | primitive_mesh, csg, procedural_mesh, multimesh, immediate_mesh, parametric_surface, curve_extrusion, voxel_grid |
| **Material** | How does it look? | opaque_standard, transparent, emissive, shader_driven, vertex_color, cull_disabled |
| **Physics** | How does it respond to force? | none, rigid_body, soft_body, custom_integration, particle_system, collision_only |
| **Time** | How does it evolve? | static, continuous, discrete_step, event_driven, simulation, accumulative |
| **Algorithm** | What computation drives it? | trig_functions, noise_sampling, cellular_automata, flocking_rules, fractal_iteration, physics_equations, vector_arithmetic, reaction_diffusion, lsystem_expansion, probability, topology, state_machine |
| **Interaction** | How do humans engage? | none, grab, slider, button, touch_surface, spatial_presence |
| **Containment** | What holds it? | none, glass_jar, glass_tank, petri_dish, table, pedestal, frame, box |
| **Information** | How does it explain itself? | none, label_3d, formula_display, data_visualization, color_encoding, spatial_encoding |

Each dimension is *sparse and weighted*. An artifact can have multiple values per dimension:

```
jelly_cube = {
    material: {transparent: 0.7, emissive: 0.3},
    physics: {soft_body: 1.0},
    interaction: {grab: 0.8, slider: 0.5},
    ...
}
```

## Files

| File | Purpose |
|------|---------|
| `SubstrateVector.gd` | Core 8D vector class (extends Resource). Construction, dot product, cosine similarity, distance, blend, add, scale, per-dimension similarity, serialization. |
| `SubstrateAnalyzer.gd` | Inference engine. Auto-tags artifacts by keyword-matching descriptions, tags, categories. |
| `SubstrateTrajectory.gd` | Named path through substrate space. Waypoints, interpolation, dimension arcs. |
| `SubstrateSpace.gd` | Query engine. Nearest neighbors, region search, gap analysis, clustering, trajectories. |
| `substrate_vector_generator.py` | Python script that reads all 17 registry JSONs and outputs `substrate_vectors.json`. |

## Data

- **`substrate_vectors.json`** lives in `commons/artifacts/registry/`
- Maps every artifact `lookup_name` → 8D substrate vector dictionary
- Generated by `substrate_vector_generator.py`, with hand-curated overrides for key artifacts
- ~448 artifacts covered

## Usage in GDScript

### Load the space
```gdscript
var space := SubstrateSpace.new()
var count := space.initialize("res://commons/artifacts/registry/substrate_vectors.json")
print("Loaded %d artifacts" % count)
```

### Find similar artifacts
```gdscript
var jelly := space.get_vector("jelly_cube")
var neighbors := space.find_similar(jelly, 5)
for n in neighbors:
    print("%s — similarity: %.2f" % [n["name"], n["similarity"]])
```

### Find artifacts by substrate
```gdscript
# All soft_body artifacts
var soft := space.find_in_region("physics", "soft_body", 0.3)
```

### Explore trajectories
```gdscript
var traj := space.get_trajectory("cube_freedom")
print(traj.describe_arc())
var midpoint := traj.interpolate(0.5)
```

### Gap analysis
```gdscript
var gaps := space.find_gaps()
for gap in gaps:
    print(gap["description"])
```

### Infer vector for a new artifact
```gdscript
var analyzer := SubstrateAnalyzer.new()
var result := analyzer.classify_artifact({
    "name": "My New Thing",
    "description": "A soft body jellyfish in a glass jar",
    "category": "physics",
    "tags": ["soft_body", "transparent", "emissive"],
})
print("Confidence: %.1f" % result["confidence"])
print(result["vector"].to_string_readable())
```

## Pre-defined Trajectories

Six trajectories from the theory document:

1. **specimen_in_jar** — `dna_specimen → random_walk_terrarium → queer_morphology_specimen → boids_aquarium`
   *Increasing agency inside a container*

2. **cube_freedom** — `static_reference_cube → rotating_cube_demo → oscillation_controlled_cube → jelly_cube → queer_morphology_specimen`
   *Rigidity dissolving*

3. **vector_to_terrain** — `vector_addition_demo → flow_field_painter → wave_interference_tank`
   *Point → field → surface*

4. **grid_to_world** — `game_of_life_petri → ca_rule_explorer`
   *Grid escapes container*

5. **math_to_walkgrid** — `mandelbrot_dive → mandelbrot_space`
   *Artifact becomes terrain*

6. **observation_collapses** — `superposition_display → schrodinger_box → queer_morphology_specimen → brouwer_choice_sequence`
   *Interaction entangled with algorithm*

## Backward Compatibility

The old `SubstrateVector.gd` in `commons/context/walkgrids/` is untouched. It handles terrain/walkgrid substrate weights (sine, noise, fractal, etc.) and remains fully functional. This new system lives in `commons/substrates/substrate_vector/` with a distinct `class_name SubstrateVector` — **note: you cannot have both loaded simultaneously in Godot** since they share the class name. The old one should be renamed or wrapped if both are needed in the same project.
