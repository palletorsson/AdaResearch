## Adaptations

- Life's large original walk field is centred at (0,8.2); rear/side specimens remain at
  original size. Full drawn parts clear shafts/arrival and measured bounds clear pillars.
- A shallow host cutout restores the proximity study's existing basin. The original
  0.5-second XR collision-exception release timer is allowed to finish before teardown.
- Study/budget config is passed before `_ready` where required. Auto catalyst binding
  resolves locally to cellularautomata; source metadata remains auto, no global progress changed.
- The chair grid hid empty geometry during reset and never restored visibility after
  seeding. Trial-only adapter restores the source occupied display. Original 2D callbacks
  are accessible through a 3D rack; the source algorithm is unchanged.
- The centred pyramid uses the museum's measured grounding, original 0.25 m plinth and
  0.03 m float. Its source layout height/scale remain unchanged; full construction visible.
- Fog's existing Compatibility central-slice fallback extends to Mobile. Original
  preview_grid=12 is applied before allocating the grid.
- The source SIR display often has no sampled infection. Export adds an explicit empty
  sample arrangement marker; native state and random infections remain untouched.
- An empty early Crossway export advances its source row clock within a bounded loop;
  it does not insert cells. Disclosure is stored in manifest notes if advancement occurs.
- Artifact scale schema accepts legacy 10× models (bounded maximum 16); no source model
  was shrunk to satisfy the editor.

floor, and the proximity tray protrudes under its slab. Some secondary/keyboard-only
source controls, catalyst pickup/lease combat and physical headset behavior remain
untested. This is source transfer, not final encounter curation. See the batch review
JSON for exact limits and receipts. Original chapter texts were not edited.
