# Color Pillar / Codex transfer

All seven source artifacts retained, as original scenes with authored token
configuration, scale and orientation (two height placements adjusted below). No original files or chapter texts edited.
The source occupies 41 x 38 m; the standard Void remains 42 x 32 x 6 m.
Individual placement translations put the field centrally, mixing bench/stick/
film/sphere/spectrum in the west wing and the palette wall in the east wing.
The 35-pillar field, neutral reference, HSV sampler and 12 named palettes remain
one editable assembly each, with source constituent objects intact.

## Fit / source notes for curation

- The field's visual floor is 16.7 m wide: its margins overlap the inner edges
  of both shaft openings by 0.85 m. This is visual geometry, not a new solid
  cover. Shaft centres and descent pad remain clear; do not mistake that
  visual margin for walkable support. Its 4.6 m colour ceiling is preserved.
- Mixing bench token height -0.4 would bury the interactive disks: mount raised
  to 0.9 m. Palette-wall token height -0.5 would bury the base: mounted at 0 m.
  Both are placement-only changes and valid non-negative editor heights; source
  tokens remain in the inventory. Original geometry/configs stay unchanged.
- The source comparison bench sets both disk families to additive blending;
  its default subtractive label does not change that setting. Not corrected
  as part of this transfer.
- Spectrum's source origin is floor level. Some dots intersect the slab in
  the straight-line phase. Curation can raise it without changing its code.
