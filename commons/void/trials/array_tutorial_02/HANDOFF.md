# Arrays - reviewed museum transfer, batch 12

Codex transferred Tutorial_3D; Claude Opus supplied Tutorial_Tiling_Floor in a
bounded two-file handoff. Codex reviewed the originals and integrated the five
independent artifact placements. The editor and both native player modes use
these rooms.json and layout.json files.

## What remains intact

Floor 1: original 64-address flight enclosure, Open Structures, Reference
Suspension. Floor 2: film monitor and complete six-field tiling installation,
including its linked rule desk and 16 x 16 field. Source dimensions, controls,
configuration and chapter files are retained. No new curated path is claimed.

## Fit decisions

The 12 m flight enclosure uses 14 m storeys in this isolated trial. A 72 m deep
slab retains the original 22 m and 21 m spacing between the three installations.
The main tower is unchanged. This is a transfer envelope for inspection; compact
integration still needs a decision.

Claude moved the monitor from inside shaft B to [9,5.5], retaining its orientation.
Codex moved the default navigation sign to [16,-8] on floor 2 after an actual
walking test found it blocking a tiling field. This uses an optional layout
floor_sign_positions override; other floors retain their existing defaults.
A control-panel stand extends 9 cm into the slab as in the source.

## Acceptance evidence

See evidence/source-checks.json, checks.json and editor-checks.json for current
verdicts. Native checks use real mouse events and synthetic tracked XR input,
actual flight and physical pickup contact. They include rule changes, undo,
flat-floor walking, shaft descent, floor sleep/resume and checkpoint retry.
Physical-headset play is not covered. The web editor contains exported model
snapshots; the native game runs the original behaviours.
