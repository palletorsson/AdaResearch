# Pattern Temple — floor 3

Codex transferred the complete original PatternTemple assembly as one editable placement, at original scale and height. All eight receiver classes, the dome, shell, original console and shaders remain.

Native checks exercise SOURCE, ALL, AGE and CLEAN through actual mouse and synthetic XR button interaction. A Void-only lifecycle subclass frees the original temporary generator during unload; the original artifact script is unchanged.

Measured height is 8.35 m in a six-metre storey. The dome intersects the upper slab and appears on the floor above. Keep this visible in review: the transfer is usable for inspecting the original controls, but it is not a resolved architectural fit. Curation must decide how to house it. Neither the tower dimensions nor source scale were changed.
