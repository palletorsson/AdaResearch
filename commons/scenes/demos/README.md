# Demos

Standalone demonstration scenes showcasing specific algorithms or art-historical references.

## How It Works

Each demo is a self-contained scene that can be loaded independently. The demos range from audio experiments to mathematical art recreations, serving as reference implementations and visual showcases.

## Files

- `PopMusicDemo.tscn` -- Pop music audio demonstration scene
- `durer/` -- Albrecht Durer's Melencolia I recreations (polyhedron and magic square)
