# Portals — Sequence Navigation Gateways

Visual portal system for navigating between learning sequences in the lab.

## Files

| File | Description |
|------|-------------|
| `SequencePortal.gd` | `SequencePortal` — animated portal mesh with unlock requirements, color, interaction area. Emits `portal_entered`/`portal_focused`/`portal_unfocused` signals. |
| `pickup_gate.gd/.tscn` | Gate that opens when the player picks up a required artifact |
