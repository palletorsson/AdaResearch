# Multimeter

Digital multimeter with an analog-style oscillating needle. Supports four measurement modes demonstrating different waveforms.

## Modes

| Mode | Behavior |
|------|----------|
| AC Voltage | Sine wave at ac_frequency with noise |
| DC Voltage | Steady value with small noise |
| Resistance | Slow sinusoidal drift |
| Frequency | Mode 3 |
