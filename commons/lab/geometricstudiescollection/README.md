# Geometric Studies Collection

Procedural collection of historical geometric studies including Bruckner polyhedra, Renaissance constructions, tessellated cubes, and a twisted spire.

## Behavior

- Generates study layout with paper/ink materials
- Builds Bruckner polyhedra with configurable material type (paper, crystal, metal)
- Color theory system for tessellated cube faces
- Optional animations (show_animations)
