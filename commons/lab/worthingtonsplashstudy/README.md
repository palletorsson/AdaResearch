# Worthington Splash Study

Procedural recreation of Professor A. M. Worthington's 1895 mercury drop splash photography from The Splash of a Drop.

## Behavior

- Renders a sequence of splash stages based on Worthington's recorded observations
- Each stage has diameter, shape, crown height, and droplet data
- Paper/ink/mercury materials with period-appropriate tones
- Optional scientific labels and animation
