# Holographic Display

Floating hologram with scan lines, flicker, and rotation -- demonstrates interference patterns and wave visualization.

## Behavior

- Hologram content rotates at rotation_speed and bobs vertically
- Scan line sweeps at scan_frequency
- Subtle flicker at flicker_frequency (default 15 Hz)
- Scale pulse adds breathing effect
- SpotLight3D projectors illuminate from below
