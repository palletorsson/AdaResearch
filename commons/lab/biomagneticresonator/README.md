# Biomagnetic Resonator

Pulsing resonator core surrounded by expanding field rings, demonstrating standing waves and harmonic overtones.

## Behavior

- Core sphere breathes at the fundamental resonance_frequency
- Concentric field rings pulse with harmonic overtones (up to harmonic_count)
- Energy beams and an OmniLight3D track the core pulse
