# Curation — Fractal_CrossSequence ("Fractals Meet Evolution")

*Sequence: fractals (10th spine, lambda_edge phase) · the 14th and final fractals map · the cross-sequence bridge.*
*Curation is an argument made with placement.*

## The argument

This is not a "topic" wall — it is the sequence's closing claim that **the fractal is a principle, not a
subject**. The map's own `intent.md` names three threads that converge here: fractal recursion
(`fractal_stochastic_tree`), discrete computation (`cellular_automata_3d_stacked`, imported from the CA
sequence), and adaptive search (`evolutionary_algorithms`, imported from optimization/randomness). The wall
stages that convergence as a five-beat walk: **a seed → a bridge → computation → evolution → useful
structure**. Each beat is the *same* lambda_edge rule — deterministic grammar plus a stochastic injection
(`F + lambda E(S)`) — wearing a different body: vegetable, then digital, then alive, then engineered.

The reading is left→right (the editor's +X axis), but the composition is built for the free-cam orbit: the
focal seed is thrown forward into its own alcove, the computation block is pressed back against the wall, and
the applied finale steps up off the floor. Geometry, computation, and life literally occupy different depths
so that "convergence" is something you walk *through*, not just read.

## Why each prop (chosen for meaning, sized to footprint)

- **`station_micropod` for the seed** — measured AABB is **0.44 m** (genuinely sub-1 m). The micropod is a
  ~0.6 m sub-grid post that snaps to one cell *without over-claiming it* — "the home for tiny precious things"
  (its own identity). A full plinth would lie about the tree's scale; the micropod tells the truth and still
  lifts it to eye line. `caption_text` = the display name, rendered as a surface-pinned 2D-in-3D plate.
- **`station_plinth` 1x1 slim (top 1.3, cap_inset 0.3) for Hilbert3D** — fp 1 cell, but 1.18 m tall, so a
  *high-narrow* podium per the plinth's "size IS the argument": raise it high and narrow → "this is precious /
  a specimen". Caption plate carries the name.
- **`station_plinth` 2x2 (top 0.9) for the CA stack** — fp 4 → the brief's 2-4 plinth at low-ish height; broad
  enough to hold the 2 m volumetric stack, low enough that the mass reads as "a world on a deck".
- **`station_plinth` 3x1 low (top 0.85) for evolution** — fp 3, a long thin thing laid *across* a 3-wide low
  podium (exactly the plinth identity's "1x3 = a long thing laid across").
- **`station_stage` 4x2 (step 0.18) for the gallery** — fp 8 → the brief's 5-9 stage; low and broad, the
  honest pedestal you step onto. Label via **`name_plate`** (NOT caption_text — stage uses the framed plate),
  set to the display name, so the big walk-in artifact still gets its 2D-in-3D plate.
- **`station_panel` x5 (wall, 2D-in-3D)** — one tier/beat header each, carrying the map's *own* truth-beats
  instead of the default "CURATION / ON SHOW": SEED ("F + lambda E(S): rule + noise / the QFEP made
  vegetable"), BRIDGE ("one line visits every point / the way out to L-systems"), COMPUTATION ("Rule 90 draws
  Sierpinski / the stack IS the fractal"), EVOLUTION ("fitness landscapes are fractal / selection walks the
  ridges"), USEFUL STRUCTURE ("Hilbert, Peano, Moore / infinite edge, finite room"). These are the wall doing
  the teaching, in plain pinned words. The editor hides each artifact's floating Label3D, so these plates +
  the base captions are the only text.
- **`station_pillar` x3** — bay-end columns (left entry, mid-divider before the finale, right exit) so the run
  reads as built architecture, not furniture in a void. The two end pillars carry signage lines that bracket
  the whole argument: "THE LAMBDA-EDGE, IN FULL" (entry) and "WHERE GEOMETRY, COMPUTATION, LIFE CONVERGE"
  (exit) — the map's thesis as a doorway and a closing word.

argument (the brief's footprint fallback). This is honest to the cross-sequence nature of the map — three of
its five hero artifacts belong to *other* sequences, which is the entire point.

## How this beats the baseline

The current `spine_walls.json` entry puts **every base on a single flat z=0.8 line**, spaced evenly by import
order, with the *centerpiece* stochastic tree on a generic 1x1 plinth indistinguishable from Hilbert3D, and
five `station_panel`s left at their default "CURATION / ON SHOW" text. This curation: (1) sizes the seed to a
**micropod** and throws it forward as a clear single focal point; (2) **staggers depth and height** into a
real 3D composition (6 z-depths, 5 heights, back/forward/step-up layers); (3) loads every panel and both end
pillars with the **map's own lambda_edge truth-beats**; and (4) reorders the walk to follow the *argument*
(seed → bridge → computation → evolution → applied) rather than the JSON's import order.

## Prop gaps flagged

- **No "convergence" / four-views capstone prop.** Both `intent.md` and the concept-map note call for a QFEP
  dashboard that shows the same stochastic tree as four simultaneous views (quantum discreteness, fractal
  self-similarity, emergent complexity, edge-of-chaos poise). No such artifact exists, so the *synthesis* beat
  is carried only by adjacency + panel text. The station kit has no multi-view display module to stand in for
  it — a `station_panel` variant that renders an image/quad array, or a dedicated `qfep_dashboard` artifact,
  would let the wall *show* the convergence instead of merely asserting it.
- **No floor/threshold label for the bridge.** The "bridge to L-systems" idea is the one cross-link with no
  physical connector — a low floor plate or directional marker prop (a `station_*` floor decal) between
  Hilbert3D and the gallery would make the L-system link spatial rather than textual.
- **Pillar signage is a single line only.** The end-pillar `signage_text` is a one-liner; a two-line bracketed
  plate option would let the entry pillar state the full `F + lambda E(S) + phi dE(S,t)` formula the summary
  leans on.
