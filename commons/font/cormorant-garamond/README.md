# Museum lettering

Cormorant Garamond, upright variable font, redistributed unchanged under SIL OFL 1.1.
The complete license is in OFL.txt; the identical OFL.md is also included by the
project's headset export filter. Upstream revision and SHA-256 are in provenance.json.

Source: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

The shared museum identity uses weight 500 and spaced capitals above a lowercase
tagline. This is a close typographic interpretation of the comic lettering, not
a claim that its generated letterforms correspond to an identifiable typeface.

The font is a project resource used by em_identity.gd, so headset exports do not
depend on a font installed on the development computer.
