# An endpoint cannot tell the whole journey

The claim is testable: A then -A yields a zero resultant, but a nonzero travelled distance. Direct and via-A runs can have identical endpoints and different histories. Addition discards route order from the endpoint; it does not prove that order is irrelevant to lived movement, collisions or time. SWAP preserves the vector sum in this shared frame, while changing the intermediate waypoint.

The queer opening is specific to the two records. The return trip belongs to zero in one account and remains a journey in another. Neither account owns the whole event. Which becomes authoritative depends on the question and the receiver. Calling all such loss entropy would require a defined state space and measure, which this encounter does not supply.

The apparatus also admits its own framing: bounded components, fixed height, prescribed speed and an instantaneous home reset excluded from the distance counter. Those are implementation choices. An alternative learner experiment can change the frame, retain a trace, count the reset or add obstacles. None is silently claimed as an existing control.
