# Noise Voxel

Four retained works: the Perlin lattice bench, its large voxel receiver, a live section screen and the independently pulsing dark orb. The hall carries the array into three dimensions and asks what a threshold lets have a body.

THRESHOLD, CELL, SEED and CUT distinguish changes to classification, inspection, source and visibility. Both volumes sample the same 24³ field; cell spacing changes from 4 cm to 1 m. The screen compares biased values with actual stored occupancy. Occupied count, connected pieces and a player's possible routes remain different questions.
