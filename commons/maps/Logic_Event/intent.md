# Logic — event and consequence

Before there is a condition there is a chain. The room holds one work, the tyre/plank/wedge reference study (`reference_tyre_chain`), three cells in from the spawn. Loose parts can be carried; the attached beams stay pinned. Dropping the mover, or pressing RELEASE, starts a single physical take: ramp, plank, wedge, boxes, rest. RESET puts the authored arrangement back.

The room's work is to make "then" visible before anyone says "if". Each event happens because a body touched another body, not because a script decided it. A second take can go differently from the first, and that difference is the point: it separates what the construction makes likely from what it guarantees. Logic_AND next asks the same chain to depend on two supports.
