A grid of cells. Each cell holds or doesn't — on, off, filled, empty. That binary decision, repeated across an 8×8 matrix at height 2, produces letterforms. Columns rise like strokes. Gaps open like counters. The page is architecture.

Glyph generation reduces writing to spatial pattern. Walk the grid randomly and trails become serifs. Remove cells and negative space carves a bowl, a stem, a descender. Rotate columns and letters tilt into italics. Every typographic decision — weight, width, contrast — is a height map with opinions.

Character cells predate pixels. Teletypes, punch cards, dot matrices — all grids pretending to be language. The pretense holds. A letterform is a pattern that learned to mean something. The grid doesn't read. The grid doesn't need to.
