# Recommendation Systems

A 12×12 grid. Eight-by-eight interior. Algorithms compete for space using nothing but dice rolls and distribution curves.

Gaussian peaks rise where probability clusters. Random walks carve trails across the field — drunk trajectories that somehow produce structure. Height maps mutate. Cubes spawn, rotate, vanish. Profiles generate and regenerate, each iteration a different landscape built from the same stochastic rules. The grid breathes between configurations.

This is the arena where order emerges uninvited. No designer places each cube. No pathfinding algorithm optimizes the route. Randomness alone — constrained by bounds, shaped by distributions, accumulated over steps — produces architecture. The walker has no destination but leaves a city behind. Every roll of the die is a decision made by no one.
