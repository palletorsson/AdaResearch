# Point One - Map Summary

## Overview
Point One isolates the minimal act of individuation within an infrastructural field. After establishing the origin as prerequisite in Point_Zero, this map introduces a single point that exists **beyond** the zero reference - the first discrete unit.

## Spatial Layout
- **Dimensions**: 7×15 grid
- **Architecture**: Large continuous platform on the west (columns 0-2), with an isolated single cube at (4,2)
- **Height**: Mostly single level with one isolated raised block

## Key Elements

### Interactables
- **Interactive_point_origin** (1,3) - A grabbable, moveable point sphere with emission glow
- **Dark sphere** (3,2) - Ambient darkness creating intimate examination space
- **Coordinate System** (0,0) height -1.45m - Sunken into the ground, de-emphasized

### Utilities
- **Teleporter** (1,5) - Exit to next map
- **Label annotation** (1,3) - "la:point"
- **Floating text** (1,8) - "that_which_has_no_part" (Euclid's Definition 1)

## Atmosphere
- **Background**: Sky blue [0.2, 0.3, 0.7]
- **Audio**: Default ambient
- **Lighting**: Standard directional + ambient
- **Mood**: Contemplative, embodied, minimal interaction

## Learning Sequence
1. Player enters larger, more open space than Point_Zero
2. Encounters a single point they can **grab and move**
3. Physically manipulates the point - body creates position
4. Reads the Euclidean label: "that which has no part"
5. No clipboard, no code - purely **embodied** learning
6. Exits via teleporter

## Design Intent
The architectural shift from Point_Zero's L-shape to Point_One's open platform creates **space for movement**. The isolated cube at (4,2) metaphorically represents "the one" separate from the continuous field. The grabbable point is the first moment where the player's **body instantiates position** - your hand's movement creates the point's location.

No tutorial text appears. This is **phenomenological learning** - understanding through physical interaction rather than reading.
