# Puzzle 02: Translate - The Mover

Copy preserves. Translation displaces. The cube exists here — then exists there. Same object, new address. Nothing duplicated, nothing destroyed. Pure relocation.

Scattered blocks obstruct the path forward. The TRANSLATE agent picks them up and sets them down somewhere else. No rotation, no duplication — just repositioning within the grid. Move the obstacles. Clear the passage. Reach the teleporter. The structure doesn't grow or shrink. It rearranges.

Position is the first property that feels like identity. "Where I am" precedes "what I am." Change position and the system reconfigures — same parts, different relationships. Every migration is a proof: the thing that moved is still itself, but the world it inhabits is not the same world.
