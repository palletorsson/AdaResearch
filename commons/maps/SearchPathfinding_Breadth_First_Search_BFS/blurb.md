A 12×12 grid. An 8×8 interior where algorithms perform. Gaussian distributions raise terrain into bell curves. Random walks leave trails across the surface — drunk steps that accumulate into structure. Cubes spawn, rotate, dissolve. Height fields ripple with noise. Profile generators carve random silhouettes into mesh.

Every algorithm here uses the same raw material: `randf()`, the uniform draw, the coin flip scaled to purpose. Order is not imposed. It precipitates.

This is the arena where determinism learns to let go. Not chaos — controlled surrender. The grid holds; the randomness fills it. Structure as container, chance as content. The first lesson in how systems become interesting: stop deciding everything.
