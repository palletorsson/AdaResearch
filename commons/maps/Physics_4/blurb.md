One index finds a point on a line. Two indices find a point on a plane. The 2D array is a grid — rows and columns, X and Y, a coordinate system made of memory slots. Navigate one axis and you slide along a row. Navigate the other and you drop into a column. Every cell has an address. Every address has two parts.

Dark spheres pulse at grid intersections, marking positions in a 7×9 field. Move through them. Feel the difference between stepping right and stepping down — one changes X, the other changes Y, but both are just offsets into the same flat structure.

Arrays are always one-dimensional in memory. The grid is an interpretation. A way of folding a line into a plane. Dimensionality is not given — it is imposed.
