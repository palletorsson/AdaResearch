Concept: Classification as geometric partitioning — drawing a boundary through feature space that separates one category from another. The decision boundary is the central artifact: a line, curve, or hyperplane that encodes what the model has learned.
Sequence role: Third map in the Machine Learning sequence (15th spine sequence, integration phase). Takes the gradient descent machinery from ML_Gradient_Landscape and applies it to a concrete task: separating data into classes. The decision boundary concept carries forward into ML_Neural_Networks where deeper architectures bend boundaries into arbitrary shapes. Connects back to gradient optimization and forward to neural network composition.
Technical angle: Linear classifiers (logistic regression) as the simplest boundary — a hyperplane defined by weights and bias. Support vector machines maximize margin. The kernel trick projects data into higher dimensions where linear separation becomes possible. Cross-entropy loss as the objective function for classification. Confusion matrices, precision, recall as evaluation geometry.
Critical angle: Every classifier draws a line and declares two sides different. The boundary is a political act disguised as mathematics — who falls on which side depends on which features were measured and which were ignored. Classification is the computational form of categorization, and categorization is never innocent. The integration phase asks: what are we integrating, and at whose expense?
Key artifacts: classification_demo provides interactive 2D classification with adjustable decision boundaries, data distributions, and real-time accuracy metrics.
Gap: Needs a feature-selection artifact showing how the same data produces radically different boundaries depending on which two features are chosen as axes.
