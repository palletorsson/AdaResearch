Memory is a long hallway with numbered doors. The first door is not 1 — it is 0. This is the original off-by-one: computers count from nothing, from the void before the first thing. Every programmer learns this the hard way. You will learn it by walking.

An array is the simplest structure that isn't a point. One element is just a value. Two elements are a pair. But line them up — zero, one, two, three — and something new emerges: sequence. Direction. The difference between a row and a column is the difference between reading and falling.

Walk the index. Pick up what you find at each position. Watch the number change. Before you can sort, search, or shuffle, you have to know where you are.
