# LSTMs

A network that remembers. LSTMs — Long Short-Term Memory — solve the problem every recurrent network hits: the vanishing gradient, where signals decay to nothing across time. Three gates control the flow. Forget gate: what to discard. Input gate: what to store. Output gate: what to surface. A cell state runs through the architecture like a conveyor belt, carrying information across hundreds of timesteps without degradation.

Here the arena stages the machinery. Fine-tune a pretrained model — watch weights shift in small, deliberate increments. Pit generator against discriminator in adversarial training, each network sharpening the other through structured opposition. Step inside the LSTM cell and trace the gates firing, memory persisting, sequences resolving into prediction.

Memory is not storage. It is selective survival — what a system chooses to forget defines what it becomes.
