# An ability carried forward

`opening_progression.gd` extends the tested `proving_ground.gd` museum route. It adds an acquisition room and local capability ownership. `first_catalyst_field.gd` accepts an optional capability source; normal halls still resolve CatalystCapabilityManager. The test uses the original two-hand formation script and suspends its global counterpart only for this scene's lifetime.

`progression_point.gd` extends the existing `resolution_catalyst.gd`. Two explicit permissions gate resolution changes and emission. The same PointBody grants the first ability, moves to the later return plinth, changes its SphereMesh and emits a copied form. Holding prevents the return system from moving it away.

The original drawing pen, fixed grip, tip-distance sampling and trace renderer remain in use. Charging requires the acquired hand ability. Releasing the rod copies its world-space positions into the trial's record; the sculpture transforms that copy for display. The source positions remain independent. This trial does not write to TraceData.

A physical projectile collision lights `practice_receiver.gd`. Only then can BEGIN move the original tableau head into the arena. One interruption ends each explicit round. Added rotation and scale use the existing counterpart implementation, including the matching collision radius. REST disables attacks and emission; RESET cancels an arrival tween, clears local state and closes the actual gate collider.

The map is 13 × 44 m, with an 8 m acquisition room before the earlier 13 × 36 m route. Its private plan and the common test launcher build the real museum shell and XR rig. The main spine plan and curriculum texts are not edited.
