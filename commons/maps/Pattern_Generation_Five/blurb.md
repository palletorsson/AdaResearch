# Pattern Generation: Algorithm Arena

A 12×12 grid. An 8×8 arena at its center. Algorithms compete here — each one a different strategy for filling space with pattern. Same grid, same pixels, different logic. Watch them run side by side and the question shifts from "which is best" to "what does each one assume."

Randomness on a GPU is a performance. `fract(sin(dot()))` isn't random — it's deterministic chaos wearing a mask. The shader doesn't roll dice. It hashes coordinates. Every pixel computes its own fate from its own address, simultaneously, independently. The arena makes this visible: eight algorithms, eight philosophies of disorder, all executing in parallel across the same surface.

Pattern generation sits exactly where order meets its own undoing. The function is pure. The output looks wild. That gap — between rule and result — is where computation becomes aesthetic.
