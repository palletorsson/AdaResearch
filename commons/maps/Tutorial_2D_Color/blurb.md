A 7×7 grid of color. Each cell holds a position — column and row, X and Y. The floor is a palette. Walk it.

Rotating prisms catch light at angles. Shader cubes shift hue in real time. Pick-up nodes cluster in bands around a central piece at (3,3) — the focal point of the grid. An XYZ coordinate visualizer tracks position along the front row. Every step is an address. Every color is a coordinate made visible.

Two-dimensional arrays map space the way a chessboard maps possibility — discrete, finite, navigable. But color refuses the grid's logic. It bleeds between categories, mixes on contact, exists in perception rather than position. The array says: one value per cell. The spectrum says: boundaries are agreements.
