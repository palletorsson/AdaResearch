# Random Mushrooms

A six-metre specimen bed makes a population's construction inspectable. Six template recipes are copied into scattered positions, an explicit ring and two clusters. SHOW follows copies; KIND separates the routines and rejected candidates; SIZE removes per-instance scale variation under the same seed; REGROW repeats the build; NEW SEED changes the current seed.

Scale 1 preserves the templates' different dimensions. The size rule uses uniform ranges, not Gaussian draws. Template details can also change between seeds. Three separately planted edible mushrooms add pickup and a timed perception effect, extending the question from the displayed bodies to the looking body.
