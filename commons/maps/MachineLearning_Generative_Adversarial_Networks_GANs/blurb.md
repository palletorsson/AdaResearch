Eleven algorithms. One grid. Each one reshapes the same 12×12 surface through a different relationship to chance. Gaussian distributions cluster height around a center. Random walks carve drunk paths across cubes. Profiles extrude terrain from noise. Removal algorithms dissolve geometry by column, row, or range — subtraction as generation.

The arena treats randomness not as absence of control but as a medium. Height variations, slope gradients, procedural kitbashing — every algorithm writes order from disorder, then watches it shift. A walker raises cubes where it steps. A remover eats them where it lands. Same grid, same cubes, opposite operations, both producing structure.

Randomness is not the opposite of pattern. It is what pattern looks like before you name it.
