# Variational Autoencoders VAEs

Randomness as building material. Gaussian distributions shape terrain. Random walks carve paths through grids. Height maps rise and fall on dice rolls. Cubes appear, rotate, vanish — selected by chance, placed by probability. The arena is a 12×12 grid where algorithms compete to generate form from noise.

Walk a random path and watch it accumulate into structure. Raise columns by sampling bell curves. Remove geometry at random and find what remains still holds. Profile curves jitter with variation. Every algorithm here uses the same raw ingredient — unpredictability — but each constrains it differently. Gaussian focus. Uniform scatter. Weighted drift.

The lesson is not that randomness produces chaos. It produces *variety under constraint*. The same stochastic engine, differently bounded, builds landscapes or erases them. Control is not the opposite of randomness — it is randomness with a frame.
