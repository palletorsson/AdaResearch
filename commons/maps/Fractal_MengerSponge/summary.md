# Fractals_6 - Recursive Trees

## Overview
Fractals_6 presents pure recursive trees—deterministic branching without the stochastic variation of Fractals_2. Here, the focus is on the branching rule itself: how a single trunk becomes a forest through repeated division. These trees demonstrate that complex organic forms require no stored blueprint—only a rule applied recursively.

## Spatial Layout
- **Dimensions**: 7×8 grid
- **Architecture**: Simple platform focused on the central tree
- **Height**: Up to level 2

## Key Elements

### Interactables
- **Fractal Recursive Tree** (3,3) - Primary deterministic recursive tree
- **Dark Sphere** (3,2) - Ambient lighting element

### Utilities
- **Teleporter** (5,6) - Exit to Fractals_7

## Atmosphere
- **Background**: Sky blue [0.2, 0.3, 0.7]
- **Lighting**: Warm directional with cool ambient
- **Mood**: Organic, branching, botanical contemplation

## Learning Sequence
1. Player enters and observes the recursive tree
2. Traces branching from trunk to tips
3. Notes that every branch is a scaled version of the whole
4. Recognizes the pattern: binary division, angle, scale reduction
5. Compares to Fractals_2's stochastic trees—same structure, no randomness
6. Understands: determinism produces identical forms
7. Exits to explore stochastic variation

## Design Intent
The map isolates **pure recursive branching**—the generative principle underlying all tree-like forms. Without stochastic variation, every tree from the same rule is identical. This reveals the deterministic skeleton that stochastic processes clothe in variation.

## Connection to Sequence
- **Position in fractals sequence**: 6/14
- **Precedes**: Fractals_7 (Stochastic Trees Advanced)
- **Follows**: Fractals_5 (Koch Curve)
- **Establishes**: Binary branching, angle and scale parameters, deterministic organic form
