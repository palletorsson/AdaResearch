A loom in space. Three panels float in a cylindrical arc at arm's reach — threading, tie-up, treadling — each a binary grid of on/off, warp-over or weft-over. Click a cell. The drawdown recomputes. The fabric rewrites itself.

Weaving is the oldest binary language. Every crossed thread is a bit. Every pattern a program executed in fiber. The Jacquard loom fed punched cards to a machine in 1804 — Babbage saw it and imagined the Analytical Engine. Ada saw it and imagined software. The grid precedes the pixel.

Here the 2D interface inhabits 3D space. Flat controls rendered onto surfaces that curve around the body. A screen inside a world inside a screen. The panel bridge doesn't simulate weaving — it simulates the interface to weaving, which was already a simulation of logic.
