# Release the point; keep the attachment

Primary: `force_play_springs`.

Make one spring from the familiar point and a fixed anchor. In your small study, grab the point itself to set its position, then release it to see the spring act. The thin cylinder shows the attachment.

Carry: Here a repeating movement comes from forces changing velocity. Next, make a similar repetition by assigning positions.

Check: Release from the same position with damping at 0.5, then at 3.0. Predict which will keep moving longer. Restore damping and double stiffness. Compare the stronger return without changing rest length.
