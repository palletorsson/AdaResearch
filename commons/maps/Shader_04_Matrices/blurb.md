# UV Transforms

A matrix is a machine for warping space. Translate shifts the origin. Rotate spins it. Scale stretches or crushes it. Three operations, each a 2×2 or 3×3 grid of numbers, each rewriting where "here" means. The UV coordinate doesn't move — the space underneath it does.

Composition is where it gets dangerous. Multiply matrices and operations stack. Translate then rotate ≠ rotate then translate. Order matters. The same point lands somewhere different depending on which transformation happened first. Non-commutativity — the mathematical proof that sequence is meaning.

A dark sphere pulses in the corner, its slow rotation a single matrix applied per frame. Every spinning object, every scrolling texture, every camera in every game — matrices underneath. The coordinate system is never fixed. It was always a choice.
