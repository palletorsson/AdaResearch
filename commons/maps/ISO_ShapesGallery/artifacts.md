# ISO ShapesGallery — Artifacts
*Isosurfaces: Implicit to Explicit · F_order · 3 artifacts*

> Seven sculptures stand in a row. Each one computed from the same algorithm, different parameters — sphere, torus, strange attractors made solid. A control panel lets you scroll through preset caves, drag sliders for noise scale, iso level, chunk density. The geometry rebuilds in real time. Turn one knob and the cave breathes open. Turn another and it collapses into stone.
