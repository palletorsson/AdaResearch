# Primitives Godot — selected artifacts

| Token | Source | Encounter |
| --- | --- | --- |
| `primitive_mesh_library` | `commons/artifacts/ignorance_gallery/primitive_mesh_library.tscn` | Eight supplied mesh specimens in reusable scenes. |
| `seven_words_choir` | `commons/artifacts/seven_words_choir/seven_words_choir.tscn` | Seven common forms with authored breathing motion; a selection, not an exhaustive list. |

The library contains PrismMesh, TorusMesh, PlaneMesh, QuadMesh, PointMesh, TextMesh, RibbonTrailMesh and TubeTrailMesh. The PointMesh uses a 22-pixel mark. Trail meshes are shown at rest. Neither installation supplies a general mesh-editing interface.

Both tokens are relocated from Ignorance. Current placement and any retained supporting objects are defined by [map_data.json](map_data.json); artifact presence does not establish a taught skill or certify headset usability.
