# Cave Explorer 3D

A 12×12 grid. An 8×8 arena carved from its center. Algorithms enter, execute, leave their marks. Each one reshapes the same space differently — flood fill, random walk, cellular automata, noise. Same grid, same dimensions, different logic, different world.

The arena is a proving ground for procedural methods stripped to their bones. No decoration, no context — just the raw behavior of each algorithm made visible on a flat plane. Watch a random walk stagger and cluster. Watch a cellular rule snap into geometry. The grid doesn't care which algorithm runs. It receives all of them equally.

What separates order from accident is not the space but the rule applied to it. Eight-by-eight cells. Infinite possible configurations. The constraint is the freedom.
