# Point_Line_Grid — return visits

The book follows four artifacts through one question: how can a position become a place we can name again? These other encounters remain physically present. They can extend that question after the first passage.

## A plan before a route — room_grammar

Look at the generated arrangement of walls and doors. Trace a possible approach through it before calling it a room someone can inhabit. Which placements help the approach, and which complicate it? This is a comparison with a proposed use, not a claim that the artifact already tests reachability or accessibility. It can later connect this small grid to procedural architecture.

## Movement outside this record — floating_sphere_field

Watch the drifting spheres while a walking record grows. Their positions do not enter that recorder. Compare what you can see happening with what this particular instrument follows. More records would allow other comparisons; they would also need a reason to be made.

## An address and a body — modulor_man_demo

Bring the standing scale reference into the question of placement. A coordinate can locate an object without describing the room a body needs beside it. The figure offers a comparison with one represented body; it cannot stand for everyone's reach, width or movement.[^point-grid-return-modulor] Check any future accessibility claim against actual visitors and routes.

## Other programs for the same grid

The earlier tutorial sketches a dictionary that retains only first visits, and an axis-by-axis stepping algorithm. Both are preserved in the [previous tutorial](../../../doc/space/point-grid-focus-2026-09-16/previous/tutorial.md). They are possible comparisons for a later pass, not the installed walking recorder. A set of first visits loses returns; a stepped route imposes another order on movement. An edge count becomes distance only after specifying the metric and step lengths.

The vitrine also contains controller-mounted drawing behavior for VR. Keep that as an additional encounter until its current headset behavior has been checked; the book's floor-plan exercise works without it. New sliders for walking-grid spacing and origin remain proposals.

A more focused next experiment would hold one released trace and its pink rendering fixed while a small control changes only the green replay's snap pitch. The [operational inquiry note](../../../doc/book/OPERATIONAL_INQUIRY.md) specifies the comparison and the checks needed before adding it to the book. That replay control is proposed, not installed.

[^point-grid-return-modulor]: Le Corbusier’s *The Modulor* develops an anthropometric system of architectural proportion. See the [Fondation Le Corbusier’s account of the Modulor](https://www.fondationlecorbusier.fr/dossier-thematique/vocabulaire-corbuseen/). This is the reference behind the artifact’s name, not evidence that the represented figure covers the range of bodies who may use the museum. Proportion and actual accessibility need different checks.
