# Point Line Grid - Map Summary

## Overview
Point Line Grid formalizes space into a system of addressability. After experiencing individual points (Point_One), measured lines (Point_Line), and networks of lines (Point_Lines), this map reveals how the grid transforms free space into indexed, computable territory. The focus shifts from geometric objects to the **coordinate system itself** as foundational infrastructure.

## Spatial Layout
- **Dimensions**: 8×10 grid (compact rectangular space)
- **Architecture**: Rectangular platform with large central void (rows 1-5, columns 2-6)
- **Border walkway**: Perimeter path around central emptiness
- **Entry**: Type "I" - immersive spawn

## Key Elements

### Primary Interactable
- **grid_lines** (4,3) - The grid overlay visualization
  - Makes coordinate system visible as geometric object
  - X and Z axes rendered as intersecting lines
  - Demonstrates how space becomes indexed

### Atmosphere & Context
- **dark_sphere** (3,4) - Intimate lighting creating focus
- **Floating text** (4,12) - "the_grid/the_trace" - connects to previous map

### Utilities
- **Teleporter** (4,8) - Exit to next map
- **Annotation** (7,8) rotated -90° - Navigation marker

## Atmosphere
- **Background**: Sky blue [0.2, 0.3, 0.7]
- **Lighting**: Cool ambient with warm directional (1.2 energy)
- **Mood**: Contemplative, minimal, focused on abstraction
- **Visibility**: Hidden tiles except corners - grid appears against void

## Learning Sequence
1. Player spawns on perimeter walkway
2. Encounters large central void (absent tiles)
3. Observes grid_lines overlay - coordinate system made visible
4. Experiences tension: embodied walking vs. numerical position
5. Recognizes that their VR position is always grid-indexed
6. Understands grid as organizational technology, not discovered truth
7. Exits having seen the infrastructure beneath all spatial calculation

## Design Intent

The **central void** is critical: It creates negative space that the grid_lines overlay must span. The grid exists **independently** of the platform architecture - it's not derived from the tiles, but imposed upon space itself.

The perimeter walkway forces you to **walk around** the void while the grid **crosses through** it. This reveals the difference between:
- **Embodied space** (where you can walk)
- **Indexed space** (where coordinates exist)

The grid doesn't care about walkability. It partitions space whether or not anything occupies that space. This is the grid's power: It **addresses the void**.

## Minimal Interactables

Unlike previous maps with multiple tools and demonstrations, Point_Line_Grid is nearly empty:
- One visualization (grid_lines)
- One atmosphere element (dark_sphere)
- Navigation utilities only

This minimalism emphasizes **the grid as the only necessary object**. Everything else can be positioned, stored, and retrieved because the grid exists.

## The Grid/Trace Pairing

The floating text reads "the_grid/the_trace" - connecting this map to Point_Trace.

**The Trace** (Point_Trace):
- Continuous gesture
- Embodied duration
- Resists discretization

**The Grid** (Point_Line_Grid):
- Discrete coordinates
- Instantaneous addressing
- Enforces quantization

These are opposing logics:
- Trace preserves the path
- Grid compresses to indexed cells

Together, they stage the fundamental tension in digital embodiment: continuous bodies moving through discrete coordinate systems.
