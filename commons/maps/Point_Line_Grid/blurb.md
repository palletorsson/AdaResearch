The Grid provides the stable structure of space; the Trace records what happens within it. Where the Line reduces movement to an efficient relation, the Trace accumulates duration—sequence, hesitation, deviation. As a body moves, positions are recorded against the grid, forming a temporary history. Yet this history is bounded: memory is finite, motion is sampled, and deviation is measured relative to fixed frames. The Trace resists reduction, but only from within the grid that enables its capture, leaving a remainder that cannot be fully contained.
