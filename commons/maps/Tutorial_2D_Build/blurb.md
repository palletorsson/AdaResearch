# Tutorial_2D

One index finds a slot. Two indices find a point. The jump from line to grid is the jump from sequence to space — from knowing *where* to knowing *where in relation to what*.

Row and column helpers break the axes apart. The 4×4 grid at the center locks them back together. Pick up a cube, read its coordinates, watch the pulsar's binary table pulse in glass tubes — every artifact a different way of saying the same thing: position is relational. A dark sphere floats. A grid agent copies and wanders. The static grid and the living agent occupy the same coordinate system but inhabit it differently.

Arrays gave you order. The second dimension gives you territory.
