# Magritte Windows

A painting sits on an easel before a window. The canvas continues the landscape exactly. Remove the canvas — the view remains. Replace it — no difference. Magritte's *The Human Condition* asks: which surface holds the real? The window frames what is outside. The painting frames what is represented. When frame and scene align perfectly, the distinction collapses — and that collapse is the point.

The window is a function that promises transparency. Look through glass, see truth. But every frame selects, crops, excludes. The edge of the window is the edge of the formal system. What falls outside the frame does not cease to exist — it ceases to be represented. Representation has boundaries. The frame that shows is the frame that lies.
