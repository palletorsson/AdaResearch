# Pattern Generation 7

An 8×8 arena inside a 12×12 grid. Eight algorithms compete on the same field — same dimensions, same constraints, different logic. Each one generates a pattern from randomness. Some fill space evenly. Some cluster. Some leave gaps that look deliberate.

A dark sphere pulses at the edge, ambient catalyst, watching the grid rewrite itself. Animal patterns emerge from procedural rules — stripes, spots, the markings that evolution arrived at through reaction-diffusion long before computers existed.

The point is comparison. Same grid, different process, radically different output. Randomness is not one thing. It has textures, biases, signatures. What looks arbitrary carries structure. What looks structured carries noise. The algorithm doesn't eliminate chance — it gives chance a shape.
