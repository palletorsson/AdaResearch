# What was the world made of, hall by hall?

Ten glass cages along an aisle, one per hall of the primitives sequence. In the first there is one grey point, and you can move it. Then a line between two points; then a floor that remembers where the point has been; a lattice; the first face; the first closed body; a body that moves by itself; a sphere; a body made of many parts; a form that is only for looking. Nothing here has a colour: colour is four sequences away. Every cage is built from the same vocabulary file the biome reads, cut at that hall.
