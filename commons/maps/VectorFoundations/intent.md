Concept: VectorFoundations introduces the grammar of directed quantity in 3D space. Three islands present the building blocks — basis vectors, addition, and subtraction — as hands-on spatial instruments rather than textbook definitions. The learner grabs arrows, stretches them, stacks them tip-to-tail, and watches components decompose along axes. The becoming_catalyst pickup marks the beginning of a physical relationship with force that will evolve through every subsequent map.

Sequence role: Opens the Vectors & Forces: From Direction to Dynamics sequence (map 1 of 9). The learner arrives with spatial reasoning from the primitives and transformation prerequisites but no formal vector vocabulary. This map establishes the component-magnitude-direction triplet and the arithmetic of addition and subtraction that every later map depends on. It feeds directly into VectorOperations, where dot and cross products extend these basics into measurement and perpendicularity. In QFEP terms, this is the first encounter with the state vector S — the mathematical object that encodes where something is and which way it faces.

Technical angle: VectorBasics implements v = |v| * v-hat with a draggable endpoint that simultaneously updates magnitude (arc sweep from x-axis), unit vector (rescaled arrow), and three component arrows along i, j, k. A spring scale gadget deflects proportionally to magnitude, making length a felt quantity. basis_vectors_rig renders the standard orthonormal frame at interactive scale. vector_addition_demo performs head-to-tail stacking (A + B = C) and parallelogram-law visualization. vector_subtraction_demo shows A - B as the displacement from B's tip to A's tip. ForceMagnitudeDemo connects magnitude to F = ma: drag the force arrow longer, watch the ball accelerate proportionally, establishing that magnitude is not decorative but causal. coordinate_system_switcher exposes the arbitrary nature of axis conventions.

Critical angle: A vector is not a number and not a point — it is a displacement, a difference between two positions carrying both how far and which way. This distinction matters because QFEP's state S is built from vectors: position, velocity, orientation are all directed quantities. The sequence truth states "Direction + magnitude = vector. F = ma. Acceleration is the only thing you feel." VectorFoundations enacts the first clause. The learner discovers that decomposition into components is a choice (which coordinate system?) applied to something that exists prior to any coordinate system. This tension between the object and its representation is a quiet rehearsal for the QFEP insight that formalism encodes but does not create the phenomena it describes. The becoming_catalyst — a tool that evolves with the curriculum — embodies this: the same object acquires new meaning as understanding deepens, just as the same vector acquires new components in a rotated frame.

Key artifacts: VectorBasics is the entry point — drag an arrow, watch magnitude arc sweep and component arrows resize along axes, feel a spring scale deflect proportionally to length. basis_vectors_rig renders i-hat, j-hat, k-hat as the standard orthonormal frame the learner stands inside, making orientation embodied. vector_addition_demo performs interactive head-to-tail addition (A + B = C) with parallelogram visualization. ForceMagnitudeDemo bridges magnitude to physics — drag the force arrow longer and the ball accelerates harder, establishing that magnitude is causal via F = ma. VectorSubtraction shows A - B as the arrow from B's tip to A's tip, the displacement that answers "how do I get from here to there." vector_subtraction_demo reinforces this with interactive controls. becoming_catalyst is the evolving hand tool that tracks curriculum progress. coordinate_system_switcher exposes axis convention as a choice, not a given. dark_sphere serves as ambient marker and catalyst preview station.

Gap: The @identity block for ForceMagnitudeDemo notes a missing mass slider to demonstrate a = F/m with different masses — currently force magnitude drives acceleration but mass is fixed at 1, preventing the learner from feeling that heavier objects resist acceleration more. VectorBasics notes a missing VR button to toggle component visibility, which would let the learner isolate individual axis contributions. An interactive demonstration showing that the same vector has different components in different coordinate frames would connect the coordinate_system_switcher more tightly to the decomposition artifacts.
