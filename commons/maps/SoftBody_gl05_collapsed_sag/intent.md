Concept: A pressurized soft-body sphere with a top pin runs the same algorithm as gl01-gl04 with deliberately broken parameters — stiffness near zero, no pre-inflation, increased gravity, and 500 timesteps instead of 200. The body never reaches equilibrium; it stretches into a long teardrop hanging from the pin, with thin walls and an elongated mouth. The vessel pattern fails. The map is a gallery study; the player walks around the single soft-body marker.

Sequence role: Fifth and final glass-vessel study (gl05) in the imported soft-body gallery cluster within the Soft Bodies sequence (13th spine, integration phase). Closes the gl-family parameter sweep by documenting parameter-limit breakdown. gl01-gl03 sweep pin-ring radius (bulb/bottle/bowl). gl04 perturbs gravity direction (lopsided vase). gl05 pushes stiffness past the lower limit and runs long enough for the failure mode to develop fully. Pair-contrast with gl04: gl04 is a parameter perturbation that yields a recognizable family member; gl05 is a parameter excess that yields a non-member. Together they bracket the family's domain — what counts as "a vessel" requires the stiffness to be above some threshold and the time to be below some threshold.

Technical angle: Spherical mesh of mass points with structural and bending springs (same as gl01). Top ring pinned. Stiffness coefficient set to a small value (e.g., k_struct = 5 instead of the usual 200, k_bend = 1 instead of 50). Pre-inflation skipped — no internal pressure injected at t=0 to bias the sphere outward. Gravity increased (e.g., 1.5x or 2x normal). Verlet or PBD integration for 500 steps with light damping. Under these settings, the springs are too weak to balance gravity, the bending springs are too weak to preserve the sphere's local curvature, and pre-inflation is not there to push back. The body falls and stretches; the unpinned vertices migrate toward the bottom; the surface thins as vertices spread apart along the gravity direction. By t=500, the body is a long thin teardrop and would continue stretching if the simulation kept running.

Critical angle: The gl-family teaches that vessel-ness lives in a parameter region, not in a recipe. gl05 marks the region's boundary. Documenting the failure mode is doing the same work as documenting the success modes — both are points in the same parameter space; the simulation does not distinguish "good vessel" from "broken vessel," only "this is what these parameters produced." The aesthetic difference between gl03's wide-bowl and gl05's collapsed-sag is not a quality judgment from the physics; it is a perceptual judgment from the viewer, based on which family of objects each result resembles. By including the failure case in the gallery, the cluster refuses to hide the parameter window's edge. A craft tradition's vocabulary for the same failure ("over-cooked", "left too long in the kiln") names the perceptual boundary; the simulation simply records the parameter values that produced it.

Key artifacts: gallery_marker_soft-body holds the gl05_collapsed_sag configuration. The long thin teardrop is the artifact — the simulation's record of what happens when the stiffness-and-time parameter pair falls outside the vessel window.

Gap: A stiffness slider on the gallery marker would let learners interactively cross the vessel boundary — watch the same configuration collapse as k drops below the threshold, and re-form as k rises again. The threshold itself is the lesson the cluster teaches.
