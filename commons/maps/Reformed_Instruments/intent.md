Concept: A showcase hall where six previously-bespoke teaching workbenches are rebuilt on a single canonical interface (the ControlConsole + Braun panel + smooth slider from the 2026-06-13 interface overhaul). The map's subject is the interface itself: the same control surface carrying six very different ideas.
Sequence role: A demonstration/integration map in the Forces sequence, built to feature the recently-migrated console artifacts rather than to teach a new force concept. It functions as a showroom for the interface-overhaul work — paired with the /interface-overhaul blog — letting a walker confirm that the unified console behaves consistently across unrelated visualizations. Orientation/meta phase, not a difficulty step.
Technical angle: Six workbench artifacts, each a domain visualization mounted on the shared ControlConsole — transform_composition_workbench (matrix composition), ca_rules_workbench (cellular-automata rule selection), complexity_dial_workbench (a complexity parameter sweep), qfep_balance_workbench (the F/E/lambda balance), halting_workbench (the halting problem), russell_paradox_workbench (set self-membership). All wear the same Braun console chassis and smooth slider while keeping their individual visualizations above the panel.
Critical angle: Standardizing the control surface across six incommensurable problems is itself an argument — that the gap between learner and idea is mostly interface friction, and that a consistent grammar of interaction lets attention rest on the concept instead of relearning the buttons each time. It also quietly flattens domains: halting, paradox, and matrix algebra all become "things you turn a dial on," which thickens the water (one handle for many ideas) while risking the foreclosure that genuinely different problems look interchangeable.
Key artifacts: transform_composition_workbench composes transformations; ca_rules_workbench selects and runs cellular-automata rules; complexity_dial_workbench sweeps a complexity parameter; qfep_balance_workbench balances the QFEP order/entropy/edge terms; halting_workbench stages the halting problem; russell_paradox_workbench dramatizes set self-membership.
Gap: As an interface showroom this map has no narrative arc between stations — a short label per bench naming which migration it demonstrates would make the "before/after the overhaul" point legible to a walker. Longer term, consider whether this belongs in the player-facing Forces sequence or in a dedicated tools/interface sequence, since none of the six benches concern forces.
