## The walk

Four arrays, and each takes the same handful of parts and lays them out by a different law: a line, a ring, a grid, a tower. The parts do not change — only the rule that places them, and with it what the arrangement makes visible. The clipboard reframes what an array is for: not repetition, but *systematic exhaustion of possibility* — a way of trying every placement of a kind so that none is missed.

## What it fixes

The walk corrects the reflex that an array is decoration — the same thing stamped out for pattern's sake. Here the array is a *search*. The bricoleur with a pile of parts faces a combinatorial problem — which arrangement holds, which affords the use, which satisfies the constraint — and an array is the disciplined way to walk that space: linear to compare along one axis, radial to test rotation, grid to cover a plane, stack to probe height. Each is a different question asked of the same stock. This is the chapter quietly arming itself: before you can build without a blueprint you need a way to *look* without one, and the array is that instrument — improvisation given a method, the pile turned into a space you can survey.
