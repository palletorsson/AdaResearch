# Bricolage_Arrays_as_Probes - Summary

## Overview

Arrays are not mere repetition—they are systematic questions about potential. This map reframes arrays (from the array_tutorial sequence) as probing tools: "What does this part want to become when repeated?" A single cylinder is just a cylinder. But a linear array of cylinders wants to become a fence, a ladder, a spine. Arrays reveal latent structure.

Consistent warm workshop lighting. The array demonstrations are low-height (0.3) to allow observation of repetition patterns from above. The spacing between demonstrations allows cross-comparison.

## Learning Sequence

1. Read nested_arrays_axioms clipboard—understand dimensional ladder
2. Examine linear array: one dimension of repetition → fence-like structures
3. Examine radial array: angular repetition → wheel-like structures
4. Pass through dark_sphere—synthesis moment
5. Examine grid array: two dimensions → floor/wall-like structures
6. Examine stack array: vertical repetition → shelf-like structures
7. Recognize: array type determines emergent structure type
8. Exit to Constraints—what pushes back against assembly

## Design Intent

Each array type reveals a different category of emergent structure:
- **Linear**: One-dimensional structures (fences, spines, sequences)
- **Radial**: Rotational structures (wheels, stars, domes)
- **Grid**: Two-dimensional structures (floors, walls, platforms)
- **Stack**: Vertical structures (shelves, towers, layers)

The bricoleur learns to "ask" parts what they want to become by trying different array types.

## Theoretical Framework

### Arrays as Questions
The engineer uses arrays for efficiency: "I need 20 fence posts." The bricoleur uses arrays as questions: "What happens when I repeat this?" The answer often reveals affordances invisible in the single part.

### The Four Array Types
| Array Type | Repetition Pattern | Emergent Structure Category |
|------------|-------------------|----------------------------|
| Linear | Along a line | Sequence, path, spine |
| Radial | Around a center | Wheel, dome, star |
| Grid | Across a plane | Floor, wall, mesh |
| Stack | Along vertical axis | Shelf, tower, layer |

### Dimensional Ladder
From nested_arrays_axioms: arrays represent dimensional increase:
- Point (0D) → Line (1D array of points)
- Line (1D) → Plane (2D array of lines)
- Plane (2D) → Volume (3D array of planes)

Arrays are the operation that moves up the dimensional ladder.
