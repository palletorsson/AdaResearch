# Attention Economy

A 12×12 grid. An 8×8 arena at its center. Algorithms compete for space using randomness as their only weapon. Gaussian distributions raise terrain into bell curves. Random walks carve drunk paths across the field. Cubes appear, rotate, vanish — selected by coin flip, placed by probability.

Each algorithm reshapes the same grid differently. Height randomness builds landscapes from noise. Profile generators extrude silhouettes no one designed. A walker staggers 128 steps, raising every cell it touches, composing topography through accident. Remove functions dissolve structure — column, row, range — entropy eating order in controlled bites.

Randomness is not the absence of decision. It is decision distributed across every possible outcome simultaneously. The arena doesn't produce chaos. It produces form that no single intention could have authored.
