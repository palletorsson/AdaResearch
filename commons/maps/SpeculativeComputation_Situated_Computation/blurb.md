*There is no view from nowhere.*

Haraway's situated knowledge argued that objectivity is not the absence of a perspective but the careful accounting of which perspective you're in. "Partial, locatable, critical knowledges" — the opposite of the god-trick.

Computation inherited the god-trick. The algorithm runs "the same" anywhere. Temperature-invariant. Body-invariant. Nowhere-shaped. But a recommender in Lagos is not the same object as a recommender in San Francisco, even when the code is identical — the training data, the prior, the user's expectations, the network latency, the power grid all silently relocate it.

Situated computation is the practice of letting the location back in. The sensor knows where it is. The model knows whose data trained it. The interface shows its seams.

In this map, the same computation returns different results in different parts of the room. The gap is not a bug. It is the knowledge being honest about where it comes from.
