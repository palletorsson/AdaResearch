Concept: Randomness applied to individual object geometry — each cube's edge profile is determined by coin flips, making every instance unique. The cube becomes a frozen record of its random generation history, where form encodes chance.
Sequence role: Fourth map in Randomness sequence. Follows Randomness_10_PRINT_Algorithm (randomness generating grid patterns) and shifts scale from grid to object. Precedes Random_Rotate_Random_XYZ, where randomness moves from shaping form to controlling transformation. The coin_toss and dice_throw artifacts make the generation mechanism tangible before random_edge_profile applies it to geometry.
Technical angle: Procedural geometry modification — randomizing edge bevels, extrusions, or profile curves per edge using boolean or float random values. The coin_toss artifact maps to binary random (heads/tails per edge), while dice_throw maps to discrete uniform random (1-6 determining profile type or magnitude). random_object_spawner instantiates multiple randomized cubes, demonstrating that each seed produces a distinct object. GDScript ArrayMesh or SurfaceTool for runtime geometry modification.
Critical angle: The cube is the sequence's primitive — maximally regular, six identical faces, twelve identical edges. Randomizing its edges is a controlled violation of symmetry. Each cube becomes an individual, distinguished not by design intent but by stochastic history. This is individuation through entropy: identity as the accumulation of random events. The frozen coin flip on each edge literalizes the relationship between process (flipping) and product (form).
Key artifacts: random_edge_profile is the core artifact — geometry shaped by per-edge random decisions; coin_toss and dice_throw make the random mechanisms physically interactive before they are applied to geometry; random_object_spawner demonstrates population-level variety from a single algorithm; dark_sphere provides the unrandomized control.
Gap: No artifact lets the learner replay the same seed to see the same cube regenerated — this would reinforce the PRNG determinism lesson from map 1 at the geometric level.
