# A return that keeps the branch

The point comes back; the drawn branch stays. This division is useful before it is metaphorical. Restoring a travelling state lets another segment proceed without inheriting every local alteration of the last branch. The program can support several departures because it has a procedure for returning from them.

What counts as a return is nevertheless specified. The saved record includes position, axes, angle, length and depth. The segment list is outside it. The turtle comes back while its drawing keeps the detour. Another implementation might save a different record. To investigate that choice, we need to follow both what is restored and what continues accumulating. A picture alone does not show the division.

The length ratio makes a second assumption available for play. A value below one gives us smaller branches; one gives equal strides; a value above one lets a branch outgrow its parent's stride. All use the same multiplication. The name length_decay carries an expectation that the operation does not enforce. The change can be pleasurable without proving that a longer branch is freer, more alive, or more queer. It makes the expectation of a proper proportion available to examine.

This is one place where the book's question about code as law becomes precise. A saved state specifies what a branch can carry back. The museum's collision system separately specifies what the visitor can stand on. These thin lines supply a visible form without supplying bodily support. If we want to inhabit them, we must make and test that further relation. More branches, greater height, a different abstract branching graph and a newly accessible passage are different outcomes.

The older critical manuscript raised useful questions about inherited conditions, repeated rules and environmental constraint. It also treated similarities to theoretical ideas as confirmations, assigned unmeasured QFEP coordinates, and claimed an on/off test of agential realism through context-free versus context-sensitive rules. Those claims exceeded both the experiment and the installed code. The archive keeps that manuscript available; the current text carries its questions forward without those verdicts.

In particular, ContextSensitiveTree queries physical obstacles during drawing. It does not implement the neighbouring-symbol rewriting function described in the earlier tutorial. The retained trees also use different programs, so their placement in a corridor and a clearing cannot establish that habitat alone changed an identical organism. A useful later experiment would keep a grammar, parameters and seed fixed, record each collision query, and vary one obstacle. Then we could ask which boundary prunes, supports, shelters or redirects this particular construction.

Rewriting does not preserve every original character as a historical object: symbols are replaced. A final sentence is not in general a uniquely recoverable record of all earlier sentences. The state stack has a narrower responsibility: nested returns during interpretation. Neither should be asked to prove an entire theory of memory.

Entropic morality helps keep the consequences of a limit open to investigation. Holding a modest tree steady may make its operation understandable; refusing a further generation may preserve the ability to encounter it at all. A named allocation budget is revisable infrastructure. It does not establish a universal optimum of complexity. Here the visitor can compare shortening and lengthening, retain a reference, and return to the initial state. Those are specific capacities for investigation. What else would a body need before the tree's promise of shelter became a place?
