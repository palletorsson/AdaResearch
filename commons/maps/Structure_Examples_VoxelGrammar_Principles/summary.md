# Structure Examples: Voxel Grammar Principles - Map Summary

## Overview
A playable showcase map composed from `voxel_grammar_subset.json` modules. It demonstrates how local voxel modules scale from connectors and thresholds to larger systems and topological ideas.

## Layout
- 4x5 station grid (20 modules total)
- Upper rows focus on **between** grammar
- Lower rows focus on **beyond** grammar

## Navigation
- Spawn: northwest corner
- Exit teleporter: southeast corner
- Annotation boards and 3D text markers guide progression
