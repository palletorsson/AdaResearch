# Structure Examples: Voxel Grammar Principles - Technical

This map is generated by stamping `heightmap` modules from:
`res://commons/maps/Structure_Examples/voxel_grammar_subset.json`

## Core Idea
Each module is a local 2D footprint with height values (`0..4`) placed into the `structure` layer.

## Why It Matters
This lets you author space as a compositional grammar:
1. Define module
2. Stamp module
3. Rotate/mirror variants
4. Chain by flow ports
