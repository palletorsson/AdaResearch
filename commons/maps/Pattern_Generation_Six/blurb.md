# Pattern Generation 6

A 12×12 grid. An 8×8 region at its center. Algorithms compete here — not for speed, but for pattern. Each one takes the same empty field and fills it differently. Same input, different logic, different world.

Randomness is the raw material. One algorithm scatters. Another clusters. A third grows structure from noise, finding edges where none were planted. The dark sphere pulses at the margin, ambient witness to each generation cycle. Color floods the grid in waves — not decoration but data, each hue a decision made visible.

The arena makes the invisible contest legible. Every algorithm encodes a bias about what order should look like. Watch long enough and the question inverts: the pattern doesn't reveal the algorithm. The algorithm reveals what it assumes disorder is.
