# Primitives Portals - Map Summary

## Overview
Primitives_Portals is a **transition map** - a long, narrow corridor (7×40) that serves as threshold between the primitives sequence and other sequences. The map features **combine_portals** which demonstrates transitions and connections, staging movement through space as **liminal passage** rather than destination.

## Spatial Layout
- **Dimensions**: 7×40 grid (extreme elongation - longest map in sequence)
- **Architecture**: Single-tile-wide walkway (column 3) suspended over void
- **Void dominance**: Most tiles absent - only narrow path remains
- **Mid-corridor focus**: dark_sphere at (3,18) - halfway point
- **Southern alcove**: Exit area expands slightly at rows 32-34

## Key Elements

### Primary Feature
**combine_portals** (3,4) sunken -0.2m - Near entrance
- Demonstrates portal/transition systems
- Shows how primitives connect to other sequences
- Visualizes passage and transformation

**clipboard** (1,1) rotated -85°, sunken -0.2m - Tutorial reference
- Links to btorus_axioms (torus/circle/π approximation)

### Atmosphere
**dark_sphere** (3,18) - Mid-corridor atmospheric focus
- Positioned at approximate center of 40-row journey
- Creates moment of stillness in long passage

### Utilities
- **Teleporter** (4,33) - Exit near southern end
- **Annotation** (6,1) rotated -90° - Navigation marker

## Atmosphere
- **Background**: Sky blue [0.2, 0.3, 0.7]
- **Lighting**: Warm directional (1.2 energy)
- **Mood**: Liminal, transitional, focused forward movement
- **Visibility**: Hidden tiles except corners - minimal revelation (mostly void anyway)

## Learning Sequence
1. Player spawns into narrow corridor
2. Encounters combine_portals immediately - transition visualization
3. Begins long walk on single-tile-wide path
4. Experiences void on both sides - suspended passage
5. Reaches dark_sphere at midpoint - moment of atmospheric shift
6. Continues forward through 15+ more rows of corridor
7. Arrives at exit alcove with slight expansion
8. Exits via teleporter, having experienced **pure transition**

## Design Intent

The **extreme elongation** (40 rows - longest in sequence) creates **temporal experience** - this map takes time to traverse.

The **single-tile walkway** suspended over void emphasizes:
- **Linearity** (only forward/backward, no choice)
- **Precarity** (narrow path, void on sides)
- **Focus** (nothing to distract, only movement)
- **Transition** (this is passage, not destination)

The map is **almost entirely void** - architecture reduced to minimum path. This staging says:

**Portals are about absence, not presence.**

Transitions are **between** places, not places themselves. The corridor embodies **liminality** - neither here nor there, only passage.

## Approximation and Limits

From map_info: "A toroidal portal sequence guided by increasing rings approaching π, staging continuity as asymptotic relation rather than arrival."

The torus (referenced in clipboard btorus_axioms) relates to **circles and π** - the relationship between:
- **Discrete** (polygons with finite sides)
- **Continuous** (true circle requires infinite points)

Approximation is **asymptotic** - you approach but never arrive. More sides = closer to circle, but never exact.

This mirrors the corridor experience: You walk toward the exit for 40 rows - approaching but not arriving until the end.

## Transition Function

Primitives_Portals serves as **meta-transition** - it connects:
- **Primitives sequence** → **Other sequences** (color, sound, wavefunctions, etc.)
- **Discrete geometry** → **Continuous phenomena**
- **Mastery** → **New ignorance**

The map says: "You've completed primitives. Now **pass through** to what lies beyond."

## Minimal Architecture

The map has **almost no content**:
- One visualization (combine_portals)
- One atmospheric element (dark_sphere)
- One reference (clipboard)
- Otherwise: void and narrow path

This minimalism is **intentional** - transitions should be **emptied** of content. They're about **movement**, not objects.
