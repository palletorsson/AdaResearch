# JSON Demo

Data has a shape before it has a meaning. JSON is the container — curly braces for objects, square brackets for arrays, colons binding keys to values. A syntax so minimal it fits on a napkin. So universal it moves between every language, every platform, every system that needs to say something structured to something else.

Walk the test room. Find the artifacts. Each one is a piece of notation waiting to be assembled — key-value pairs that describe worlds before worlds exist. Maps, configurations, save states. The scaffold beneath every dynamic system is static text in a file.

A format with no opinions. No types, no schema, no enforcement. Just structure offered freely, meaning deferred to whoever reads it. The simplest possible agreement between two systems that have nothing else in common.
