# Mandelbrot Deep Space

z → z² + c. Square and add. Square and add. Start from zero and iterate — does the orbit escape to infinity, or stay bounded? That single test, applied to every point in the complex plane, draws the boundary. The boundary is where everything happens.

Zoom in. The edge between escape and captivity never resolves. Miniature copies of the whole set appear — structurally complete, nested at every scale. Finite equation, infinite geography. The narrow entry opens onto depths without floor.

Every point in the Mandelbrot set indexes a different Julia set. One object cataloging every possible dynamical behavior. Two operations — square and add — and a map that contains all maps.
