# Fractals_11 - Inverted Trees

## Overview
Fractals_11 presents inverted recursive trees—branching downward rather than upward. This reflects the dual nature of tree structures: canopy above, roots below. The same recursive algorithm, reflected through the ground plane, reveals that "up" and "down" are arbitrary conventions in fractal geometry.

## Spatial Layout
- **Dimensions**: 7×8 grid
- **Architecture**: Platform with raised center section
- **Height**: Up to level 2

## Key Elements

### Interactables
- **Inverted Tree Cloud** (3,3) - Downward-branching tree visualization
- **Recursive Tree** (3,4) height 0.7m - Standard upward tree for comparison
- **Dark Sphere** (3,2) - Ambient lighting element

### Utilities
- **Teleporter** (5,6) - Exit to Fractals_12

## Atmosphere
- **Background**: Sky blue [0.2, 0.3, 0.7]
- **Lighting**: Warm directional with cool ambient
- **Mood**: Reflective, dual, root and crown

## Learning Sequence
1. Player enters and observes the inverted tree
2. Notes: same branching pattern, opposite direction
3. Compares with the standard recursive tree
4. Recognizes: rotation doesn't change the fractal nature
5. Considers: roots and canopy as mirror structures
6. Understands: orientation is convention, pattern is essence
7. Exits to explore more tree variations

## Design Intent
The map demonstrates **directional invariance** of recursive structures. The same algorithm produces the same pattern whether "growing" up or down. This parallels the biological reality: root systems often mirror canopy complexity, following similar branching rules into the earth.
