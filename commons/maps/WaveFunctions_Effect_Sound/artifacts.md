## Harmonic Distance Table
![Harmonic Distance Table](/scene-catalog/harmonic_distance_table.png)

Tabletop artifact with 12 chromatic pitch nodes in circle-of-fifths layout. Grab nodes to hear intervals; spatial distance corresponds to harmonic consonance. Activate a node as tonal center to see all others recolor by harmonic function (tonic=green, dominant=blue, subdominant=yellow). Glowing overtone connection lines show shared harmonics between pitches. Cognitive compression: harmonic distance becomes a felt spatial relationship.

`harmonic_distance_table`

## Chord Tension Spring
![Chord Tension Spring](/scene-catalog/chord_tension_spring.png)

Four pitch nodes connected by visible springs. Consonant chord = springs relax, nodes settle. Dissonant chord = springs vibrate, nodes jitter. Drag nodes to change pitch and feel tension physically. Preset buttons for major, minor, dom7, dim, aug, sus4, tritone. Resolution IS relaxation.

`chord_tension_spring`
