Concept: Mosaic_WFC_Reconstruction feeds documented mosaic patterns into the Wave Function Collapse solver to test whether algorithmic generation can reproduce what craftsmen built. The learner extracts adjacency rules from historical mosaics — which tile colors can neighbor which, in which orientations — and passes them to the WFC constraint propagation engine. The solver generates new tilings that satisfy the same local constraints, and the learner compares algorithmic output to the originals. The result is instructive failure: WFC gets the neighborhood logic right but misses the larger compositional structure.

Sequence role: Map 6 of 7 in Mosaic Analysis: Grid Logic in Stone and Glass. The learner arrives from Mosaic_Capri_Villa (map 5, mixed-period fragment analysis) carrying experience with wallpaper group identification, material-specific pattern analysis, and decontextualized fragment reasoning across the previous five maps. This map is the algorithmic test — the point where the sequence stops analyzing historical patterns and starts generating them. It feeds into Mosaic_Pattern_Maker (the final synthesis map), where the learner creates original patterns using all the tools and knowledge accumulated. In QFEP terms, this is the integration phase where the formal description F (symmetry groups, adjacency rules, lattice types) is put to the most demanding test: can it reproduce the phenomena (historical mosaics) from first principles?

Technical angle: WFC tile extraction begins with mosaic photographs: the learner identifies the discrete tile vocabulary (the set of distinct tessera configurations that appear in the mosaic), then defines adjacency rules specifying which tiles can neighbor which on each edge. The constraint propagation algorithm starts with every cell in superposition (all tiles possible), selects the lowest-entropy cell, collapses it to a specific tile, and propagates the constraints to neighbors — removing tiles that would violate adjacency rules. This process repeats until every cell is resolved or a contradiction forces backtracking. wfc_tile_mosaic implements this pipeline with mosaic-specific tile sets extracted from the patterns studied in previous maps. pattern_tile_puzzle provides the motif extraction interface. The critical comparison is between the WFC output (which satisfies all local adjacency constraints) and the original mosaic (which satisfies both local constraints and global compositional intentions like symmetry axes, border-to-center transitions, and figural focal points).

Critical angle: WFC reconstructs the rule but not the noise, and it reconstructs the local logic but not the global design. The algorithm converges on tilings that satisfy every adjacency constraint extracted from the original — no illegal neighbor pairs, no broken edges — yet the output looks different from the original because the original was designed with intentions that extend beyond neighborhood rules. A Roman floor mosaic has a center medallion, a surrounding field of repeating geometric pattern, and a border that frames the whole. WFC knows nothing about center, field, or border — it only knows which tiles can touch which. This is the lambda gap made visible: the distance between constraint satisfaction and design intention. The sequence truth declares "the pattern is the algorithm made visible across centuries," and WFC tests that claim rigorously. If the algorithm is truly the pattern, then WFC should regenerate the mosaic from its rules alone. It does not — not because the rules are wrong but because the rules are incomplete. The craftsman's knowledge included not just which tiles can neighbor which but where in the floor different patterns belong, how the overall composition relates to the room's architecture, and how the border transitions to the wall. QFEP reads this as the irreducible gap between F (the formal adjacency rules) and E (the entropy of design intention): constraint satisfaction is necessary but not sufficient for pattern. The WFC solver's truth from the codebase captures it: "The world does not emerge from randomness — it emerges from the collapse of possibility under constraint." The mosaic proves the corollary: the world that emerges from constraint alone is not quite the world the craftsman made.

Key artifacts: wfc_tile_mosaic implements the full WFC pipeline applied to mosaic reconstruction — tile extraction from documented patterns, adjacency rule definition from physical edge matching, constraint propagation with entropy-based cell selection, and output comparison to historical originals. The solver generates new tilings that satisfy all extracted local constraints, revealing where constraint satisfaction matches historical craft and where it falls short. pattern_tile_puzzle provides the interactive motif extraction interface, letting the learner select tile vocabularies and define edge-matching rules from mosaic photographs before feeding them to the WFC solver.

Gap: The map critically needs a side-by-side comparison viewer that quantifies the difference between WFC output and historical original — not just visual similarity but structural metrics like symmetry group preservation, color distribution matching, and compositional hierarchy (does the output have a center, a field, and a border, or is it uniform?). A hierarchical WFC variant that operates at multiple scales (tile-level adjacency, room-level zone assignment, floor-level compositional layout) would test whether adding global structure to the constraint system closes the gap. A failure analysis tool that highlights WFC contradiction sites — cells where no tile satisfies all neighbor constraints — would reveal where the extracted rules are insufficient, pointing the learner toward the implicit design knowledge that the craftsman held but the adjacency rules did not capture.
