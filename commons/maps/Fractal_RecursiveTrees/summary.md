# Fractals_2 - Stochastic Trees

## Overview
Fractals_2 introduces stochastic recursion—the combination of deterministic rules with random variation. Where Fractals_1 showed pure recursion producing identical copies, here the same grammar generates unique forms each time. This is how nature builds: rules plus noise, structure plus variation.

## Spatial Layout
- **Dimensions**: 13×22 grid (large exploration space)
- **Architecture**: Extended platform with varied heights, stepped terrain for tree viewing
- **Height**: Up to level 4, creating elevated vantage points

## Key Elements

### Interactables
- **Stochastic Tree Separated** (11,1), (2,9), (11,11) - Multiple instances of randomized recursive trees, each unique
- **Cantor Pagoda VR** (6,16) - Cantor set principle applied to architectural form
- **Dark Sphere** (7,10) - Ambient lighting element

### Utilities
- **Teleporter** (10,20) - Exit to Fractals_3

## Atmosphere
- **Background**: Sky blue [0.2, 0.3, 0.7]
- **Lighting**: Warm directional with cool ambient
- **Mood**: Organic, varied, forest-like contemplation

## Learning Sequence
1. Player enters the expanded space
2. Encounters first stochastic tree—observes its unique branching pattern
3. Moves to second tree—same rules, different result
4. Compares trees—recognizes structural similarity despite surface difference
5. Examines Cantor Pagoda—sees recursive deletion applied to architecture
6. Understands: randomness within structure produces natural forms
7. Exits to explore circular fractals

## Design Intent
The map demonstrates that **identical rules can produce diverse outcomes** when randomness is introduced. Each stochastic tree follows the same L-System grammar, but random choices at each branch point create unique individuals. This is the QFEP's λE(S) term in action: entropy injection within deterministic structure.
