# The same return, a different cause

Primary: `phase_rod_array`.

Use two sphere points as the tips of two arms. Give each an angle and a turning rate. OFFSET changes one angle once; DRIFT changes how quickly that angle advances.

Carry: A circular path can be prescribed. Next, let two points attract each other and see what path results.

Check: Press OFFSET with equal rates and watch the 45° gap persist. Restart, press DRIFT and wait thirty seconds: predict an added gap of 72°. Change the rate difference to 2% and predict 36°.
