# PG: Marching Cubes Gallery

A threshold divides inside from outside. Marching cubes walks a grid, cell by cell, asking one question at each corner: above or below? Eight corners, two states each — 256 possible configurations, reduced by symmetry to fifteen. From this lookup table, triangles emerge. Surface from samples. Form from binary.

The gallery holds what the algorithm finds when pointed at different scalar fields. DNA helices. Atomic orbitals. Human figures. Abstract forms no one designed. Same method, different fields, different bodies. The cube marches identically each time. What changes is what counts as inside.

Every sculpture here was latent in its field — the algorithm didn't create it, only extracted the boundary where one condition becomes another. Identity as isosurface. The shape is just where the threshold falls.
