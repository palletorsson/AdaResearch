# Which side did the name choose?

A case number can look like an objective name for a surface. Here two complementary numbers describe the same eight samples: the display marks high values, while the extractor marks low ones. Showing both makes a convention inspectable instead of allowing a label to become a fact about inside and outside.

MARGIN offers a second distinction. Classification stays fixed while geometry moves. Keeping a label does not keep a body in the same place or guarantee its accessibility. Conversely, a visible change does not establish a different connectivity.

The fifteen examples include a surrounding sampled neighbourhood. Their miniature sheets cannot certify a walkable tunnel merely because an inherited label called one “Tunnel.” A later experiment can test competing connections on an ambiguous face; this hall begins by admitting what its table has already decided.
