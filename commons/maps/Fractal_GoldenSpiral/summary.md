# Fractals_7 - 3D Cantor Variations

## Overview
Fractals_7 extends the Cantor principle into three dimensions. The cube subdivision demonstrates how the 1D Cantor set (remove middle third) becomes the 3D Menger sponge (remove center and face-centers). This is the transition from fractal lines to fractal volumes—spaces you can walk through.

## Spatial Layout
- **Dimensions**: 7×8 grid
- **Architecture**: Standard platform with raised center section
- **Height**: Up to level 2

## Key Elements

### Interactables
- **Cantor Set** (3,3) - 1D Cantor set visualization for reference
- **Cube Subdivision** (1,6) - Interactive cube that subdivides following Menger rules
- **Dark Sphere** (3,2) - Ambient lighting element

### Utilities
- **Teleporter** (5,6) - Exit to Fractals_8

## Atmosphere
- **Background**: Sky blue [0.2, 0.3, 0.7]
- **Lighting**: Warm directional with cool ambient
- **Mood**: Geometric, architectural, spatial exploration

## Learning Sequence
1. Player reviews the 1D Cantor set
2. Observes the cube subdivision—sees the 3D extension
3. Interacts with subdivision cube—watches removal pattern
4. Notes: 27 cubes become 20 (7 removed: center + 6 face-centers)
5. Connects 1D deletion to 3D deletion
6. Understands the Menger sponge emerges from this principle
7. Exits to continue exploring dimensional extensions

## Design Intent
The map bridges **1D and 3D Cantor constructions**. By showing both the linear Cantor set and the cube subdivision together, players can see how the same principle (remove middles) operates across dimensions. This prepares for understanding the Menger sponge as walkable fractal architecture.

## Connection to Sequence
- **Position in fractals sequence**: 7/14
- **Precedes**: Fractals_8
- **Follows**: Fractals_6 (Recursive Trees)
- **Establishes**: Dimensional extension of deletion, from line to volume
