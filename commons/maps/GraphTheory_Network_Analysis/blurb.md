# Network Analysis

A 12×12 grid. An 8×8 arena at its center. Algorithms enter, execute, and leave traces — not as abstract pseudocode but as visible, spatial events. Cells light up, paths form, regions fill. Randomness is not decoration here. It is method.

Network flow rendered in three dimensions. Edges carry capacity. Nodes accumulate pressure. The system finds routes the way water finds cracks — not by planning but by pushing against constraint until something gives. Max-flow, min-cut: the proof that every network's throughput equals its narrowest bottleneck. Abundance defined by scarcity.

Watch the algorithms work the grid. Some sweep. Some scatter. Some converge on structure through pure stochastic groping — no blueprint, no overview, just local rules and iteration. Order extracted from coin flips. The arena demonstrates what every random process already knows: given enough trials, chaos is a strategy.
