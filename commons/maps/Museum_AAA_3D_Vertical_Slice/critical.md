# The room is not neutral

The first platform test treated space as whatever remained after objects had been placed. This court reverses that assumption. Space is declared, negotiated, and made visible before it becomes atmosphere.

The three artifacts do not receive equal empty squares. Equality here would be a false neutrality: the wall meter is read frontally, the loom produces matter into a runway, and the neural network asks a body to move around a large computational section. Giving each the same clearance would privilege the compact static object as the unmarked norm.

The architectural shell is therefore a host, not a sovereign. It can provide shade, rhythm, edges, and scale, but it cannot silently compress an artifact's operating face or convert productive space into decoration. The next AAA pass should preserve this division while improving material, light, acoustics, and eye-level legibility.
