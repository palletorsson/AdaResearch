Concept: The Mandelbrot set — the atlas of all Julia sets. Each point c in the complex plane indexes a Julia set; the Mandelbrot set is the catalog of which Julia sets are connected. z=z^2+c with z_0=0, iterated: the simplest possible iteration rule producing the most complex known mathematical object.
Sequence role: Ninth map in the Fractals sequence (10th spine, lambda_edge phase). The culmination of the complex dynamics arc opened by Fractals_8's Julia sets. The mandelbrot_dive artifact enables infinite zoom, revealing self-similar copies of the whole set at every scale — the Mandelbrot set contains miniature copies of itself, the ultimate demonstration of self-similarity across scales. Fibonacci (Fractals_7) meets Sierpinski (Fractals_5) in the sense that growth by addition and growth by deletion both find their reflections in the Mandelbrot boundary; leads to Fractals_10.
Technical angle: Mandelbrot set M = {c in C : the orbit of 0 under z^2+c remains bounded}. Escape-time algorithm: iterate z_{n+1}=z_n^2+c from z_0=0, color by iteration count when |z|>2. Mandelbrot-Julia correspondence: for c in M, the Julia set J_c is connected; for c outside M, J_c is totally disconnected (Cantor dust). The mandelbrot_dive enables deep zoom, revealing the infinite nesting of miniature Mandelbrot copies along filaments.
Critical angle: The Mandelbrot set is arguably the most complex object in mathematics, yet it is defined by five characters and an inequality. It is the complete index of dynamical behavior for z^2+c — a finite description containing an uncountably infinite catalog. The lambda_edge truth reaches its apex: the boundary of M has Hausdorff dimension 2 (proven by Shishikura), meaning the border is as complex as the plane it lives in. The edge is as rich as the whole.
Key artifacts: mandelbrot_set implements the escape-time visualization of M; mandelbrot_dive enables infinite zoom into the boundary filaments; dark_sphere anchors.
Gap: Needs a Mandelbrot-Julia bridge artifact that displays the Mandelbrot set with a movable cursor, rendering the corresponding Julia set in real time beside it — making the atlas metaphor interactive and the M-J correspondence tangible.
