Concept: The entire L-Systems concept in miniature — axiom, rules, string, tree. A single character becomes a sentence becomes a forest through iterated rewriting. This is the moment the learner sees that grammar is not description but generation: a sentence can become a forest.
Sequence role: First map in the L-Systems sequence (11th spine sequence, lambda_edge phase). Opens the generative grammar arc by establishing the full pipeline: axiom to production rules to string expansion to turtle-graphics rendering. Beginner difficulty — the learner needs no prior L-Systems knowledge, only the recursive intuition built through earlier fractal and cellular automata sequences. Connects forward to LSystems_Growth where the same pipeline gains temporal animation and environmental context.
Technical angle: String rewriting as the core operation — an axiom string is expanded through production rules across discrete generations, then interpreted by a turtle-graphics renderer that maps characters to movement, rotation, and branching commands. Koch snowflake, Sierpinski triangle, dragon curve, and plant presets demonstrate how different rule sets produce radically different geometries from the same rewriting mechanism. The lsystem_editor artifact exposes the rule table for direct manipulation.
Critical angle: L-Systems reveal that complexity does not require complex instructions — a two-rule grammar can generate a tree. This is Lindenmayer's original insight: biological morphology follows from local rewriting, not global blueprints. The lambda_edge phase thesis crystallizes here: grammar is generative, and a sentence can become a forest. The gap between symbol and shape is bridged by iteration.
Key artifacts: fractal_lsystem_string visualizes the raw string expansion before rendering; lsystem_editor provides direct rule manipulation; lsystem_tree renders the turtle-graphics interpretation; dark_sphere anchors the research environment.
Gap: Needs a side-by-side string-to-shape comparator that highlights which substring maps to which branch segment, making the symbol-to-geometry correspondence fully legible at each generation.
