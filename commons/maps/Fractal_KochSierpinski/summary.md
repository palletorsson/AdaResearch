# Fractals_4 - Cantor Set

## Overview
Fractals_4 introduces the Cantor set—the simplest fractal, defined entirely by deletion. Take a line segment, remove the middle third, repeat forever. What remains has zero length but uncountably many points. This is the foundational example of fractal dimension: D ≈ 0.631, more than a point (D=0) but less than a line (D=1).

## Spatial Layout
- **Dimensions**: 7×8 grid
- **Architecture**: Compact space with raised central platform
- **Height**: Up to level 2, intimate viewing area

## Key Elements

### Interactables

- **Fractal Cantor Set** (3,3) - Second instance at default height

## Atmosphere
- **Background**: Sky blue [0.2, 0.3, 0.7]
- **Lighting**: Warm directional with cool ambient
- **Mood**: Sparse, contemplative, focused on absence

## Learning Sequence
1. Player enters compact space
2. Observes the Cantor set at eye level—sees the gaps, the remaining segments
3. Examines the 10-iteration version—finer detail, more gaps
4. Notices the pattern: what remains gets smaller but never vanishes
5. Encounters the Menger sponge—the same principle in 3D
6. Understands: fractals can be defined by what is removed
7. Exits to explore the Koch curve

## Design Intent
The map demonstrates **subtraction as generation**. Most fractals are built by adding—branches to trees, circles to gaskets. The Cantor set is built by removing, yet what remains is infinitely complex. The Menger sponge extends this to 3D: infinite surface area, zero volume.
