Concept: The set of all sets that don't contain themselves — self-reference breaks naive set theory, proving that the foundations of mathematics harbor contradiction.
Sequence role: Third map in Foundations Crisis; the first genuine paradox. Non-Euclidean spaces showed alternatives; Russell's paradox shows breakdown. The transition from "geometry has choices" to "logic has contradictions" is the crisis escalating. Prepares Gödel by establishing that self-reference is dangerous; follows NonEuclidean_Spaces; leads to Godel_Incompleteness.
Technical angle: Naive set theory, unrestricted comprehension, the paradox construction (S = {x : x ∉ x}, then is S ∈ S?), the resulting collapse of Frege's system. The russell_set_box artifact makes the paradox spatial — a box that contains itself only if it doesn't.
Critical angle: Self-reference is the mechanism that breaks formal systems. A set that asks about its own membership, a statement that asserts its own unprovability — the pattern repeats through Gödel and beyond. Russell's paradox reveals that every formal system has an outside: the thing it cannot consistently describe is itself. This is the sequence truth in its first appearance.
Key artifacts: russell_set_box makes the paradox tangible — a physical object embodying the logical impossibility.
Gap: An interactive version where the learner tries to sort boxes into "self-containing" and "non-self-containing" piles, encountering the paradox experientially.
