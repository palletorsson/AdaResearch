Concept: A walkable hall of four pattern-making machines, each embodying a distinct generative process — weaving, printing, milling, and pressing. Pattern is staged as the structural substrate that precedes color: before the spectrum arrives, the repeating motif is manufactured here.
Sequence role: Opening map of the Color sequence. It seats the learner in front of structure before hue — patterns are made first, then the rest of the sequence (Color_Context_Placed, Color_Grid_Pallet, Color_Rainbow) layers color onto and through that structure. Low difficulty, orientation phase: nothing to solve, everything to watch. Establishes that color is not a thing in itself but a property applied to an already-patterned ground.
Technical angle: Four procedural artifacts — pattern_machine_a (loom: warp threads, weave bar, feed roller), pattern_machine_b (printer: extrusion print head + spinning feed roller), pattern_machine_c (mill: gantry drum with kaleidoscope mirror-wedge rotor), pattern_machine_d (press: editable stamp matrix on a press head with guide rods). Each animates a different repetition mechanism — translational weave, extruded tiling, rotational symmetry, and stamped registration.
Critical angle: Putting pattern generation on machines makes visible that "pattern" is a manufacturing decision, not a found fact. Each machine encodes a different symmetry operation (translate, extrude, rotate, stamp), so the same hall demonstrates that there is no single way to repeat — repetition is plural, mechanical, and authored. Foregrounding pattern before color resists the habit of treating color as primary; here color is downstream of structure.
Key artifacts: pattern_machine_a weaves a translational pattern from warp threads; pattern_machine_b prints an extruded repeating motif; pattern_machine_c mills a rotational, kaleidoscopic pattern; pattern_machine_d presses a stamped matrix into registered rows.
Gap: The four machines display their processes but do not yet hand the learner an output they can carry into the color maps — a sampled pattern swatch that Color_Grid_Pallet or Color_Paint could then recolor would make the "structure first, color second" thesis literal. Editable stamp/loom parameters (a slider per machine) would let the learner author the pattern rather than only observe it.
