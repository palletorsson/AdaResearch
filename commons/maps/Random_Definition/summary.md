# Random_Definition - Map Summary

## Overview
Random_Definition introduces the fundamental concepts of entropy and pseudo-randomness. The map establishes the theoretical foundation for understanding randomness not as chaos but as **freedom from pattern**—the high-dimensional space where algorithms cannot predict or control.

## Spatial Layout
- **Dimensions**: 5×17 grid (narrow corridor)
- **Architecture**: Linear path with raised platforms at entry (height 2) and near teleporter
- **Height**: Variable (1-2), creating subtle elevation changes

## Design Intent
The narrow corridor constrains physical movement while the axioms describe entropy as **freedom**. This tension embodies the paradox: we use deterministic algorithms (constrained, ordered) to simulate randomness (free, disordered). The 1955 RAND book grounds abstract concepts in material history—randomness has always been computational labor.

## Theoretical Framework

### From Information Theory (Shannon)
- **Entropy** = bits required to encode a message
- High entropy = high unpredictability = many possible states
- The algorithm cannot search high-dimensional space exhaustively

### PRNG vs TRNG
- **PRNG** (Pseudo-Random): Deterministic sequences from seed, reproducible
- **TRNG** (True Random): Physical phenomena (thermal noise, quantum effects)
- Most computational randomness is pseudo—"deterministic chaos"

### Key Insight from Nature of Code
Randomness raises two fundamental questions:
1. "How do you define the rules that govern behavior?"
2. "How do you implement these rules in code?"
