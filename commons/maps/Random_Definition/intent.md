Concept: Defines randomness as the absence of pattern — not chaos, but the irreducibility of a sequence to a shorter description. Distinguishes pseudo-random number generation (algorithmic, deterministic, reproducible) from true randomness (physical, entropic, irreproducible).
Sequence role: Opens the Randomness sequence (E_entropy phase, 7th spine sequence). No predecessor within the sequence. Establishes the conceptual vocabulary — PRNG vs TRNG, seed, entropy source, uniform distribution — that every subsequent map assumes. The 12x12 grid format grounds randomness in the same spatial infrastructure the learner knows from earlier sequences; leads to Random_Remove.
Technical angle: PRNG algorithms (linear congruential generators, xorshift), seed initialization, RandomNumberGenerator class in GDScript, the distinction between randi(), randf(), and randf_range(). How deterministic algorithms produce statistically random output. The entropy_jar and prng_crank_machine should be analyzed as mechanical metaphors for algorithmic state progression.
Critical angle: Randomness as ontological category — is randomness in the world or in the observer? Kolmogorov complexity defines randomness as incompressibility. The 1955 RAND random number book (random_number_book_page_1955) as historical artifact: the moment randomness became a publishable commodity. The cadastral grid resists randomness because grids are order; the sequence begins by naming the tension it will explore for twelve more maps.
Key artifacts: prng_crank_machine makes the PRNG algorithm physically operable; entropy_jar collects and displays entropy as substance; trng_vs_prng stages the central distinction; random_number_book_page_1955 anchors the historical dimension; slot_machine demonstrates biased vs uniform distributions; random_butterflies show randomness in biological motion; dark_sphere persists as the control object.
Gap: No artifact explicitly demonstrates seed reproducibility — feeding the same seed and showing identical output sequences would make the "pseudo" in PRNG viscerally clear.
