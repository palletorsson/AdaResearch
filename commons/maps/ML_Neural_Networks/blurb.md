# Neural Network Pipeline

A corridor of chambers connected by bottlenecks. Data enters one end — raw, undifferentiated — and emerges the other end transformed into decision. Each chamber is a layer. Each narrow passage forces compression. Walk the architecture.

Inside, neurons pulse with activation. Weight lines thicken where signal flows strong, thin where it fades. Forward pass animation shows information reshaping itself — layer by layer, representation by representation. The network doesn't store answers. It learns *features*. Edges in one layer become textures in the next become objects in the last. Each layer throws away what doesn't matter and keeps what does.

Training is gradient descent through a landscape no one can fully see. Too much fitting and the network memorizes — collapses into rigid certainty. Too little and it learns nothing — noise without structure. Generalization lives in the narrow corridor between knowing and forgetting.
