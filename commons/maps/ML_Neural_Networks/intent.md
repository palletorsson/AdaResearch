Concept: Neural networks as function composition — layers of weighted sums and nonlinear activations stacked to approximate arbitrary mappings. Each layer transforms its input, and depth creates representational power that no single layer can achieve.
Sequence role: Fourth map in the Machine Learning sequence (15th spine sequence, integration phase). The architectural core of the sequence. Builds on ML_Classification's decision boundaries by showing how multiple layers bend and fold those boundaries into complex shapes. Connects back to classification (single-layer = linear boundary) and forward to ML_Perception (zooming into a single neuron) and ML_Sequence_Memory (adding temporal state). The perceptron in map 5 is a deliberate zoom-in after seeing the whole.
Technical angle: Forward pass as matrix multiplication plus activation. Backpropagation as reverse-mode automatic differentiation — the chain rule applied layer by layer. Activation functions (ReLU, sigmoid, tanh) as the source of nonlinearity. Universal approximation theorem: one hidden layer suffices in theory, depth helps in practice. Weight initialization, vanishing/exploding gradients.
Critical angle: A neural network is a cascade of simple functions that collectively approximate complexity — the same principle as cellular automata but with tunable parameters. The network learns representations, not rules: the hidden layers encode features no human specified. This opacity is both the power and the danger — the model works but cannot explain why, which is the central tension of the integration phase.
Key artifacts: neural_network_3d provides a three-dimensional visualization of network architecture, forward pass data flow, weight magnitudes, and activation patterns across layers.
Gap: Needs a representation visualizer showing what each hidden layer has learned to detect, making the internal features visible as the abstraction hierarchy deepens.
