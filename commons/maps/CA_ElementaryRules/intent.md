Concept: Elementary cellular automata — the simplest possible class, one dimension, two states, three-cell neighborhoods, 256 total rules. Rule 30 produces chaos from order; Rule 110 is Turing complete. The full showcase reveals the spectrum from trivial death to computational universality within a single parameter space.
Sequence role: Third map in the Cellular Automata sequence; the systematic survey after CA_1's grid introduction and CA_2's Life deep-dive. Drops from 2D to 1D to isolate the minimal ingredients of complex behavior. The sequence truth crystallizes here: Rule 110's Turing completeness proves that simple rules can compute anything. Connects forward to CA_4's totalistic generalization and back to CA_2's single-rule-multiple-behaviors theme.
Technical angle: Wolfram's elementary CA: 1D array, radius-1 neighborhood (left, center, right), 2^3 = 8 possible inputs, 2^8 = 256 rules. Rule numbering as binary encoding of the output table. Rule 30: Class III chaotic behavior, used as a pseudorandom number generator (Mathematica). Rule 110: Class IV complex behavior, proven Turing complete by Matthew Cook (2004). The structure_growth artifact shows how pattern complexity evolves over time steps.
Critical angle: Wolfram's classification (Class I-IV) parallels Langton's lambda parameter and Kauffman's NK model — all converge on the same insight: complexity lives at the boundary between order and chaos. Rule 110's Turing completeness is the sequence's deepest result: a one-dimensional, two-state, nearest-neighbor automaton can simulate any computation. Simplicity is not a limitation; it is sufficient.
Key artifacts: structure_growth demonstrates how elementary CA patterns develop over successive generations, revealing class behavior; dark_sphere anchors the research space.
