A grid is a line that learned to turn. One axis gives sequence — left to right, start to finish. Add a second axis and sequence becomes space. The 2D array maps every cell to a pair of coordinates: column and row, X and Y. Two numbers to name any point on a plane.

Navigate the grid. Dark spheres pulse at intersections, slow-rotating markers that breathe purple light across a 7×9 field. Each one sits at an address — a pair of integers that locate it in two-dimensional space. Move along X, the world shifts horizontally. Move along Y, it shifts vertically. Combine both and you can reach anywhere.

One dimension is a story. Two dimensions is a territory. The moment you add a second axis, you stop reading and start mapping.
