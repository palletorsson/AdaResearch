# Museum AAA Featured Pass — Technical

The map is generated by:

```powershell
python tools/compose_map_from_dressing_rooms.py `
  --name Museum_AAA_Featured_Pass `
  --rooms origin lambda_slider phi_slider platonicsolids --png
```

The composer rotates complete dressing-room tile arrays, applies artifact-local `#key:value` variants, stamps utilities, and uses A* only between room interfaces. It never routes through reserved room territory.

The same source contracts build the individual maps and the connected pass; no placement is duplicated by hand. Phi adds a support-height rule: a floorplan offer fails even when its room is large enough if it cannot supply a 0.9–1.1 m host surface.
