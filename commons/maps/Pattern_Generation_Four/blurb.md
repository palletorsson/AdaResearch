An 8×8 grid sits inside a 12×12 frame. Sixty-four cells. Each one a coin flip, a dice roll, a weighted draw from some distribution the learner controls. Algorithms compete here — not for speed, but for texture. What pattern does pure randomness produce? What happens when you bias it? Constrain it? Layer one stochastic process over another?

Fabrics stretch across the grid. Each cell's state rendered as material — color, weave, density shifting with every generation. The arena makes chance tactile. Run the same algorithm twice: different output. Run a different algorithm once: different *kind* of different.

Randomness is not the absence of pattern. It is pattern's raw material — the thing structure metabolizes to become itself.
