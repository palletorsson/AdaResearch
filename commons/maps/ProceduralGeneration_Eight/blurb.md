# Procedural Generation 8

An 8×8 grid nested inside a 12×12 frame. The arena where randomness performs. Grab a stick and poke the system — watch cells flip, patterns emerge, dissolve, re-emerge. The mirror takes flat cellular textures and folds them into three dimensions, proving that surface rules generate volume. The rhizomatic maze grows not from a blueprint but from local decisions, each cell choosing its walls based on neighbors and chance.

Eight algorithms. Same grid. Different behaviors. One seed produces a labyrinth, another produces fog. The arena doesn't care which algorithm wins — it cares that each one reveals a different relationship between constraint and freedom. Order is not opposed to randomness here. Order is what randomness builds when given a frame to push against.
