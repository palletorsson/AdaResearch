# PG: Genetic Programming

Programs that write programs. Not fixed code — living syntax trees where each node is an operation, each branch a possible computation. Standard genetic algorithms evolve strings of parameters. Genetic programming evolves *structure itself*. The genome is executable.

Expression trees undergo subtree crossover — a branch severed from one parent, grafted onto another. Not blending, not averaging. Surgical recombination of functional parts. A sine function mating with a polynomial. Offspring that compute things neither parent could. Symbolic regression finds equations that fit data not by fitting coefficients but by discovering the equation's shape from nothing.

The fitness landscape isn't numeric. It's syntactic. Selection pressure acts on meaning. Mutation doesn't tweak a value — it rewrites a verb. When the unit of evolution becomes the program itself, the distinction between code and creature dissolves.
