# Intent

A row can wait for an answer, a rug can impose symmetry, and a network can retain a growth history. Let the visitor arrive in time to see the last unfold. A finite saved history should not pretend that growth exhausted all possibilities.

Let the row’s wrapped boundary become visible around the visitor. The overhead ring reads the same state and history as the desk; it adds no second automaton. Standing inside a drawn neighbourhood does not yet make the body an input to its rule.
