# Fractals_13 - Mandelbrot Set

## Overview
Fractals_13 presents the Mandelbrot set—perhaps the most famous fractal, the "fingerprint of God," the infinitely complex boundary of a simple iteration. The formula z = z² + c, iterated from z=0, produces a set whose boundary contains infinite detail at every scale. This is the culmination of the fractals sequence: the icon of complexity from simplicity.

- **Dimensions**: 7×8 grid

## Learning Sequence
1. Player enters and encounters the Mandelbrot set
2. Observes the familiar shape—the cardioid, the bulbs
3. Zooms into the boundary (if interactive)
4. Discovers: infinite detail at every scale
5. Recalls Julia sets—the Mandelbrot indexes them all
6. Understands: maximum complexity at the edge
7. Exits to conclude with stochastic synthesis

## Design Intent
The map presents the **culminating fractal**—the set that summarizes complex iteration. The Mandelbrot set is not just another fractal; it is a map of all quadratic Julia sets, an index of infinite complexity, a demonstration that five characters of formula can contain unbounded structure.
