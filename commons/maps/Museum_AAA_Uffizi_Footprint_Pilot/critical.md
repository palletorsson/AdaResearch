# Architecture is an offer, not an alibi

Starting with the Uffizi does not mean treating historical architecture as neutral authority. Its ordered corridor distributes movement, attention, and prestige before any computational artifact arrives. The long axis promises hierarchy; the side rooms make stopping optional; the end-stop announces that one object deserves to pull every body forward.

The negotiation layer makes that prior decision visible. It protects circulation, but it also records when a room must change because the collection contains bodies and operations that the inherited type did not anticipate. The neural network cannot be miniaturized merely to preserve an eight-metre Renaissance-derived bay. The bay expands outward while the shared route remains legible.

This is the useful tension: neither artifact nor architecture is sovereign. The artifact cannot colonize the corridor, and the corridor cannot disguise exclusion as proportion. Every accommodation becomes an inspectable rule trace rather than an aesthetic intuition applied after the fact.
