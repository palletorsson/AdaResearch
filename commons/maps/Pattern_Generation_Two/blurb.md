# Pattern Generation 2

An 8×8 grid sits inside a 12×12 frame. The arena floor. Algorithms compete here — not for speed, but for pattern. Wave Function Collapse builds structure from constraint, assembling tiles that satisfy local rules until global order emerges from nothing. Each run different. Each run coherent.

Dark spheres pulse at the edges, purple light breathing slow. Ambient catalysts. The grid is the canvas; randomness is the brush. But randomness alone produces noise. The trick is constrained randomness — freedom within rules, chaos that resolves into form.

This is where order and disorder negotiate. Not one winning over the other, but both held in tension on a 64-square stage. The pattern was never designed. It was grown.
