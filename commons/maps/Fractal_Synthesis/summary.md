# Fractals_10 - Julia Sets

## Overview
Fractals_10 introduces the Julia set—the fractal generated by iterating z² + c with a fixed c value. Where the Mandelbrot set asks "for which c values does iteration remain bounded starting from z=0?", the Julia set asks "for which starting z values does iteration remain bounded for a fixed c?". Each c produces a different Julia set, forming an infinite family of fractals.

## Learning Sequence
1. Player enters and observes the Julia set
2. Notes the boundary complexity—neither inside nor outside
3. Explores different c values (if interactive)
4. Sees connected vs. disconnected Julia sets
5. Understands: c inside Mandelbrot → connected Julia; c outside → disconnected
6. Grasps the relationship between Mandelbrot and Julia
7. Exits to explore recursive trees in new contexts

## Design Intent
The map introduces **parameter space**—the idea that a family of fractals exists, indexed by a complex parameter c. Each point in the Mandelbrot set corresponds to a unique Julia set. The Julia set is the Mandelbrot's complement: where Mandelbrot maps c-space, Julia maps z-space for fixed c.
