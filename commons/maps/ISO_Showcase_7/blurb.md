# ISO Showcase 7 — Base MC + Animated Noise

Noise evolves. The isosurface chases it.

A scalar field fills the volume — dense here, hollow there. Marching cubes walks the grid, case by case, extracting geometry wherever the field crosses threshold. That's the base implementation: 256 configurations, one lookup table, mesh out. Static noise produces static caves.

Now animate the noise. The field breathes — density shifts, thresholds migrate, surfaces ripple and reform. Sliders control the parameters: noise scale, iso level, chunk resolution. Scroll through presets and watch caves become coral become bone become nothing. The gallery holds sculptures side by side, each a frozen moment from a different configuration space. Toggle island tracing to see how one continuous field fragments into disconnected forms.

The surface was never there. It was always a question the algorithm kept asking — and the answer kept changing.
