A cube of cells, each alive or dead, each surrounded by twenty-six neighbors. The rules are the same as the flat grid — birth, survival, death — but the third dimension changes everything. Complexity doesn't add. It multiplies.

The cube breathes. Layers stack and dissolve. Structures crystallize inward, then burst outward — coral, cathedral, tumor. The same rule that produces a stable blinker in 2D generates architecture in 3D. Space itself becomes a variable. More room to grow means more ways to die.

Watch the generations accumulate. Each layer is a fossil record of the rule's appetite. The automaton doesn't know it has depth — it only counts neighbors. But depth knows it has the automaton. A flat law, given volume, discovers forms it was never told to make.
