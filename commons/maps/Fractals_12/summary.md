# Fractals_12 - Fractal Scene

## Overview
Fractals_12 presents a composed scene of multiple fractal elements—a landscape populated by recursive structures. Where previous maps isolated individual fractals for study, this map combines them into an environment. The result is a computed wilderness: algorithm as ecology.

## Spatial Layout
- **Dimensions**: 7×8 grid
- **Architecture**: Flat terrain allowing free movement among fractals
- **Height**: Single level

## Key Elements

### Interactables
- **Fractal Scene** (1,1) - Composed arrangement of multiple fractals
- **Recursive Tree 2** (3,3) - Variation on the recursive tree theme
- **Dark Sphere** (3,2) - Ambient lighting element

### Utilities
- **Teleporter** (5,6) - Exit to Fractals_13

## Atmosphere
- **Background**: Sky blue [0.2, 0.3, 0.7]
- **Lighting**: Warm directional with cool ambient
- **Mood**: Immersive, environmental, computed nature

## Learning Sequence
1. Player enters a populated space
2. Moves through multiple recursive trees
3. Observes how the same rules create a "forest"
4. Notes variation through parameter differences
5. Experiences fractals as environment, not specimen
6. Understands: algorithms can compose into ecologies
7. Exits to encounter the Mandelbrot set

## Design Intent
The map transitions from **study to immersion**. Previous maps presented fractals as objects of analysis. This map presents them as habitat—surrounding, enveloping, navigable. The same recursive rules that generate individual trees can generate forests.

## Connection to Sequence
- **Position in fractals sequence**: 12/14
- **Precedes**: Fractals_13 (Mandelbrot Set)
- **Follows**: Fractals_11 (Inverted Trees)
- **Establishes**: Fractal composition, algorithmic landscape, computed ecology
