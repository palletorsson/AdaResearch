# Maximum Flow Algorithms

A 12×12 grid. An 8×8 arena inside it. Algorithms enter, roll dice, build terrain. Gaussian distributions raise geometry into bell curves. Random walks trace drunk paths through cube-space. Height fields mutate. Profiles generate. Objects scatter according to patterns — grid, circle, line — or no pattern at all.

Each algorithm uses randomness differently. The walk accumulates. The distribution clusters. The remover subtracts. The sculptor shapes fluid masses from noise. Same source — pseudorandom numbers — different constraints, different worlds. A random walk with 128 steps builds mountains. A Gaussian with tight sigma builds hills. Loose sigma builds chaos.

This is the arena where order negotiates with chance. Not randomness as absence of structure, but randomness as raw material. The grid doesn't care what you build. The dice don't care either. Structure is what happens when something cares enough to listen.
