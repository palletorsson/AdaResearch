An irregular room. Void nodes scattered across the floor without pattern. No obvious hierarchy, no clean rows, no symmetry. Connections between platforms run in every direction. This is not a tree. This is a graph.

A graph is pure relation without hierarchy. Nodes and edges — that is all. No root, no leaves, no parent-child constraint. Any node can connect to any other. The structure admits cycles, disconnected components, weighted paths, directed flow. It is the most general data structure: every tree is a graph, every linked list is a graph, but a graph is not necessarily either.

The room refuses to organize itself for you. There is no natural traversal order, no obvious starting point. You must choose — breadth-first or depth-first, Dijkstra or Bellman-Ford. The structure does not prescribe the algorithm. It only offers relation, and leaves the rest to you.
