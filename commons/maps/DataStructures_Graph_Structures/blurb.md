# Graph Nodes Arena

Nodes scattered across an irregular room. No grid, no hierarchy, no sequence — just points in space and the connections between them. A graph is the most general data structure: anything can link to anything. Trees are graphs with rules. Lists are graphs with constraints. Strip the constraints and what remains is pure relation.

Walk between void nodes. Each one exists only through its edges — remove every connection and the node becomes unreachable, structurally dead but still present. The room's topology shifts with each link added or severed. Randomness built the terrain beneath: gaussian heights, random walks, procedural profiles all constructing ground that refuses regularity. The graph sits on chaos and imposes just enough structure to stay navigable.

Graphs don't minimize entropy. They negotiate it — every edge a local decision, every path an emergent consequence no single node intended.
