# PG Space Colonization

Scatter points in space. Call them attractors. Drop a seed. The nearest branch segment reaches toward the nearest attractor. When it gets close enough, the attractor dies. New segments sprout. The tree grows not from a blueprint but from hunger — each branch extending toward whatever nourishment remains.

Adam Runions published the algorithm in 2007, borrowing from how real auxin transport guides leaf venation. The math is simple: find nearest, step toward, kill when reached, repeat. The complexity is emergent. No two runs produce the same tree. The branching pattern is a fossil record of the attractor distribution — geometry remembering what it consumed.

Walk the corridor alongside the growth. Watch the tree solve a problem no one posed. Structure without intention. A body built entirely from appetite.
