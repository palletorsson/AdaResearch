# Bricolage_Affordances - Summary

## Overview

This map transforms the question from "what IS this part?" to "what can this part DO?" Following James Gibson's affordance theory, each primitive reveals its action potential—not category but capability. A cylinder isn't merely cylindrical; it can be load-bearing (column), spanning (beam), rotating (axle), or conducting (tube).

Same warm workshop lighting as Inventory map—continuity of space. The demonstration stations are spaced to allow examination of each affordance in turn. The pairing (column/axle, seat/wall, joint/hub) emphasizes that the same primitive can serve radically different functions.

## Learning Sequence

1. Read affordance_catalog_axioms clipboard—understand the theoretical frame
2. Examine cylinder demonstrations: same shape, different functions (column vs axle)
3. Pass through dark_sphere—moment of synthesis
4. Examine plane demonstrations: orientation determines affordance (seat vs wall)
5. Examine sphere demonstrations: topology enables connection (joint vs hub)
6. Recognize: affordance is activated by context, not inherent to shape
7. Exit to Arrays as Probes—how repetition reveals affordance

## Design Intent

The paired demonstrations (same primitive, different use) make the core insight visceral: affordance is relational, not essential. A cylinder "becomes" a column when placed vertically under load; it "becomes" an axle when placed horizontally with rotation. The part doesn't change—the context does.

## Theoretical Framework

### Gibson's Affordances
J.J. Gibson (1979) defined affordances as action possibilities that exist in the relationship between agent and environment. A chair affords sitting for a human, climbing for a child, hiding for a cat. The affordance isn't in the object or the agent—it's in their meeting.

### Applied to Primitives
Each primitive carries multiple latent affordances:
- **Cylinder**: column (vertical support), beam (horizontal span), axle (rotation), tube (passage)
- **Plane**: seat (horizontal support), wall (vertical barrier), shelf (storage), ramp (transition)
- **Sphere**: joint (articulation), hub (connection), roller (motion), cap (termination)

Context—including orientation, neighboring parts, and intended use—activates specific affordances while suppressing others.
