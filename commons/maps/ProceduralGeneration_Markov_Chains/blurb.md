# PG: Markov Chains

A system with no memory. The current state is all that exists — the past is irrelevant, the future is a weighted coin flip. Transition matrices encode probability: from any state, a set of possible next states, each with a weight. Roll the dice. Move. Roll again. The chain has no plan, no goal, no history. Only now, and what comes next.

States float as nodes in space. Probability arcs connect them — thick lines for likely transitions, thin for rare. A selector spins and lands. The chain walks. Over thousands of steps, something emerges: the stationary distribution, a stable pattern no single step intended. Structure assembles from pure chance, given enough repetition. A tree grows by the same logic — branch, terminate, or keep growing, each decision a state transition. Low randomness produces rigid symmetry. High randomness produces tangles. The sweet spot between them grows something that looks alive.

Memorylessness is not emptiness. It is the minimum condition for emergence — a system that cannot remember, yet converges.
