Concept: Recurrence as memory — when a network's hidden state feeds back into itself, the present computation carries traces of the past. Sequence processing requires the network to remember, and the hidden state is where memory lives.
Sequence role: Sixth map in the Machine Learning sequence (15th spine sequence, integration phase). Introduces the temporal dimension that was absent from feedforward networks. After ML_Perception showed the static neuron, this map adds the recurrent connection that makes the neuron aware of history. Connects back to ML_Neural_Networks (feedforward architecture) and forward to ML_Generative (where memory enables generation). The hidden state concept bridges to QFEP's phi term — sensitivity to rate of change.
Technical angle: Recurrent neural networks (RNNs) with hidden state h(t) = f(W_h * h(t-1) + W_x * x(t)). Backpropagation through time (BPTT) unrolls the recurrence into a deep feedforward network. Vanishing and exploding gradients in long sequences. LSTM gates (forget, input, output) as learned memory management. GRU as a simplified gating mechanism.
Critical angle: Memory transforms a function into a process — the same input produces different outputs depending on what came before. This is the computational form of context-dependence, which is also the condition of meaning. A word means nothing without the sentence; a note means nothing without the phrase. Recurrence is how machines begin to approximate the temporal thickness of experience that Brouwer's intuitionism insisted was foundational to mathematics itself.
Key artifacts: rnn_visualization provides an interactive recurrent network showing hidden state evolution over time, gate activations in LSTM cells, and the effect of sequence length on gradient flow.
Gap: Needs a vanishing gradient artifact — a visualization showing gradient magnitude decaying exponentially as it propagates backward through time steps, making the memory limitation concrete.
