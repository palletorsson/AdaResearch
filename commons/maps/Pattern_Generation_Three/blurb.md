# Pattern Generation 3

A 12×12 grid. An 8×8 arena at its center. Three pattern generators compete for the same space — Wave Function Collapse, Truchet tiles, procedural noise. Each algorithm takes identical input and produces radically different structure. Same constraints, different worlds.

WFC propagates local rules until global order emerges from nothing. Truchet rotates simple arcs into labyrinths. The dark sphere pulses at the edge, marking the threshold between calculated form and something stranger. Touch each generator. Watch the 8×8 region fill. Compare what "random" actually means when different logics govern it.

Randomness is never neutral. Every algorithm encodes a politics of pattern — what it permits, what it suppresses, what it calls order. The arena doesn't ask which is best. It asks which assumptions you're willing to inhabit.
