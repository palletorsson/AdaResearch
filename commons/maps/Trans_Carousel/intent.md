Concept: A rotation can be applied by a rule instead of once. If each of eight stacked layers turns 1.2 times faster than the layer under it, the top layer turns 1.2^7, about 3.6 times as fast as the bottom. Speed builds up as a geometric progression.
Sequence role: Follows Trans_Rotation, which turned bodies and paths around a centre. This floor turns the rate. It also comes before Trans_Scale, because a ratio applied layer after layer is how scale works too.
Centre: "Together": all eight layers turn at one speed (multiplier 1). A carousel_ring circles it with a ball and handle, so a visitor can move at the ring's own speed beside a machine where nothing gains on anything.
Flanks: "Cake" uses the rule as stated (1.2 per layer). "Opposed" keeps the same rule but alternates direction, so neighbouring layers turn against each other.
Profiles: "Spindle", "flare", "ziggurat" and "column" keep the speed rule and change the silhouette. Flare widens and ziggurat narrows as segment counts step up the stack. Column keeps one radius, so only speed tells its layers apart. The caption on each names what changed.
Critical angle: A still image shows the stack but not the rate. Only watching, or riding the ring, shows the progression, so this hall argues through time, not shape. The profiles risk making it look like the silhouette is the point. It is not: the multiplier is.
Evidence: The floor stands in the Void tower as floor 17 (commons/void/rooms.json, map Trans_Carousel, committed 6f6d7f9db). There is no grid map_data.json for this hall yet, and nobody has walked it in the headset.
