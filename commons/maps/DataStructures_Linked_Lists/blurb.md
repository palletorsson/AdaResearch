# Linked List Chain

Each node holds one thing and knows one address — the next node. No index, no random access, no overview. To find the fifth element, start at the head and walk four links. The chain is its own map.

A 13×5 corridor of rooms connected by narrow passages. One way forward, one way back. Insert a room: repoint two links. Delete one: bridge the gap. The geometry *is* the data structure — linear, sequential, legible only by traversal. Random walks carve the terrain; Gaussian distributions shape what rises from the grid. The space builds itself procedurally, node by node, the way a list allocates.

Arrays know where everything is. Linked lists know only what comes next. This is the first trade: omniscience for flexibility. Structure without surveillance.
