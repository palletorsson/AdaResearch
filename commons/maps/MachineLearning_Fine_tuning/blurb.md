A 12×12 grid. An 8×8 arena inside it. Algorithms fight for space using randomness as their only weapon.

Gaussian distributions sculpt terrain into bell-curved landscapes. Random walks trace drunk paths across the grid, raising cubes wherever they stumble. Height maps roll dice for every cell. Profiles generate jagged skylines from pure noise. Objects spawn, scatter, vanish — removed at random, placed at random, rotated into patterns that dissolve on the next pass. Each algorithm reshapes the same grid differently. Same substrate, different stochastic signature.

Randomness is not the absence of structure. It is structure's raw material — the thing that exists before decisions get made. Every procedural world begins here: in the gap between a coin flip and a landscape.
