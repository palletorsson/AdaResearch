# InfoBoard Visualizations

Standalone visualization scenes and scripts shared across info boards.

## Key Files
- `RandomWalkVisualization.gd` — AlgorithmVisualizationBase subclass showing walker position, trail points, grid overlay with wrapping boundaries
- `polyhedra_showcase.gd` — Creates platonic solids (tetrahedron, cube, octahedron, dodecahedron, icosahedron) and Johnson solids
- `polyhedron_nets.gd` — 2D net visualizations for polyhedra with animated fold progress control
- `polyhedra_showcase.tscn` — Scene for platonic solids showcase
- `polyhedra_showcase_johnson.tscn` — Scene for Johnson solids showcase
- `polyhedron_nets.tscn` — Scene for polyhedron net fold animation
- `polyhedron_nets_cube.tscn` — Cube-specific net visualization
