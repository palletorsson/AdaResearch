# Point InfoBoard

Educational info board on point geometry — the fundamental building block.

## Key Files
- `PointInfoBoard.gd` — Hardcoded content pages on point definition, visualization, sizes, instantiation, labels, dynamic points
- `PointInfoBoard_Refactored.gd` — Refactored version loading content from centralized JSON; includes play/pause and speed controls
- `PointVisualizationControl.gd` — Visualizes origin point, example points, size variations, instantiation process, labeled points, and dynamic point animation
- `PointInfoBoard.tscn` — Combined layout with text and visualization
- `2d_in_3d_point_vis.tscn` — 2D point visualization in 3D viewport
