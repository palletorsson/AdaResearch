# Random Walk InfoBoard

Educational info board on random walk algorithms and their history.

## Key Files
- `RandomWalkInfoBoard.gd` — AlgorithmInfoBoardBase subclass with pages on random walk fundamentals, historical context (Pearson, Einstein, Bachelier), 1D/2D/3D behavior, return probabilities
- `RandomWalkInfoBoard.tscn` — 3D handheld board using HandheldInfoBoard base
- `RandomWalkInfoBoardUI.tscn` — UI template for the board
