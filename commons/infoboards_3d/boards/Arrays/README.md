# Arrays InfoBoard

Educational info board covering 1D, 2D, and 3D array concepts.

## Key Files
- `ArrayInfoSheet.gd` — Content pages on array fundamentals with code examples
- `ArrayVisualizationControl.gd` — Interactive visualization showing array layouts with animated element highlighting and iteration patterns
- `ArrayInfoBoard.tscn` — Combined layout with left text panel and right visualization area
- `2d_in_3d_array_vis.tscn` — 2D array visualization embedded in 3D viewport

## Topics Covered
1D arrays, 2D grids, 3D arrays, element access, iteration patterns.
