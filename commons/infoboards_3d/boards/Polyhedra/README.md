# Polyhedra InfoBoard

3D visualization of platonic solids and Johnson solids.

## Key Files
- `PolyhedraVisualizationControl.gd` — Uses SubViewport and Camera3D to render rotating platonic solids (tetrahedron, cube, octahedron, dodecahedron, icosahedron), nets, and Johnson solids
- `PolyhedraVisualizationControl.tscn` — Container scene with SubViewport setup
