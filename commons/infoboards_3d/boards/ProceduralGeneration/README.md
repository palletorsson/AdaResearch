# Procedural Generation InfoBoard

Educational info board covering procedural generation techniques.

## Key Files
- `ProceduralGenerationInfoBoard.gd` — AlgorithmInfoBoardBase subclass with pages on noise terrain, L-systems, BSP dungeons, cellular automata
- `ProceduralGenerationInfoSheet.gd` — Content sheet with code examples for each technique
- `ProceduralGenerationVisualization.gd` — Visualization with noise terrain, L-system plant drawing, BSP dungeon layout
- `ProceduralGenerationVisualizationControl.gd` — Extended visualization with terrain grid coloring (water/beach/grass/forest), L-system string interpretation, dungeon grid rendering
- `ProceduralGenerationInfoBoard.tscn` — Combined board scene
- `2d_in_3d_proceduralgeneration_vis.tscn` — 2D visualization in 3D viewport

## Topics Covered
Noise-based terrain, L-systems, BSP dungeon generation, cellular automata.
