# Unit Circle InfoBoard

Educational info board on the unit circle and trigonometric wave functions.

## Key Files
- `UnitCircleInfoBoard.gd` — AlgorithmInfoBoardBase subclass with pages on unit circle definition, sine/cosine/tangent, phase relationships, combined waves
- `UnitCircleVisualization.gd` — Visualizes rotating point on unit circle, sine/cosine/tangent wave graphs, and wave superposition
- `UnitCircleInfoBoardUI.tscn` — UI template for the board
- `2d_in_3d_wave_vis.tscn` — 2D wave visualization in 3D viewport
