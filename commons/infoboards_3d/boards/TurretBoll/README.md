# TurretBoll InfoBoard

Static canvas demonstrating vector operations through a turret-to-ball targeting scenario.

## Key Files
- `TurretBollInfoSheet.gd` — Draws vector operations from turret position to ball position: subtraction, magnitude, normalization, addition with range visualization
- `TurretBollInfoBoard.tscn` — Board scene template
- `2d_in_3d_turretboll_vis.tscn` — 2D visualization in 3D viewport
