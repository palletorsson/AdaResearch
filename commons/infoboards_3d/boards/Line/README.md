# Line InfoBoard

Educational info board on line geometry concepts.

## Key Files
- `LineInfoBoard.gd` — Content pages on connecting points, direction, magnitude, and lines as cylinder primitives
- `LineVisualizationControl.gd` — Visualizes basic lines, direction/magnitude arrows, cylinder representation, and multiple lines with animation
- `LineInfoBoard.tscn` — Uses UniversalInfoBoard with `board_id="line"`
- `LineVisualizationControl.tscn` — Container scene for the visualization
