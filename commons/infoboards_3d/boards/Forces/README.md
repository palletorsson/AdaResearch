# Forces InfoBoard

Educational info board on physics forces — gravity, friction, attraction, wind.

## Key Files
- `ForcesInfoBoard.gd` — Content pages extending AlgorithmInfoBoardBase with physics explanations and code examples
- `ForcesVisualization.gd` — AlgorithmVisualizationBase subclass showing particles, attractors, repellers, force vectors, and flow fields
- `ForcesVisualizationControl.gd` — 2D Control-based variant for particle motion, vector addition, and force field display
- `VRScrollTest.gd` — Test script validating VR scroll input on the Forces board
- `ForcesInfoBoard.tscn` — 3D handheld board with HandheldInfoBoard base
- `ForcesInfoBoard_new.tscn` — Updated version with improved VR input handling
- `ForcesInfoBoard_old.tscn` — Legacy version kept for reference

## Topics Covered
Gravity, friction, attraction/repulsion, wind forces, force vectors, flow fields.
