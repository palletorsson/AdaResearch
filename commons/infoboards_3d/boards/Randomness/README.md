# Randomness InfoBoard

Educational info board on types of randomness and distributions.

## Key Files
- `RandomnessInfoSheet.gd` — Content pages covering uniform distribution, Gaussian distribution, random walks, and Perlin noise with code examples
- `RandomnessVisualizationControl.gd` — Visualizes histograms, particle cloud behavior, random walker paths, and Perlin noise mesh with animated values
- `RandomnessInfoBoard.tscn` — Combined board scene
- `2d_in_3d_randomness_vis.tscn` — 2D randomness visualization in 3D viewport
