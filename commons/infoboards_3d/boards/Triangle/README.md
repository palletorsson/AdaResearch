# Triangle InfoBoard

Educational info board on triangle geometry — the foundation primitive.

## Key Files
- `TriangleVisualizationControl.gd` — Visualizes triangles with 3 vertices, normal vectors, area calculation, mesh triangulation, and triangles as the fundamental rendering primitive
- `TriangleInfoBoard.tscn` — Combined board scene
- `TriangleInfoBoardUI.tscn` — UI template
- `TriangleVisualizationControl.tscn` — Container scene for the visualization
