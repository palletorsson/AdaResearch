# Wave InfoBoard

Educational info board on wave functions and the unit circle.

## Key Files
- `WaveInfoSheet.gd` — Content pages on unit circle, sine/cosine/tangent functions, and combined waves
- `WaveVisualizationControl.gd` — Visualizes unit circle rotation, sine wave, cosine wave, tangent wave, and combined wave superposition
- `WaveInfoBoard.tscn` — Board scene template
