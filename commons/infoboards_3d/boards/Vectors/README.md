# Vectors InfoBoard

Comprehensive educational info board on vector mathematics.

## Key Files
- `VectorsInfoBoard.gd` — AlgorithmInfoBoardBase subclass with pages on vector basics, addition/subtraction, scalar multiplication, magnitude, normalization, physics applications
- `VectorsInfoSheet.gd` — Content sheet covering introduction, addition, scalar multiplication, forces, and field visualization
- `VectorsVisualization.gd` — Particle-based visualization with forces, velocity trails, and field vectors; supports multiple visualization types (intro, addition, multiplication, forces, fields)
- `VectorsVisualizationControl.gd` — Basic vector visualization with duality, subtraction, magnitude, normalization, and line definition demonstrations
- `VectorsTest.gd` — Test script that instantiates and validates the board
- `VectorsInfoBoard.tscn` — Combined board layout
- `2d_in_3d_vectors_vis.tscn` — 2D vector visualization in 3D viewport
