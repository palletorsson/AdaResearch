# Dialectic Content

JSON-based dialectic panel definitions for educational content.

## Purpose
Contains structured JSON files with thesis/counter/critique/pragmatic argument patterns. These are loaded by `DialecticPanelGenerator.gd` (in `content/`) which spawns color-coded text panels along the Z-axis in 3D space.

## Structure
Each JSON file defines a dialectic with multiple positions (thesis, counter-thesis, critique, pragmatic resolution), rendered as color-coded 3D panels.
