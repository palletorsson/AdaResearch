Ada / Visual teaching studies · 4 October 2026

Let the change become visible.

Six interactive comparisons and a picture plan for every hall in the first four sequences.

The photographs come from the Endless Museum. The diagrams let you try proposed teaching comparisons here in the browser. Their controls have not been installed in the museum.

Move → predict → compare → inspect the value → use it again. Keep the body and its consequence in the foreground; bring in the code when it explains what changed.

01 / Variables · values · coordinates · diagnosis

A value places a body.

Interactive teaching sketch · proposed comparison

Do / compare In the hall: move the held point along one named direction. In the sketch: change Y while radius, X and Z stay fixed.

What becomes legible See the difference between the value, its reference frame and the object receiving it.

What this representation leaves out

The sketch supplies the visible sphere. The sphere is a representation of a point; a position value alone does not draw anything.

02 / Conditions · arrays · loops

A movement becomes a record.

Interactive teaching sketch · proposed comparison

Do / compare Stop the pen; move it a little; move it farther. Then read and join the retained neighbours one pair at a time.

What becomes legible The condition decides whether to keep a position. The list retains it. A later loop draws relations between entries.

What this representation leaves out

This reduced candidate sequence is an explanatory model. The museum pen also shapes samples; the diagram is not a replay of a captured stroke.

03 / Execution · events · retained state

A response can remember.

Interactive teaching sketch · proposed comparison

Do / compare Approach, then leave. Compare a response that follows current distance with a change that remains. Step the clock separately.

What becomes legible Repeated execution, current input and stored history produce different outcomes.

What this representation leaves out

Two schematic gates make the comparison legible; the museum has distinct responsive and retained-change works. One image does not prove the update logic.

04 / Functions · inputs · returned data

One rule makes a family.

Interactive teaching sketch · proposed comparison

Do / compare Keep one column fixed. Change only the other column’s height or radial count. Walk around the museum forms to compare their facets.

What becomes legible The same operation can return different position lists when its inputs change. The unchanged reference makes that change inspectable.

What this representation leaves out

This diagram uses a straight two-ring profile and a supplied surface builder. The museum columns have richer profiles; their different shapes are not caused by resolution alone.

05 / Indexed reads · writes · traversal

An address survives an absence.

Interactive teaching sketch · proposed comparison

Do / compare Select a slot, change its occupancy, look elsewhere, then return. Run a rule over the whole array and compare its reach.

What becomes legible Selection reads an address; assignment changes a value. An empty slot retains its index.

What this representation leaves out

The diagram is a small displayed occupancy record. It does not claim that the museum floor stores colours or occupancy in exactly this form.

06 / Classes · objects · references

The same methods, separate lives.

Interactive teaching sketch · proposed comparison

Do / compare Advance palette A while B keeps its index. Then compare two references to one Palette and explicitly refresh both receivers.

What becomes legible Independent instances share a definition, not their changing state. Two references can instead lead to the same object.

What this representation leaves out

Palette is a proposed learner class. The museum already has colour records and receivers; this class and its student binding are not installed. Both browser previews explicitly read after every action.

Let the room keep its life.

Not every idea needs a new exhibit or a permanent label. Use the existing object, a controlled contrast and an optional step-through view. A temporary highlight can reveal a loop or reference, then disappear so the student can compose with the result.

Pictures make relations inspectable; understanding still needs the student to predict an unfamiliar case and explain what happened. Scope, execution and reference ownership require the small code connection as well as the visible consequence.
