# ISO_FlatTerrain

**Desire.** Find a place beneath the apparent ground and determine what description made it possible.

**Route / writing move.** Keep the gold column through one-crossing hills before INTERIOR. Let the side view and changed crossing count reveal something missed from above; the second specimen should then add a different compositional inquiry.

**Encounter to lean on.** `mc_flat_landscape` asks “How many times can the ground be above the same place?” `mc_overhang_landscape` adds terms whose names can guide looking without guaranteeing an arch.

**Explain / linger.** Explain why a height function alone has one answer, and why a three-dimensional term can change that. Protect the distinction between fixed height function and changing final skyline. Twenty-five-by-twenty-five column tests describe sampled triangle intersections, not every route.

**Rhythm beside its neighbors.** Sculpting concentrated on local gesture and history; this hall invites a slower orbit below a landscape. Portal Landscape will repeat the amber field alone, so leave that return a narrower, purposeful comparison.
