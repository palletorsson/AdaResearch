Primitives_Columns

One rule makes a family

One angular rule makes two straight columns. A fixed four-sided, two-metre reference stands beside editable height and radial count; the two-ring position list stays visible in the geometry.

SIDES cycles 4, 6, 8, 12 and 16. LOWER / RAISE changes height. The other column remains four-sided and two metres tall.

What the study represents

Port of the Function browser study, not the museum's richer profile generator. Height 1–3 m in 0.1 m steps; radial counts 4, 6, 8, 12, 16. A declared 0.70 m display radius replaces browser pixels. Side faces and top cap only. Rendering duplicates corners for flat normals; the input list contains exactly 2*n positions.

Point_Coordinates

A value places a body

A native sphere responds to the browser study's height value; an optional mistaken one-metre offset separates its displayed and expected positions. Four physical controls lower, raise, toggle the offset and reset.

LOWER / RAISE changes Y by 0.1 m. FRAME compares the extra one-metre offset. RESET returns to 1.2 m.

What the study represents

A faithful port of drawPoint, with height 0–3 m in 0.1 m steps and default1.2 m. A visible representation of a point, not a controller for the existing museum coordinate artifact. The +1 m is an incorrect value sent to a local receiver.

Point_Trace

Read a candidate. Keep a position. Join a pair.

Eight given positions become a retained list by the exact distance >=0.8 m test. The learner reads candidates and separately joins retained neighbours, with both route and stored list visible in 3D.

READ NEXT tests the next candidate against the last kept position. JOIN PAIR connects the next retained neighbours. RESET clears the study.

What the study represents

Fixed candidates from the browser study, not live hand tracking or a replay of a museum drawing. Two-dimensional source positions are embedded on a 3D table with equal units; joining does not alter those positions.

Godot scene

Trans_Body

A response can remember

A teaching clock moves a cube while two physical gate models compare present proximity with a retained visit. FRAME, APPROACH / AWAY and RESET let the visitor separate the events.

FRAME advances the teaching clock by 0.5 seconds. APPROACH / AWAY compares a current response with a remembered visit. RESET clears both.

What the study represents

Exact State browser-study transitions presented in 3D. Each FRAME adds a synthetic 0.5 seconds; it is not a measured engine frame. APPROACH is an explicit input, not player tracking. No museum gate is controlled.

Array

An empty address still exists

Sixteen persistent sockets distinguish selecting an address, toggling its Boolean and overwriting the grid with a checker rule.

NEXT SLOT reads another address. WRITE toggles its value. RULE assigns a checker pattern. RESET restores the occupied grid.

What the study represents

A native port of the browser teaching study; its private cells do not control the museum floor. Height displays occupancy, not a third array index.

Godot scene

Color_Grid_Pallet

One class; whose state changes?

Two colour receivers read actual RefCounted Palette objects. Separate reference paths converge when both receivers share one instance.

ADVANCE A / B changes the referenced palette. LINK / UNLINK compares shared and separate state. RESET keeps the link setting and resets both indices.

What the study represents

Proposed Palette teaching class, with the browser's three inks and reset semantics; no claim that existing museum floor cells already use this class. Receivers refresh explicitly.
