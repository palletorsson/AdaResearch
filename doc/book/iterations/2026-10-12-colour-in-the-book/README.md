# Colour in the book

Eight canonical tutorials, using the reviewed 6 October drafts. Current final.md reflections are preserved. Tutorial on the left, reflection on the right; short summaries and dated museum photographs locate the work.

The reviewed main lesson programs are unchanged. Supplied Grid and Walls controls now provide labelled targets for the prepared museum pointer, and Grid's readout names those controls. Nails includes the full inherited PointBody and LineSkin files. These learner files do not alter the live museum's runtime or install additional artifacts.

Read `ALL_TUTORIALS.md`, `ALL_FINAL.md` and `SUMMARIES.md`. Each hall folder contains the exact individual files. `sequence-verification.json` collects fresh source-checked native evidence, including the supplied pointer controls. The tests are teacher-authored; this is not a headset or independent ghost-student report.

To rerun from this AdaResearch checkout:

1. Run `Color_Context_Placed/run_checks.py`, `Color_Flashlight/run_checks.py`, and `Color_Nails/run_checks.py` with Python.
2. Run `run_checks.py`, then `run_render.py` in this folder.
3. Run `collect.py` to verify the exact manuscript/source/evidence relationship.

Godot 4.6 and the repository's prepared XR Tools addon are required. `prepare.py` is a one-shot historical import and must not be rerun over edits. The review ZIP is a reading/source collection, not a standalone museum distribution. GPU fixtures are isolated studies; museum photographs are dated earlier captures.
