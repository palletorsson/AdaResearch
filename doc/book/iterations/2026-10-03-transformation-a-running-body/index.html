A body that changes

In the last lesson, you placed three bodies. They stayed where you put them. Now keep one cube and change its position while the scene runs. Then add a turn and a change in size.

Open trans_pre.tscn in the shared starter. Edit studies/trans_pre/motion.gd. The supplied Cube makes a 0.6-metre box with a dark mark on one face. The room and the small numerical display are also supplied. Every lesson object is created in code.

1. Let the clock run

The study starts with:

var stage := 0
var elapsed := 0.0

Run it. The cube stays still, but the elapsed time below it increases.

Point Zero counted frames. Here _process(delta) receives the time since the previous frame, in seconds:

    elapsed += delta

Adding those intervals gives us a clock. The animation will use seconds, so rendering more frames does not make it run faster.

2. Move between two heights

Set stage to 1 and run again. The cube rises, reverses and returns. These variables determine its journey:

var centre := Vector3(0, 1.3, 0)
var travel := 0.25
var leg_seconds := 1.5

The centre starts 1.3 metres above the floor. Its lower and upper limits are 1.05 and 1.55 metres. travel is the distance from the middle to either end.

Inside _process, one value carries time into position:

    var t := pingpong(elapsed / leg_seconds + 0.5, 1.0)
    if stage >= 1:
        cube.position.y = lerp(centre.y - travel, centre.y + travel, t)

pingpong produces a value that travels from 0 to 1 and back at a steady rate. The added 0.5 starts it halfway up. lerp uses that value to choose a position between the two heights: 0 gives the lower end, 1 the upper end, and 0.5 their midpoint.

if stage >= 1 runs this indented line whenever the stage is at least 1. The later stages will keep this movement.

Set travel to 0.4. The cube now reaches 0.9 and 1.7 metres. Restore 0.25, then set leg_seconds to 3.0. The distance stays fixed; the journey slows. This value is the time between the ends. A complete return takes twice as long. Because we start in the middle, the first arrival takes only half a leg.

Restore leg_seconds to 1.5 before continuing.

3. Add a turn

Set stage to 2. The same cube keeps rising and falling, and now turns:

    if stage >= 2:
        cube.rotate_y(turn_speed * delta)

The dark mark lets you follow a particular face. The turn is around the cube's centre, about the vertical Y axis. Its centre still follows the same path.

turn_speed is TAU / 8.0 radians per second. TAU is one complete turn in radians, so this setting takes eight seconds per turn. Multiplying by delta gives the angle to add in this frame. Change the divisor to 4.0 for a four-second turn, then restore 8.0.

4. Change size as well

Set stage to 3:

    if stage >= 3:
        var factor: float = lerp(1.0 - pulse, 1.0 + pulse, t)
        cube.scale = Vector3.ONE * factor

With pulse at 0.3, the factor travels between 0.7 and 1.3. Vector3.ONE is (1, 1, 1): multiplying all three components by the same factor preserves the cube's proportions. Its mesh remains 0.6 metres wide; the displayed width ranges from 0.42 to 0.78 metres.

The assignment writes a new scale each frame. It does not keep multiplying the previous scale. The same t drives height and size, so the cube is largest at the top. Turning has its own rate.

Try pulse at 0.1. Keep a version whose timing and extent you like. You can now change a body's position, orientation and size without rebuilding its mesh.

For a short comparison, replace steady travel with sine. The endpoints stay fixed; the way the cube arrives changes.

The museum adds touch detection and collection to these operations. This reduced study animates a visible body. In the next hall, a moving surface will also have to support the visitor.

Optional comparison · one changed expression

A different way to arrive

The cube rises at a steady speed and reverses at the top. What changes if it slows before turning back?

In studies/trans_pre/motion.gd, set stage to 1. Replace the line that calculates t with:

    var t := (sin(TAU * elapsed / (2.0 * leg_seconds)) + 1.0) / 2.0

Run again. The cube has the same lower and upper heights. It reaches them at the same times. Between them, its speed changes: fastest through the middle, slowing to zero at each end.

sin() returns the sine of an angle in radians, a value between −1 and 1. TAU is a full turn. The expression inside sin() advances one turn over 2.0 * leg_seconds, which is three seconds here. Adding 1 and dividing by 2 changes the output range to 0–1, ready for our existing lerp.

Set leg_seconds to 3.0. The complete cycle takes six seconds. The height range stays fixed. Restore 1.5, then set travel to 0.4. The movement reaches farther, but its cycle still takes three seconds.

We can use a periodic function before studying how it relates to a circle, other waves or sound. Here we have learned to change its duration and extent. The later Wave Functions sequence returns to its structure.

The museum's Trans_Pre cubes keep the linear version. This is a comparison you can make in the student study. Restore the pingpong line before continuing the main lesson, or retain the sine version in a separate saved copy.

The complete study

The first script contains the operations taught here. The other two supply the marked cube and its readout. All are included in the starter. The lesson uses direct references to objects created in code.

motion.gd
extends Node3D

const Cube = preload("res://studies/trans_pre/marked_cube.gd")
const MotionReadout = preload("res://studies/trans_pre/motion_readout.gd")

var stage := 0
var elapsed := 0.0
var centre := Vector3(0, 1.3, 0)
var travel := 0.25
var leg_seconds := 1.5
var turn_speed := TAU / 8.0
var pulse := 0.3
var cube := Cube.new()
var readout := MotionReadout.new()

func _ready():
    # Supplied guards keep this study within its intended working range.
    assert(stage >= 0 and stage <= 3, "Use stage 0, 1, 2 or 3.")
    assert(leg_seconds >= 0.25, "Use at least 0.25 seconds for each leg.")
    assert(travel >= 0.0 and travel <= 0.5, "Use a travel extent from 0 to 0.5 metres.")
    assert(pulse >= 0.0 and pulse <= 0.5, "Use a pulse extent from 0 to 0.5.")
    cube.position = centre
    add_child(cube)
    add_child(readout)
    readout.configure(centre, travel)
    _process(0.0)

func _process(delta: float):
    elapsed += delta
    var t := pingpong(elapsed / leg_seconds + 0.5, 1.0)
    if stage >= 1:
        cube.position.y = lerp(centre.y - travel, centre.y + travel, t)
    if stage >= 2:
        cube.rotate_y(turn_speed * delta)
    if stage >= 3:
        var factor: float = lerp(1.0 - pulse, 1.0 + pulse, t)
        cube.scale = Vector3.ONE * factor
    # Supplied annotation observes the values. It does not drive the animation.
    readout.show_values(stage, elapsed, t, cube.position.y)

marked_cube.gd
extends MeshInstance3D
## Supplied visible body, created entirely in code. No collider or collection.
## The corner mark lets a learner follow a particular face as the cube turns.

func _init():
    var box := BoxMesh.new()
    box.size = Vector3.ONE * 0.6
    mesh = box
    var stone := StandardMaterial3D.new()
    stone.albedo_color = Color("e7ddd2")
    stone.roughness = 0.7
    material_override = stone
    var mark := MeshInstance3D.new()
    var patch := BoxMesh.new()
    patch.size = Vector3(0.09, 0.09, 0.006)
    mark.mesh = patch
    mark.position = Vector3(0.16, 0.16, 0.302)
    var ink := StandardMaterial3D.new()
    ink.albedo_color = Color("26232c")
    ink.roughness = 0.9
    mark.material_override = ink
    add_child(mark)

motion_readout.gd
extends Node3D
## Supplied annotation: stage, time and two height ticks. No animation state is changed.

var title := Label3D.new()
var values := Label3D.new()

func _init():
    title.position = Vector3(0, 2.25, 0)
    title.font_size = 29
    title.pixel_size = 0.0025
    title.outline_size = 0
    title.modulate = Color("ddadbe")
    add_child(title)
    values.position = Vector3(0, 0.57, 0)
    values.font_size = 22
    values.pixel_size = 0.003
    values.outline_size = 0
    add_child(values)

func configure(centre: Vector3, travel: float):
    for height in [centre.y - travel, centre.y + travel]:
        var tick := Label3D.new()
        tick.position = Vector3(-0.86, height, 0)
        tick.text = "%.2f  ─" % height
        tick.font_size = 20
        tick.pixel_size = 0.0025
        tick.outline_size = 0
        tick.modulate = Color("c8c0c4")
        add_child(tick)

func show_values(stage: int, elapsed: float, t: float, height: float):
    title.text = ["0 / STILL", "1 / RISE AND FALL", "2 / ADD A TURN", "3 / ADD A CHANGE IN SIZE"][stage]
    values.text = "%.2f seconds    t = %.2f\ncentre height = %.2f m" % [elapsed, t, height]
