A visual review found a directional bug

The earlier code said that dragging right increased a panel slider. A new check against the actual panel axes showed that the opposite was true. The shared panel now rotates the slider correctly. Its value screen counter-rotates to stay upright and clear of the handle.

Earlier tests checked range changes and travel distance. They now also check the direction. This repair applies to horizontal sliders created by the shared panel, including the previous pilots. Standalone vertical sliders keep their orientation.

Keep the source; change the prediction

EXPECT 0 and EXPECT 1 retain the same stored draws and bit colours. They change which cells count as prediction errors. A selected button now stays cyan after release, and the existing monitor also names the active predictor. Pressing the same choice again leaves it selected.

The shared button exposes set_selected(bool); its owner decides the selection. Ordinary buttons keep their momentary behaviour. Selection adds feedback without changing the experiment or making every button a toggle.

The primary monitor's support column previously hid bottom-centre grid cells. Moving the support behind the screen restores those cells. This correction lives in the shared monitor builder.
