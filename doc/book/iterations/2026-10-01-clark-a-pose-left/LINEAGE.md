# Where the hinge belongs

**Proposed first encounter: a focused return just after Trans_Rotation.** One small study bay is enough. The current Rotation hall already contains several large comparisons; do not add this in a passage merely because the registry says transformation. The study is presently a standalone companion, not an installed map.

| Earlier capacity | What returns here | What is new |
|---|---|---|
| Point Zero: retained state and repeated updates | Five angles persist; `_process(delta)` can update them | An update can undo an intervention |
| Coordinates: local and world frames | A child joint is located relative to its parent | The same local angle can travel in world space |
| Line and face | Edges relate neighbouring plates | An edge becomes an axis of permitted movement |
| Trace | Retain a corner’s successive positions | Equal final poses can have different histories |
| Rotation | Turn about a specified axis | Turning one part carries a branch while another stays still |
| Later: Form Finding | Revisit support, constraint and contact | Release the fixed root; investigate a physical assembly |

The first making task borrows the assembled object. It requires `loop`, `coordinates` and `rotation`; `trace` enables the optional path comparison. It changes a release policy and its rate, rather than teaching the entire recursive fabrication code. Rebuilding constraints and contacts remains a later task. The artist-capacity atlas’s broader hinge profile deliberately includes that later construction work.

The short encounter, the tutorial and the hall have different roles. The encounter stays with what an action leaves behind. The tutorial lets the student author a release rule. The room offers enough space to inspect the plates from another side. None needs a row of additional sculptures to explain the same point.

No active sequence, map token, prerequisite node or `final.md` was changed in this study.
