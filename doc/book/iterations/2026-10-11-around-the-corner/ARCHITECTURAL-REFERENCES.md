# Architectural references for linked rooms

12 October 2026. Research/design candidates supplied by the user. Existing room code and reviewed lesson texts are unchanged.

Core: architecture teaches through movement. Carry the same point. Let the visitor predict a spatial relation, walk it, then compare the prediction with what occurs. Distinguish visual perspective, route connectivity, gravity and intrinsic curvature.

| Reference | Grounded observation | Proposed museum encounter | Learning/check |
|---|---|---|---|
| Manifold Garden, William Chyr Studio | Its official description specifies repeated architecture, return through falling, and gravity changes permitting movement on visible surfaces. | A visible repeated gallery; carry the point across a boundary and return elsewhere. Explore changes of gravity as a separate encounter. | Connectivity/wrapping; retained object identity. Predict the arrival and retrieve an object left behind. |
| Francesco Borromini, Palazzo Spada | The gallery uses forced perspective: diminishing elements and converging construction exaggerate apparent depth. | A colonnade that looks deep from a marked viewpoint. Walk beside it; compare the same sphere with the shrinking columns. | Perspective and scale. The apparent depth changes with viewpoint; its physical dimensions remain fixed. |
| Labyrinth (general spatial pattern) | User's “Labyrinten” is retained without assigning it to a particular film, game or building. | A turn hides the next passage. Stable room numbers and the carried point distinguish a new room from a return. | Local direction versus global route. Four right turns may restore heading while reaching another room. |
| Antoni Gaudí, Sagrada Família | Official documentation connects inclined/branching columns, double-twist geometry, ruled surfaces and structural load paths. | A column forest: one profile becomes a shaft, branches, and meets a vault. Show the generating rule and a separately labelled load-path model. | Profiles, rotation, branching and geometric construction; force representations must declare their model. |

## Suggested progression

Perspective changes the appearance → turns withhold information → portal links change the overall arrangement → repeated boundaries extend the world. A branching column room connects this spatial inquiry back to primitives, transformation, L-systems and forces. Gaudí's hyperboloids are geometric surfaces; their use does not establish an intrinsically hyperbolic walking space.

Short future-AI instruction: `Reuse point. Borromini: apparent depth vs measured scale. Labyrinth: heading vs route. Manifold: wrap/linked space; gravity separately. Gaudi: profile→twist→branch→vault; declare load model. Build one readable action per encounter. No conflation with intrinsic curvature.`
