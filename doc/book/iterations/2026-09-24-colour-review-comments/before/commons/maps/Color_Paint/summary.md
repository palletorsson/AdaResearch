# A painting already in progress

The existing wet-paint canvas makes automatic strokes before the visitor touches it. A visible ball follows two differently timed oscillations while hue changes. Thirty grabbable pigment balls sit in two rows on a tray at about 1.2 m. Held balls project marks onto the canvas they actually hit; on release they stop painting and return to their tray positions.

The canvas faces the usable approach inside the recovered 19 by 25 metre room. Its four-by-two-and-a-half metre proportions are used for manual UV mapping. The Albers gallery remains the second primary encounter. No pattern machine is added.

The image accumulates and changes through viewport feedback, diffusion, vertical flow and fading toward white. This is a visual paint effect, not a pigment chemistry model or a recoverable stroke archive. The automatic brush uses elapsed time, while the wet effect updates on rendered frames.
