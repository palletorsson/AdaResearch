# A field of colour samples

Thirty-five pillars stand in a 5 by 7 field, spaced 3.2 m apart and rising 4.6 m. Their colours sample a continuous floor gradient: x changes hue, z changes saturation, and value remains 0.95. Beyond the field, twelve named palette sets hang on a framed wall. Existing mixing and spectrum artifacts remain secondary.

The recovered source footprint is preserved inside a new perimeter wall. See `museum_recovery.md` for historical provenance and placement exceptions.
