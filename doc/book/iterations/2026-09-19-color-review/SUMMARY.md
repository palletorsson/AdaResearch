# Color: let the room support the invitation

19 September 2026. Three parallel local audits cover all nine halls. This pass follows the author's instruction to strengthen encounters before cutting text. The [comparison page](../2026-09-19-review-comparison/index.html#color) presents actual image pairs and labels changes to teaching notes separately from book prose.

## The progression is already doing useful work

Color begins with forms, transformations and arrays the visitor has already met. It adds a value to that familiar construction, then changes the conditions under which the value can act:

> Assigned colour → illumination → a dressed body → an authored rainbow → field and sample → address and stored choice → accumulated trace → partitions and representation → message and receiver.

This progression gives the scientific and associative accounts of colour different places to meet. The RGB box lets a hand revisit a numerical choice. The same choice dresses bodies at different scales. The office lets sight pass where a body cannot. These are specific encounters from which the critical questions can develop.

All nine `final.md` chapters are retained. Their current bytes match both the start of this pass and the original 18 September review package. The sequence order and the current primary/secondary choices remain intact. Several apparent gaps in the ZIP were missing implementation evidence, rather than missing work in the project.

## Evidence and limits

Detailed evidence: [opening halls](opening/SUMMARY.md), [Rainbow, Pillar and Grid Pallet](fields/AUDIT.md), [Paint, Walls and Chamber](late/AUDIT.md). Original snapshots, probe scripts, logs and captures accompany each audit. The [final verification record](verification.json) checks manuscript parity, original review hashes and local comparison-page references; the [manuscript check](manuscript-check.json) also preserves the original parity result.

All nine focused museum probes pass: Context 691 checks, Flashlight 30, Nails 36, Rainbow 93, Pillar 97, Grid Pallet 30, Paint 27, Walls 59 and Chamber 32. These counts include repeated assertions across individual columns, labels and samples; they are not 1,095 independent learner tests. Baseline runs are not added again to that total.

The Pillar pair is a reconstruction of old/current placement within one actual museum run, holding the camera and lighting fixed. Independent original runs also remain available. Flashlight and Walls use separate before/after runs. Nails uses the same camera and selected colours but has a visible ambient-brightness difference: the placement changed; no lighting repair is claimed. Shared museum source was being edited outside this pass, so we cannot confidently attribute that brightness shift. One transient parse failure during that concurrent work was retained, and Context passed after retrying the repaired shared source.

No headset session or unassisted learner trial is claimed. Capsule sweeps, simulated input and Godot captures can expose wrong placement, missing geometry and faulty wiring; they do not establish comfort, tactile reach or what a learner understands. Existing startup/resource warnings remain visible in the logs.

Paint's two update mechanisms still deserve a more direct beginner-facing comparison. That is recorded as future artifact development, not as an implemented experiment or a reason to cut the manuscript's distinction. A future Color source package should include the salon, paint shader and projectile/receiver dependencies that were absent from the first bounded review bundle.
