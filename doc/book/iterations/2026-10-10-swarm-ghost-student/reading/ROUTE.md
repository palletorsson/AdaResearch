# Swarm — what the next room keeps

| Hall | What changes |
| --- | --- |
| 1. Physarum | A body leaves a trace that another can read. |
| 2. Flow Fields | A supplied direction differs from a trace made by agents. |
| 3. Boids | Nearby bodies contribute different steering requests. |
| 4. Agent-Based Modeling | The same point carries a state that changes what it does. |
| 5. Ant Colony | Outward and returning travellers use different trail channels. |
| 6. Particle Swarm | A score selects a remembered position. |
| 7. Population Support | A population account makes supplied support visible. |

The point remains recognisable while its useful relations change. These are different models, not seven behaviors silently added to one universal agent. The closing account leads into Graph Theory, then Machine Learning.
