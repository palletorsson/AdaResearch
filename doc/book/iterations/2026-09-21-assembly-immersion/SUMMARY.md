# Assembly Laboratory — leave a body different

The hall now supports an actual intervention: take a joint, move it, release it, and walk around the altered body. The automatic catalogue remains beside it. This continues the approved Rhizome pass by making a particular bodily encounter carry the writing.

## Built

- `MolecularDesigner` gains an opt-in `body_workshop` configuration; existing placements retain their defaults. The current hall enables it and moves the automatic assembly to cell (3,5). The authored floor is preserved.
- `AssemblyBodyStudy.gd` reuses the existing `VRBody` specification: thirteen joints, twelve connections, body scale 1.12. Its rigid bodies remain at unit global scale beneath the enlarged parent exhibit.
- `AssemblyJoint.gd` uses the existing XRTools pickable system and desktop carry hooks. Released joints remain where the visitor leaves them. Bonds redraw between the endpoints; no anatomical length constraint or spring coupling is implied.
- The automatic cycle cannot overwrite the independent visitor pose. Spare carriers are staged along the left wall, keeping the two encounters clear of each other.
- A thin floor inlay marks the horizontal limits of the working area. No control console is added.

## Evidence and limits

The final rendered Godot museum probe exits 0. Twenty-two interaction/placement checks and ten continuous controlled walking segments pass. These include a raycast through the actual desktop pickup code, carrying and release, a synthetic XR controller using the real XRTools grab driver, preservation across automatic assembly changes, bounded movement, live connection lengths, and unchanged legacy defaults. The synthetic controller is not a headset session.

Four actual museum captures show the new body in its original pose and after a reproducible four-joint gesture. The automatic reference is settled and held for the photographs. These are before/after poses, not before/after builds. The final run has no script errors; unrelated existing UID, certificate and renderer warnings remain. An initial probe loaded XRTools types before its settings autoload; using runtime loading for the probe resolved that startup issue.

The floor and movement permit circulation around both bodies. Joint pickup collisions and visual rods do not make a wearable avatar, a load-bearing chair, or a new navigable rhizome. The graph stays fixed. Pose export is available to authoring/probes, but the pose is currently retained only for the loaded visit; it is not saved to disk. Headset reach, comfort, Quest performance and learner response still need testing.

The live game was not restarted and its museum bake was not replaced. The probe uses private museum files. Existing cross-project warnings from rebuilding the long-museum and necklace indexes are recorded in earlier audits and are outside this hall change.
