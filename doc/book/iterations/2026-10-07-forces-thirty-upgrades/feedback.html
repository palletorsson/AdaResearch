Marked ten scene groups using eleven existing idea IDs. Visual prominence does not promote the optional bridge into a core lesson.

Adapt

Never reset automatically

Preserve inspectable aftermath by default, with declared exceptions for player recovery, lost objects and capacity. Do not promise infinite state or prevent an exit.

Adapt

The player cannot intervene

Invite a pause through flight time, distance and clear view. Keep movement and available corrective actions; interruption becomes another recorded cause.

Adapt

Every event manufactures a damaged artifact

Begin with actual arrangements, motion and recorded paths. A friction trail is not abrasion, two oscillators are not automatically a knot, and a cluster is not a fused mesh.

Adapt

Every scene reads silently in 5–20 seconds

Use it as a target for simple physical reveals, not a hard timing, accessibility or comprehension claim for every lesson.

Keep

Physical and pedagogical exactness

Precision and lawful alternative outcomes both count. Separate model limits, selected conditions and numerical errors. Tutorial code reconstructs one focus; reflection can follow the aftermath.

Example: the point returns

Before: Continue spring_tower with the familiar point on a visible spring. Change rest length or stiffness, release from a chosen extension, then compare damping.

The existing learning elements stay: Restoring force, Rest length, Damping, Equilibrium.

Added encounter:

Promise
Bring the stretched point home.
Prediction
Predict whether it will stop at the rest position.
Release
Release the grabbed handle without erasing velocity.
Reveal
It may pass equilibrium and return again, depending on damping.
Residue
Leave the actual moving/settled state and a bounded displacement trace.

A successful return is still a valid outcome. Overshoot depends on the selected damping and initial state. The design must not secretly force a comic ending.
