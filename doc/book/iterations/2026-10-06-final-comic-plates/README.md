# Final-text companion illustrations

Eighty-nine six-panel museum comics: fourteen Primitives halls from Point One through Melencolia, followed by seven Transformation halls, five Arrays and Regularity halls, eight Colour halls, eight Tiling halls, two Change halls, thirteen Forces halls, six Form Finding halls twelve Wavefunctions halls and fourteen Randomness halls. The opening eight follow the same halls as the tutorial plates: Point One, Coordinates, Lines, Trace, Grid, Triangle Context, Polyhedra and Cube. Primitives continues through Ignorance, Godot Primitives, Columns, Profiles, Portals and Melencolia. Transformation follows Trans_Pre, Trans_Introduction, Trans_Translation, Trans_Rotation, Trans_Scale, Trans_Body and Trans_Pit. Arrays follows Array, Tutorial_3D, Tutorial_Tiling_Floor, Tutorial_Tiling_Walls and Tutorial_Disco. Colour follows Context Placed, Flashlight, Nails, Rainbow, Pillar, Grid Pallet, Paint and Walls. Each page pictures selected encounters and their poetic or critical consequences, using brief passages from final.md. Point Zero is outside this illustrated run.

Open index.html, choose a hall under its sequence, or use previous/next across the complete route. Each page links the full final text and image. The first eight link their existing tutorial companion images; subsequent pages link tutorial.md. Printing the gallery prints one illustration per page.

The fictional student and older companion retain the prior comic's visual language. Room staging and diagram overlays are illustrative, not museum screenshots. The chapter is not reduced to its six panels, and the illustrations are not evidence of runtime behaviour or learning. The polyhedra page distinguishes the museum artifact's convex collision hull from its visibly open base; this differs from the stripped teaching reconstruction in the tutorial companion. The continuation also uses actual museum and book images as material references for the capsule, letter sweeps, planar limit comparison and sculptural Melencolia tableau. The last page follows the reconstruction, not a historical reenactment.

Built-in image_gen creates the raster illustrations. Selected images are copied into this directory while generated originals remain in place. plates.json retains the prompts and source fingerprints; sources/ retains all eighty-nine texts read at drafting; PROMPTS.md includes any corrective edits; provenance.json records selected image hashes. Museum logic, final.md and tutorial.md are not changed by this pass.

Some chapters changed while these illustrations were being made. The gallery records those reviewed revisions separately, preserving the texts used to draft the pictures. Transformation retains the earlier colour studies as visual keying; the current museum uses grayscale. These differences are noted beside the affected plates. check_gallery.py checks all selected image records, source snapshots, reviewed versions, local links and hall navigation.
