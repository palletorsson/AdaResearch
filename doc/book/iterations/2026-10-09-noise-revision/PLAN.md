# Noise — the next relation

9 October 2026. Eight halls in the existing museum spine. One focused revision at a time. These are editable working summaries, not approval of every proposed lesson. Lab Path remains an optional return outside the eight-hall route.

Randomness has already introduced seeds, independent draws, accumulated state and sampled fields. Noise should develop the relation between an address, a value and the body that receives it. Keep the point class, cube, lists, loops and mappings available. Do not turn each gallery into an inventory of new programming subjects.

The broad progression holds: **admission → driver → receiver → occupancy → accumulated material → borrowed address → bodily passage → comparison**. It is not eight introductions to noise. The strongest handoffs are a retained sample used twice, an original address kept beside a warped one, and a proposed route kept beside an actual passage.

The current tutorials after Noise Columns are mostly encounter instructions or partial source passages. Their titles and subject labels are useful plans; they do not yet establish reconstructability. Audit the actual artifact before expanding each. The optional Uncertain Surface and Related Weather can remain available without becoming prerequisites for every learner.
