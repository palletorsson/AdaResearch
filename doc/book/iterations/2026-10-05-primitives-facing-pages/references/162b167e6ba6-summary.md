# Primitives Godot — map summary

A room for supplied forms, after Ignorance and before Columns. The eight-specimen mesh library and the seven-form choir compare generated surfaces with the scenes that present them. The choir is a deliberately limited selection.

The library's PointMesh mark is measured in screen pixels; the trail meshes show rest geometry. These are viewing specimens, not a set of visitor-operated parameter controls. Proposed teaching selects one small comparison rather than explaining every artifact.
