The interface in front of the work

The old continuous slider was already rounded to an integer inside the artifact. A six-position selector now makes that rule visible. It stays at the chosen generation after release. Its position, the depth display and the generated geometry agree.

The status label is 2D on a backed screen, and updates when its text changes. The grammar rules and provenance text are preserved.

The whole connection is tested

The test casts physics rays at the real screen collider. Their hits become pointer events, then viewport GUI events, then the artifact's own callback. Selecting generation two changes the first grammar from 10 to 50 line vertices: five segments become twenty-five.

Shared repairs

  • Individual rack cases and complete module faces use the same pointer bridge. Hit bounds follow the visible screen inside the bezel, even when rotated or scaled.
  • Only the pointer that started a drag can change or end it. Leaving the screen, losing focus or removing that pointer releases the control.
  • Passive meters and labels have no pointer collider. They remain displays.
  • The artifact helper's buttons now listen to the signal the rack button actually emits. One press invokes one action; release does not repeat it.
  • Labels and initial values survive construction. A discrete value is quantized using its configured step count.

The 2D drawing now scales as a whole, including the lettering, rather than stretching the control rectangle around undersized text. These are shared implementation changes; each placement still needs inspection.

Evidence and next placements

Headset reach, tracked hands, Quest performance and museum sightlines remain untested here. Existing startup UID, certificate and shader-cache warnings are recorded; the final runs have no script errors and exit successfully.
