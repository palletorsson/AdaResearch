# Preserved first failures

1. `runs/import_01`: the harness test for Soft Rules used `:=` to infer a conditional value whose other branch was a dynamic study member. Godot rejected this test variable. This is a **harness bug**, not a printed-code defect. The test now declares `Vector2i`. The first import also ended with Windows access-violation code 3221225477 and resource-leak diagnostics during editor shutdown; that is recorded separately as an environment/import shutdown issue pending the actual runtime tests.

2. `CA_Introduction/original/runs/run_01`: the expected state assertions passed, but the harness compared MultiMesh colours with `is_equal_approx`. Stored colours are quantized (for example a literal component 0.5294118 reads back as 0.5292969). Replaced that receiver assertion with per-component tolerance 0.005, smaller than the difference between the two palette colours. Applied the same correction proactively to the volume receiver test. This is a **harness precision bug**, not a book defect. Both Introduction programs subsequently exit zero with all 54 checks passing.

3. Screenshot review: the single neutral camera was too distant for the first three studies and faced the backing of the Presence frieze. The harness now frames these studies individually and approaches Presence from the panel side. Previous screenshots remain in their original run folders. This is a **harness framing issue**, not a lesson-code repair.

4. `CA_ExpandingSpace/variation/runs/run_02`: during the camera rerun, the narrow-radius field's target stayed at 1.0 instead of reaching 0.76. The fixture had transformed the host, assigned one rigid-body pose, then waited through a physics frame before stepping; it did not verify that the synthetic held pose was still present at the committed update. The first run had passed, so this is a timing-sensitive fixture observation. The repaired fixture settles the transformed parent first and supplies/asserts the hand pose before each committed update, as a continuing hand controller would. Original and variation subsequently pass with the correct values. The failed run is preserved, including its shutdown resource diagnostics. The exact physics synchronization path of that first failure was not separately instrumented; it should not be claimed as an identified book bug.

No prediction was revised to match an observed automaton outcome. No printed original was edited. No executable book defect was found in the tested scope.
