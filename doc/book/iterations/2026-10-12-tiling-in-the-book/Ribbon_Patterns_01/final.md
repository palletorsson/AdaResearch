# A mark acquires an inside

*An optional excursion into volume.*

The mark has acquired an inside. Can you find it?

Temple distributed a recipe across surfaces. Here there are addresses behind the ones you can see. This path leads towards spatial data; the garment ahead will return to a surface.

<!-- @grid_2d_4x4 -->

Begin with the low array and the volume beside it. Find the familiar colour arrangement. The pale cells belong too. Pale does not mean absent.

The low array is made of cubes, but each address needs only a row and a column. Giving a cell thickness has not given its data another index.

<!-- @grid_3d_4x4x4 -->

Follow the selected address upwards through the volume. At first, each layer reads the same source. Turn on SLICE. Only one layer remains visible: sixteen cells shown, sixty-four stored. The hidden cells have not become empty.

Change from REPEAT to SHIFT. Now height advances the column read from the source. Keep one position in view and follow its colour through the slices. Can you anticipate where it returns?

Restore ALL. The layers make a relation that no single slice contains. The cubes have stayed in place; their colours now depend on height. A slanting appearance can arise without moving the layers.

<!-- @ -->

The order used to store an address is a convention; it does not rearrange the directions in space.

The extra index gives us another direction in which to arrange relationships. It has not decided what those relationships mean. Here every value receives a coloured cube. Zero could instead mean a vacancy; a value could describe resistance or affinity. Each would ask for another program.

A slice helps us see by withholding most of the display. That is a useful reduction while we remember what it leaves out. Turn the full volume back on before leaving.

In the next room, return to the surface. Keep a value fixed and ask what its surroundings contribute to what you see.
