Inside the museum

Which object carries each lesson?

Preserve the sphere's identity wherever it helps. Give it a new relation or ability, then let the supporting artifacts test that understanding. A museum object does not automatically become another programming assignment.

First pilot: the tethered point. Pull it, release it, change damping, compare a hinged seat, then disturb or settle the motion with the available tools. The tutorial reconstructs the spring response; the whole room remains open for play.

The current full catalyst is a separate existing implementation, BecomingCatalyst. The learner's PointBody can carry the conceptual lineage without inheriting its complete editor and mode system. Choreography's conveyor is a proposed focus change; the current main placement remains the phase rods.
