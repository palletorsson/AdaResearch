Five amounts, one shape

Learning elements

  • Harmonic number and coefficient
  • A weighted sum from a list and loop
  • Holding phase while comparing recipes
  • Copying a baseline without resetting the clock
  • The limits of a finite representation

Find the dark synthesis bench in the museum. Press HOLD. Lower H2 through H5 one by one. The pale curve changes until only a sine remains. None of the five smooth component rows has the slope you first saw; the slope belonged to their sum.

In Beats, two nearby frequencies drifted in and out of alignment. Here the frequencies stay in integer ratios: one, two, three, four and five times a fundamental. We change their amounts. The unchanged PointBody returns five times as a hand control; LineSkin draws the five contributions and their sum. Arrays supplies the list, and Trace supplies the loop through stored entries.

Build beside the existing bench

Use the prepared Endless Museum, with its player, XR Tools, camera and lighting. Save the three scripts below together. Attach 12_five_amounts.gd to an empty Node3D at hall-local (16, 0, 11), Y rotation 180 degrees, unit scale. The script creates all five points, six rows and labels. Keep point_body.gd and line_skin.gd unchanged.

Raise a point to increase its harmonic's amount. Local Y = 0.8 metres means zero; 1.6 metres means one. Release it to keep that height. Horizontal movement does not change its coefficient. Each point keeps its harmonic identity even if you move it past another.

The display starts held. The H1 point's trigger toggles HOLD/RUN. The H5 point's trigger restores BASELINE, releasing any held controls and returning their heights. It preserves the phase and held state. These are the established PointBody actions; we are giving them new jobs.

Multiply a contribution, then add it

amounts[h] is a coefficient. h + 1 is the harmonic number because array indices begin at zero. The coefficient changes the amount; the harmonic number changes how many cycles fit in one fundamental cycle. A nonnegative coefficient can still contribute a negative value when its sine is below zero.

extends Node3D

const PointBody = preload("point_body.gd")
const LineSkin = preload("line_skin.gd")
var baseline: Array[float] = [1.0, 0.5, 1.0 / 3.0, 0.25, 0.2]
var amounts: Array[float] = []
var points: Array = []
var rows: Array = []
var phase := 0.0
var held := true
var segments := 64
var width := 3.2
var gain := 0.16
var label: Label3D

func text_at(words: String, at: Vector3, size: int = 22) -> Label3D:
    var text := Label3D.new()
    text.text = words
    text.position = at
    text.font_size = size
    text.pixel_size = 0.002
    add_child(text)
    return text

func _ready() -> void:
    amounts = baseline.duplicate()
    var ink := StandardMaterial3D.new()
    ink.albedo_color = Color(0.04, 0.04, 0.045)
    ink.roughness = 0.2
    for h in range(amounts.size()):
        var point := PointBody.new()
        point.position = Vector3(-1.4 + h * 0.7, 0.8 + amounts[h] * 0.8, 0.75)
        point.get_child(0).material_override = ink
        add_child(point)
        points.append(point)
        text_at("H%d" % (h + 1), Vector3(point.position.x, 0.6, 0.75))
    points[0].action_pressed.connect(toggle_hold)
    points[4].action_pressed.connect(restore_baseline)
    label = text_at("", Vector3(0, 3.55, 0), 23)
    text_at("Raise each point: amount 0 to 1\nH1 trigger: HOLD / RUN     H5 trigger: BASELINE", Vector3(0, 0.34, 0.75), 20)
    for row in range(6):
        var lines: Array = []
        var finish := StandardMaterial3D.new()
        finish.albedo_color = Color(0.98, 0.7, 0.82) if row == 5 else Color.from_hsv(float(row) / 5.0, 0.4, 0.95)
        for i in range(segments):
            var line := LineSkin.new()
            line.material_override = finish
            add_child(line)
            lines.append(line)
        rows.append(lines)
        text_at("SUM" if row == 5 else "H%d" % (row + 1), Vector3(-1.9, row_height(row), 0), 20)
    draw_state()

func read_amounts() -> void:
    for h in range(points.size()):
        amounts[h] = clampf((points[h].position.y - 0.8) / 0.8, 0.0, 1.0)

func contribution(h: int, angle: float) -> float:
    return amounts[h] * sin((h + 1) * angle)

func sum_at(angle: float) -> float:
    var total := 0.0
    for h in range(amounts.size()):
        total += contribution(h, angle)
    return total

func row_height(row: int) -> float:
    return 2.95 if row == 5 else 2.4 - row * 0.29

func plot_position(row: int, u: float) -> Vector3:
    var angle := u * TAU + phase
    var value := sum_at(angle) if row == 5 else contribution(row, angle)
    return Vector3((u - 0.5) * width, row_height(row) + gain * value, 0)

func toggle_hold(_point: Variant = null) -> void:
    held = not held
    draw_state()

func restore_baseline(_point: Variant = null) -> void:
    amounts = baseline.duplicate()
    for h in range(points.size()):
        points[h].drop()
        points[h].position.y = 0.8 + amounts[h] * 0.8
    draw_state()

func _process(delta: float) -> void:
    read_amounts()
    if not held:
        phase = fposmod(phase + TAU * 0.2 * delta, TAU)
    draw_state()

func draw_state() -> void:
    for row in range(rows.size()):
        var previous := plot_position(row, 0.0)
        for i in range(segments):
            var next := plot_position(row, float(i + 1) / segments)
            var displacement := next - previous
            rows[row][i].show_segment(previous, displacement, displacement.length())
            previous = next
    var values := PackedStringArray()
    for h in range(amounts.size()):
        values.append("H%d %.3f" % [h + 1, amounts[h]])
    label.text = "%s | phase %.2f rad\n%s\nAll rows: %.2f m per signal unit" % ["HOLD" if held else "RUN", phase, "   ".join(values), gain]

sum_at() starts a new total for each angle. It does not add yesterday's curve to today's. Each pass through the loop adds one signed contribution at the same angle. This is the familiar sum extended from two named values to a list.

The baseline is copied with duplicate(). Editing the working list must not edit the recipe we hope to restore. restore_baseline() copies it again, moves the handles and leaves phase alone. The inherited drop() releases a held control before repositioning it; otherwise the hand would continue commanding its position.

Hold one thing still

While held, move a point and inspect the resulting change at one fixed horizontal position. Only when RUN is selected does _process() advance the common phase, at 0.2 fundamental cycles per second. Multiplying that shared angle by each harmonic number keeps the ratios intact.

At phase zero, a quarter of the way across the rows is angle PI/2. H1 contributes +1; H3 contributes −1/3; H5 contributes +1/5. H2 and H4 are zero there. Predict the total: about 0.867. Now remove H3. The sum rises to 1.2 at that place. Removing something can increase the result because what you removed was negative.

All six rows use the same gain: 0.16 metres per signal unit. Their baselines are vertically separated, so add displacements from those baselines, not absolute screen heights. Unlike the last lesson, the sum has no extra half gain. It can extend farther than any component. The display does not normalize it when you change the recipe.

The program draws one fundamental cycle as 64 cylinder segments. Five harmonics do not make an exact sawtooth jump. The finite sum is smooth; the displayed polyline is a further sampling of it. These are two separate limits. This construction also supplies no negative coefficient, independent phase or constant offset. It does not express every periodic shape, and it produces no sound.

The carried pieces

These are the earlier grabbable point and finite-cylinder renderer. Their complete files remain here so the example can be reconstructed.

extends XRToolsPickable

const RADIUS := 0.14

func _init() -> void:
    freeze = true
    freeze_mode = RigidBody3D.FREEZE_MODE_KINEMATIC

    ranged_grab_method = XRToolsPickable.RangedMethod.NONE

    collision_mask = 196615

    surface.mesh = sphere

    var boundary := CollisionShape3D.new()
    var shape := SphereShape3D.new()
    shape.radius = RADIUS
    boundary.shape = shape
    add_child(boundary)

# Supplied renderer, adapted from commons/primitives/line/line.gd.
# This finite cylinder gives the segment a visible thickness. It is not a collider.
# Inputs share the parent station's local frame; that station has unit scale.
extends MeshInstance3D

func _init() -> void:
    var cylinder := CylinderMesh.new()
    cylinder.top_radius = 0.012
    cylinder.bottom_radius = 0.012
    cylinder.radial_segments = 16
    cylinder.rings = 0
    mesh = cylinder
    var finish := StandardMaterial3D.new()
    finish.albedo_color = Color(0.98, 0.70, 0.82)
    finish.roughness = 0.3
    material_override = finish
    visible = false

func show_segment(start: Vector3, displacement: Vector3, distance: float) -> void:
    # A zero-length segment has no direction. Do not normalize it.
    visible = distance > 0.0001
    if not visible:
        return
    (mesh as CylinderMesh).height = distance
    position = start + displacement * 0.5
    # CylinderMesh runs along local Y. This borrowed basis aligns it to the ends.
    var direction := displacement / distance
    var right := direction.cross(Vector3.UP).normalized()
    if right.length() < 0.001:
        right = Vector3.RIGHT
    var depth := right.cross(direction).normalized()
    basis = Basis(right, direction, depth)

Make a change you can explain

  1. With the display held, remove H3. Predict the change at the quarter-cycle position, then inspect it. Restore BASELINE with H5's trigger.
  2. Lower H2 through H5. Compare the sum with H1. Their displacement should agree because they use the same gain. Lower H1 too: all rows become flat.
  3. Run the phase, then hold it. Change several amounts and restore BASELINE. The old shape returns at the held phase. Repeat while running: the recipe returns, but time keeps moving.
  4. Build a second recipe: [1.0, 0.0, 1.0 / 3.0, 0.0, 0.2]. Before running it, predict what the second half of a cycle will do. With only odd harmonics, it is the negative of the first half. The complete 12_odd_recipe.gd variation is included in the code download.

The museum bench uses the same weighted-sine principle with sliders, four visible cycles and finer sampling. Its component rows and sum have different drawing gains; its H3 baseline is rounded to 0.333. It hides component ribbons below 0.01 and assigns recipe names within a tolerance. Our reduced study keeps every component line and does not classify recipes. Those extra display decisions are useful to investigate in the exhibit without rebuilding them here.

Native checks execute the exact printed files, known signed contributions, both PointBody actions, baseline independence, phase preservation, displayed geometry and the odd-harmonic variation. Deliberately wrong indexing, unsigned contributions and a shared baseline must fail. Passing these checks establishes code behaviour; it does not establish a reader's understanding or headset comfort.

The sum on the bench

In Beats, two quick motions made a slow pulse. Here a wave is waiting to be taken apart.

Find the bench with the dark board above it. The board carries a pale wave with five coloured rows beneath it, and the wave already has a shape when you arrive: a long slope down and a steep rise, four times across the board, drifting to the left. On the bench, at its right end, five sliders stand in a column, one for each row.

Five amounts

Read the rows before you touch anything. The top row is one smooth rise and fall per cycle; each row below has more, two, three, four, five, and each is drawn smaller than the one above. None of them looks like the pale wave. Press HOLD on the panel at the left of the bench and the drift stops, so a place on the board stays where it is.

Now take the four lower sliders down, one at a time, and keep your eye on the pale wave while each row leaves the ladder. What remains is the top row, drawn larger: a sine. Press BASELINE and the four return together; press H1 ALONE and they leave together. The shape you arrived at is not one thing with a slope in it. It is five smooth returns added, and the slope belongs to none of them.

Bring the second row back on its own slider and choose a place on the board. The amber line marked mark is one such place. Before you raise the third slider, decide what the sum will do there: the third row is at a crest, or crossing its middle, or in a trough, and its slider decides how much of that is admitted. Raise it and read the plate on the bench. Its third line lists each row's value at the mark; the fourth adds them and prints the total drawn beside them. With these five visible rows, their sum agrees with the total. Each row makes an integer number of returns in the same span. Its slider decides how much it contributes. The pale line gathers these signed contributions at each place on the board. A crest adds; a trough subtracts. What looks like one slope is a relation maintained across many positions.

This is a visual instrument. It does not play the curve as sound. No slider changes the fundamental's frequency. Unlike the separately struck bars in Air Music, these rows cannot choose separate beginnings. A shifted row or a negative amount would need a control the bench does not offer. BASELINE restores the five amounts the room was placed with: one, a half, approximately a third, a quarter and a fifth. The plate names which coefficients differ, so you can wander and still know what has changed.

With the baseline held, look at the rise. An ideal sawtooth jumps; this one climbs through a visible distance. Its descent ripples where the ideal would be straight. Raise the fifth slider and those ripples change. Other amounts can make the sum rise further. Five smooth returns can suggest a corner and cannot make an exact one. From across the room the pale line suggests a sawtooth. At the bench its rounded rise remains available to inspect.

Take the second and fourth rows out and leave the odd three; the label offers a name. Move the fifth a little. At first the name stays. Move further and it gives way to Custom Waveform. The curve has changed continuously; the naming rule crossed a threshold. It checks all five amounts relative to the first, allowing a small difference from a recipe. Custom is a place to continue from.

Then remove the row you think matters least and find where its absence shows. It is not in one place, because each row runs the whole cycle. Near zero, a row disappears before its coefficient reaches zero: the display hides values below 0.01 while the sum still includes them. At some marks the plate can report a difference between the visible rows and the total. Something has left the picture without leaving the calculation.

What the room keeps

At the bench, one slider changed how much of a wave was present. Another instrument in the laboratory, Slow Circuits, offers ENTER ROOM. It takes you out of this hall and into a listening room. BACK TO HALL will bring you to the museum again. Take a phrase with you.

A loudspeaker stands inside. At the Voice station, press RECORD / END, say a short phrase, and press again to finish. Eight seconds is the limit. DEMO VOICE offers a synthetic phrase if you prefer. Listen once. Then press HEAR ORIGINAL, let it finish, and hear it again. The instrument plays the same stored recording. Repetition has not yet altered its data.

Press NEXT PASS. Something has acted on the phrase. Listen for a vowel, a consonant, a pause. Press again. Which is easiest to follow now? AUTO continues the returns; HEAR ORIGINAL interrupts them with the recording you began from. The comparison remains available even when the words become difficult to recognize.

The room keeps the result of each pass and makes that result the next input. The next pass begins with a sound that has already been changed. RESET returns to a copy of the original instead.

A copy can keep the values. A filter acts on them. Here, delayed sound returns into the calculation, reinforcing some frequencies more than others. Repeating the operation makes that unevenness increasingly audible. The voice and the rule participate in what remains.

Alvin Lucier's I Am Sitting in a Room begins with a voice recorded and played back into a physical room, then recorded again. The room's resonances become prominent through successive returns. A digital recorder could take part in that physical process too; tape damage is not required for its central effect.[^synthesis-lucier]

Calling everything we hear here analogue distortion would hide a distinction we can investigate. In Lucier's physical setup, sound passes through air between a loudspeaker and a microphone. In this virtual room, the first recording enters a numerical model. Three delayed paths use the room's dimensions; damping changes what returns. The visible walls do not, by themselves, act on the sound.[^synthesis-room-model]

Go to SURFACE and move ABSORB. The panels change colour and the experiment returns to the stored voice. Begin the passes again. Keep the same phrase and compare what happens under the changed conditions. Colour and acoustic response have been connected by code. One has not caused the other.

A wall can look like concrete before we have given it any of concrete's acoustic behaviour. What would it mean to give that wall the response of cloth? Or to let a curtain ring? Those rooms are possibilities for another iteration. The current control changes absorption; it does not yet let us exchange a whole material's behaviour. Even this smaller choice makes appearance and action available to question separately.

There are other choices inside the return. Each pass is adjusted to the same peak amplitude. The recording has a fixed length, with a short allowance for its tail. Sound that continues beyond that window is cut away. HEAR ORIGINAL means the first recording this instrument stored; it cannot give us the voice before recording, sampling and preparation. Walking changes where we hear the virtual loudspeaker, while the simplified resonance model stays fixed.

Listen once more to the original. What became difficult to hear has not been deleted from every place. It remains in a buffer we chose to keep. The room's rules shaped one version of the voice; comparison lets us notice their work. Which properties would we carry into another room, and which might we let it change?

Back at the bench

Choose BACK TO HALL and find the five rows again. Press HOLD, then BASELINE. Pick a place on the pale curve and move the fifth slider. Watch that place change. Press BASELINE once more: with the phase held, restoring the five amounts brings the curve back to where you just saw it.

In the listening room, each pass began with the altered result of the last. Here the slider changes an amount used to calculate the sum afresh. The previous curve does not become an ingredient in the next one. Both instruments let us return, but they keep different things available.

Release HOLD. The five amounts stay while the shape moves across the board. BASELINE can restore this recipe without recovering the moment before we left the hall. Repeating a recipe and repeating an exact instant ask for different things to be kept. In Random Definition, that question will meet an unfamiliar result: what would we need to retain to bring it back?

[^synthesis-lucier]: Alvin Lucier, I Am Sitting in a Room (1969). Collins also attends to Lucier's stutter as a rhythmic contribution. Lucier’s stutter is part of the voice the room receives, not a fault the passes correct. “Less intelligible” describes what happens to the recording, not a judgement of its speaker.
