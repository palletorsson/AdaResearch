# Array — an address survives an absence

**Bring:** the familiar cube, pickup, one-metre construction blocks and the `wp` wedge.

**Do:** walk into cube `[2]`. Read `0` at address 2; cube 3 keeps its place. Cross to the two-dimensional grid. Collect `[1,2]`; its plaque stays and `[2,1]` remains occupied. At the centre deck, copy or consume one cube, then walk onto the changed support.

**Learn:** independent instances; stable indices; occupancy values separate from object references; nested iteration; an address mapped to physical support.

**Surprise:** a value can disappear while its address remains. A write to the next collection changes what can support your body.

**Controls:** desktop left click / XR pointer and trigger operate COPY ONE, CONSUME ONE, PAUSE / RESUME and RESTORE. The original blue agent runs when resumed. Step out of an empty cell to let restoration finish. R / right B rebuilds the trial.

**Pass:** collecting one cube does not shift another address. Copy and consume each change one cell and its collision. The outer deck stays fixed. Restore waits for an occupied cell. Retry returns the row, grid and deck to their original state without changing museum progress.

**Carry forward:** a bounded, addressable construction grid, with pause, individual operations and safe restoration. Move/copy/rotate the worksite as one artifact in the lab editor; paint the approach wedges and other construction cells in the voxel editor. Desktop and VR read the same trial layout.

**Scope:** this is a separate first-map trial. It includes the original row and grid plus an adapter for the original floor writer. The Molnár comparison and the later 3D, tiling and clocked-array maps have not been migrated here. The existing `final.md` and `tutorial.md` remain unchanged.
