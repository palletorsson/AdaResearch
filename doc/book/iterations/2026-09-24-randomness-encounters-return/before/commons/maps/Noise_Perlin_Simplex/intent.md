# Ask both functions

Let the visitor propose a difference before we explain it. Keep the original matched displays and their independent controls. Make the same query visible at two places, and let a deliberate mismatch appear in the live readout. Restore the shared conditions without resetting unrelated artifacts.

Changing the display's use of a value should become a separate operation: VIEW flattens the cubes while colour retains the same samples. The square cube grid must not be confused with the internal gradient lattice. The small moving sheet remains relevant precisely because it fails the paired contract: a different basis, seed, sampling domain, mesh and clock. Do not discard it for failing a comparison it was not built to satisfy.
