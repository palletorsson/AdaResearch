# Release the point; keep the attachment

Primary: `force_play_springs`.

Reconstruct one spring using the familiar pickable point. While you hold this small study’s point, the hand places it; release returns it to physics. This intentionally simpler hand boundary differs from the museum’s force-transmitting rose grip. The spring always refers to the same anchor. A thin cylinder draws the attachment; it is not the force.

Carry: A spring can repeat because forces continually change velocity. In Choreography, a similar repetition will come from assigning positions.

Check: Keep stiffness and the release position fixed; change damping from 0.5 to 3.0. Predict less persistent motion. Then restore damping and double stiffness. The return should be stronger for the same extension; rest length itself has not changed.
