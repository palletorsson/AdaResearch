The hand, the number and the sound

The old radio shrank its two controls, printed fictional FM values and let station shortcuts leave the physical wheel behind. The volume wheel had a dead negative range, and changing its value did not change layers already playing.

Tuning now starts between stations at 20°. Turning the wheel moves the degree needle; choosing a station through code moves the wheel too. The level control covers −40 to 0 dB across its full travel and changes sounds already playing. The quiet end is attenuation, not a mute switch.

Four ways to describe the same selection

The existing variants are part of the encounter. Changing the panel changes which clues it gives you while preserving the selected sound.

The interface reached into playback

The player now resolves the sound IDs used by the shipped presets through the existing sound bank. Random-event sounds are prepared in the background. If you tune again while preparation is underway, the radio keeps the latest request; it does not wait for a worker to finish inside the wheel callback. Informative panels show when the selected sound is still being prepared.

This remains a threshold between preset centres and the existing drone used in the gaps. It does not simulate an FM receiver or continuously blend signal clarity.

A reference, ready for the next placement check

78 checks cover the four face restrictions, actual XR Tools grabs and ray hits, station shortcuts, degree and dB agreement, queued selections, live audio gain and full-length mono loops. Separate checks exercise the real threaded player with short diagnostic streams and generate small production sounds. The visual radio fixture uses silent playback logging; screenshots are not evidence of perceived sound quality.
