# Turn until you hear it

21 September 2026. The existing SoundscapeRadioRack now uses the repaired physical wheels at full size, with flat screen text, synchronized tuning and live volume. The four authored face variants remain distinct. This is a consumer integration following the angular-control reference.

## Changes

- The case is 60 × 70 × 9 cm. Two 18 × 25 cm control plates sit 29 cm apart, at scale 1. The old placement shrank them to 0.6 and 0.5. The case, side rails and screen bezel provide visible backing. A shared viewport-backed screen replaces every radio Label3D, including the nine-row list. Visual review caught and corrected a screen placed behind its bezel.
- Tuning starts at 20°, between the first two station centres, matching the initial noise/drone state. Nine stations occupy 0°–320° at 40° intervals, with a final gap to the 360° end-stop. The degree band replaces fictitious FM values. The rule remains nearest station within the existing 0.3-station-width threshold; this is a discrete preset switch, not continuous signal blending.
- The level wheel uses its full −135° to +135° travel for −40 to 0 dB of additional attenuation. Initial −6 dB agrees with the actual wheel angle and reading. −40 dB is quiet attenuation, not mute. Native degree/radian APIs and canonical scene paths remain intact.
- `set_station`, `next_station` and `previous_station` move the physical wheel. Empty catalogues are guarded. Noise and station transitions preserve the selected gain.
- Audio requests settle for 180 ms. While generation is running, the radio retains only the latest selection instead of stopping and joining the worker inside a wheel callback. Informative faces distinguish queued/preparing/incomplete sound states. A previous sound can remain audible while the next one is being prepared; this is not an instantaneous crossfade.
- The shared SciFiLoFiSoundscape backend now reads the shipped `sound_id` and `sound_pool` preset format through the existing SoundBank. Event pools are generated by the worker and reused when events fire. Older `generator`/`method`/`params` configurations still work. Techno-noir and trap-beat parameter dictionaries are passed through to their existing generators. Other bank families retain their existing parameter behavior.
- Live `volume_adjustment` now updates continuous layers and active events while preserving their individual mix offsets. New players inherit the current gain. WAV loops use frame count, including mono streams, rather than assuming every stream is 16-bit stereo.

## Preserve the four accounts

| Face | Available evidence |
| --- | --- |
| `scale` | Degree band, moving needle, station name and tuning angle; gaps have a readable position. |
| `presets` | One lamp per station and the selected name; gaps extinguish all lamps. No numeric tuning substitute. |
| `list` | The same nine station names with the selected row highlighted. No tuning coordinates. |
| `void` | Dark screen and physical wheels. Both numeric control readings are hidden; tune by ear. Static TUNE/LEVEL captions remain. |

Changing a face preserves the selected station and does not reload audio. Identical, unrelated and invalid grid configuration does not rebuild the face. The radio's registry description is updated accordingly; its historical `was` field remains historical context.

## Evidence

**78 checks pass** in desktop Godot 4.6 Mobile, without SCRIPT ERROR. The existing project UID warning remains. The six baseline checks all failed before this pass; the pre-edit source and images are preserved in `before/`.

The radio fixture replaces only the soundscape player with a silent request recorder. Its real scene, controls, input routes, face code and readouts run unchanged. Tests use actual XR Tools pickup/release and actual physics ray hits at yaw 0°/90°, exercising tuning, live level mapping, end-stops, public shortcuts, all four face restrictions and latest-request switching.

A separate test uses the actual threaded soundscape backend with a bounded diagnostic PCM generator to check sound-ID dispatch, event pre-generation, continuous/event separation, live gain, repeated gain assignments and mono loop length. Small real production sounds are also generated through the bank and legacy paths, including a parameterized short drone. This verifies generation and state, not perceived sound quality or a complete audition of every station.

Before/after radio captures use identical cameras. The new focused `commons/interactables/interactable_radio_demo.tscn` loads the production radio through InteractableDemo, at root height 1.20 m and a 15° backward tilt on an upright plinth. The operating camera is 1.60 m high. These describe the fixture; they do not certify reach for a particular body. Its reference capture cancels the delayed audio startup and therefore honestly shows a pending tuning state. The stand is visual, with no locomotion collider.

## Remaining work

- The Nostromo preset refers to `SciFi.space_ambience` and `SciFi.dystopian_alarm`. No implementation was found for either identifier. They are retained rather than silently replaced with unrelated sounds. Missing streams now populate `unavailable_sounds`; informative faces display “SOME SOUNDS UNAVAILABLE.” Complete the sound catalogue and audition every station in an audio pass.
- Headset comfort, shorter/seated positions, Quest text legibility, sound quality, generation latency, teardown cost and peak memory remain unmeasured. Pre-generating event pools avoids synthesis when the event fires but increases preparation work and retained streams. No Quest performance claim is made.
- Direct placements appear in WaveFunctions_Synthesis_Lab, its Placed/p1/p2/p3 variants and Ribbon_Wavefunctions_08, with additional curation references. The shared scene changes propagate to them, but their enlarged-case placement and surrounding geometry have not been verified. No map, manuscript or primacy was changed.
- The separate stepped/zero lever scenes and UniversalVRAudioController's legacy angular orientation assumptions remain the next interface-family integration candidates.
