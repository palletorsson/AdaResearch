# The boundary takes a detour

Koch holds endpoints while adding path length. Sierpinski multiplies kept pieces while reducing their summed area, then lets discarded middles become the visible work. A fixed-sample box counter changes grid size and fitting range to expose the conditions of a numerical reading. Three primaries anchor the book; all ten existing placements remain. The next hall carries removal into the Menger sponge's volume and asks which openings admit the player.
