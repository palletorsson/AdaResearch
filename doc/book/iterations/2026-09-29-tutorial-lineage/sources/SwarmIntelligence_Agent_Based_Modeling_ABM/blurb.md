Give agents rules. Let them interact. Watch what emerges. Agent-based modeling makes no assumptions about aggregate behavior — it builds the aggregate from individuals. Markets, epidemics, ecosystems: when the whole is too complex to model, model the parts.

`ABMSimulation` stages a general agent model between two elevated platforms. Each agent has state, perception, rules, and environment interaction; the simulation loop runs perceive → decide → act → update every frame. The arena geometry adds elevation as a constraint, channelling agents through spatial complexity. ABM is complexity science's methodological revolution: instead of writing equations for the system, write rules for the individual and let the system happen. The macro cannot be derived from the micro analytically — but it can be simulated. Petri dish for artificial societies.
