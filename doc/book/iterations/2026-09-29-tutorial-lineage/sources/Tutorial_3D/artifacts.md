# Tutorial 3D — Artifacts
*Array Tutorial Sequence · F_order · 6 artifacts*

> Two dimensions flatten. Three dimensions inhabit. The grid gains a vertical axis — X, Y, and now Z. Height enters the data structure. What was a spreadsheet becomes a volume.

The map, read through what it holds — its artifacts in the order you meet them:

## grid_3d_4x4x4
![grid_3d_4x4x4](/scene-catalog/grid_3d_4x4x4.png)

Populates a 4x4x4 lattice of pickup cubes for volumetric layouts.

`grid_3d_4x4x4`

## Dark Sphere
![Dark Sphere](/scene-catalog/dark_sphere.png)

USE a neutral sphere as a reference for scale, silhouette, and atmospheric change.

`dark_sphere`

## Sorting Algorithm Race
![Sorting Algorithm Race](/scene-catalog/sorting_algorithm_race.png)

Four rows of 16 colored bars sort simultaneously using Bubble, Insertion, Selection, and Merge sort. Animated step-by-step so you can watch algorithms race and feel the difference in strategy.

`sorting_algorithm_race`

## BarArray Substrate
![BarArray Substrate](/scene-catalog/bar_array.png)

Universal 1D array visualization. MultiMesh bars with emission and smooth transitions. Defaults to Bubble Sort. Use #algorithm:<name> to select cartridge.

`bar_array`

## Grid3D Substrate
![Grid3D Substrate](/scene-catalog/grid3d.png)

Universal 3D graph visualization. MultiMesh spheres + cylinder edges. Defaults to BFS. Use #algorithm:<name> to select cartridge.

`grid3d`

## BarArray — Bubble Sort
![BarArray — Bubble Sort](/scene-catalog/bar_array_bubble_sort.png)

Bubble sort on a MultiMesh bar array. Adjacent comparisons, largest bubbles to the end. O(n²). The canonical first sort.

`bar_array_bubble_sort`
