# Which block moved?

<!-- @animated_noise_explorer -->

Are these blocks travelling, or are different blocks appearing?

Choose a small region of the animated display and keep its position in view through several updates. Watch for a block-sized location that changes from empty to occupied, then disappears again. Try following a particular block as if it were a particle. Notice where that reading becomes difficult.

Try looking at the display in two ways over similar intervals. First follow the apparent centre of a visible cluster, as you might follow a moving object. Then hold your attention on one fixed position and record its appearances and disappearances. These readings can produce different descriptions of the same updates. The second makes replacement easier to notice, while the first draws together successive shapes into an imagined traveller. Comparing them gives you an observable reason to question particle-like motion before learning how the representation is rebuilt.

The generator advances an offset through a deterministic spatial field built from several trigonometric terms. At intervals, it samples the field again and rebuilds the displayed geometry. It does not preserve a set of individual blocks and integrate their velocities through the volume.

The current extraction shows whole cells whose corner values lie on both sides of the threshold. Such a cell contains evidence that the boundary passes somewhere through it. Drawing its complete box marks that region without determining the interpolated surface inside it.

That is a coarser representation than the triangle surfaces earlier in the sequence. The blocks should be read as boundary-containing cells, not as a finished marching-cubes mesh with unusually square triangles. The distinction matters when estimating thickness or deciding whether neighbouring features actually connect.

The cave generation room compared different authored fields. This display changes where one field is sampled and lets you see successive representations. Apparent motion can come from replacement, even when no persistent object follows the path your eye invents.

Before leaving, pick one cell that has just filled and say which of its eight corners crossed the level. The gold markers in the lookup hall located such crossings one edge at a time; this display draws the whole box instead. Both views at one resolution, with the offset frozen, would settle what a finer sampling improves.

# The Surface Chases the Field

Noise evolves; the isosurface follows. Animation here is not motion — it is re-extraction.

The cheapest time axis is a scrolling offset through 3D noise:

```gdscript
var t := 0.0

func density(p: Vector3) -> float:
    return noise.get_noise_3d(p.x, p.y, p.z + t * 0.6)   # slide the field past

func _process(delta: float) -> void:
    t += delta
    remesh()
```

The honest time axis is a fourth dimension — sample 4D noise so the field *changes in place* instead of drifting past:

```gdscript
func density_4d(p: Vector3) -> float:
    # two 3D samples faked into 4D: blend between two noise spaces over time
    var a := noise_a.get_noise_3d(p.x, p.y, p.z)
    var b := noise_b.get_noise_3d(p.x, p.y, p.z)
    return lerp(a, b, 0.5 + 0.5 * sin(t * 0.4))
```

With a scroll, blobs migrate across the room. With in-place evolution, they breathe — swelling, splitting, merging where they stand. Watch a blob divide: there is no "split" event anywhere in the code. Two maxima in the field drifted apart, and the threshold stopped connecting them.

Re-extracting every frame is the cost, so budget it:

```gdscript
func remesh() -> void:
    frame_counter += 1
    if frame_counter % 2 == 0:            # every other frame is plenty
        mesh_instance.mesh = extract(density, 24)   # modest resolution
```

Halving resolution is an 8× saving in cells; the eye forgives coarse triangles on a moving surface far more than it forgives a stutter.

Try: freeze `t` with a button. The mysterious breathing thing becomes an ordinary static sculpture instantly — proof that all the life was in the field's evolution, none of it in the geometry. Motion here is the *derivative of the field*, rendered; the previous sequence's calculus is running under this room.

Noise evolves. The isosurface chases it.

A scalar field fills the volume — dense here, hollow there. Marching cubes walks the grid, case by case, extracting geometry wherever the field crosses threshold. That's the base implementation: 256 configurations, one lookup table, mesh out. Static noise produces static caves.

Now animate the noise. The field breathes — density shifts, thresholds migrate, surfaces ripple and reform. Sliders control the parameters: noise scale, iso level, chunk resolution. Scroll through presets and watch caves become coral become bone become nothing. The gallery holds sculptures side by side, each a frozen moment from a different configuration space. Toggle island tracing to see how one continuous field fragments into disconnected forms.

The surface was never there. It was always a question the algorithm kept asking — and the answer kept changing.
