What was stopping it

  • The basket detector recognised XR bodies but missed the museum’s desktop player. It now checks both, with actual feet inside the boarding area.
  • The FIRE button’s physical collider blocked the entrance. It now sits beside the basket; the cup has a clear front and an overlapping access ramp.
  • The old direction pointed back toward boarding. The launch now points over the axle. Preview and release share one world-space velocity, including when the catapult is rotated.
  • The launch uses the museum’s desktop and XR movement owners. The basket floor clears during release, and the red path stays at the release position while the arm swings.

The swing is a release animation. The actual flight is a velocity handoff followed by gravity and collisions. The red line predicts an unobstructed flight; another object can interrupt it.
