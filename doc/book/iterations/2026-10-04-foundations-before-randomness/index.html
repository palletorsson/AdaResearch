Ada / Proposed curriculum · 2026-10-04 · 35 halls

Before Randomness

Establish the programming fundamentals by the end of Colour. Reuse them through Tiling, Change, Forces, Form Finding and Waves before the deep study of Randomness.

Use the existing Endless Museum. Select a small operation from its artifacts, explain its supplied surroundings, then let the student vary and reuse it. The tutorial, reflective writing and museum remain overlapping sets.

Planning only. This document adds a proposed foundation layer to the current hall summaries. It does not approve proposals, rewrite tutorials, change code, or move maps.

01 / 15 halls

Primitives

Name, connect, keep and generate.

Use named positions, a short list, a condition, a loop and a returning function to make a small geometric arrangement. Explain which values describe it and which objects display it.

02 / 7 halls

Transformation

Make a rule run, decide and remember.

Write a timed or input-responsive rule with a branch and retained state. Reset it deliberately; explain whether the state is recomputed or remembered.

03 / 5 halls

Arrays

Organize many things without losing one.

Read and change one entry in a collection, distinguish a value from an object reference, and write a repeatable spatial or timed rule over the collection.

04 / 8 halls

Colour

Calculate a value, assign it, give it state.

Use a returning function and a small authored class. Create two instances with independent state, apply results to known receivers, and use the foundation concepts together.

Introduce → practise → use independently. The six foundations are variables, conditions, loops, functions, arrays and objects. The Nature of Code assumes these already. Every hall does not need a new language concept.

01 · Primitives15 hall choices

Leave able to Use named positions, a short list, a condition, a loop and a returning function to make a small geometric arrangement. Explain which values describe it and which objects display it.

Introduce

Point Zero

Initialization and repeated execution; read a call and its argument.

Compare one reading with repeated readings in the existing counter. A frame callback and a list loop are different forms of repetition.

Try independently Predict which instruction runs once and which runs again.

Supplied Existing counter, display, player, camera and room.

Introduce

Point One

Named values, assignment, basic types, arithmetic; resource and node references.

Separate the variable holding a position from the sphere displaying it. Read .new(), property assignment and add_child in the existing construction; give var and const distinct meanings.

Try independently Change radius once and predict which visible and physical parts use it.

Supplied Existing corridor conditions; collision construction can be read before it is authored.

Reuse

Point Coordinates

A changing property in one reference frame; persistent script state versus a local temporary.

Read the held point's X, Y and Z. Keep the object reference available to the callback that needs it; explain scope when the code crosses callbacks.

Try independently Move along one named axis and explain the changed value.

Supplied Hold connection, input and coordinate readout.

Introduce

Point Lines

Expressions and returned values: subtract positions, then obtain length.

Reuse variables and method calls. Distinguish position, displacement and scalar distance before normalizing anything.

Try independently Choose two other endpoints with the same separation in another direction.

Supplied Existing segment renderer and endpoint input.

Introduce in three beats

Point Trace

A one-dimensional list, first comparison/if, then indexed for traversal.

Beat 1: append and read a position. Beat 2: keep a sample only when distance reaches spacing. Beat 3: join neighbours. Explain true/false, indentation, zero-based indices and range bounds beside their first use.

Try independently Predict the retained points for stop–move–return, then the number and order of joined segments.

Supplied Pen/point input, segment renderer and session record. Align the eventual lesson with the museum, not the older starter host.

Reuse

Point Line Grid

List order versus spatial address; original data versus a derived display.

Follow the museum's fit-then-round operation in three dimensions. Read/traverse known data; preserve its source.

Try independently Find two recorded visits that occupy one displayed address and show that the original remains distinct.

Supplied Existing session transfer and grid receiver; no promise of persistence after restart.

Introduce

Point Triangle Context

A face as three ordered positions.

Reuse a short position list and a supplied face submission call. Inspect winding without rebuilding the renderer.

Try independently Make another non-collinear triangle; reverse its order and predict the visible side.

Supplied Mesh submission/display support.

Introduce

Primitives Polythedra

Indices refer to shared positions; a face list describes connectivity.

Close a tetrahedron using a small known vertex list. Reuse index reading and traversal.

Try independently Alter one corner and identify every face that refers to it.

Supplied Mesh assembler; no long factory data dump.

Reuse

Point Animatedcube

Shared corners, face connectivity and a diagonal.

Reuse position and face lists. Separate editing their data from moving the whole node.

Try independently Change the diagonal while retaining the same outer corners.

Supplied Existing cube comparison and display.

Introduce

Primitives Ignorance

Author a small function: parameters, local values and a return.

Turn a repeated geometric construction into a reusable position generator. Distinguish defining a function from calling it. Use a small subset of the existing forms.

Try independently Call the same generator twice with different inputs and explain the two returned results.

Supplied Display/mesh assembly and any not-yet-taught formula.

Reuse

Primitives Godot

Engine class, instance, resource and scene have different roles.

Relate the resource instances already met in Point One to one documented parameter. Authoring a new class comes later.

Try independently Make two resources with different settings; identify which object an edit affects.

Supplied Museum presentation and collision support.

Reuse

Primitives Columns

Functions plus nested repetition generate a family.

Vary profile, height and radial count separately. Explain each loop's job; this is construction using known pieces.

Try independently Use the same rule for another column and compare resolution at fixed shape.

Supplied Mesh stitching/receiver where not already understood.

Selected exploration

Primitives Profiles

Source outline versus construction along a route.

Change one disclosed recipe input. Reuse functions/lists without requiring font extraction, triangulation and sweeping at once.

Try independently Predict which feature follows the outline and which follows the route.

Supplied Font outlines, hole processing and sweep construction.

Reuse

Primitives Portals

A running total and a stopping comparison express a chosen tolerance.

Reuse neighbour traversal, arithmetic and a returning function. Explain any accumulation before using it as a result.

Try independently Choose a different tolerance and justify a finite resolution.

Supplied Comparison display; no proof that more segments make better art.

Compose / reflect

Primitives Melencolia

No required new syntax.

Arrange a small family made with known values, lists, loops and generators. Preserve the reflective question about geometry and desire.

Try independently Make and explain one arrangement without copying the previous example exactly.

Supplied Museum staging; unfamiliar scale controls remain supplied until Transformation.

02 · Transformation7 hall choices

Develop

Trans Pre

delta, elapsed time, comparisons and if/else.

Begin with one familiar cube moving or holding at a duration boundary. Reuse Trace's first if. Size, turns and a supplied sine call become separate variations after this works.

Try independently Change duration and endpoints; predict start, middle and finish.

Supplied Museum collection and readout; circular derivation of sine waits for Waves.

Develop

Trans Introduction

An event invokes a handler; a reset assigns known starting state.

A supplied connection calls the learner's reset function. Reuse timing on one deck with declared input/output.

Try independently Restart twice and account for what returns to its start.

Supplied Event wiring, collision, physical deck and rider transport.

Reuse

Trans Translation

Guard an invalid operation; keep a waypoint index.

Read a short route. Check length before division, then advance the index at the end of a leg. Contrast per-frame stepping with traversing the whole list in one call.

Try independently Include a repeated waypoint and explain how the rule handles a zero-length leg.

Supplied Preview marker; use carrying only after its deck contract is settled.

Reuse

Trans Rotation

Pivot and order of operations.

Reuse a returning position function, known offsets and timed angles.

Try independently Reverse two turns and predict when their results differ.

Supplied Ride physics and readouts.

Reuse

Trans Scale

Parent-child transform ownership.

Use direct references to a small group. Scaling its parent changes placement and size relative to a fixed comparison.

Try independently Predict which child distances change and which outside object stays fixed.

Supplied Museum room, bottle and relocation.

Develop

Trans Body

A current boolean versus a retained flag; combine simple conditions.

Compute proximity afresh, then compare it with a remembered visit. Introduce and/not only where the chosen rule needs them.

Try independently Walk away and predict reversible response versus remembered change.

Supplied Visitor-position query, collision update and carving infrastructure.

Compose

Trans Pit

No required new syntax.

Compose two leaves from one opening fraction using known functions, timing and an occupancy input.

Try independently Choose an opening/reset rule, predict an intermediate pose and test it.

Supplied Airlock frame, event/input binding and physical leaf wrapper.

Develop in two beats

Array

Independent objects, stored references and indexed writes; then nested traversal.

Start with a short row made through a named creation function. Compare two references to one object with references to separate objects. Keep occupancy records distinct from display references; extend to a plane only afterwards.

Try independently Change one object and one occupancy entry; predict their separate effects while addresses stay fixed.

Supplied Creation/display adapter and collection event. The full tutorial is currently missing.

Reuse

Tutorial 3D

An extra index and explicit storage order.

Use distinct rows/layers. Explain conversion from the earlier [x][z] plane to the installed values[y][z][x] representation.

Try independently Write/read one slot with unequal x, y, z; preserve its neighbours.

Supplied Flight, selection and collection; no matrix-algebra detour.

Develop

Tutorial Tiling Floor

Remainder gives a repeating address-to-turn rule.

Reuse nested traversal, a function and a conditional exception; zero now means orientation, not vacancy.

Try independently Predict a 4×4 sample, then expand the same rule and preserve one chosen exception.

Supplied Asymmetric motif and raster-image renderer.

Reuse / reflect

Tutorial Tiling Walls

No required new syntax.

Use the same image on another supplied receiver. Compare image rotation with movement of the wall.

Try independently Explain what changes in appearance and what changes in passage.

Supplied Upright receiver, hinge and collision.

Tutorial Disco

Read a boolean record through time.

Start with one short score. Reuse elapsed time, retained index and remainder; a true entry triggers a supplied sound operation.

Supplied Sound and display; robust catch-up scheduling remains supplied.

Palette lookup and assignment.

Color Flashlight

An object's property and its receiver are distinct.

Change the existing light's colour, then its aim with colour held fixed.

Try independently Explain why an equal numeric colour need not look equal on different surfaces.

Supplied Light reference, grabbing and renderer.

Develop

Color Nails

A complete position-to-Color function with a stated contract.

Reuse functions authored in Primitives. Name positive box dimensions, parameters, locals, clamping and return. Separate calculation from assigning albedo.

Try independently Check origin, opposite corner and an outside point; change one coordinate and predict one channel.

Supplied Input/hand support and one explicitly bound preview receiver; full function binding is proposed.

Optional / reflect

Color Rainbow

No required new syntax.

Reuse a hand-picked palette if desired. Keep the celebration independent of completing an exercise.

Try independently Optionally vary palette length at fixed total width.

Supplied Arch construction and accessible route; automatic colour transfer is not assumed.

Reuse

Color Pillar

Same function contract, another coordinate-to-colour rule.

Return Color from HSV-based inputs; caller/receiver can stay the same. Explain the hand-height adapter.

Try independently Vary value alone, then diagnose a wrong coordinate frame separately from a wrong formula.

Supplied HSV conversion and explicit height adapter.

Introduce a small class

Color Grid Pallet

One class defines state and methods; separate instances keep separate current indices.

Propose Palette with a colour list and index, current_colour() and next_colour(). Start with a nonempty palette; create two instances and advance one. Reuse known modulo/functions and send the result through the existing floor receiver.

Try independently Predict both instances after separate advances, then store and revisit a colour at an address.

Supplied Class shell and address-to-MultiMesh receiver. This learner class and binding are proposed; there is no material/node per cell.

Reuse / reflect

Color Paint

Known time, functions and bounded surface coordinates.

Change one existing automatic path rate/amplitude; compare its calls with the manual cans' shared paint operation.

Try independently Predict narrow/wide or slow/fast path changes without confusing the evolving image with a retained gesture list.

Supplied UV-to-hit conversion, spraying and feedback shader.

Compose / reflect

Color Walls

Combine known palettes, instances, functions and assignments.

Use a small existing part list or pane arrangement to make an independent variation. Keep transparency and lighting implementation supplied.

Try independently Use a different palette length, a returning function and a bounded condition; explain which objects share values and which keep state.

Supplied Pane receiver, collision and rendering; preserve privacy/authority inquiry.

Then let the foundations work

Colour closes the first foundation pass. Five existing sequences give those capacities further work before Randomness.

Tiling

Return to palette instances, addressed reads, copies and references. Let the same record acquire another reader.

Supply serialization and complex rendering; do not add a language prerequisite merely because it appears in the artifact.

Change

Use known functions, loops and running totals for a finite difference and finite sum. Keep a position through repeated field steps.

The mathematical relationship is new; programming basics should be familiar. Choose exact learner edit bindings before writing.

Forces

Keep position and velocity as separate state; update several independent bodies using the same small rule.

Make state-plus-update reusable for particles and agents. Engine physics and the learner's explicit update remain different operations.

Form Finding

Reuse conditions, functions, state and repeated updates to search or satisfy a constraint.

Annealing needs a local bounded-random-draw introduction: range, when a draw occurs and one acceptance comparison. Do not pretend Arrays already taught it.

Waves

Reuse elapsed time, the short sine preview, lists, functions and independent state. Return to traces through sampling.

Give new signal/coupling concepts room. Event selection may reuse the bounded draw; distributions and seeds wait for Randomness.

At the entrance to Randomness

Given the working museum, named input/display interfaces and a changed requirement, make a small study with several independently stored bodies or marks. Use a list, a loop, a returning function, a condition and two class instances. Add a reset, predict an outcome, inspect values and explain a correction. Then replace one deterministic choice with a supplied bounded random draw and state what remains unchanged.

Passing this practical review would support foundation readiness; appearing in code, a summary or a completed reading does not. The task can build on the student's existing work and need not become another museum artifact.

Return to the named first lesson or practice hall for the missing operation; do not solve a language difficulty by adding another algorithm.

What can wait
  • Inheritance hierarchies or polymorphism
  • Dictionaries before a lesson needs them
  • General matrix algebra
  • Manual memory management or asynchronous programming
  • Implementing the renderer, XR player, physics engine or shader system
  • A full theory of probability before Randomness

Write one tutorial at a time

  1. Review these placements as a proposed foundation layer; retain current accepted summaries until a deliberate revision is agreed.
  2. For the next hall, write its short storyboard with: brings, first new operation, practice, supplied interface and one independent variation.
  3. Check the existing artifact and identify the exact learner edit location before expanding that single tutorial.
  4. Read the next two halls to ensure they reuse the result rather than silently adding prerequisites. Update both full and compact summaries when a choice is adopted.
  5. After each sequence, assess the small independent work. Record observed difficulty and adjust the next introduction; no invented time estimate or mastery score.
  6. At Colour, check the six NOC fundamentals together. Practise them further in the intervening sequences before the Randomness checkpoint.
Open teaching contracts and source differences
  • Point Trace's current companion uses a starter scene and persisted TraceMemory, while the museum notes describe the existing pen and session transfer. Preserve the museum's source record and fit-then-round Grid behavior; reconcile the teaching host before promoting the lesson.
  • The current Point One source edit starts with a constant. Make the intended variable/assignment learning explicit without falsely presenting the corridor as a live draggable point.
  • Array's reduced creation/display binding and Tutorial_3D's storage conversion need concrete lesson contracts. A visible collection alone does not teach independent object ownership.
  • Nails' complete authored function, Grid's proposed Palette class and custom colour receiver are not delivered learner exercises yet.
  • The older subject register still assigns first conditions to Translation and a random draw to Array. Reconcile it only when these proposed teaching placements are adopted.
  • Core by Colour is a curriculum target, not evidence of a tested beginner course or a claim that all 35 full tutorials already meet it.
