## Decision

Develop an existing artifact rather than add another object to the room. The automatic-writing desk previously generated sine-shaped script modulated by head-position speed, with seeded rows and optional demo input. It now has an opt-in `head_height` mode selected only in Point_Trace. The default `asemic` mode remains intact elsewhere.

Measured mode starts empty. An observer approaching the front of the desk establishes a height baseline. Elapsed time carries the nib across five rows; relative head height displaces the ink within a row. Constant height produces a level stretch. Lost input produces no observations while the active page's clock can continue. A full page stays visible until the observer leaves and returns. Head height beyond the bounded row range is reported. No sine/random trajectory or generated handwriting enters this mode.

The active measured-view selector is shared with head_trace_projection. It admits the current normally tracked XR camera or, without active XR, the labelled desktop museum walking view. It refuses spectator cameras and inactive rigs and reports notified discontinuities. The existing head-path behaviour is regression checked after this extraction.
