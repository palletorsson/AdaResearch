Wavefunctions — assessment decisions

8 October 2026. Author approved a small clarification pass after the external assessment. The twelve-hall order, complete printed programs and tested interactions remain intact.

Applied

  • Intro ends with four distinctions: oscillation, spatial pattern, propagation through coupling, and composition. Movement, record and composition remain the narrative questions. These two views serve different purposes; neither imposes a new room order.
  • Propagation's learning labels identify neighbour coupling and distinguish it from delayed animation. The existing old/next-state explanation and coupled/independent comparison remain.
  • Air Music foregrounds onset, continuing voices and sample addition. Its generated decay does not establish a physical resonance model.
  • Cage explicitly interrupts periodic expectation. Timing, records and replay continue the lineage; bounded random selection previews the later Randomness sequence.
  • Synthesis states the formal tutorial's completion task. Room Memory remains in the museum and reflection as an optional listening investigation, not a prerequisite for Randomness.

Pendulum and Sine Space are preserved. Existing independent variations remain the learning checks; code assertions establish program behaviour, not student understanding. Comparative ratings against other sequences are editorial opinions, not grounds for restructuring this one.

Proposed extension — one recipe, two receivers

Status: proposed, not implemented or validated. Optional after Synthesis.

Carry the five coefficients and the signed harmonic sum. Let one shared function receive an angle and return a value. Draw one cycle using that function, then use it to generate a short audible note. Keep the familiar point controls. The same coefficient edit must reach both receivers; separate copies of the formula would weaken the demonstration.

The student chooses a recipe, predicts one value on the curve, then changes one coefficient and explains what remains shared between the visible and audible versions. The aim is to carry a generating relationship into another medium, not to infer timbre from the picture alone. Spatial display scale and audio playback gain must remain declared, separate decisions.

Before this becomes a lesson:

  • Print the complete reduced program with the carried dependencies, following the existing museum host contract.
  • Assert that both receivers evaluate the same function at corresponding phases.
  • Check a single harmonic, a mixed recipe, a negative contribution and the all-zero case.
  • State the audio sample rate and allowed frequency range; provide fixed output headroom across the supported coefficient range.
  • Test the student's changed recipe as well as the initial one. Check audible output and actual museum placement separately from numerical assertions.

No extension code, sound or completion requirement was added in this clarification pass.
