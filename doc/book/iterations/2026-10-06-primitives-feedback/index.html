Where the feedback needed qualification

The saved trace is a finite sample, not a complete continuous movement. Lines already teaches relations; Triangle adds an ordered face recipe. A generating rule can reduce manual work without making its output unknowable. The closing exercise asks for an arrangement using known constructions; an inhabitable structure would introduce unlearned collision work.

Godot, Profiles and Portals already had useful reflective passages, so the changes there stay in the tutorial. Tetrahedron, Cube and Columns already carry the proposed progression and need no extra explanation.
