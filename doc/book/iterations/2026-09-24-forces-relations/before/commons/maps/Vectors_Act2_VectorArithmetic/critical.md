# A remainder can change its role

The subtraction station retains displacement under common translation but reverses it under exchange of A and B. Relation and distance are not identical: equal separation does not decide which address is the destination.

Projection retains one component relative to a chosen unit rail. A perpendicular change alters the input without altering the kept vector. The station explicitly preserves the remainder, so kept+remainder recovers the input; information loss occurs if only the projection is retained. Turning the rail reallocates what is kept. This is a testable framing choice, not proof that every classification or exclusion is the same process.

The live connection makes the comparison accountable: both stations use one room-local pair of coordinates. Controls state their bounds, the diagrams state their half-size scale, and the receiver can visibly edit the upstream A. These conditions are part of the experiment.

The retained dot console applies FRIEND to an angular threshold; its target has no modeled social relation. The retained torque console prints rpm from a normalized angular factor without measuring revolutions. These are specific seams between implementation and naming. A later force experiment should supply dynamics and measured state before claiming that the wheel teaches physical acceleration. Neither information-theoretic entropy nor a body's lived experience is measured by these stations.
