## The new comparison

**Writing orientation** names the artifact-to-text relation: an operation proposed for attending to a supported encounter. A hypothesis needs a consequence worth testing. The current comparison changes the whole Geiger passage, with three arrangements of the same factual material. It is more demanding than rephrasing its opening, while keeping the other four encounters, the five-stop room/final order and the ending fixed.

These are intentions, recorded before reading. **Observed effects remain empty and both tests unassessed.** Do not count generated formal differences as proof of reader effects. The existing author toolbox supplies provenance for the operations; these original passages are neither imitations nor a new scholarly study of those authors.

Read the passages before opening the predictions. Then read a complete chapter and describe what became noticeable and whether another encounter acquired a changed significance. Record the exact edition, reading order, setting and response. An unchanged reading, a preference for the reference, confusion or redundancy all count as findings. Discard a candidate that supports neither test. One supported test can justify a scoped revision; two make a stronger candidate without automatic adoption.

This is a local intervention testing a map relation. It does not yet show that a map can compose itself. Length, explanation timing and rhythm vary together; repeated reading can also change attention. The comparison is editorial, not a causal experiment isolating an author's effect.
