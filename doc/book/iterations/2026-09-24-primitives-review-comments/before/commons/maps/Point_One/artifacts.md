## What is not in this first walk

`wireframe_threshold` was deferred to Point Triangle Context. `static_point`, `script_runner`, `dark_sphere`, `lab_room` and `grid_lines` are not current interactable cells here. Their absence is not a recommendation to add them. Older catalogues and alternate layout notes should not override the current authored map or silently remove its secondaries.

`folding_past` is a special case: it is present through the lobby builder rather than the interactable layer. The global generated dealing manifest currently misses that view; its consumer is a different layout path. Correcting that generator is a separate task, not a reason to omit the work from this chapter or add a duplicate to the floor.
