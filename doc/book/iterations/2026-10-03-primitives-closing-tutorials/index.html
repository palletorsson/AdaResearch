One column — an outline made of numbers

The octahedron used a rule to place six corners. Now we give a rule an outline to work with.

Open primitive_column.tscn in the Ada student starter. One pale column stands in the room. Its sides catch the light differently as you walk around it.

1. Read the outline

Open studies/primitive_column/column.gd:

var profile: Array[float] = [0.50, 0.50, 0.32, 0.22, 0.32, 0.50, 0.50]
var height := 2.2
var sides := 8

The profile describes the column from bottom to top. Each entry is a radius in metres. Array[float] holds numbers where Trace's Array[Vector3] held positions.

Each radius makes one horizontal ring of positions. Seven entries give seven rings, equally spaced over the full height. The first two have radius 0.50. The middle ring has radius 0.22: that is the narrow waist. Straight strips join neighbouring rings.

Change only 0.22 to 0.55 and run again. The waist becomes a bulge. The neighbouring strips change slope. Height and the number of sides stay the same.

2. Follow one entry into space

This function turns the radii into positions:

func column_positions(radii: Array[float], full_height: float, divisions: int) -> Array[Vector3]:
    var circle := CircleSamples.points_on_circle(divisions, 1.0)
    var step := full_height / (radii.size() - 1)
    var points: Array[Vector3] = []
    for i in range(radii.size()):
        for p in circle:
            points.append(Vector3(p.x * radii[i], i * step, p.y * radii[i]))
    return points

CircleSamples is supplied. It returns equally spaced positions around a circle of radius one in the XY plane. Here we use its X and Y values for the column's X and Z. The ring lies horizontally; the column's Y comes from i * step.

Seven rings leave six intervals, so step divides the height by radii.size() - 1. The outer loop visits each radius. The inner loop places its ring. With seven radii and eight sides, the function returns 56 positions, starting at the bottom.

In _ready(), the returned positions become a surface:

    positions = column_positions(profile, height, sides)
    surface.mesh = ColumnSurface.make(positions, sides)

ColumnSurface is a supplied builder. It connects adjacent rings with triangles and closes the top and bottom. Its source is included; lighting normals and seam closure stay inside it for now. The position function returns data. The builder makes the mesh from that data.

3. Separate height from resolution

Restore the middle radius to 0.22. Change height to 1.6 and run again. Every ring keeps its radius. Only the spacing between rings changes.

Restore 2.2. Now try sides at 4, 6, 8, 12 and 16, running after each change. The profile and height stay fixed. The circular cross-sections gain sides; the straight intervals up the outline remain straight.

More rings would not automatically make this outline smoother. Adding an entry also changes the equal spacing. This reduced lesson joins specified radii with straight intervals; the larger Rings of Ash gallery uses curved profiles and a separate setting for sampling those curves.

4. Keep an outline of your own

Change two radii. Keep the height and side count fixed while you decide whether to keep the result. Then try it at another height.

Use 2–32 radii, each above zero and at most 0.8 metres. Keep the full height above zero and at most 2.5 metres in this room. The supplied sampler accepts 3–256 sides. These are the study's working bounds, not definitions of a column.

The column is a visible surface without a collider. The room, input, material and mesh builder are supplied. Your list and position rule produce its form; no prepared mesh is fetched from a scene.

Four sides can be the shape you want. Sixteen can suit another purpose. In Portals we will give one comparison a measurable requirement. That requirement will still be ours to choose.

Melencolia — arrange what you can make

We can place points, connect faces and generate a form. Portals gave us a way to check one requirement. Now make an arrangement with the constructions we know.

Open primitive_composition.tscn in the Ada student starter. Three identical pyramids stand on the floor. The middle one is farther away. Walk to the side and compare their outlines.

1. Place the same form three times

Open studies/primitive_composition/arrangement.gd:

var positions: Array[Vector3] = [
    Vector3(-1.15, 0, 0),
    Vector3(0, 0, -0.8),
    Vector3(1.15, 0, 0),
]

These are positions for whole bodies. They are measured from the study's origin, which the scene places 0.7 metres behind the room's centre. Each pyramid's local origin is at the centre of its base. Keeping Y at zero leaves its base on the floor.

The familiar list and loop now arrange objects:

func _ready():
    for at in positions:
        var body := Pyramid.new()
        body.position = at
        add_child(body)
        bodies.append(body)

Pyramid is the supplied script in pyramid.gd. Each call to Pyramid.new() creates a mesh instance and builds its geometry in code. It uses five positions and a face list, as in Polyhedra. Its square base uses two triangles, as in Cube.

The six render triangles make five geometric faces. Every copy has the same dimensions and material. The loop gives each copy a different position and keeps its reference in bodies.

2. Bring the centre forward

Change the middle entry's Z value from -0.8 to 0.8 and run again. From the entrance, the middle pyramid is now closer than its neighbours.

Its vertex positions inside the mesh have not changed. Its size on the screen has. Walk around it: which overlaps belong to this viewpoint?

Moving a body places its local construction elsewhere. In Cube, moving a corner changed the construction itself. Those operations can look related while changing different data.

3. Change the distance between neighbours

Keep the centre forward. Change the outer X values from -1.15 and 1.15 to -0.55 and 0.55. Run again.

The arrangement becomes tighter. From some positions the outlines overlap; from others they separate. No pyramid has gained a vertex, and no face has been removed. The gaps and the view have changed.

These surfaces have no colliders. The gaps are visual and spatial relationships, not a tested walking clearance. The museum's raised court and solid obstacles are separate constructions.

4. Make one arrangement to keep

Restore the outer X values to -1.15 and 1.15. Place the middle pyramid somewhere else on the floor. Keep its Y value at zero and its X and Z values between -2 and 2 for this room.

Look from the entrance, then from one side. Keep an arrangement that gives you something different from both positions. Save the script: restarting rebuilds the positions you wrote. Walking changes your view, not the saved arrangement.

This is a reduced study of the museum's geometric court. It does not reconstruct Dürer's engraving. The court, the tableau and the magic square have different tasks; the museum source notes keep those distinctions available.

We have made something exact enough to inspect and open enough to compose. Nothing in the pyramid's face list decided where it should stand. The critical text follows the desire invested in such forms. Here we have a small means of acting on it.

column.gd
extends Node3D

const CircleSamples = preload("res://prepared/circle_samples.gd")
const ColumnSurface = preload("res://studies/primitive_column/column_surface.gd")

var profile: Array[float] = [0.50, 0.50, 0.32, 0.22, 0.32, 0.50, 0.50]
var height := 2.2
var sides := 8
var positions: Array[Vector3] = []
var surface := MeshInstance3D.new()

func column_positions(radii: Array[float], full_height: float, divisions: int) -> Array[Vector3]:
    var circle := CircleSamples.points_on_circle(divisions, 1.0)
    var step := full_height / (radii.size() - 1)
    var points: Array[Vector3] = []
    for i in range(radii.size()):
        for p in circle:
            points.append(Vector3(p.x * radii[i], i * step, p.y * radii[i]))
    return points

func _ready():
    # Supplied guards name this study's usable range before constructing a mesh.
    assert(profile.size() >= 2 and profile.size() <= 32, "Use 2 to 32 radii.")
    assert(height > 0.0 and height <= 2.5, "Use a height above zero and at most 2.5 metres in this room.")
    for radius in profile:
        assert(radius > 0.0 and radius <= 0.8, "Use radii above zero and at most 0.8 metres.")
    positions = column_positions(profile, height, sides)
    surface.mesh = ColumnSurface.make(positions, sides)
    surface.material_override = preload("res://studies/primitive_column/stone.tres")
    add_child(surface)

column_surface.gd
extends RefCounted
## Supplied renderer. Consecutive rings have the same number and order of samples.
## It joins neighbours, closes the seam, and adds two planar caps. No collider.

static func make(points: Array[Vector3], sides: int) -> ArrayMesh:
    assert(sides >= 3 and points.size() >= 2 * sides and points.size() % sides == 0)
    var rings: int = points.size() / sides
    var builder := SurfaceTool.new()
    builder.begin(Mesh.PRIMITIVE_TRIANGLES)
    for ring in range(rings - 1):
        for side in range(sides):
            var next := (side + 1) % sides
            var a := points[ring * sides + side]
            var b := points[(ring + 1) * sides + side]
            var c := points[ring * sides + next]
            var d := points[(ring + 1) * sides + next]
            triangle(builder, a, b, c)
            triangle(builder, c, b, d)
    var bottom := Vector3(0, points[0].y, 0)
    var top := Vector3(0, points[-1].y, 0)
    var last := (rings - 1) * sides
    for side in range(sides):
        var next := (side + 1) % sides
        triangle(builder, bottom, points[side], points[next])
        triangle(builder, top, points[last + next], points[last + side])
    return builder.commit()

static func triangle(builder: SurfaceTool, a: Vector3, b: Vector3, c: Vector3) -> void:
    # Outward normal from the ordered construction; Godot front faces are clockwise.
    var normal := (b - a).cross(c - a).normalized()
    for point in [a, c, b]:
        builder.set_normal(normal)
        builder.add_vertex(point)

pyramid.gd
extends MeshInstance3D
## Supplied construction: five positions, four side faces and a triangulated base.
## All dimensions are local metres. This visible enclosure has no collider.

const SurfaceBuilder = preload("res://studies/primitive_column/column_surface.gd")
var vertices: Array[Vector3] = [
    Vector3(-0.4, 0, -0.4), Vector3(0.4, 0, -0.4),
    Vector3(0.4, 0, 0.4), Vector3(-0.4, 0, 0.4),
    Vector3(0, 1.5, 0),
]
var faces := [[0, 4, 1], [1, 4, 2], [2, 4, 3], [3, 4, 0], [0, 1, 2], [0, 2, 3]]

func _init():
    var builder := SurfaceTool.new()
    builder.begin(Mesh.PRIMITIVE_TRIANGLES)
    for face in faces:
        SurfaceBuilder.triangle(builder, vertices[face[0]], vertices[face[1]], vertices[face[2]])
    mesh = builder.commit()
    material_override = preload("res://studies/primitive_column/stone.tres")
