The grid
under load.

Mona Hatoum’s suspended fragments let us ask a different question of an array: when every object has an address, what makes the arrangement feel precarious?

01 / Read the image against the study

A place held overhead

You enter beneath a set of repeated addresses. Thin uprights carry rough fragments at regular intervals. Their outlines differ; their places return. The eye reads a grid before it reads any single piece.

Then the grid stops feeling like a neutral background. Heavy material hangs above the route. Order does not remove danger; it gives danger a pattern. A space that looks countable can still make the body hesitate.

In our study, the fragments change shape while their centres stay put. The result is a useful beginning, but the three equal bands make the system more orderly than the supplied photograph. The next question is: “Which address rule changes the silhouette while keeping the grid legible?”

White Cube describes Remains to be Seen (2019) as steel rebar punctuated by concrete-like floor fragments, a suspended structure that recalls the skeleton of a multistorey building. The supplied image is not independently identified as that work.

02 / Close reading of the existing artifact

Shape changes. Address holds.

The current scene makes a 5 × 5 field of uprights. Each site receives three fragments. A seeded offset changes each fragment’s corners, so resetting the slider returns the same family of shapes.

The important separation is already in the code: one loop assigns places; another calculation roughens surfaces.

for x in 5:
    for z in 5:
        var site = Vector3((x - 2) * 1.12, 0, (z - 2) * 1.12)
        for y in 3:
            var at = site + Vector3(0, 0.75 + y * 1.28, 0)
            var index = x * 15 + z * 3 + y
            mesh_at(fragment(index), at, stone)

random.seed = 821 + index * 199
corners.append(base + offset * amount)

This is the existing study’s logic. It has no simulated weight, sway or falling. The roughness is deterministic; it does not reshuffle the array addresses.

03 / A student-sized next step

Move one address rule.

1

Keep the inventory fixed

There are still 25 support sites and 75 fragments. Keep seeded roughness at zero so the position change is easy to see.

2

Change one rule

Use the row index to lower its five support sites by a small, measured amount. Keep every horizontal address and material unchanged.

3

Read the whole field

Compare the entrance view and the gaps beneath the fragments. Did one changed column alter the room’s rhythm? Which walk path now feels different?

The address is regular. What it holds does not have to be.

The code change is small but moves fifteen fragments at once: one row rule changes the silhouette of the entire field. That gives the learner an Array-level observation before we introduce a real constraint. Support, load and bounded sway belong later. The exercise does not turn the historical work’s materials or political address into a “collapse” game mechanic.

04 / Grounding and limits

What the translation leaves out

Hatoum’s work uses industrial materials and grid forms to bring bodily unease and political conditions into a gallery. A procedural rough mesh can show how a repeated address meets local difference; it cannot stand in for concrete, labour, displacement, or the viewer’s actual exposure to a suspended structure.
