# The six that does not finish

An additive continuation rule built around the existing physical die. Placed in Random_Cubes at (2,5), facing the first chamber.

Each freshly released, settled face adds to a live column. Six permits another accepted throw; 1–5 closes the chain. Five throws is the displayed budget. A fifth six leaves the chain UNFINISHED, rather than pretending the continuation rule ended it. NEW CHAIN clears the live record; RETURN DIE retrieves a loose die without adding a result.

The worked example 6+6+3 is a separate, labelled sculpture. Its values never enter live state. The scene does not choose or force a live face, generate reward rain, or automatically reroll. It reuses `commons/artifacts/paired_dice_column/paired_die.gd` and the original settled-orientation reader unchanged.

Every pip adds 9cm to the column. Maximum retained height: 2.7m above a 14cm base. Each throw has a seam and label. Stationary column collision follows its height. The original pickable die retains VR grip and desktop drop hooks; a held die is not reclaimed by NEW CHAIN.
