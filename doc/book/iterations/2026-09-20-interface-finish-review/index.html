What improved

The empty top border is removed. A slim frame and four flush fasteners attach the face to its housing. Printed labels sit closer to their controls, within subtle shaded wells. The value windows use larger type, and their backing clears the slider handle at every position.

F, E(S), λ, φ and KEEP still perform the same experiment. The retained total and comparison remain visible. The design makes their relationship easier to follow.

One principle, different instruments

The focused reference console combines a slider, dial, joystick and RESET. Size, rotation and position change the orange body. The two joystick axes appear in the same flat summary screen. Every visible caption and value on the console is 2D text carried by a surface in 3D.

The first reference capture revealed a mistake: the specimen platform hid the readout. Moving the platform back and up restored both views. An interaction test can pass while the spatial arrangement still needs work.

Reuse it in the project

var console = InterfacePresets.build(
    "workbench", "Your instrument", plate_height,
    "braun", "instrument"
)
# Set the grouping before adding controls.
console.panel().layout_columns = 2
add_child(console)
var size = console.add_slider("SIZE")
var turn = console.add_dial("TURN")
var position = console.add_joystick("POSITION")
var reset = console.add_button("RESET")

The instrument layout fits the casing to unscaled controls. It defaults to three columns; this reference uses two. The existing full sampler remains available. Enable reference_console on InteractableDemo, or use commons/interactables/interactable_console_demo.tscn, for the focused example.

This profile applies to console housings. Other housing forms and bespoke controls still need their own inspection. Adopt it per encounter, preserving the actions and comparisons that matter.
