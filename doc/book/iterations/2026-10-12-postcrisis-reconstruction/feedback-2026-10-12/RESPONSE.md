# After the Post-Crisis assessment

The assessment identifies the right pressure point: making alternatives is easier than deciding which alternatives deserve to remain. The eight-hall progression still holds. This revision adds two small experiments to the printed tutorials while preserving the reflective texts and the existing halls.

## What changed

| Place | Revision | What the student can establish |
| --- | --- | --- |
| Applied Ethics | RULE switches an authored minimum centre distance between 0.50 m and 0.90 m. The code checks all pairs. | The same six seats can pass one criterion and fail another without moving. The criterion is a design decision; it is not an accessibility standard or a measure of participation. |
| Collective Knowledge | The explanation separates retaining a revision from deciding whether it is warranted. | Source counts and revision counts do not establish collaborative knowledge. Contested explanations shared between participants remain a future project. |
| Rhizome | The text names the fixed boundary, arrival order and distance rule. | Changing link count is not shared control of the rules. Decentralized adjacency does not remove structural privilege. |
| Assembly → Synthesis | Optional PREDICT and KEEP NOTE controls retain one before/after experiment in a separate file. | A prediction can be wrong and remain visible alongside an observation and a reason for keeping the result. The note can be matched to the exact saved pose. |

The optional experiment asks the learner to write three short text values in the supplied scripts. It does not generate intentions or add a VR keyboard. It refuses blank values, accidental replacement of an existing note and completion against a pose changed on disk before rereading. A malformed note is retained rather than overwritten. Later poses can be distinguished from the subject of an earlier note.

The new code and assertions appear in the canonical `tutorial.md` files. The sphere, graph, body and pose validator continue their existing lineage. The note reuses that validator. No additional hall or replacement tutorial object is introduced.

## What the note does not solve

Editable, reversible and accountable describe different capacities. A before snapshot can support comparison, but it does not implement Undo. A learner-written explanation can make a decision inspectable, but the code cannot prove its truth, establish sincere prediction or provide another participant with authority to contest it. The note stores no identity, tracked hand path or complete revision history.

One experiment may contain several changed releases. Its snapshots show the starting and ending states; the intervening actions are not reconstructed. Changing a joint away and back can increase the edit count while returning to the same geometry.

## Engine corrections

The default audio bus referred to a stale resource UID. It now names the existing `default_bus_layout.tres` by path. The sound configuration itself is retained.

The Applied Ethics `tt` display loaded an XRTools scene containing an unbound serialized ViewportTexture. That placeholder has been removed; the existing viewport script supplies each screen's live texture when ready. A native check creates two displays and checks that their materials and textures are separate. The scene is exempted from the add-on ignore rule and included in the review package so the correction can be retained with the project.

The revised run checks explicitly for both reported errors. Its per-hall receipts also retain construction-time warnings. Those warnings describe artifact creation stalls, not measured steady-state frame rate. Headset profiling and any required scheduling or construction changes remain separate work; passing the lesson checks is not a performance clearance.

## What remains a useful next pass

The shared bench keeps setup and controls familiar. The review is right that this also makes several studies look alike. Retain it for these bounded code reconstructions, then test whether people can distinguish the learning tasks while visiting the larger installed artifacts. Spatial redesign should follow that evidence.

A collaborative layer that preserves competing descriptions and reasons for revision is worth developing. It would need contribution, contest and review mechanisms beyond this single-student model. It is not silently represented as completed here.

All eight reflective texts, map placements and sequence order are preserved. The current test report distinguishes automated reconstruction from independent learning and physical VR use. Before/after sources and the original assessment are included with this response.
