# Post-crisis review package

Open index.html for the route, ghost.html for evidence, or parallel.html for facing pages. tutorial.md and final.md contain the whole sequence. REPORT.md records scope and limitations.

This is a review/extraction package, not a standalone Godot game. Use Godot 4.6 in AdaResearch_46 with the existing XRTools and museum infrastructure. source/ mirrors project paths; learner/ contains the 32 exact printed and inherited scripts. Eight supplied .tscn launchers and their scripts are under source/doc/book/studies/postcrisis-lineage/. Point their LESSON preload at your reconstructed folder and run with F6. Preserve your working tree when comparing source copies. feedback.html explains the latest revisions, with the assessment, earlier files and logs in feedback-2026-10-12/.

Reproduce from project root with python tools/test_postcrisis_reconstruction.py, then python tools/run_postcrisis_rooms.py. These create private test records; they do not overwrite the installed visitor's Assembly pose. The native runner checks isolated actual halls; full-route walking and headset comfort remain untested.
