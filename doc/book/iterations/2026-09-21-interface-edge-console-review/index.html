Physical controls, flat text

Lambda changes one authored route through the reaction-diffusion coefficients. Speed controls how quickly model time is requested. The timestep button restarts the same seed with a finer calculation. These are different operations, now gathered within one backed surface.

See the consequence above the controls

Both captures use the same camera, seed, lambda and model time. The two fields and their timestep labels stay visible from this operating pose. The simulation results match the previous implementation exactly after 200 ticks.

Available, held, absent

The low and high preset versions also hold lambda. Speed, restart and seed controls stay available. These access rules apply to both the single field and paired experiment.

The single-field clamped version keeps its deliberately contradictory UNLOCKED sign. Better controls should help the visitor encounter that contradiction. The withheld version retains its changed title and identifies the missing fader directly on the console.

State follows the hand—and the source

Previously a locked handle could move while its value was ignored. It now refuses both grab and pointer input. External configuration still sets the parameter when authorized by the map, and the held cap and bracket follow that value together.

HOLD and the smaller timestep have persistent selected-button feedback. RESTART repeats the numbered seed; NEW SEED changes it. The difference between the two B fields remains visible without calling that number a measure of beauty, life or chaos.

A reusable parameter station

The shared component accepts two parameter definitions and up to four actions. Each parameter declares whether it is available, held or absent. The same physical-slider implementation now supports continuous values, discrete stops and authored input restrictions.

81 edge checks exercise XR grab-driver movement, physics ray input, all ten access/comparison combinations, readout synchronization, pause, seed and timestep controls, and live reconfiguration. 46 grammar and 45 fitness checks protect the earlier controls.

What still needs the museum

These are real Godot artifact captures in a desktop test scene. Headset reach, tracked-hand comfort, placement on raised exhibit furniture and standalone Quest performance remain untested. The next useful pass is to check the shared consoles inside their actual halls before widening the migration.
