# Local ↔ global memory pilot

4 October 2026. Known-case regression using Point Zero and Lines → Trace → Grid, then the carry toward Arrays. The conflicts were identified in earlier work. This is not a blind-discovery experiment or a benchmark against another memory system.

Scope: read a frozen selection of source and planning files, recover the local facts, carry their implications upward, and test a fresh reader using a compact packet. No Godot run, artifact edits, map reordering, tutorial expansion or production service implementation.

1. Save exact source copies and SHA-256 identifiers in `manifest.json`.
2. A source reader, without this conversation, checks the listed claims against the snapshot. Record scope and citations. Comments alone are not proof of behavior.
3. Assemble a compact working-memory packet from the verified findings and current author decisions. Keep proposals and unknowns explicit.
4. A fresh reader gets only that packet, not the conversation or snapshot. Ask what should happen next and what it cannot claim. It cannot independently verify the packet's source claims; this tests whether a handoff retains them.
5. Compare the answer against the criteria below. Check that production sources still match the manifest. Simulate one changed input in memory and verify its fingerprint differs; this tests stale-input detection, not semantic invalidation.

Criteria fixed before either reader returns:

| ID | Required distinction |
| --- | --- |
| C1 | Existing Endless Museum and counter remain the starting environment. |
| C2 | The pen keeps accepted positions; its released record can span pickups. Do not substitute an ideal fresh raw stroke. |
| C3 | Grid centres/fits first, then rounds display coordinates; preserve the source separately. |
| C4 | Later address-to-position generation cannot reconstruct arbitrary original positions lost to rounding. |
| C5 | Session retention does not establish persistence through restart. |
| C6 | Source evidence cannot certify headset traversal, beginner learning or the quality of all 204 halls. |
| C7 | Correct a proposed summary/register conflict; do not silently alter code or the museum to fit prose. |
| C8 | Carry the finding upward: explain its consequence for the sequence and wider teaching agreement without declaring a new global order. |

A criterion passes only if the fresh answer preserves it explicitly or unambiguously. Report omissions. Do not treat fluency as a pass.

Limits: one known passage, one source reader and one handoff reader, manually assessed by the parent agent. No measured model token usage, latency comparison, long-term memory guarantee, whole-project correctness claim or evaluation of artistic quality.
