The next physical interface reference makes a difference visible: a control can set a position, or command movement over time. Their handles share a compact station; their consequences remain in view behind it.

The shared controls needed repair

The old wheel had a 40 cm frame collider around an 8 cm wheel, and no collision shape on its rotating body. The smooth lever had two hand-pose redirects with no target. Neither component supplied a root pointer route or a reading.

The wheel now has four usable grips and a visible orientation index. Physical grabs and pointers agree, including after the station rotates. Holding still does not accumulate rotation; regrabbing beyond a half-turn preserves the current angle. Releasing a grip also preserves its pointer targeting.

One station, two meanings

ControlWhat it changesOn release
Wheel · set angleThe orange bar takes the selected angle.Wheel and bar stay where you left them.
Lever · command speedThe cyan bar keeps turning. Pull farther for more degrees per second; reverse the lever to reverse direction.The lever returns to zero. The bar stops at its accumulated angle.

This comparison connects transformation to change over time. It provides a basis for a later force control, whose input would change velocity rather than directly prescribe it.

A reference we can reuse

interactable_angular_demo.tscn adds this encounter to InteractableDemo. The smooth wheel and lever keep their existing scene paths and native hinge APIs. The reference explicitly opts its lever into spring return; the shared smooth lever still retains its setting by default.

The controls stand in front of the work on an inclined case with an upright support. The operating view uses a 1.60 m camera height. The reference is ready for placement and headset trials; it is not yet a verified museum installation.

What the checks establish

100 checks cover real XR Tools pickup/release, ray-hit pointer dispatch, limits, optional detents, wheel wraparound, two simultaneous grips, input cancellation, mapped readings and the visible receivers. Half a second at 60°/s adds 30°; zero command preserves the accumulated pose and stops receiver processing. The run contains no script errors.

Still to establish: comfort and reach in the headset, shorter and seated positions, Quest legibility and performance, and the larger controls inside existing museum placements. These are desktop captures with synthetic hand drivers using the real input APIs.
