- Random Return's sphere has an authored return path. Releasing it ends the carried ride. This distinction matters when discussing the participant's agency.
- Noise One's REMAP reuses the signed source value. It does not recover discarded negative distinctions from a clipped pixel alone.
- The prefab study retains the same inventory, but whole objects and mesh parts receive different random draws. A matched-motion follow-up is specified before claiming a single-variable grouping test.
