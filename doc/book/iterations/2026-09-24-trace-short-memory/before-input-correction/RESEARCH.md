# Autonomous encounter research: a line with a short memory

24 September 2026. Author request: try improving the book and space through curiosity about a topic and its edges.

## Starting evidence

Point_Trace already has a strong account of selection, movement thresholds, quantisation and inscription. Its text says the 4096-place line can lose its beginning, while detours.md explicitly leaves a smaller capacity as a future experiment. The gap was an encounter worth adding. The text did not need to abandon its question.

## Question and choice

Can forgetting become a drawing gesture? What happens if the body continues, pauses, and changes the purpose of the record?

Considered three moves: lower the existing dots' capacities; add a capacity menu; add one contrasting tool. Chose the companion so the existing recorder/resolution comparisons remain available and the visitor changes tools rather than learning another interface. The first render showed the inherited data table obstructing the drawing, so this variant now has only a small capacity plaque. Beads and cord make the retained points legible in space.

## Built

`trace_short_memory` inherits draw_dot. It keeps 32 positions, uses amber ink and the existing 5 mm movement gate, and does not fade over time. Its local script changes only rendering: 32 small beads and up to 31 cord segments read directly from the inherited list. The shared draw_dot implementation and scene are unchanged. The scene is registered, placed at (2,9) in the exit bay, and promoted alongside the existing primary artifacts. It faces the approach from the central passage. No original room artifacts were removed.

A focused new section in final.md asks the visitor to draw, watch the far end, pause, read the deletion rule, then try using the short record as a tail. The earlier 4096-capacity paragraph now leads to that encounter. The ending clarifies that only surviving positions are copied to Grid. The technical, tutorial, critical and detour companions and core encounter hashes are synchronized. Earlier prose and footnotes are preserved.

## What the experiment established

The same scripted 72-position gesture entered two held tools through their actual recorder callbacks. The original retained 72; the companion retained exactly the final 32. Its first loop disappeared from the short record. Four seconds of stationary callbacks did not remove any position. Motion below the gate spent nothing. One further accepted position removed exactly one oldest entry. Release copied the remaining 32 into TraceData. The beads match the stored positions exactly.

15 checks and two selected walking paths passed in the isolated actual Endless Museum, exit 0. Actual loop and tail images were inspected. No new GDScript errors. Existing unrelated engine UID/material warnings remain. The captured gesture is scripted through XRTools pickup state, not a live hand performance. Capacity counts accepted positions; it is neither a fixed duration nor a fixed spatial length. Thirty-two is a curatorial trial, not a measured optimum. Headset reach, comfort and whether the encounter invites play remain open.

## What this contributes

The distinction between waiting and continuing becomes something to try. A limit first described as loss can acquire another purpose: a short-lived form accompanying the hand. This does not prove an inherently liberating effect of small memory. It gives the visitor a material difference with which to ask that question.

## Repeating this method

1. Read an existing passage and the relevant artifact, including secondary work.
2. Name one question that the encounter cannot yet let a visitor investigate.
3. Prefer restoring or varying working material; isolate the difference being tried.
4. Build and compare behaviours, then look at the actual room. Let a failed staging attempt change the design.
5. Write only what the new encounter can carry, leaving its interpretation open.
6. Preserve the prior text, show the difference and record what still needs a person in the room.

A next possible inquiry is how a timed recorder could keep a pause that this position list omits. The existing hand telemetry is a candidate, but its active input must be verified before treating its rows as evidence of the visitor's hand. This is a future lead, not work silently added to this pass.
