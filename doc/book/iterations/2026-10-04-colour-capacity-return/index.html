Eight map summaries · 2026-10-04

Colour · what changes

A short comparison for each map: what the plan said, what is proposed now, and why.

All images are earlier museum captures. This update changes teaching plans; there are no new visual or runtime changes.

01 Color_Context_Placed

Let colour regroup an assembly

Before
Palette assignment was useful, but the plan also required building a new stack and left category data unsettled.
After
Use the existing forms; change their palette rule. Begin with list position and make shape categories a small optional return.

Why Keep the opening focused on how colour regroups familiar parts.

02 Color_Flashlight

Change what reaches a surface

Before
The plan asked the student to create another light in a supplied receiving room.
After
Use the museum lamp and the small source edit already taught here. Change colour and aim separately.

Why The existing encounter already provides the necessary experiment.

03 Color_Nails

Use a position to choose a colour

Before
Position-to-RGB was promised, but its input, output and first receiver were left broad.
After
Specify one small local-position → RGB function and one preview material. Keep the hand system supplied and preserve the critical skin/polish passage.

Why Give the student a reusable operation without making the salon a wiring lesson.

Review this map’s proposal ↗

04 Color_Rainbow

Divide one span into chosen colours

Before
A new partition generator was a required output of the hall.
After
Make palette substitution and fixed-width partitioning optional. A chosen Nails colour can return through a recorded value; celebration needs no task.

Why Preserve the room’s generosity and avoid treating every artwork as homework.

Review this map’s proposal ↗

05 Color_Pillar

Ask a field for a colour

Before
The field function was sound, but its coordinate change and hand-height conversion were only generally described.
After
Return to Nails’ function with explicit HSV coordinates and height conversion. Keep one sample for the next hall; preserve the fog-like ceiling encounter.

Why Make the change of representation teachable without claiming one formula serves both rooms unchanged.

Review this map’s proposal ↗

06 Color_Grid_Pallet

Let one address keep a colour

Before
The plan introduced a separate material grid and made exception protection its main output.
After
Keep a colour from Nails or Pillar at one address using the existing instance model. Teach leaving, returning and overwriting; protection becomes optional.

Why Make the strongest sequence handoff concrete while distinguishing the proposed input from the installed four inks.

Review this map’s proposal ↗

07 Color_Paint

Give a mark somewhere to remain

Before
The plan required a second teaching brush and left the shared canvas connection unresolved.
After
Edit the existing automatic path. Both painters already use the same spray operation; distinguish accumulating, fading paint from a saved trace.

Why Use the implemented encounter to teach one meaningful change, with less machinery.

Review this map’s proposal ↗

08 Color_Walls

Compose a view through colour

Before
The plan required composing two new panes despite useful edits already present in the companion.
After
Use an existing pane or palette edit. Keep view versus passage central and carry palette-versus-arrangement into Tiling.

Why Preserve an accomplished ending without adding another required construction.
