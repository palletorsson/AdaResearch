# Tutorial · The Three Verbs

Start at the near end of the hall. The box and the sphere are the same pair in every bay; only the operation changes. Read the result before reading the label. What does the boundary let your body do?

At **union**, the two surfaces become one result. The seam disappears because the region belonging to either operand is kept. In code the verb is an enum, not a second object:

```gdscript
combiner.operation = CSGShape3D.OPERATION_UNION
```

At **intersection**, keep only the region both operands claim. Walk toward the overlap and notice the empty case: a successful operation can return no surface at all. At **difference**, subtract the sphere from the box. The cavity wall is generated by the operation; neither input carried that face as a separate object.

The three bays are one lesson in a fixed order: include, agree, remove. Return to the centre and say the expression aloud: `A ∪ B`, `A ∩ B`, `A − B`. Then ask what the grammar cannot say. There is no fourth operation for partly, becoming, or reversing the operands without changing the sentence.

The next hall, **Boolean_Gallery**, lays out the hidden variants of these verbs. It asks whether a published ladder of values agrees with the code that builds it.
