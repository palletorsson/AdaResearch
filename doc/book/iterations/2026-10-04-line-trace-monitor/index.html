What stays?

The endpoints and their 4-metre straight segment. All three journeys connect the same pair of positions.

What is kept?

Ordered samples of the moving point. The trace joins neighbouring samples; its length is measured from those segments. It is a record of this journey.

This is a separate preview of the same artifact shown in the museum capture. Its illustration uses three authored example routes. Connecting a visitor’s own drawing is a possible next study.

Build and verification

Each monitor owns a SubViewport and an isolated World3D. The camera films the geometry; the viewport texture appears on the physical screen. A PackedScene supplies the illustration, so another concept can use the same monitor housing.

Controls use the existing XR Tools pointer and touch-button component. The test checks pointer presses, sample stepping, fixed endpoints, measured trace lengths, world isolation and suspension at a distance. Tracked-headset usability and Quest performance remain untested.
