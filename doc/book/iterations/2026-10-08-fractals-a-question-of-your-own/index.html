Name what another call needs

The recipe dictionary groups three settings under names. seed is the familiar Vector2(start, length), here (0, 6). fraction says how much of each parent survives at each end. steps is the number of replacements. A dictionary packages these decisions; it does not prove they are valid. build() bounds the depth, and the replacement function requires a fraction strictly between zero and one half.

replace_intervals() makes a separate next array. For each parent it places one descendant at the original start and another at start + length - size. It never appends to the array it is reading. build() starts from the seed every time, replacing the current list once per step. Editing a setting therefore reconstructs the requested version rather than applying another cut to yesterday's result.

At three cuts, eight pieces survive. For quarters their combined length is 0.75 metres; for thirds it is about 1.778 metres; for two fifths it is 3.072 metres. The count alone cannot distinguish these constructions.

Keep a recipe, reconstruct its result

kept_recipe = recipe would give two names to the same dictionary. A later edit through one name would reach the same object. duplicate(true) creates a separate copy. The fields used here are numbers and a Vector2; the deep-copy option also copies nested arrays or dictionaries if we add them later. It is not a universal copy of every possible resource.

KEEP copies the settings. rebuild() then constructs both lists independently. RESTORE also copies: after restoring, a new LIVE edit must leave KEPT alone. The rendered bars are disposable views; they are removed and drawn again without removing the point or changing the saved recipe.

Both rows use the same scale: one model metre represents 0.34 metres on this table. Neither row is stretched to fill the width. The readouts state the model lengths. A length written as six metres does not make this miniature six metres wide.

Complete code

recipe.gd contains the replacement, copy, input and drawing. Its hand control offers the three declared fractions; the display is centred on the six-metre seed. Treat that framing as an explicit choice when developing another work.

extends Node3D
const PointBody = preload("point_body.gd")
const FRACTIONS := [0.25, 1.0 / 3.0, 0.4]
const LIMIT := 5
const DISPLAY_SCALE := 0.34
var recipe := {"seed": Vector2(0, 6), "fraction": 1.0 / 3.0, "steps": 3}
var kept_recipe: Dictionary = {}
var live: Array[Vector2] = []
var kept: Array[Vector2] = []
var point: XRToolsPickable
var drawing: Node3D
var live_caption: Label3D
var kept_caption: Label3D

func _ready() -> void:
	drawing = Node3D.new()
	add_child(drawing)
	point = PointBody.new()
	add_child(point)
	point.action_pressed.connect(keep_current)
	live_caption = label("", Vector3(0, 1.40, 0))
	kept_caption = label("", Vector3(0, 1.79, 0))
	label("CHANGE ONE RULE / KEEP A COMPARISON", Vector3(0, 2.02, 0))
	for i in 3:
		label(["1/4", "1/3", "2/5"][i], Vector3((i - 1) * 0.35, 1.0, 0.55))
	kept_recipe = recipe.duplicate(true)
	rebuild()
	park()

func replace_intervals(intervals: Array[Vector2], fraction: float) -> Array[Vector2]:
	assert(fraction > 0.0 and fraction < 0.5)
	var next: Array[Vector2] = []
	for interval in intervals:
		var size := interval.y * fraction
		next.append(Vector2(interval.x, size))
		next.append(Vector2(interval.x + interval.y - size, size))
	return next

func build(settings: Dictionary) -> Array[Vector2]:
	assert(settings.steps >= 0 and settings.steps <= LIMIT)
	var intervals: Array[Vector2] = [settings.seed]
	for generation in range(settings.steps):
		intervals = replace_intervals(intervals, settings.fraction)
	return intervals

func rebuild() -> void:
	live = build(recipe)
	kept = build(kept_recipe)
	redraw()

func choose(index: int) -> void:
	var fraction: float = FRACTIONS[clampi(index, 0, 2)]
	if is_equal_approx(recipe.fraction, fraction):
		return
	recipe.fraction = fraction
	rebuild()

func keep_current(_body = null) -> void:
	kept_recipe = recipe.duplicate(true)
	rebuild()

func restore() -> void:
	if point.held():
		return
	recipe = kept_recipe.duplicate(true)
	rebuild()

func advance() -> void:
	if point.held():
		return
	recipe.steps = mini(recipe.steps + 1, LIMIT)
	rebuild()

func reset_live() -> void:
	if point.held():
		return
	recipe = {"seed": Vector2(0, 6), "fraction": 1.0 / 3.0, "steps": 3}
	rebuild()

func _physics_process(_dt: float) -> void:
	if point.held():
		var local := to_local(point.global_position)
		choose(clampi(roundi(local.x / 0.35) + 1, 0, 2))
	else:
		park()

func park() -> void:
	var index: int = FRACTIONS.find(recipe.fraction)
	var home := Vector3((index - 1) * 0.35, 1.15, 0.55)
	point.global_transform = global_transform * Transform3D(Basis.IDENTITY, home)

func _process(_dt: float) -> void:
	if Input.is_action_just_pressed("ui_accept"):
		keep_current()

func total(intervals: Array[Vector2]) -> float:
	var length := 0.0
	for interval in intervals:
		length += interval.y
	return length

func redraw() -> void:
	for child in drawing.get_children():
		drawing.remove_child(child)
		child.queue_free()
	draw_row(live, 1.27, Color("28252c"))
	draw_row(kept, 1.66, Color("e99db8"))
	live_caption.text = describe("LIVE", recipe, live)
	kept_caption.text = describe("KEPT", kept_recipe, kept)

func describe(title: String, settings: Dictionary, intervals: Array[Vector2]) -> String:
	return "%s / %d cuts / %.1f%% at each end / %d pieces / %.3f m" % [title, settings.steps, settings.fraction * 100, intervals.size(), total(intervals)]

func draw_row(intervals: Array[Vector2], y: float, colour: Color) -> void:
	for interval in intervals:
		var surface := MeshInstance3D.new()
		var shape := BoxMesh.new()
		shape.size = Vector3(interval.y * DISPLAY_SCALE, 0.045, 0.06)
		surface.mesh = shape
		surface.position = Vector3((interval.x + interval.y * 0.5 - 3) * DISPLAY_SCALE, y, 0)
		var finish := StandardMaterial3D.new()
		finish.albedo_color = colour
		surface.material_override = finish
		drawing.add_child(surface)

func label(text: String, at: Vector3) -> Label3D:
	var tag := Label3D.new()
	tag.text = text
	tag.position = at
	tag.font_size = 36
	tag.pixel_size = 0.0016
	tag.outline_size = 7
	add_child(tag)
	return tag

After

The boundary takes a detour

Four metres of line wait behind the desk. Keep its ends in view. Where could more line go?

Press NEXT. The middle lifts into a peak. Follow it up and down before reading the counter. The ends have not moved apart, but travelling between them along the line now takes longer. Press again. Each of the four new segments takes its own detour, including the ones already climbing.

At the fourth step, 256 segments share a path a little over twelve and a half metres long. The endpoints still stand four metres apart. Distance between them and distance along the boundary have begun telling different stories.

Beside the desk, the familiar black point rests on a smaller drawing. Take it and follow a fold. A second point travels over the larger line on the floor. The same position has acquired another reach. Press the trigger once while holding: every segment takes the next detour. The point has become a way to read the construction as well as a way to ask for more of it.

Your hand can leave the line. The reading finds its nearest span; on release, the sphere settles there. Jump across a fold and the number can jump too. It tells you where you are along the path, not how far your hand has travelled. Try the floor drawing with your eyes and feet. The little turns that fit inside one gesture have spread across the room, but at the fourth step some are already too small to follow as separate steps. A route can remain exact after this body loses the means to perform every part of it.

This is the small decision inside each replacement:

var b := start + dir * (len / 3.0)
var d := start + dir * (2.0 * len / 3.0)
var c := mid_point + perpendicular * height

The next list joins start → b → c → d → end. Four segments, each a third of the old length. The next call receives these segments as its beginning. In the cellular automata halls every cell wrote its next state into a separate array before the arrays were swapped; this list is that swap, with segments for cells, and in the next sequence it will be a sentence. Each of the 256 pieces at the fourth step is a separate object in that list; nothing here has yet asked one of them to move. A multiplication of four thirds can be followed with the eye.

Try TURN. The detours go to the other side. The count and path length survive the reversal. They have not told us everything about the shape.

RESET, then FORM. A triangle closes the starting line into a boundary. NEXT sends its peaks outward; TURN folds them inward. There is an inside to negotiate now. An instruction about direction has become a decision about where an enclosure extends.

var m1 = (v1 + v2) / 2.0
var m2 = (v2 + v3) / 2.0
var m3 = (v3 + v1) / 2.0

The next calls receive the three corner triangles. Their sides are half as long, so each has a quarter of its parent's area. Three quarters remain. At four cuts, eighty-one kept triangles occupy about 4.93 square metres of the original 15.59. There are more pieces to address and less surface to colour.

Now press VIEW. Pale middles appear where the rule made its removals. Press again. The kept corners disappear from the drawing, and the middles stand in their colours. What we had called the waste now holds the room's attention.

The program still computes the same corner triangles. It has changed which results receive meshes. The negative view draws forty removed middles from the four cuts. These are parts the operation already located; we did not need a new fractal to find another subject inside it.

DEPTH gives the drawn pieces more thickness. Their planar area does not change. Neither view makes these pieces load-bearing: the sculpture has no collision, although its control desk does. An opening in an image, a hole in a solid and a passage for our body ask different things of the implementation.

We can change the view back. That matters here. The ease with which this display restores a discarded part belongs to this stored construction. It does not make every act of removal reversible.
