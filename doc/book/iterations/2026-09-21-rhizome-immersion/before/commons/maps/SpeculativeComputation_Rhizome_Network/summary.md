# Connect

Can a network grow without naming a root?

The commons machine had many sources and one centre. Here a new node chooses several existing neighbours.

Primary: `rhizome_grower`.

Watch a new shoot and trace its links. Hold growth, switch between one and three links on the same points, then predict what happens when a busy node is temporarily removed. Trace the surviving routes before reading the component count.

New nodes connect by distance within a fixed region. They have no designated root, but some nodes accumulate more links than others. NODE exposes birth index and degree. CUT leaves a ghost and permits restoration; the graph does not repair itself. REPLAY retains the sample sequence. The absence of a named root does not establish equal influence.

The assembly laboratory replaces nearest-neighbour growth with a catalogue and an authored target.

Supporting artifacts remain: `rhizome_cave_demo`.
