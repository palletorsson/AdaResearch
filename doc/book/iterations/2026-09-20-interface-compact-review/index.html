What the encounter needs to keep

The existing review asks us to preserve the differences between a shared source, a saved recipe and a receiver that holds an earlier image. MARK, SAVE, RESTORE, LINK / HOLD, TARGET, UNDO LINK, REPEAT SIZE and OFFSET +5CM all remain. The manuscript and map configuration were not edited.

The new layout brings those experiments closer together. The receiver selection, saved-state semantics, held images and undo behaviour remain attached to the same buttons.

A change other panels can use

ControlPanel now supports an optional column count, maximum row width and gap between rows. It measures both visible geometry and collision shapes. Oversized controls receive more space; wrapped layouts preserve their authored scale and rotation.

# Set before adding controls. Existing callers retain the single row.
panel.layout_columns = 4
# Optional: wrap sooner for the available space, in panel-local metres.
panel.layout_max_width = 1.2

This first adoption is in pattern_machine_a/recipe_study.gd. Other halls retain their current arrangement. The separate ControlConsole still scales its inner panel to its cabinet width; that enclosing scale needs its own repair before wider console adoption.

Evidence, and what remains to test

  • 70 layout and input-handler checks pass: full-size buttons, correct callbacks, flat labels, backing, persistent readout state, repeated layout and rotated oversized controls.
  • 101 existing Foundry regression checks pass: recipe restoration, held receivers, relink/undo, sampling and selected collision approaches.
  • Before and after capture records retain actual control centres and 24 hall/setup checks each.
  • Exact source changes and source hashes connect these images to the implementation.

Direct pointer-handler calls and selected museum inputs are desktop evidence. Tracked hands, seated reach, headset legibility and Quest performance remain untested. Existing UID/certificate and unrelated museum warnings remain in the logs. Generated panel labels are 2D on surfaces; older loom and receiver labels still await migration.
