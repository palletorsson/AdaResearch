# Symmetry Seventeen — floor 2

Codex transferred all 16 original placements. Registry delegates resolve to their original loom/mill scenes with their named presets applied before and after ready. The symmetry comparison retains its original tile data, held sample and undo behaviour.

Wall Pattern Gallery uses its original no-grid fallback: sixty preview cubes. A Void-only adapter keeps their generated geometry, lights and overlays local to the editable assembly, rather than writing world coordinates before entering the tree. No museum walls were recreated.

The original PatternArtifact has group unset and no config file, so it intentionally creates no runtime geometry. It remains a placement; the web export supplies a clearly labelled UNCONFIGURED PATTERN SOURCE marker for selection. This marker is not an invented native exhibit. The original small kaleidoscope is also retained at source scale.

Native checks verify delegate presets and actual mouse/XR PM, HOLD, PG and UNDO actions, plus gallery geometry belonging to this floor. Source files and relative scales/facings are checked separately. The Pattern Temple dome from the floor below penetrates this floor; its original 8.35 m height is an explicit curation conflict, not silently resized.
