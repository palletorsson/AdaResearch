From a moving hand to a changed form

The test moves a generated grabber through the actual XR Tools pickup, grab-driver and release path. It visits all six stops in both directions and holds each still. Separate physics rays exercise pointer dragging, competing pointers, exit and focus loss.

In the real grammar artifact, both grab and pointer input change generation one to two: the first grammar goes from five to twenty-five rendered segments, and its readout changes to Depth: 2. The tests also found and fixed a feedback bug where a stationary held proxy could repeatedly advance its parent track.

46 physical checks and 46 retained-screen checks pass. The complete selector range is checked on the isolated control; the real geometry check uses generations one and two. The existing much heavier generation-six rendering has not been performance-certified.

What this establishes

One artifact now uses a physical control through a reusable helper. The grammar rules and manuscript are unchanged. The screen variant remains available for comparison; other artifact interfaces retain their existing implementations.

Headset reach, tracked-hand comfort and Quest performance still need a headset session. The discrete stops have visible feedback; controller vibration or force feedback has not been added.
