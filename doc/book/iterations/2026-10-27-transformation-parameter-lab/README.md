## Deliberate size presets

Hand, Table, Ground and Full-floor now share a context selector in both views. The original copy count, rotation, scale progression and relative spacing remain unchanged; an explicit `worldScale` uniformly changes copies and their positions. Presets fit repeated source bounds inside these width × depth × height envelopes: Hand 0.35 × 0.35 × 0.35 m; Table 2.4 × 1.6 × 1.5 m; Ground 8 × 6 × 2.4 m; Full-floor 32 × 12 × 5.5 m. Table retains the fixed board; the other contexts omit it. Envelope limits describe the repeated objects, not the display board. Angles and the pattern remain editable, which marks the size custom while retaining its context multiplier. Switching source within an active preset refits the new source.

The preset and multiplier travel in shared links, saved recipes and lineage. Old settings default to custom / multiplier 1, and controls-only document changes no longer invalidate an archived recipe's geometry. Native source, adapter and frozen recipe fingerprints remain checked.
