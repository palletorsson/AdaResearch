# A body for a position

## We arrive with

Day Zero has established opening, editing, saving and running a supplied project. Point Zero has let us arrive in a world already at work. Its first tutorial introduces _ready(), _process() and a named value kept between calls. The first tutorial may borrow the prepared environment; it must introduce the position itself.

## Here we investigate

What must be attached to a position before it can be seen, resist a body or follow a hand? The repeated name, Point one, crosses absence, surface, collision and holding. A coordinate locates something without exhausting what it can become. The closing sphere remains a sculpture as well as a return to the question.

## The encounters

The hall, main text and tutorial are overlapping selections. They have different jobs.

| Encounter | Work in the hall and main text | Work in the first tutorial |
| --- | --- | --- |
| point_absent, point_visible | Distinguish an address from the body used to show it | Keep a Vector3 position; place and reveal a supplied marker |
| point_solid, point_held | Compare seeing, resistance and being able to carry something | Change the supplied collision radius; borrow pickup as an encounter without rebuilding its machinery |
| CoordinateSystem3M, coordinate_readout | Locate the held point; encounter reference, rounded reporting and finite guides | Change X, Y and Z in one fixed reference; guides are supplied explanatory objects |
| drag_point_target | Let different gestures satisfy one arrival rule; intention remains outside the test | Defer distance thresholds, rearming and triggering |
| point_pedestal | Give the same name a body larger than the hand; a pause before departure | No further code required |

The distance arrow helps someone understand coordinates. Its construction is outside this first lesson. Neither a technical helper nor an atmospheric object needs to become another coding task.

Current placement is recorded in artifacts.md. The case, force point, Fontana, snap sphere, floating field and other retained works remain secondary. Do not promote them simply because they exist, or remove them merely because the tutorial does not use them. Give an object a reason to occupy attention: comparison, contradiction, return, bodily consequence, pleasure or rhythm. If no relation can be found, reconsider its placement. This writing pass changes no museum placement; it does not claim that the present density has been walked and resolved.

## We learn to make

Follow the corridor's order: keep the absent point's position; move and resize the visible sphere; change the solid sphere's collision radius; then borrow the museum's held point. Only after carrying it do we enter the coordinate comparison. The target and pedestal complete the walk without demanding another implementation exercise.

The main scene is doc/book/studies/point-one/study.tscn, the existing three-station comparison. Its complete scripts are supplied; the tutorial selects a few real lines to inspect and change. This is a source study of the first three conditions, not a full recreation of the corridor. The pickup system is in the museum. coordinates.tscn and points.gd remain available for the later coordinate comparison and two-point handover.

The tutorial follows the encounter order while choosing a different depth at each stop. A supplied class can be named without requiring the beginner to rebuild it. Arrows, reporting, pickup and target logic stay borrowed. The point's changing relations hold the progression together.

## We leave with

Two named positions, a and b, and the ability to arrange their visible markers independently. Point Lines should start by connecting these positions before multiplying them. Trace can later retain successive positions; the grid selects addresses; three non-collinear positions can bound a triangular face. This is a lineage of added relations, not permission to teach every later operation here.

## Writing decision

Keep final.md as the continuous encounter, with its single position line and the critical distinctions carried by the prose. The tutorial is read separately, but follows the same corridor and room order. It must not jump ahead to an isolated coordinate exercise. A correct program, an intelligible lesson and a compelling room require different evidence; native execution alone cannot settle the last two.
