## Reasoning effort

These are recommendations for selecting effort, not automatic changes to the model or app settings:

- **High:** choosing the relation between text, artifact and bodily experience; uncertain curation; debugging across systems.
- **Medium:** implementing a settled proposal, straightforward prose edits, references, established checks and comparison-page updates.
- **XHigh or above:** a specific unresolved conceptual or technical problem whose difficulty warrants escalation. State the problem and expected benefit first; do not make higher settings routine.

Work can be divided into a judgment pass and an implementation pass when that division helps. This does not mean stopping for approval between ordinary authorized steps. Flag a useful effort-level change to the author; claim a setting changed only with confirmation from the app. Do not create tasks or delegate simply to imitate automatic model switching.
