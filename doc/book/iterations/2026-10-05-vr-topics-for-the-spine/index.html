A world you can act with.

27 researched candidates for the existing Endless Museum. Eight deserve the first editorial pass. The placements and exercises are proposals: they do not assert that a hall already implements or teaches the feature.

Keep the museum usable from Day Zero. Introduce a selected connection when the student can act on it, then return to it with greater depth. A supplied player, an authored operation and a critical reflection have different teaching responsibilities. The geometry and algorithm lineage remains central.

Locate → hold → act → target → change → receive feedback → keep → share

FoundationAvailable from arrival; inspect selected principles later.
CoreStrong candidate for a small authored operation in an existing tutorial.
ReturnDeepens an earlier capability after its prerequisites.
OptionalLater branch or capstone; may require new implementation or hardware.

Proposed teaching, not an implementation audit. Godot and XR Tools supply the main technical references; Unity supplies teaching examples. W3C XAUR describes user needs, rather than a compliance standard. The body-ownership study informs a question, not a promised response.

Current source material must be checked against Ada's installed Godot 4.6 and plugins before implementation. Hardware-dependent features remain optional. Saved tutorial choices and the live museum are unchanged.

Where the critical question lives

The most useful questions are already inside these operations: which body can reach, which action is accepted, which surface counts as solid, which record survives, and who can alter a shared object. They can enter final.md as reflection while tutorial.md teaches the exact operation. Neither track needs to explain everything the room contains.

Start with a few existing objects: the sphere, the pen, the can, the grid and the sounding bar. Name what is supplied and what the learner changes. Promote a proposal into a hall's learning elements only after choosing its teaching role.
