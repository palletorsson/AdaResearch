# Point One — positions before connections

Prepared in Day Zero. The main scene is coordinates.tscn; the short learner script is points.gd. Read TUTORIAL.md for the first exercise.

The download opens with two white markers placed by the complete script. The tutorial first reduces that script to an unused position, then reveals one marker, changes each coordinate, and places a second. Both positions use the same scene reference. This is the material that Point Lines will connect.

Supplied parts: base.tscn from Day Zero; two hidden MeshInstance3D markers sharing a 0.14 m radius SphereMesh; fixed coloured axes and labels. The coordinate script assigns their positions and visibility. It does not build meshes, arrows, readouts, colliders or pickup systems. There are no missing helper functions or plug-ins.

Optional: CONSTRUCTION.md and study.tscn preserve the preceding visible/solid comparison with its complete position.gd, visible.gd and solid.gd scripts. Those files are unchanged. They are a further look at the same museum encounter, not prerequisites for the next Line exercise.

Both scenes are fixed-camera desktop studies. The museum supplies walking and XR pickup. The code and lesson variations are checked in Godot; beginner understanding and headset behavior require separate trials.
