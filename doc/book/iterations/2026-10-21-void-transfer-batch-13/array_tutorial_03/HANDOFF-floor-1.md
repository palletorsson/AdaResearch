# The same rule stands up — source transfer

All two original placements retained at scale 1. The six five-metre pattern
walls, reversible rule desk and 25-sample eye chart remain one editable
installation. The turning wall, its collision, occupied-landing guard and glass
landing remain another. The live pattern binding uses the existing floor-scoped
`em_map` metadata, so both displays receive the same image.

Tiling Principles is at [0,-2], facing 180; Wall Exception at [10,-12], facing
0. Shafts remain clear. Eight-metre storeys retain the 6.3 m chart without
clipping; the floor signs move to [16,8] rather than standing in the exhibits.
These are isolated trial settings, not changes to the main tower.

The original museum enclosure is not imported: the turning sheet demonstrates
its movable collision and landing, but does not yet define an inside/outside
boundary for the whole Void floor. That spatial integration belongs to curation.
Original artifact scripts, maps and chapter texts are preserved.
