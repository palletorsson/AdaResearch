# An address gains depth

A paired planar and volumetric study follows Symmetry_Seventeen. Select corresponding addresses, repeat one motif through four layers, then make the source lookup depend on height. Slice view reveals the interior while retaining all 64 values. The distinction is between changing a lookup, changing visibility and changing geometry.
