## Rules applied to the paragraphs

1. Start with a particular operation or encounter, not a catalogue of everything in the room.
2. Return to an earned object, record or operation. Say which kind of continuity it is; do not imply that all halls share one live object.
3. Name supplied construction, input or solver support. Required lesson code must eventually be printed and initialized; a paragraph cannot excuse a hidden dependency.
4. Add a bounded capability and ask for a prediction, counterexample, controlled comparison or independent variation.
5. State the useful result that travels onward, preserving its frame, units, ownership and lifetime where relevant.
6. Separate a calculation from its display, a model from its interpretation, and evidence from aspiration.
7. Let composition and reflection consolidate known tools. Every hall need not introduce syntax.
8. Keep the plan editable. A source conflict prompts a specific decision; it does not trigger an automatic rewrite or forced reorder.

This is an editorial judgment applied to the text, not a keyword score. The structural validator checks coverage, single paragraphs, known IDs and preserved sources. It cannot certify a good explanation or a good teaching choice.

## The future reconstructing reader

“The student is a future you” is a useful way to test what survives outside this conversation. That reader receives the selected paragraph, its hall choice, the exact predecessor files, declared supplied support, proposed assertions and source-bound results. It does not inherit an unwritten fix or a vague promise that something was taught earlier.

For an eventual cold reconstruction trial, give an independent reader only that packet. Ask it to assemble and run the printed code without importing production scripts to complete missing lesson objects. Record requested clarifications and repairs as failures of explicitness. Then run the agreed behavioural checks and the exact exercise variant. Do not quietly repair the candidate before grading it.

The current pass writes those plans; it has not run that independent trial. A future model reconstructing the program would establish a form of reproducibility under stated conditions. Human pacing, comprehension, independent transfer and physical VR comfort still require their own observations.

The final assembly deliberately returns to the opening points and connections. What has grown is the learner's ability to choose representations, write operations, test consequences and retain accountable revisions. It need not become one enormous class that survives every chapter.
