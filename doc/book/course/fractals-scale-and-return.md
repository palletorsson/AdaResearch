## Spatial test now implemented

Tree hall: describe the tree; KEEP a view; turn a point; compare PLAN (X/Z, no height) with SIDE (X/Y, no depth); walk beneath the changed canopy; return and revise the description. Same source endpoints, different projections and affordances. Black = live; rose = kept. Fixed drawing scale. A segment aligned with the omitted axis appears as a dot.

KEEP stores one in-memory endpoint/rule snapshot for comparison. It does not restore a tree, retain the player's route, judge the outcome, or persist across visits. CLEAR drops only the comparison. The original geometry, hand controls and canopy remain owned by the existing source. The new drawings are supporting artifacts, not an added tutorial assignment.

Synthesis adds a separate recipe comparison. Its KEEP copies seed, retained fraction and depth; RESTORE copies that recipe back into LIVE. Both lists are regenerated and drawn at the same fixed scale. RESET changes only LIVE. This snapshot is also local to the visit. Unlike the tree's kept projection, it is a reconstructable recipe with a restore operation. Do not describe the two controls as identical persistence systems. ## How an observation travels

Keep a concrete before/after and name the tested rule and representation. Ask what became possible, obstructed or noticeable. Preserve the difference locally first. Change a room when placement or bodily use warrants it. Change the sequence when a recurring finding changes the question or prerequisite. Change the book when its account no longer fits the encounter. A one-off surprise may remain a local artwork; no score or automatic promotion is needed.

AI may inspect alternatives and check claims. A numerical invariant is not evidence of aesthetic value, and a successful test is not evidence that a person learned. Do not turn “interesting” into a branch count.
