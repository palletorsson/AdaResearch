## 1.1 Make a sphere

*[a white sphere above the floor; beside it, the code that creates it]*

A node is a building block in Godot.
A scene is a group of nodes.
Code will make the sphere in this scene.

1. Open the [supplied project](/course/sketch/first-sphere.zip) in Godot.
   - Supplied means made for you.
   - The room, camera and lighting are ready.
2. Open `first_sphere.gd` and replace its contents below.
   - A script contains code.
   - This script is attached to the scene's root node.
   - The root node is the scene's top node.

<!-- code: claim="get_children().filter(func(n): return n is MeshInstance3D and n.mesh is SphereMesh).size() == 1" claim="get_children().filter(func(n): return n is MeshInstance3D and n.mesh is SphereMesh)[0].position == Vector3(0, 1, 0)" -->
```gdscript
extends Node3D

func _ready():
	var ball = MeshInstance3D.new()
	ball.mesh = SphereMesh.new()
	ball.position = Vector3(0, 1, 0)
	add_child(ball)
```

**Run the project**: press Play, at the top right.
A sphere appears above the floor.

- `extends Node3D` says this script belongs to a `Node3D`.
  - A `Node3D` is a node in 3D space.
- `func` defines a function: a named block of code.
  - Godot runs `_ready()` once the node's children are ready.
  - An indent is spacing that groups code inside a block.
  - Here, one tab groups the code inside `_ready()`.
- `var ball = MeshInstance3D.new()` creates the node.
  - `var` declares a variable: a name for a value.
  - `ball` keeps the node.
  - `=` assigns the value on its right.
  - `MeshInstance3D` is a built-in class: Godot provides it.
  - `.new()` creates one.
- `ball.mesh = SphereMesh.new()` gives it a sphere mesh.
  - The mesh is what the node draws.
  - `mesh` is a property: a named value on the node.
- `ball.position = Vector3(0, 1, 0)` places it.
  - `Vector3` holds three numbers as one value.
  - A position is where a node stands relative to another.
- `add_child(ball)` adds it under the root node.
  - A child is a node directly under another.

1. Change `Vector3(0, 1, 0)` to `Vector3(0, 2, 0)`.
2. Run again: the sphere appears higher.

Create the node, give it a mesh, place it, add it.

## 1.2 Somewhere to count from

*[the origin sphere with three short axes, lime x, cyan y, orange z, seen from above and to one side]*

The origin is where counting starts.
At the origin, all three numbers are zero.

Stop the project before changing its code.
Each example replaces the script below `extends Node3D`.
The sphere is created again each time you run.

Make the same sphere with different coordinates.

<!-- code: claim="ball.position == Vector3(1, 2, 2)" -->
```gdscript
var ball = MeshInstance3D.new()

func _ready():
	ball.mesh = SphereMesh.new()
	add_child(ball)
	ball.position = Vector3(1, 0.5, 2)
	ball.position.y = 2
```

- An axis is a straight way out from the origin.
  - Three axes leave it: x, y and z.
  - x runs right, y runs up, z runs toward you.
- A metre is the length of a count of one.
- `Vector3(1, 0.5, 2)` is one right, half up, two toward you.
  - Each of the three numbers is a coordinate.
  - A point is a place: three coordinates, no size.
- `position.y` is one coordinate alone.
- Lines of code run in order, top to bottom.
  - The second sets y to 2.
  - `ball` stands at (1, 2, 2).

The position of a node is a point.

## 1.3 A position needs a body

*[three stations in a row: an empty label, a white sphere, a sphere that stops the cyan feeler]*

A position is a point.
It has no size: nothing shows.

The code builds three stations.
The supplied feeler will test what stops it.

The editor is Godot's window for building scenes.
The scene tree is the editor's list of nodes.
The FileSystem is the panel listing the project's files.
The Inspector is the panel showing a node's properties.

**Add a node**: select the node it goes under.
Press + above the scene tree.
Choose its kind, then Create.
Double-click the new node to name it.

**Attach a script**: drop it from the FileSystem onto the node.

1. Add a `Node3D` under the root node.
2. Attach the supplied `contact_probe.gd` to it.
   - It is the feeler, a cyan rod that moves.

**Example 1.1: three stations**

<!-- code: claim="fixed_body.get_child_count() == 2 and contact.global_position == fixed_body.global_position" -->
```gdscript
var here = Node3D.new()
var seen = MeshInstance3D.new()
var fixed_body = StaticBody3D.new()
var body_mesh = MeshInstance3D.new()
var contact = CollisionShape3D.new()

func _ready():
	add_child(here)
	seen.mesh = SphereMesh.new()
	add_child(seen)
	add_child(fixed_body)
	body_mesh.mesh = SphereMesh.new()
	fixed_body.add_child(body_mesh)
	contact.shape = SphereShape3D.new()
	fixed_body.add_child(contact)
	here.position = Vector3(-1.5, 1.12, 0)
	seen.position = Vector3(0, 1.12, 0)
	fixed_body.position = Vector3(1.5, 1.12, 0)
```

Run the project.

- The feeler runs along the three stations.
  - At `here`, it meets nothing.
  - At `seen`, a white sphere: the feeler passes through.
  - At `fixed_body`, the same sphere: the feeler stops.
- A mesh is what is seen.
- A shape is what is touched.
  - `SphereShape3D` defines a sphere for contact.
  - `CollisionShape3D` gives that shape to `fixed_body`.
- `StaticBody3D` is a body that stays put.
  - Its mesh and its shape are separate children.
- Each station is a body, a node you place.
  - The nodes under `fixed_body` go where `fixed_body` goes.

The feeler meets the shape, never the mesh.

## 1.4 Godot's own meshes

*[a row of lime primitives, box, sphere, cylinder, prism, torus; one sphere at 4, 8, 16 and 64 segments]*

A primitive is a mesh Godot builds from a few numbers.
Each node gets its mesh in code.

A court is an open square with bodies on it.
Build five bodies around its centre.

**Example 1.2: a court of primitives**

<!-- code: claim="box.position.y == box.mesh.size.y / 2 and ball.position.y == ball.mesh.height / 2 and spire.position.y == spire.mesh.height / 2 and prism.position.y == prism.mesh.size.y / 2 and is_equal_approx(ring.position.y, (ring.mesh.outer_radius - ring.mesh.inner_radius) / 2)" -->
```gdscript
var spire = MeshInstance3D.new()
var box = MeshInstance3D.new()
var ball = MeshInstance3D.new()
var ring = MeshInstance3D.new()
var prism = MeshInstance3D.new()

func _ready():
	spire.mesh = CylinderMesh.new()
	add_child(spire)
	box.mesh = BoxMesh.new()
	add_child(box)
	ball.mesh = SphereMesh.new()
	add_child(ball)
	ring.mesh = TorusMesh.new()
	add_child(ring)
	prism.mesh = PrismMesh.new()
	add_child(prism)
	spire.mesh.top_radius = 0
	spire.mesh.radial_segments = 4
	spire.position = Vector3(0, 1, 0)
	box.position = Vector3(1.5, 0.5, 1.5)
	ball.position = Vector3(-1.5, 0.5, 1.5)
	ring.position = Vector3(-1.5, 0.25, -1.5)
	prism.position = Vector3(1.5, 0.5, -1.5)
```

- `BoxMesh` makes a box.
- `TorusMesh` makes a ring.
- `PrismMesh` makes a prism.
- A segment is one slice around a round mesh.
  - `radial_segments` counts the segments.
  - A `SphereMesh` at four segments has corners.
  - Set its `radial_segments` to 64: the sphere looks round.
- `top_radius` at 0 closes the top to a tip.
  - Four segments and no top make the `CylinderMesh` a pyramid.
- The same primitive with other numbers is another mesh.
- Each body stands on the floor.
  - A box one metre high stands at y 0.5.

A mesh is centred on its position.

## 1.5 Two points, three points

*[two white spheres joined by a thin white line; three spheres closed into a lime face, seen from slightly above]*

A line is the straight piece between two points.
A face is the flat piece filled between three points.

<!-- code: claim="$Supplied._ft_calls == ['line', 'triangle']" -->
```gdscript
func _ready():
	$Supplied.line(Vector3(0, 1, 0), Vector3(1.5, 1, 0))
	$Supplied.triangle(Vector3(0, 1, 1), Vector3(1, 1, 1), Vector3(0.5, 2, 1))
```

- This example uses the supplied parts.
  - Their node is named `Supplied`.
  - `$Supplied` gets that existing node from the scene.
  - Its calls are supplied parts.
- Give `line(a, b)` two points: it draws a line.
- Give `triangle(a, b, c)` three points: it fills a face.
- A name with round brackets after it is a call.
  - A call asks a supplied part, or Godot, to work.
  - `$Supplied.line` is the call `line` on the node `Supplied`.
  - `Vector3(0, 1, 0)` is a call too, to Godot.

Two points make a line.
Three points make a face.

## 1.6 Every frame

*[the counter panel in three stills a second apart, the number larger each time]*

Godot draws the scene again and again.
A frame is one picture Godot draws.

**Add a scene**: drop it from the FileSystem onto the node it goes under.

Add `counter_panel.tscn` to the root node.

**Example 1.3: the frame counter**

<!-- code: nodes=Counter:Label3D claim="int($Counter.text) > 0" -->
```gdscript
func _process(_delta):
	$Counter.text = str(Engine.get_process_frames())
```

Run the project: the number climbs.

- `_ready` runs once.
- `_process` runs every frame.
- The counter panel is a `Label3D` named `Counter`.
  - A `Label3D` is a node that shows words.
  - Its `text` is the words it shows.
- `Engine` is Godot itself, as something you can ask.
  - `Engine.get_process_frames()` is how many frames have run so far.
- `str()` converts the number to text.
- Godot hands `_process` a number, `_delta`.
  - The underscore in `_delta` says it goes unused.

1. Write `func _ready():` and move the line of code under it.
2. Run the project again: the number never changes.

Work that happens once goes in `_ready`.
Work that changes goes in `_process`.

## 1.7 Follow the mouse

*[top view: a lime point at the mouse, a trail of small white dots behind it]*

Make one sphere to follow the mouse.
Give it a smaller sphere to leave behind.

**Example 1.4: draw with the mouse**

<!-- code: claim="get_child_count() > 40 and $Supplied._ft_calls.count('mouse_point') > 40" -->
```gdscript
var point = MeshInstance3D.new()
var mark = MeshInstance3D.new()

func _ready():
	point.mesh = SphereMesh.new()
	add_child(point)
	mark.mesh = SphereMesh.new()
	mark.mesh.radius = 0.03
	mark.mesh.height = 0.06
	add_child(mark)

func _process(_delta):
	mark.position = point.position
	add_child(mark.duplicate())
	point.position = $Supplied.mouse_point()
```

- `radius` measures from the sphere's centre to its outer edge.
  - `height` is its full height, in metres.
  - A radius of 0.03 and height of 0.06 make small dots.
- `mouse_point()` is the point on the floor under the mouse.
  - Every frame, `point` goes there.
- `mark` first goes where `point` was.
  - The original moves with it.
  - Its copies stay where they were added.
- `duplicate()` makes a copy of `mark`.
  - A copy is a new node made from another.
- `add_child()` puts the copy into the scene.
  - The copy stays where it was made.
- Move the mouse fast: the dots spread apart.

One copy each frame keeps every place `point` has been.

## 1.8 Name a number

*[the court from the front right: a lime spire, and four bodies at its corners]*

In Example 1.2, you type 1.5 eight times.
Name it once.

**Example 1.5: the court, by name**

<!-- code: claim="spire.position.y == spire.mesh.height / 2 and ball.position == Vector3(-gap, 0.5, gap)" -->
```gdscript
var spire = MeshInstance3D.new()
var box = MeshInstance3D.new()
var ball = MeshInstance3D.new()
var ring = MeshInstance3D.new()
var prism = MeshInstance3D.new()

var gap := 1.5
var tall := 3.0

func _ready():
	spire.mesh = CylinderMesh.new()
	add_child(spire)
	box.mesh = BoxMesh.new()
	add_child(box)
	ball.mesh = SphereMesh.new()
	add_child(ball)
	ring.mesh = TorusMesh.new()
	add_child(ring)
	prism.mesh = PrismMesh.new()
	add_child(prism)
	spire.mesh.top_radius = 0
	spire.mesh.radial_segments = 4
	spire.mesh.height = tall
	spire.position = Vector3(0, tall / 2, 0)
	box.position = Vector3(gap, 0.5, gap)
	ball.position = Vector3(-gap, 0.5, gap)
	ring.position = Vector3(-gap, 0.25, -gap)
	prism.position = Vector3(gap, 0.5, -gap)
```

- A variable is a name for a value.
  - `var` makes a variable.
  - `:=` gives it its first value.
- `/` divides: `tall / 2` is half of `tall`.
- `-gap` is as far the other way.
- `height` is how tall the mesh is, in metres.
- Set `gap` to 3: the court spreads.
- Set `tall` to 5: the spire still meets the floor.
  - The spire is centred: it stands at half its height.

**Example 1.6: a counter of your own**

Example 1.6 replaces the court's code: keep `extends Node3D`.
The counter panel of section 1.6 shows the count.

<!-- code: alone nodes=Counter:Label3D claim="int($Counter.text) == count and count > 40" -->
```gdscript
var count := 0

func _process(_delta):
	count += 1
	$Counter.text = str(count)
```

- `count` starts at 0, outside `_process`.
  - Each frame finds the value the last frame left.
- `+=` adds to what a variable holds.
  - `count += 1` is short for `count = count + 1`.

Change a variable once, and every use follows.
