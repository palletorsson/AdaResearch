## 3.1 Again, while it holds

*[four lime cubes in a row along x, a metre apart, the first at the origin]*

`cube.tscn` is supplied: one lime cube, half a metre wide.

1. Delete every node you added: keep the base scene's own.
2. Replace the top node's script with this.

**Example 3.1: a row of copies**

<!-- code: claim="get_children().filter(func(n): return n is MeshInstance3D).size() == 4" claim="get_child(get_child_count() - 1).position == Vector3(3, 0.25, 0)" -->
```gdscript
extends Node3D

var cube := preload("res://supplied/cube.tscn")

func _ready():
	var i := 0
	while i < 4:
		var copy := cube.instantiate()
		copy.position = Vector3(i, 0.25, 0)
		add_child(copy)
		i += 1
```

Run the project: four cubes stand in a row.

- A loop is code run again and again.
- `while` repeats its block while its test is true.
  - Here the test is `i < 4`, and `i` starts at 0.
  - Each pass places a cube at x = `i`, then adds 1 to `i`.
  - At 4 the test fails, and the loop ends.
- Without `i += 1`, the test never fails.
  - The loop never ends, and Godot draws no frame.
- `preload` loads a scene file once, when the script is read.
  - The path in quotes is where it sits in the FileSystem.
  - It starts at the project's folder, then the supplied folder.
- `cube` holds a `PackedScene`: a saved scene, ready to copy.
  - `instantiate()` makes a new node from it.
  - `duplicate()` copies a node in the scene: this needs none.
- A variable can hold a node: `copy.position` is its position.
  - Inside the loop, `var` makes a new `copy` each pass.
- At y 0.25, the half-metre cube stands on the floor.

A `while` loop needs a test that turns false.

## 3.2 `for` counts for you

*[an L of lime cubes from above: four along x, four along z, meeting at the origin]*

**Example 3.2: two rows from one count**

<!-- code: claim="get_children().filter(func(n): return n is MeshInstance3D).size() == 8" claim="get_child(get_child_count() - 1).position == Vector3(0, 0.25, 3)" claim="range(4) == [0, 1, 2, 3]" -->
```gdscript
var cube := preload("res://supplied/cube.tscn")
var spacing := 1.0

func _ready():
	for i in 4:
		var a := cube.instantiate()
		a.position = Vector3(i * spacing, 0.25, 0)
		add_child(a)
		var b := cube.instantiate()
		b.position = Vector3(0, 0.25, i * spacing)
		add_child(b)
```

Run the project: an L of cubes.

- `for` runs its block once for each value in turn.
  - `in 4` names what it goes through: 0, 1, 2, 3.
  - `i` is the loop variable: `for` sets it anew each time.
  - No `i := 0`, no `i += 1`, no test: `for` counts for you.
- `i * spacing` turns the count into a distance.
  - The same `i` places `a` along x and `b` along z.
  - At `i` 0, `a` and `b` share the corner.
- Set `spacing` to 2: both rows spread, four cubes each.
  - Restore: `spacing` at 1.0.

The loop variable says where a copy goes.

## 3.3 A loop inside a loop

*[a 4 x 4 grid of lime cubes from above, the cube at x 1, z 2 lifted]*

**Example 3.3: the grid with addresses**

<!-- code: claim="get_children().filter(func(n): return n is MeshInstance3D).size() == 16" claim="get_children().filter(func(n): return n is MeshInstance3D and n.position.y == 1).size() == 1" -->
```gdscript
var cube := preload("res://supplied/cube.tscn")
var spacing := 1.0

func _ready():
	for x in 4:
		for z in 4:
			var copy := cube.instantiate()
			copy.position = Vector3(x * spacing, 0.25, z * spacing)
			if x == 1 and z == 2:
				copy.position.y = 1
			add_child(copy)
```

Run the project: sixteen cubes in a square, one lifted.

- A nested loop is a loop inside a loop.
  - For each `x`, the inner loop runs all four `z`.
  - Every pair of counts gets one cube.
- A grid is copies laid out in rows and columns.
  - A row runs along x, a column along z.
- An address is where a copy sits in a grid.
  - Here a cube's address is its `x` and its `z`.
- The `if` picks one address: x 1, z 2.
  - It lifts that cube to y 1.
- Change the test to `x == z`: the diagonal lifts.
  - Restore: `x == 1 and z == 2`.

Two loops visit every address once.

## 3.4 Room between the copies

*[the 4 x 4 x 4 lattice of lime cubes, 2.4 metres apart, the cyan walker hovering inside it]*

1. Add `walker.tscn` to the top node.
2. Add `flight_region.tscn` to the top node.
   - It is the flight region: inside it, the walker flies.

**Example 3.4: the lattice you can fly through**

<!-- code: nodes=Walker:Node3D claim="get_children().filter(func(n): return n is MeshInstance3D).size() == 64" claim="spacing == 2.4 and $Walker.position == Vector3(-2, 0, -2)" -->
```gdscript
var cube := preload("res://supplied/cube.tscn")
var spacing := 2.4

func _ready():
	$Walker.position = Vector3(-2, 0, -2)
	for x in 4:
		for y in 4:
			for z in 4:
				var copy := cube.instantiate()
				copy.position = Vector3(x * spacing, y * spacing + 0.25, z * spacing)
				add_child(copy)
```

Run the project.

- A lattice is a grid that also climbs in y.
  - The third loop, for `y`, makes four grids: 64 cubes.
- `*` and `/` come before `+` and `-`.
- The walker starts outside, at x -2, z -2.
- In the flight region, Space climbs and Shift sinks.
- At `spacing` 2.4, the walker fits between the cubes.
- Set `spacing` to 1: it no longer fits.
  - Spacing changes the distances, never the count of cubes.
  - Restore: `spacing` at 2.4.
- Fly into a cube: the supplied walker takes it.
  - The flight region shows the collection record.
  - Per cube: a one, then zero once taken.

Three loops, one per axis, address a block of space.

## 3.5 A rule at every address

*[an 8 x 8 checker of off-white and near-black tiles, seen from above]*

The supplied `tile.tscn` is a flat tile, one metre square.
It is off-white on top, near-black underneath.

**Example 3.5: a checker floor**

<!-- code: claim="get_children().filter(func(n): return n is Node3D and n.rotation_degrees.x == 180).size() == 32" claim="5 % 2 == 1 and (1 + 1) % 2 == 0" claim="360 / 4 == 90 and is_equal_approx(6.28 / 4, 1.57)" -->
```gdscript
var tile := preload("res://supplied/tile.tscn")

func _ready():
	for x in 8:
		for z in 8:
			var copy := tile.instantiate()
			copy.position = Vector3(x, 0.02, z)
			copy.rotation_degrees.x = 180 * ((x + z) % 2)
			add_child(copy)
```

Run the project: a checker floor.

- `%` gives the remainder after dividing.
  - A remainder is what a division leaves over.
  - `5 % 2` is 1: 5 divided by 2 leaves 1.
  - `% 2` gives 0 for an even number, 1 for an odd.
- `%` takes counts, like `x` and `z`: no `.0`.
- `%` ranks with `*`: `(x + z) % 2` needs its brackets.
- A step to a neighbour changes `x + z` by 1.
  - Even turns odd: two neighbours never match.
- `rotation_degrees` is a body's turn around x, y and z, in degrees.
  - A full turn is 360 degrees.
  - Half is 180, a quarter 90.
  - `rotate_y()` counts that quarter turn as 1.57.
- Each tile turns 0 or 180 degrees around x.
  - At 180 it lies upside down: near-black shows.
- At y 0.02 it lies a hair above the floor.

One rule, asked at every address, lays the whole floor.

## 3.6 Turn the tile by its address

*[five 4 x 4 floors from one diagonal tile: as made, half turns, quarter turns, mirrored columns, shifted rows]*

The supplied diagonal tile is half near-black, cut corner to corner.

**Example 3.6: five floors from one tile**

<!-- code: claim="get_children().filter(func(n): return n is Node3D and n.scale.x == -1).size() == 8" claim="get_children().filter(func(n): return n is Node3D and is_equal_approx(n.rotation_degrees.y, 270)).size() == 4" -->
```gdscript
var tile := preload("res://supplied/diagonal_tile.tscn")

func _ready():
	for rule in 5:
		for x in 4:
			for z in 4:
				var copy := tile.instantiate()
				copy.position = Vector3(rule * 5 + x, 0.02, z)
				if rule == 1:
					copy.rotation_degrees.y = 180 * ((x + z) % 2)
				elif rule == 2:
					copy.rotation_degrees.y = 90 * ((x + z) % 4)
				elif rule == 3 and x % 2 == 1:
					copy.scale.x = -1
				elif rule == 4 and z % 2 == 1:
					copy.position.x += 0.5
				add_child(copy)
```

Run the project: five floors, one tile.

- The outer loop picks a rule.
- The inner two lay its floor.
  - `rule * 5` sets each floor 5 metres further along x.
- The first floor passes no test: its tiles lie as made.
- At `rule == 1`, every other tile turns half round.
  - A half turn swaps the tile's black and white halves.
- At `rule == 2`, a tile turns `(x + z) % 4` quarter turns.
- At `rule == 3`, odd columns get `scale.x` at -1.
  - That draws the tile flipped, left for right.
  - A reflection is a copy flipped, as a mirror shows it.
  - A comparison comes last: `x % 2 == 1` finds the remainder first.
- At `rule == 4`, odd rows shift half a tile.

The tile never changes: the rule at its address does.

## 3.7 Stand it up

*[a 4 x 4 wall of diagonal tiles in quarter turns, standing on the floor, one tile turned once more]*

Add a `Node3D` named `Wall`.

**Example 3.7: a wall with one exception**

<!-- code: nodes=Wall:Node3D claim="$Wall.get_child_count() == 16 and $Wall.rotation_degrees.x == 90" -->
```gdscript
var tile := preload("res://supplied/diagonal_tile.tscn")

func _ready():
	for x in 4:
		for z in 4:
			var copy := tile.instantiate()
			copy.position = Vector3(x, 0, z)
			copy.rotation_degrees.y = 90 * ((x + z) % 4)
			if x == 2 and z == 1:
				copy.rotation_degrees.y += 90
			$Wall.add_child(copy)
	$Wall.rotation_degrees.x = 90
	$Wall.position = Vector3(0, 3.5, 0)
```

Run the project: the wall stands, one tile out of step.

- The loops lay the quarter-turn floor of Example 3.6.
- `$Wall.add_child(copy)` puts each tile under `Wall`.
- Turned 90 degrees around x, `Wall` stands up.
  - Its tiles turn with it: a child follows its parent.
  - The floor's z runs down the wall.
  - At y 3.5, its four tiles reach down to the floor.
- The `if` turns the tile at x 2, z 1 once more.

One rule makes every tile.
One `if` makes one tile different.

## 3.8 A floor with a clock

*[the checker floor in two stills a beat apart, off-white and near-black swapped on every tile]*

**Example 3.8: the blinking floor**

<!-- code: until="phase >= 3" claim="phase >= 3" claim="$Supplied.cell_at(0, 0).rotation_degrees.x != $Supplied.cell_at(1, 0).rotation_degrees.x" -->
```gdscript
var tile := preload("res://supplied/tile.tscn")
var clock := 0.0
var phase := 0

func _ready():
	for x in 8:
		for z in 8:
			var copy := tile.instantiate()
			copy.position = Vector3(x, 0.02, z)
			copy.rotation_degrees.x = 180 * ((x + z) % 2)
			add_child(copy)

func _process(delta):
	clock += delta
	if clock > 0.5:
		clock = 0.0
		phase += 1
		for x in 8:
			for z in 8:
				$Supplied.cell_at(x, z).rotation_degrees.x = 180 * ((x + z + phase) % 2)
```

Run the project: the checker blinks.

- A phase is how far through its repeat a thing is.
- `clock` adds up the seconds.
  - Each half second is a beat.
  - `clock` starts again, and `phase` grows by 1.
- Each beat asks every tile the rule again.
  - Supplied `cell_at(x, z)` looks for the tile at x, z.
  - As `phase` grows, `(x + z + phase) % 2` swaps 0 and 1.
- Change 0.5 to 0.25: it blinks twice as fast.
  - Restore: 0.5.

No tile is added or moved.
Only `phase` changes, and the rule follows it.

### What it hides

The collection record's zero says a cube is gone, not why.
The record keeps the cubes, never the walker between them.
The near-black is no hole: the floor under it stays flat.
