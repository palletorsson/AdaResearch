## 5.1 An array of steps

*[eight squares in a row, three lime and five off-white, a white ball over one of them]*

An array is values kept in order, one after another.

1. Delete every node you added: keep the base scene's own.
2. Replace the top node's script with this.

**Example 5.1: eight steps**

<!-- code: claim="steps.size() == 8 and steps.size() - 1 == 7 and steps[3] == true" claim="beat > 0 and ball.position.x == beat" claim="$Supplied._ft_calls.count('note') > 0" -->
```gdscript
extends Node3D

var steps := [true, false, false, true, false, false, true, false]
var beat := 0
var ball := MeshInstance3D.new()

func _ready():
	ball.mesh = SphereMesh.new()
	ball.position = Vector3(0, 0.6, 0)
	add_child(ball)
	for i in steps.size():
		if steps[i]:
			square(i, 0, Color(0.8, 1, 0.25))
		else:
			square(i, 0, Color(0.95, 0.94, 0.9))

func _process(_delta):
	if Engine.get_process_frames() % 15 == 0:
		beat = (beat + 1) % steps.size()
		ball.position = Vector3(beat, 0.6, 0)
		if steps[beat]:
			$Supplied.note()

func square(x, z, colour):
	var box := MeshInstance3D.new()
	box.mesh = BoxMesh.new()
	box.mesh.material = StandardMaterial3D.new()
	box.mesh.material.albedo_color = colour
	box.position = Vector3(x, 0.05, z)
	box.scale = Vector3(0.9, 0.1, 0.9)
	add_child(box)
```

Run the project: the ball walks the row.

- An item is one value kept in an array.
  - Its index is its place, counted from 0.
- Alone, `[]` makes an array of the items inside.
- After a name, `[3]` reads one item: `steps[3]` is `true`.
- `size()` is how many items an array holds: 8.
- `for i in steps.size()` visits every index, 0 to 7.
  - A `true` step is lime.
- `square(x, z, colour)` lays one flat box in a colour.
  - `square()` comes last: functions may stand in any order.
- Every fifteenth frame, `beat` moves one index on.
  - `% steps.size()` brings it from 7 back to 0.
  - The ball stands over the step it reads.
- `$Supplied.note()` sounds the note per track: this row's note.
  - An `AudioStreamPlayer` in `Supplied` plays it: a node for sound.
  - It sounds on each lime step.

One name holds eight values.
An index picks one.

## 5.4 Repeat by rule

*[two 12 by 12 panels from one source: left, every repeat alike; right, every second column of repeats mirrored]*

Keep `palette`, `source` and `square()`: replace the rest.

**Example 5.4: two rules, one source**

<!-- code: keep=palette,source,square claim="9 % 4 == 1 and get_child_count() > 288" -->
```gdscript
func _ready():
	draw()

func draw():
	for z in 12:
		for x in 12:
			square(x, z, palette[source[z % 4][x % 4]])
			if x % 8 > 3:
				square(x + 13, z, palette[source[z % 4][3 - x % 4]])
			else:
				square(x + 13, z, palette[source[z % 4][x % 4]])
```

Run the project: one array, two panels.

- Its own function, `draw()`, lays both panels: 288 squares.
- `x % 4` runs 0, 1, 2, 3, then 0 again.
  - Wrap: off one end, back in at the other.
  - At x 9, `x % 4` is 1: square 9 reads cell 1.
  - Every square wraps into `source`.
  - Every 4 by 4 block is one repeat of `source`.
- On the left, every repeat is the same.
- On the right, `x % 8 > 3` holds in every second column of repeats.
  - There `3 - x % 4` reads the row backwards.
  - That repeat is mirrored.

`source` holds the picture.
The rule decides how it repeats.

## 5.5 Write into the array

*[the two panels after two writes: a second orange square in every repeat, and every repeat flipped]*

Keep `palette`, `source`, `square()` and `draw()`: replace the rest.

**Example 5.5: write, then draw**

<!-- code: keep=palette,source,square,draw claim="source[1] == [0, 3, 1, 0] and source[2] == [3, 0, 1, 0]" -->
```gdscript
func _ready():
	source[1][2] = 3
	flip()
	draw()

func flip():
	for z in 4:
		var row := []
		for x in 4:
			row.append(source[z][3 - x])
		source[z] = row
```

Run the project: both panels flip, the left one too.

- `source[1][2] = 3` writes into the array.
  - Row 1, cell 2 holds orange.
  - Every repeat reads that cell, so every repeat changes.
- `flip()` builds each row again, from its far end.
  - `[]` with nothing between is an empty array.
  - `append()` adds an item to the end of an array.
  - `source[z] = row` writes the new row in.
- Take `flip()` out of `_ready`, then run the project.
  - The second orange square stays, and nothing flips.
  - Restore: put `flip()` back.
- A write by code lasts while the game runs.
  - The `source` you typed stays as it was.

Flipping `source` flips every repeat.
Mirroring by rule flips every second one.

## 5.6 A picture from an array

*[the floor of sixteen repeats, the source beside it, two balls: one on a square, one over its cell]*

A floor of 256 boxes is 256 nodes.
One picture on one mesh is one node.

Keep `palette`, `source` and `square()`: replace the rest.

**Example 5.6: the floor reads the source**

<!-- code: keep=palette,source,square claim="16 * 16 == 256 and PlaneMesh.new().size == Vector2(2, 2)" claim="at == [10, 1] and here.position == Vector3(10, 0.5, 1)" claim="there.position == Vector3(2 - 6, 0.6, 1)" claim="7.5 - 8 == -0.5 and 7.5 + 8 == 15.5" -->
```gdscript
var at := [0, 0]
var here := MeshInstance3D.new()
var there := MeshInstance3D.new()

func picture() -> StandardMaterial3D:
	var image := Image.create_empty(16, 16, false, Image.FORMAT_RGB8)
	for z in 16:
		for x in 16:
			image.set_pixel(x, z, palette[source[z % 4][x % 4]])
	var paint := StandardMaterial3D.new()
	paint.albedo_texture = ImageTexture.create_from_image(image)
	paint.texture_filter = StandardMaterial3D.TEXTURE_FILTER_NEAREST
	return paint

func _ready():
	var ground := MeshInstance3D.new()
	ground.mesh = PlaneMesh.new()
	ground.mesh.material = picture()
	ground.position = Vector3(7.5, 0.01, 7.5)
	ground.scale = Vector3(8, 1, 8)
	add_child(ground)
	for z in 4:
		for x in 4:
			square(x - 6, z, palette[source[z][x]])
	here.mesh = SphereMesh.new()
	there.mesh = SphereMesh.new()
	add_child(here)
	add_child(there)

func _process(_delta):
	at = $Supplied.pick()
	here.position = Vector3(at[0], 0.5, at[1])
	there.position = Vector3(at[0] % 4 - 6, 0.6, at[1] % 4)
```

Run the project: the floor wears sixteen repeats.

- `picture()` returns a material that wears `source`, repeated.
- An `Image`: a picture in memory, written by code.
- `Image.create_empty()` makes a blank one, 16 by 16.
  - `false`: no smaller sizes of it, for seeing from afar.
  - `FORMAT_RGB8` gives each square of it red, green and blue.
- `set_pixel(x, z, colour)` sets the colour of one square.
  - Two loops set all 256 squares from `source`.
  - Supplied `paint_at()` paints this way: `set_pixel`, square by square.
- A texture: a picture a material wears on a mesh.
  - An `ImageTexture` is an `Image` ready for a material.
  - `ImageTexture.create_from_image()` makes one.
  - The material wears it as its `albedo_texture`.
- `texture_filter`: how one square blends into the next.
  - `TEXTURE_FILTER_NEAREST` blends none: each square stays sharp.
- Take out the `texture_filter` line of code: the squares blur.
  - Restore: put it back.
- A `PlaneMesh` lies flat, 2 metres a side.
  - Scaled by 8, it spans 16 metres: one per square.
  - Centred at 7.5, it runs from -0.5 to 15.5.
  - So square x lies at x.
- `$Supplied.pick()` is the floor square under the mouse.
  - It is an array: `at[0]` its x, `at[1]` its z.
  - `here` stands on that square.
  - `at[0] % 4` and `at[1] % 4` wrap it into `source`.
  - `there` stands over the cell it reads.
  - Floor square x 10, z 1 reads `source[1][2]`.

One picture on one mesh: one node, not 256.
The picture takes `source` once, when `_ready` runs.

## 5.7 What counts as the same

*[four standing panels, left to right P1, PM, PG and P4, and the one source on the floor before them]*

Keep `palette`, `source` and `square()`: replace the rest.

**Example 5.7: four wallpapers, one array**

<!-- code: keep=palette,source,square claim="read(1, 4, 0) == source[0][3] and read(2, 4, 0) == source[2][3]" claim="read(3, 4, 0) == source[3][0] and read(3, 4, 4) == source[3][3] and read(3, 0, 4) == source[0][3]" -->
```gdscript
func read(rule, x, z):
	if rule == 1 and x % 8 > 3:
		return source[z % 4][3 - x % 4]
	if rule == 2 and x % 8 > 3:
		return source[(z + 2) % 4][3 - x % 4]
	if rule == 3 and x % 8 > 3 and z % 8 < 4:
		return source[3 - x % 4][z % 4]
	if rule == 3 and x % 8 > 3 and z % 8 > 3:
		return source[3 - z % 4][3 - x % 4]
	if rule == 3 and x % 8 < 4 and z % 8 > 3:
		return source[x % 4][3 - z % 4]
	return source[z % 4][x % 4]

func _ready():
	for rule in 4:
		var image := Image.create_empty(16, 16, false, Image.FORMAT_RGB8)
		for z in 16:
			for x in 16:
				image.set_pixel(x, z, palette[read(rule, x, z)])
		var paint := StandardMaterial3D.new()
		paint.albedo_texture = ImageTexture.create_from_image(image)
		paint.texture_filter = StandardMaterial3D.TEXTURE_FILTER_NEAREST
		var panel := MeshInstance3D.new()
		panel.mesh = QuadMesh.new()
		panel.mesh.material = paint
		panel.position = Vector3(rule * 4.5 - 6.75, 2, 0)
		panel.scale = Vector3(4, 4, 1)
		add_child(panel)
	for z in 4:
		for x in 4:
			square(x - 1.5, z + 2, palette[source[z][x]])
```

Run the project: four panels, one array.

- A wallpaper group is one way to repeat a tile.
  - It names the moves that leave the wallpaper unchanged.
  - M is a mirror, G a mirrored slide, 4 a quarter turn.
- `read()` returns the cell each square reads, by rule.
- The panels stand rule 0 to 3, left to right.
- Rule 0 is P1: every repeat moved, never turned.
  - Rule 0 passes no test: it reaches the last `return`.
- Rule 1 is PM: every second repeat mirrored.
- Rule 2 is PG: mirrored, and slid two rows along.
  - `(z + 2) % 4` slides the row by two, and wraps.
- Rule 3 is P4: four repeats turn around each corner.
  - Swapping `[z]` and `[x]` mirrors the picture across its diagonal.
  - Read one backwards too, `3 - x % 4`: a quarter turn.
  - Rule 3's other two tests: a half turn, three quarters.
- A `QuadMesh` stands up, 1 metre a side.

The group is not in `source`.
It is in the reading.

## 5.8 An array of bodies

*[three figures in a row with patterned skirts and lime heads, one walking toward you]*

**Example 5.8: bodies in turn**

<!-- code: frames=120 keep=palette,source,picture claim="bodies.size() == 3 and bodies.size() - 1 == 2 and bodies[0].mesh.material.albedo_texture != null" claim="bodies[turn].position.z > 0 and bodies[turn].position.z < 4" -->
```gdscript
var bodies := []
var turn := 0

func _ready():
	var paint := picture()
	for i in 3:
		var skirt := MeshInstance3D.new()
		skirt.mesh = CylinderMesh.new()
		skirt.mesh.top_radius = 0.1
		skirt.position = Vector3(i * 1.5 - 1.5, 1, 0)
		var head := MeshInstance3D.new()
		head.mesh = SphereMesh.new()
		head.mesh.material = StandardMaterial3D.new()
		head.mesh.material.albedo_color = Color(0.8, 1, 0.25)
		head.position = Vector3(0, 1.25, 0)
		head.scale = Vector3(0.5, 0.5, 0.5)
		skirt.add_child(head)
		add_child(skirt)
		bodies.append(skirt)
	for body in bodies:
		body.mesh.material = paint

func _process(delta):
	bodies[turn].position.z += delta
	if bodies[turn].position.z > 4:
		bodies[turn].position.z = 0
		turn = (turn + 1) % bodies.size()
```

Run the project: the bodies walk in turn.

- An array can hold objects: here, three bodies.
  - Each body is a skirt with a head, its child.
  - `bodies.append(skirt)` keeps each one, in order.
- `for body in bodies` runs once for each item.
  - Every skirt wears one `paint`: sixteen repeats of `source`.
- `bodies[turn]` is the body whose turn it is.
  - It walks toward you, a metre a second.
  - At 4 metres it goes back: the next one walks.
  - `% bodies.size()` brings `turn` from 2 back to 0.
- Change `for i in 3` to `for i in 5`: five walk.
  - Nothing else changes.
  - Restore: `for i in 3`.

An array of bodies reads like an array of numbers.
