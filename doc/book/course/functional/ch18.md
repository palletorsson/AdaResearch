## 18.1 A number for every place

*[an 11 x 11 x 11 lattice of white dots, iso view, each dot sized by its noise value]*

A scalar field is a function of a point.
It answers one number, for any point.
Noise is one: `value_at(p)` asks it.
Make a new script `field.gd`.

<!-- code: claim="values.size() == 1331 and get_children().filter(func(c): return c is MeshInstance3D).size() == 1331" -->
```gdscript
class_name Field
extends Node3D

var n := 11
var gap := 0.5
var start := Vector3(-2.5, 0, -2.5)
var values := PackedFloat32Array()
var noise := FastNoiseLite.new()

func value_at(p):
	return noise.get_noise_3d(p.x, p.y, p.z)

func index(a):
	return a.x + n * (a.y + n * a.z)

func sample():
	values.resize(n * n * n)
	for z in n:
		for y in n:
			for x in n:
				var a := Vector3i(x, y, z)
				values[index(a)] = value_at(start + Vector3(a) * gap)
```

You cannot ask every point, so ask on a grid.
`n` samples a side, `gap` metres apart, from `start`.
Three loops visit all `n * n * n` addresses.
A `Vector3i` holds one address: three counts.
`index(a)` lays the grid out in one array.
x steps by 1, y by `n`, z by `n * n`.
A `PackedFloat32Array` is a compact array of floats.
It keeps the samples.

**Example 18.1: field dots**

A block with no `extends` goes into the same script.

```gdscript
func _ready():
	noise.frequency = 0.5
	sample()
	var ball := SphereMesh.new()
	for z in n:
		for y in n:
			for x in n:
				var a := Vector3i(x, y, z)
				var bead := MeshInstance3D.new()
				bead.mesh = ball
				bead.position = start + Vector3(a) * gap
				bead.scale = Vector3(1, 1, 1) * (values[index(a)] + 1) * 0.15
				add_child(bead)
```

Put `field.gd` on the top node.
Run the project: 1331 dots.
Each dot grows with its sample.
The dots are samples.
The scalar field is the function.

## 18.2 A level makes an isosurface

*[one bell sampled on the lattice, front view: the samples above 0.4 and the rest]*

Make a new script `bell.gd`.

<!-- code: claim="inside == 27" claim="is_equal_approx(snapped(value_at(Vector3(0.5, 2, 0)), 0.01), 0.78)" claim="is_equal_approx(snapped(value_at(Vector3(1, 2, 0)), 0.01), 0.37)" -->
```gdscript
class_name Bell
extends Field

var level := 0.4
var inside := 0

func value_at(p):
	var d = (p - Vector3(0, 2, 0)).length()
	return exp(-d * d)

func _ready():
	super()
	for v in values:
		if v > level:
			inside += 1
```

Put `bell.gd` on the top node.
Run the project: the dots swell around one centre.
`Bell` extends `Field` and writes `value_at` again.
`super()` runs `Field`'s `_ready` first: the dots.
One bell is largest at its centre, less further out.
Pick one number, the level: 0.4.
A sample above the level is inside.
27 samples are inside.

Half a metre out, the field is 0.78: inside.
One metre out it is 0.37: outside.
Between them it equals 0.4.
Every place where it equals 0.4 is the isosurface.
Raise the level: the isosurface shrinks.
The isosurface runs between samples, not through them.

## 18.3 Eight corners, one case number

*[one cell, its corners numbered 0 to 7, three above the level, the faces the triangle table fills across it]*

Eight samples stand at the corners of one cell.
Make a new script `field_body.gd`.

<!-- code: claim="corners.size() == 8 and lines.size() == 12" claim="table.triangles_for(0).is_empty() and table.triangles_for(255).is_empty()" claim="seen.mesh is ArrayMesh and seen.mesh.get_surface_count() == 1" -->
```gdscript
class_name FieldBody
extends Bell

var table := preload("res://supplied/triangle_table.gd")
var seen := MeshInstance3D.new()

var corners := [Vector3i(0, 0, 0), Vector3i(1, 0, 0), Vector3i(1, 1, 0), Vector3i(0, 1, 0),
	Vector3i(0, 0, 1), Vector3i(1, 0, 1), Vector3i(1, 1, 1), Vector3i(0, 1, 1)]
var lines := [[0, 1], [1, 2], [2, 3], [3, 0], [4, 5], [5, 6], [6, 7], [7, 4],
	[0, 4], [1, 5], [2, 6], [3, 7]]

func _ready():
	sample()
	seen.mesh = march()
	add_child(seen)
```

`seen` is a child `MeshInstance3D`, made in code.
`corners` holds the eight corners, numbered 0 to 7.
`lines` lists the cell's twelve lines, each as two corners.
`table` is the supplied triangle table, loaded once.
Marching cubes means six steps in every cell:

1. Read the eight corner samples.
2. Each corner above the level adds its bit.
3. The bits make the case number, 0 to 255.
4. The triangle table names the lines the isosurface crosses.
5. Find where each such line crosses the level.
6. Every three crossings fill one face.

The case number: eight corner bits read as one number.

```gdscript
func march():
	var tool := SurfaceTool.new()
	tool.begin(Mesh.PRIMITIVE_TRIANGLES)
	var at := PackedFloat32Array()
	at.resize(8)
	for z in n - 1:
		for y in n - 1:
			for x in n - 1:
				var cell := Vector3i(x, y, z)
				var case_number := 0
				for i in 8:
					at[i] = values[index(cell + corners[i])]
					if at[i] > level:
						case_number += 1 << i
				for k in table.triangles_for(case_number):
					var a = lines[k][0]
					var b = lines[k][1]
					var t = (level - at[a]) / (at[b] - at[a])
					var p = Vector3(cell + corners[a]).lerp(Vector3(cell + corners[b]), t)
					tool.add_vertex(start + p * gap)
	tool.generate_normals()
	return tool.commit()
```

Put `field_body.gd` on the top node.
Run the project: the bell becomes a ball of faces.
`1 << i` is bit `i`.
`+=` adds the bit to the case number.
Case number 0 has no corner inside, and no face.
Case number 255 has every corner inside, and no face.
`table.triangles_for(case_number)` reads one row of Ada's table.

*[one line of a cell: `at[a]` 0.6, `at[b]` 0.2, the crossing halfway, at 0.4]*

`t = (level - at[a]) / (at[b] - at[a])`

`t` is how far along, from `a` to `b`.
`lerp` goes that share along the line: interpolation.
`SurfaceTool` collects the crossings, three to a face.
`tool.begin(Mesh.PRIMITIVE_TRIANGLES)` starts a mesh of faces.
`add_vertex` adds one crossing.
`generate_normals()` works out which way each face looks.
`commit()` hands back an `ArrayMesh`: `seen` shows it.

<details><summary>Why the corner samples say where</summary>

The case number says only which corners are inside.
Two cells with one case number fill the same lines.
The samples then slide each crossing along its line.
`t` treats the field as straight between two corners.
The field bends, so each crossing is an estimate.
A finer grid makes every estimate closer.
Cells that share a line share its crossing: no gap.

</details>

The case number picks the lines.
The samples pick the places on them.

## 18.4 Metaballs add up

*[two metaballs at three distances, front view: apart, joined by a neck, one piece]*

A metaball is a centre with a falloff.
Its falloff: largest at the centre, fading with distance.

**Example 18.2: three metaballs, marched**

Make a new script `blobs.gd`.

<!-- code: claim="n - 1 == 40" claim="is_equal_approx(snapped(exp(-pow(1.15 / radius, 2)), 0.01), 0.23)" claim="is_equal_approx(snapped(value_at(Vector3(0, 0.9, 0)), 0.01), 0.47) and value_at(Vector3(0, 0.9, 0)) > 0.4 and value_at(Vector3(0, 0.9, 0)) < 0.6" -->
```gdscript
class_name Blobs
extends FieldBody

var centres := [Vector3(-1.15, 0.9, 0), Vector3(1.15, 0.9, 0), Vector3(0, 2.9, 0)]
var radius := 0.95

func value_at(p):
	var sum := 0.0
	for centre in centres:
		var d = (p - centre).length() / radius
		sum += exp(-d * d)
	return sum

func _ready():
	n = 41
	gap = 0.125
	super()
```

## 18.5 Union is min, max carves

*[the cup, front view, its formula under it]*

A distance field is each place's distance to a body.
Inside the body, the distance is negative.

**Example 18.3: the cup by min and max**

Make a new script `cup.gd`.

<!-- code: claim="is_equal_approx(snapped(cup(Vector3(0, 0.8, 0)), 0.01), 0.65)" claim="get_child(get_child_count() - 1).get_child(0).shape is ConcavePolygonShape3D" -->
```gdscript
extends FieldBody

func cylinder(p, r, bottom, top):
	var across = Vector3(p.x, 0, p.z).length() - r
	return max(across, p.y - top, bottom - p.y)

func cup(p):
	var outside = cylinder(p, 1.0, 0.0, 1.4)
	var hollow = cylinder(p, 0.85, 0.15, 2.0)
	var ring = Vector3(p.x - 1.3, p.y - 0.7, 0).length() - 0.3
	var grip = Vector3(ring, p.z, 0).length() - 0.1
	return min(max(outside, -hollow), grip)
```

`cylinder()` is a distance field: the largest of three distances.
`max` is inside only where all three are inside.
`min` is inside where either one is: the union.
`-hollow` turns the hollow inside out.

`min(max(outside, -hollow), grip)`

`max(outside, -hollow)` carves the hollow out of the cup.
`min` joins the grip to what is left.

```gdscript
func value_at(p):
	return -cup(p)

func _ready():
	level = 0.0
	n = 31
	gap = 0.1
	start = Vector3(-1.2, -0.1, -1.2)
	super()
	var body := StaticBody3D.new()
	var hold := CollisionShape3D.new()
	hold.shape = seen.mesh.create_trimesh_shape()
	body.add_child(hold)
	add_child(body)
```

Put `cup.gd` on the top node.
Run the project: a cup with a grip.
`FieldBody` counts above the level as inside.
A distance field counts below 0 as inside.
So `value_at` hands over `-cup(p)`, cut at 0.
At the cup's middle, `cup()` answers 0.65: air.
The floor of the hollow is 0.65 metres below.
`create_trimesh_shape()` gives the cup a shape: the walker meets it.
Distance fields join with `min` and carve with `max(a, -b)`.

## 18.6 A formula that repeats

*[a gyroid block at period 2 and at period 1, iso view, side by side]*

Make a new script `gyroid.gd`.

<!-- code: claim="before == 4 and after == 8" -->
```gdscript
extends FieldBody

var period := 2.0
var wobble := 0.0
var before := 0
var after := 0

func value_at(p):
	var q = p * TAU / period
	var g = sin(q.x) * cos(q.y) + sin(q.y) * cos(q.z) + sin(q.z) * cos(q.x)
	return g + wobble * noise.get_noise_3d(p.x, p.y, p.z)

func crossings():
	var count := 0
	for i in 40:
		var a = value_at(start + Vector3(i, 13, 7) * gap)
		var b = value_at(start + Vector3(i + 1, 13, 7) * gap)
		if (a > level) != (b > level):
			count += 1
	return count
```

`q` is `p` counted in periods: one `period` becomes `TAU`.

`sin(q.x) * cos(q.y) + sin(q.y) * cos(q.z) + sin(q.z) * cos(q.x)`

This sum, cut at 0, is a gyroid.
`sin` and `cos` repeat every `TAU`.
So the gyroid is periodic: it repeats every `period`.
At 0 the gyroid parts space into two halves.
The formula goes on past the block's edges.
`crossings()` walks one straight line through the block.

## 18.7 Ground with a second answer

*[a side cut through a hill with an overhang and a cave; one column, three crossings]*

Make a new script `terrain.gd`.

<!-- code: claim="crossings(20, 20) == 1 and crossings(20, 13) == 3" -->
```gdscript
extends FieldBody

func _ready():
	level = 0.0
	n = 41
	gap = 0.125
	noise.seed = 7
	noise.frequency = 0.4
	super()

func value_at(p):
	var hill = 2 + noise.get_noise_2d(p.x, p.z)
	return hill - p.y + 1.5 * noise.get_noise_3d(p.x, p.y, p.z)

	var count := 0
	for y in n - 1:
		var a = values[index(Vector3i(x, y, z))]
		var b = values[index(Vector3i(x, y + 1, z))]

	return count
```

## 18.8 Rebuild while you watch

*[the sculpting box: an orange brush point, a new lime metaball joined by a neck]*

A thread is code that runs beside other code.
Godot draws on one thread: the main thread.
Forty cells a side is 64000 cells to march.
On the main thread, no frame is drawn meanwhile.
Move the march to another thread.

**Example 18.5: a sculptor on a thread**

Make a new script `sculptor.gd`.

<!-- code: until="task == -1 and seen.mesh is ArrayMesh" claim="n - 1 == 40 and pow(n - 1, 3) == 64000" claim="seen.mesh.get_surface_count() == 1" -->
```gdscript
extends Blobs

var task := -1

func _ready():
	n = 41
	gap = 0.125
	add_child(seen)
	add(Vector3(0, 1.9, 0))

func _process(_delta):
	if Input.is_action_pressed("ui_accept"):
		add($Supplied.mouse_point() + Vector3(0, 1, 0))

func add(point):
	if task != -1:
		return
	centres.append(point)
	task = WorkerThreadPool.add_task(build)
```

`ui_accept` is the action Space sets off.
`build`, with no brackets, is the function itself: a callable.
`add_task(build)` hands `build` to a waiting thread.
The `WorkerThreadPool` keeps those threads.
It answers at once, with a number for the task.
While `task` is not -1, `add` does nothing.
`_ready` skips `super()`: the first march is a task too.

```gdscript
func build():
	sample()
	hand_back.call_deferred(march())

func hand_back(made):
	seen.mesh = made
	WorkerThreadPool.wait_for_task_completion(task)
	task = -1

func _exit_tree():
	if task != -1:
		WorkerThreadPool.wait_for_task_completion(task)
```

Put `sculptor.gd` on the top node.
Run the project.
Hold Space: a metaball lands over the mouse.
`build` samples and marches, and touches no node.
`call_deferred` asks the main thread to call `hand_back` later.
Only `hand_back` touches the scene.
Every task must be waited for, with `wait_for_task_completion()`.
`_exit_tree` waits, so no thread works for a freed body.
A thread computes: only the main thread touches the scene.
