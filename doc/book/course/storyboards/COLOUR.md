## Source boundaries for the full lesson writer

Nails’ `value_mapper_3d.gd` clamps a point in the controller’s local box and divides X/Y/Z by positive dimensions. `nail_color_controller.gd` constructs RGB and updates preview/hand materials and GameManager; `nail_salon.gd` receives application signals for the two salon hands. The proposed direct preview function is a reduced teaching connection, not a replacement for this installed route.

Pillar’s `hsv_at` maps X 0–12.8 m to hue 0–0.85, Z 0–19.2 m to saturation 0.25–1, and represented Y 0.46–4.60 m to value 0–1. `sample_volume` converts that result into `Color`; the older `sample_space` supplies the ceiling at full value and is not the height-sensitive function. The sampler adapts local hand height 0.65–1.85 m into represented height. It updates when its position changes; it has no held-only sampling gate. A stationary released card keeps its latest result. No stored sample is automatically sent to Grid. HSV value is not perceived lightness, and black cannot identify a unique input address.

Grid’s `address_lesson.gd` maps `Vector2i(x,z)` to a MultiMesh instance; the vector’s second component is named `y` in code. COLOUR chooses among four inks. RULE visits mapped interior floor cells and uses `(x+z) % palette.size()`. Selection reaches 25 sites while RULE reaches a wider region. Writes survive selection but not overwrite or reload. A reduced receiver must declare how a learner colour reaches the instance; separate per-cell materials would be a different implementation.

Paint’s automatic and manual callers both use `paper_draw_surface.draw_spray(world_hit, direction, radius_m, colour, opacity, seed)`. The supplied host maps bounded surface coordinates to the rectangular canvas and converts ray hits for manual cans. The feedback image spreads and fades. It is neither a lossless gesture list nor permanent storage. Keep shader implementation for the later sequence.
