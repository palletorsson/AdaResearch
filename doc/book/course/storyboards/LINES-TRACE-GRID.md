## Existing behavior to respect when drafting

The pen already samples and shapes positions. Its stored points are not every movement of the hand. Its visible record can continue across pickups; release copies the retained list into the existing session store. This is not currently a separate file containing only the latest held stroke.

Grid already receives that session record. It centres and resizes the drawing for display, then rounds the displayed positions in three dimensions. The source record stays separate. Do not describe this as snapping the original metre coordinates before scaling, or as a verified transfer after restarting the project.

These facts guide honest summaries. They are not instructions to change the implementation. Any later proposal to alter behavior must be discussed separately from this writing pass.
