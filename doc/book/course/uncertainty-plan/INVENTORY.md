## Gaps that remain open

- P1 now supplies a measured step comparison. Spring stability and actual collision/tunnelling remain separate future questions.
- An inspectable measured-output feedback loop; the real audio feedback needs disclosure rather than reinvention.
- A shared saved dataset with explicit mapping versus decoder-mismatch controls.
- A complete, minimal fuzzy inference chain. Continuous states and soft transitions elsewhere are not equivalent evidence.
- A fault-injection return whose baseline already has passing invariants.
- Focused later audits of float cancellation, invalid-index models, actual topology ambiguity, CSG edge cases, synchronization and adversarial classifiers. These subjects are candidates, not verified gaps or accepted additions.

The audit found no reason to change sequence order. Its strongest recommendation is to improve the agreement between an artifact's name, mechanism and tutorial claim before adding more artifacts.
