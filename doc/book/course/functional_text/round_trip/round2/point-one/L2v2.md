# Point One — give the point a body

from: *supplied*, base scene, *museum* (Day Zero) · `_ready()`, `var`, `:=` (Point Zero)

Point Zero's `_ready()` greeted; here it places a marker.

Open [the Point One study](../../../../../studies/point-one/README.md), then `study.tscn`.
Root `PointStudy` holds three *stations*: `Position`, `Visible`, `Solid`.
Each has a script and a *label*, "Point one".

Run it.
First label: nothing. Next two: white spheres.
Three pink *feelers* move left to right.
Two cross; the third stops at the solid sphere.
The sweep repeats; Space pauses, R restarts.
enters: `contact_probe.gd`'s contact test, not your code; borrowed, like the camera.
→ You change what a feeler can cross.

## Position: nothing shows

Open `position.gd`, the whole script:

```gdscript
extends Node3D

func _ready() -> void:
    var point_position := Vector3(0.0, 1.12, 0.0)
```

`point_position` is a `Vector3`, three numbers: the supplied *position*.
Not yet: its three numbers. Point Coordinates opens them.

Change `1.12` to `1.7`; run.
Nothing appears: no visible *body*, a placed node, is attached.
An unused-variable warning names this *(editor)*.
The feeler still crosses.
enters: the supplied test, not your position.
Restore: `1.12`.
→ Nothing shows; next, a mesh.

## Mesh: it shows

Open `visible.gd`, the whole script:

```gdscript
extends Node3D

func _ready() -> void:
    var point_position := Vector3(0.0, 1.12, 0.0)

    var radius := 0.14
    var sphere := SphereMesh.new()
    sphere.radius = radius
    sphere.height = radius * 2.0

    var marker := MeshInstance3D.new()
    marker.mesh = sphere
    marker.position = point_position
    add_child(marker)
```

`sphere` is a *mesh*, what is seen; `marker` shows it.
A position is not its body.

Try `1.7` here: the sphere rises.
Restore: `1.12`.
Set `radius` to `0.3`: it grows, same centre.
The feeler still crosses.
You change what it hides, not what passes through.
Restore: `radius := 0.14`.
→ Seen is not touched; next, a shape.

## Shape: it stops things

The third looks alike; its feeler stops.
Open `solid.gd`, the whole script:

```gdscript
extends Node3D

func _ready() -> void:
    var point_position := Vector3(0.0, 1.12, 0.0)

    var radius := 0.14
    var sphere := SphereMesh.new()
    sphere.radius = radius
    sphere.height = radius * 2.0

    var marker := MeshInstance3D.new()
    marker.mesh = sphere
    marker.position = point_position
    add_child(marker)

    var solid := StaticBody3D.new()
    solid.position = point_position

    var sphere_shape := SphereShape3D.new()
    sphere_shape.radius = radius
    var collider := CollisionShape3D.new()
    collider.shape = sphere_shape

    solid.add_child(collider)
    add_child(solid)
```

`StaticBody3D` takes part in collision.
`SphereShape3D` is its *shape*, what is touched.

Change only `sphere_shape.radius = radius`:

```gdscript
    # solid.gd, in _ready(), in place of sphere_shape.radius = radius
    sphere_shape.radius = 0.35
```

Run.
The feeler stops at a gap; the sphere stays small.
**Debug → Visible Collision Shapes** shows it too *(editor)*.
You have chosen whether seen mesh and encountered shape coincide.
In the museum, your movement meets this.
The fixed-camera study supplies another moving body: the feeler.
Restore: `sphere_shape.radius = radius`.

Reverse it: `radius` `0.3`, `sphere_shape.radius` `0.07`.
The feeler sinks in before its label says "stopped".
enters: the feeler's own label, not the station's.
The shape sits inside the seen body.
Restore: `radius := 0.14` and `sphere_shape.radius = radius`.
→ Seen and touched part; next, light.

## Light off, body kept

In the museum, use the wall switch.
Shadows go; a dim fill keeps spheres visible.
One line decides it:

```gdscript
# read from the museum's switch; visible.gd has no sun: do not paste it there
sun.visible = false
```

`sun`: the museum's directional light [read].
The study keeps its supplied light.
Not here: building the switch and its rig.
→ Light changes the look, not the shape.
