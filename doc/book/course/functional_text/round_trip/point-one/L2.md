## 1.1 Three stations

*[three "Point one" labels: empty air · white sphere · white sphere; pink feelers sweep past]*

Open the [Point One study](../../../../studies/point-one/README.md), then `study.tscn`.
Under `PointStudy` stand three stations: `Position`, `Visible`, `Solid`.
A station is a node with script and label.
Run: nothing, a sphere, a sphere.

Space pauses, R restarts.
Feelers (`contact_probe.gd`), floor, light and camera are supplied.

## 1.2 A position, then a mesh

*[empty air above the first label · a white sphere above the second; feelers pass both]*

```gdscript
func _ready() -> void:
    var point_position := Vector3(0.0, 1.12, 0.0)
```

That is all of `position.gd`.
A variable names a value: here a `Vector3`, three numbers.
A position is where; a point is the place it marks.
`-> void`: nothing returned.
Set `1.12` to `1.7`: nothing appears; the editor warns "unused variable".
A position gives the point no body.

`visible.gd` adds a mesh, what is seen:

```gdscript
    var radius := 0.14
    var sphere := SphereMesh.new()
    sphere.radius = radius
    sphere.height = radius * 2.0

    var marker := MeshInstance3D.new()
    marker.mesh = sphere
    marker.position = point_position
    add_child(marker)
```

`marker` is a body, a node you place.
Position and body are two things.
Set `1.7`: it rises; `radius` `0.3`: it grows about one centre.
The feeler still crosses: a mesh is not touched.

## 1.3 A shape, set apart

*[the feeler stopped short of a small sphere · the feeler sunk into a large one]*

`solid.gd` builds the same `marker`, then adds a shape, what is touched:

```gdscript
    var solid := StaticBody3D.new()
    solid.position = point_position

    var sphere_shape := SphereShape3D.new()
    sphere_shape.radius = radius
    var collider := CollisionShape3D.new()
    collider.shape = sphere_shape

    solid.add_child(collider)
    add_child(solid)
```

`solid` is a body that stops things; `collider` carries its shape.
The third feeler stops at the shape.
Set `sphere_shape.radius = 0.35`: it stops short; empty space resists.
Mesh `0.3`, shape `0.07`: it sinks in before its label says "stopped".
**Debug → Visible Collision Shapes** shows the shape.
Restore `0.14`.
Seen and touched are set apart; you choose if they agree.
In the museum, your own movement meets them.

## 1.4 Light off, body kept

*[the museum after the wall switch: shadows gone, spheres dim, shapes in place]*

```gdscript
sun.visible = false
```

The museum's wall switch: shadows go, shapes stay.
`sun` is the museum's light; `visible.gd` has none: read, do not paste.
The corridor's last sphere still says "Point one": you know how to rebuild it.
