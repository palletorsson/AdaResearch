# 1 Point One: give the point a body

`_ready()` runs once, when the scene starts.
Use that moment to place a point.
Then give the point a body.

## 1.1 Three stations, three feelers

*[three "Point one" labels in a row: empty air · a white sphere · a white sphere; a pink feeler sweeps past each]*

Open the [Point One study](../../../../studies/point-one/README.md), then `study.tscn`.
Its root is `PointStudy`.
Under it stand three stations: `Position`, `Visible`, `Solid`.
A station is a node with script and label.
The scripts are `position.gd`, `visible.gd`, `solid.gd`.
These three are what you change.
The floor, the light and the camera are supplied.
They stay as they are.

Run the study.
Above the first label: nothing.
Above the other two: a white sphere.
Three pink feelers move left to right.
Two cross their station.
The third stops at the last sphere.
The sweep repeats.
Space pauses and resumes; R restarts it.

`contact_probe.gd` moves the feelers and tests contact.
It is supplied, like the camera.
You change what a feeler can cross.

## 1.2 A point has no body

*[the first station: a label, empty air above it, a feeler passing through]*

```gdscript
extends Node3D

func _ready() -> void:
    var point_position := Vector3(0.0, 1.12, 0.0)
```

This is all of `position.gd`.
`-> void`: the function returns no value.
A `Vector3` is a value of three numbers.
`var` and `:=` name it `point_position`.
A variable is a name for a value.
A position is where something is.
A point is the place a position marks.
Its three numbers wait for Point Coordinates.

Change `1.12` to `1.7` and run.
Nothing appears.
The editor warns: unused variable.
A value changed, and nothing uses it.
The feeler still crosses the empty place.
It belongs to the test, not to your point.
Restore `1.12`.

A position alone gives the point no body.

## 1.3 A mesh is seen

*[the second station: a white sphere above the label; the feeler passes through it]*

```gdscript
extends Node3D

func _ready() -> void:
    var point_position := Vector3(0.0, 1.12, 0.0)

    var radius := 0.14
    var sphere := SphereMesh.new()
    sphere.radius = radius
    sphere.height = radius * 2.0

    var marker := MeshInstance3D.new()
    marker.mesh = sphere
    marker.position = point_position
    add_child(marker)
```

This is `visible.gd`.
`.new()` makes each part.
`sphere` is a `SphereMesh`.
A mesh is what is seen.
`marker` is a `MeshInstance3D`: a node that shows a mesh.
`marker.mesh = sphere` gives it the mesh.
`marker.position = point_position` places it.
`add_child(marker)` joins it to the station.
`marker` is a body: a node you place.
A position and the body placed there are two things.

Change `1.12` to `1.7`: the sphere rises.
Restore it, then set `radius` to `0.3`.
The sphere grows around the same centre.
Its height follows: the script makes it twice `radius`.

Watch the feeler cross the larger sphere.
You change what the sphere hides, not what passes.
Restore `radius` to `0.14`.

A mesh gives the feeler nothing to touch.

## 1.4 A shape is touched

*[the third station: the same white sphere; the feeler stops against it]*

The third station looks the same.
Its feeler stops.

```gdscript
extends Node3D

func _ready() -> void:
    var point_position := Vector3(0.0, 1.12, 0.0)

    var radius := 0.14
    var sphere := SphereMesh.new()
    sphere.radius = radius
    sphere.height = radius * 2.0

    var marker := MeshInstance3D.new()
    marker.mesh = sphere
    marker.position = point_position
    add_child(marker)

    var solid := StaticBody3D.new()
    solid.position = point_position

    var sphere_shape := SphereShape3D.new()
    sphere_shape.radius = radius
    var collider := CollisionShape3D.new()
    collider.shape = sphere_shape

    solid.add_child(collider)
    add_child(solid)
```

This is `solid.gd`.
The first part builds the same `marker`.
`solid` is a `StaticBody3D`: a body that stops things.
`sphere_shape` is a `SphereShape3D`.
A shape is what is touched.
`collider` is a `CollisionShape3D`: it carries the shape.
`solid.add_child(collider)` attaches it to the body.
`marker` and `solid` stand at `point_position`.
`sphere` and `sphere_shape` share `radius`.

The feeler stops at the shape.

## 1.5 Seen and touched, set apart

*[two stills: the feeler stopped short of a small sphere, a gap between · the feeler sunk into a large sphere]*

Find `sphere_shape.radius = radius` in `solid.gd`.
Change only that line of code:

```gdscript
    sphere_shape.radius = 0.35
```

Run again.
The white sphere stays small.
The feeler stops earlier.
A gap opens: empty space resists it.
**Debug → Visible Collision Shapes** shows the larger shape.
The test works without it.
Restore `sphere_shape.radius = radius`.

Set `radius` to `0.3` and `sphere_shape.radius` to `0.07`.
The feeler sinks into the white sphere.
Only then does its label report "stopped".
The shape lies inside the mesh.
Return both to `0.14`.

In the museum, your own movement meets this.
The study's feeler moves in your place.
Seen and touched are set apart.
You choose whether they agree.

## 1.6 Light off, body kept

*[the museum after the wall switch: long shadows gone, the spheres dim but seen]*

In the museum, use the wall switch.
The long shadows go.
A dim fill keeps the spheres seen.
The shapes stay where they were.

```gdscript
sun.visible = false
```

The switch decides in this one line of code.
`sun` is the museum's directional light.
The study keeps its own supplied light.
Building the switch lies outside this lesson.
Read the line; do not paste it.
`visible.gd` has no variable named `sun`.
