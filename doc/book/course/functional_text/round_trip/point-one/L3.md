# 1 Point One: give the point a body

`_ready()` runs once → place a point → give it a body.

<!-- section 1.1 · needs: scene, node, script · gives: station · borrows: feeler, contact_probe.gd, floor, light, camera -->
**1.1 Stations** · [study](../../../../studies/point-one/README.md) › `study.tscn` › `PointStudy` › `Position` · `Visible` · `Solid`. Run → nothing · sphere · sphere; feelers cross · cross · stop. Space pause, R restart. You change what a feeler crosses.

<!-- section 1.2 · needs: _ready, station · gives: point, position, variable, Vector3, var, := -->
**1.2 Position ≠ body** · `position.gd`:

```gdscript
var point_position := Vector3(0.0, 1.12, 0.0)
```

`1.12` → `1.7`: nothing; "unused variable".

<!-- section 1.3 · needs: position, variable, station, feeler · gives: mesh, body, .new(), SphereMesh, MeshInstance3D, add_child -->
**1.3 + mesh → seen** · `visible.gd`:

```gdscript
var sphere := SphereMesh.new()
sphere.height = radius * 2.0
var marker := MeshInstance3D.new()
marker.mesh = sphere
marker.position = point_position
add_child(marker)
```

`1.7` → rises · `radius` `0.14` → `0.3` → grows, same centre · feeler crosses.

<!-- section 1.4 · needs: mesh, body, position, feeler · gives: shape, StaticBody3D, SphereShape3D, CollisionShape3D -->
**1.4 + shape → touched** · `solid.gd` = `visible.gd` +

```gdscript
var solid := StaticBody3D.new()
solid.position = point_position
var sphere_shape := SphereShape3D.new()
sphere_shape.radius = radius
var collider := CollisionShape3D.new()
collider.shape = sphere_shape
solid.add_child(collider)
add_child(solid)
```

Feeler stops. Shape `0.35` > mesh → gap, empty space resists (Debug → Visible Collision Shapes). Mesh `0.3` > shape `0.07` → sinks in, then "stopped". Seen ≠ touched: you choose. Museum: your movement is the feeler.

<!-- section 1.5 · needs: mesh, shape, variable · borrows: sun, .visible -->
**1.5 Light ≠ body** · museum switch: `sun.visible = false` → shadows go, shapes stay. Read, not paste: `visible.gd` has no `sun`.
