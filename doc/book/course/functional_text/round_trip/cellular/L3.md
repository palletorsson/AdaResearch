## 13.3 Rule ⟨cell, buffer, `%` → neighbourhood, bit, rule, step⟩

*[Rule 90's table of eight answers; a floor leaning right]*

```gdscript
var index := now[(i - 1 + n) % n] * 4 + now[i] * 2 + now[(i + 1) % n]
now[i] = (rule >> index) & 1   # written where it is read
```

Neighbourhood = (left, self, right) = 3 bits = 8 cases; rule = 8 answers = its own name: 01011010 = 90.
Predicted row 1: two cells, mirrored. Got: ten, leaning right, no error.
This step writes where it reads: each new cell is the next one's left neighbour; the error runs the loop's way.

## 13.4 Two buffers ⟨step, buffer → two buffers, swap, Sierpinski⟩

## 13.5 Ring ⟨`%`, wrap → ring, dead end⟩

## 13.8 Pool ⟨step, neighbourhood, swap, wrap, shape → reaction-diffusion, pool⟩

*[an orange block → hollow → square wall]*

```gdscript

b_next[i] = b[i] + 0.16 * (around(b, x, z) - b[i]) + eaten - (feed + kill) * b[i]
```
