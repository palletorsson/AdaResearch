## 13.2 One row

*[one lime tile; under it, seventeen numbers, one of them 1]*

```gdscript
extends Node3D

const Look := preload("res://supplied/look.gd")

@export var n := 17                    # cells in a row
@export var cell := 0.4                # metres: a cell's width and depth
@export var rise := 0.15               # metres: a tile's thickness, and how much higher the next row stands

var now := PackedByteArray()    # the row read: one byte for each cell, 0 or 1
var tile := BoxMesh.new()       # one mesh for every cell

func _ready() -> void:
	tile.size = Vector3(cell * 0.9, rise, cell * 0.9)
	tile.material = Look.paint(Look.BODY)
	now.resize(n)
	@warning_ignore("integer_division")
	now[n / 2] = 1
	lay_row()

func lay_row() -> void:
	var row := Node3D.new()
	add_child(row)
	var tiles := MultiMesh.new()
	tiles.transform_format = MultiMesh.TRANSFORM_3D
	tiles.mesh = tile
	tiles.instance_count = now.count(1)
	var drawn := MultiMeshInstance3D.new()
	drawn.multimesh = tiles
	row.add_child(drawn)
	var k := 0          # which tile comes next
	for i in n:
		if now[i] == 1:
			tiles.set_instance_transform(k, Transform3D(Basis(), Vector3(x_of(i), rise / 2.0, 0.0)))
			k += 1
	print(now)

func x_of(i: int) -> float:
	return (i - (n - 1) / 2.0) * cell
```

A cell holds 1, live, or 0, dead.
A row is cells side by side.
A buffer is an array holding one row: `now`, seventeen bytes.
The middle cell is the seed: all that follows grows from it.
A tile is what a live cell looks like.
One `MultiMesh` draws them all.

## 13.3 The rule

*[the eight neighbourhoods and Rule 90's answers; beside them, a floor leaning right]*

A cell's neighbourhood: left, itself, right, each a bit.
Three bits stand in eight ways; a rule answers each.

| left, self, right | 111 | 110 | 101 | 100 | 011 | 010 | 001 | 000 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Rule 90 answers | 0 | 1 | 0 | 1 | 1 | 0 | 1 | 0 |

Read in binary, the answers are 01011010: 90.
The rule is its own name.
`left * 4 + self * 2 + right` is the index of a column.
`(rule >> index) & 1` reads its answer.

Add `@export_range(0, 255) var rule := 90`, `@export var rows := 11`, `var made := 0`.
Lay each row at z `-made * cell`; print it with `made`, then count up.
End `_ready()` with the loop, and add `step()`.

```gdscript
	while made < rows:
		step()
		lay_row()

func step() -> void:
	for i in n:
		var index := now[(i - 1 + n) % n] * 4 + now[i] * 2 + now[(i + 1) % n]
		now[i] = (rule >> index) & 1
```

A step makes every cell's next state from the last.
Predict row 1: two cells, a gap between, a mirrored floor.
Press Play: row 1 is ten cells, and the floor leans right.
No error: the code ran as written.
`step()` writes row 1 into `now` while still reading row 0.
Cell 8 reads cell 7, already new.
The mistake runs right, the way the loop runs.

## 13.4 Two buffers

*[the repaired stair: a triangle of triangular holes]*

Add `var next`, resized like `now`, and replace `step()`.

```gdscript
func step() -> void:
	for i in n:
		var index := now[(i - 1 + n) % n] * 4 + now[i] * 2 + now[(i + 1) % n]
		next[i] = (rule >> index) & 1
	var spare := now
	now = next
	next = spare
```

Row 1 is two cells.
The floor is Sierpinski's triangle.
Questions go to the old row, answers to the new.

> "An answer written at the left cannot slip into the question being asked at the right."

The swap trades names; no byte moves.

## 13.5 The ring

*[row 9 with a live cell at each end]*

In row 9, cell 0 lives because cell 16 did.
`(i - 1 + n) % n` wraps the index: the row is a ring.
A row must end; a ring is one choice.
Add `@export var ring := true` and read neighbours through this.

```gdscript
func cell_at(i: int) -> int:
	if ring:
		return now[(i + n) % n]
	if i < 0 or i >= n:
		return 0
	return now[i]
```

With `ring` false, beyond an end is dead: a dead end.
The two endings differ only at the border.

## 13.6 A stair to stand on

*[the walker on the seed, stopped before row 1's gap]*

Add `@export var pace := 0.25` and `var clock := 0.0`.
`_ready()` loops only when `pace` is 0; `_process` lays the rest.

```gdscript
func _process(delta: float) -> void:
	if pace <= 0.0 or made >= rows:
		return
	clock += delta
	if clock >= pace:
		clock -= pace
		step()
		lay_row()
```

Raise each row by `made * rise`.
Depth and height both mean time: the history is a stair.
The walker walks through it: a `MultiMesh` is for the eye.
Give each row a body, one box per stretch of live cells.

```gdscript
func lay_row() -> void:
	var row := StaticBody3D.new()
	row.position = Vector3(0.0, made * rise, -made * cell)
	add_child(row)
	var tiles := MultiMesh.new()
	tiles.transform_format = MultiMesh.TRANSFORM_3D
	tiles.mesh = tile
	tiles.instance_count = now.count(1)
	var drawn := MultiMeshInstance3D.new()
	drawn.multimesh = tiles
	row.add_child(drawn)
	var k := 0          # which tile comes next
	var start := -1     # where this stretch of live cells began; -1: none yet
	for i in n + 1:
		if i < n and now[i] == 1:
			tiles.set_instance_transform(k, Transform3D(Basis(), Vector3(x_of(i), rise / 2.0, 0.0)))
			k += 1
			if start < 0:
				start = i
		elif start >= 0:
			var box := BoxShape3D.new()
			box.size = Vector3((i - start) * cell, rise, cell)
			var touch := CollisionShape3D.new()
			touch.shape = box
			touch.position = Vector3((x_of(start) + x_of(i - 1)) / 2.0, rise / 2.0, 0.0)
			row.add_child(touch)
			start = -1
	print(made, " ", now)
	made += 1
```

The walker steps onto the seed, then stops.
Row 1's gap is 0.4 m; the walker is 0.6 m wide.
**Stop here**: rows rise, row 1 is two cells, the walker stands.

## 13.8 The same step, another rule

*[the pool: an orange block hollowing into a square wall]*

In `diffusion.tscn`, a cell holds two amounts, A and B.
B is made from A; both spread; A is fed in, B taken out.
That is reaction-diffusion.
The supplied part draws B and hands its heights to a shape.
Write the step.

```gdscript
func around(buffer: PackedFloat32Array, x: int, z: int) -> float:
	var left := buffer[z * g + (x - 1 + g) % g]
	var right := buffer[z * g + (x + 1) % g]
	var back := buffer[(z - 1 + g) % g * g + x]
	var front := buffer[(z + 1) % g * g + x]
	return (left + right + back + front) / 4.0

func step() -> void:
	for z in g:
		for x in g:
			var i := z * g + x
			var eaten := a[i] * b[i] * b[i]
			a_next[i] = a[i] + 0.32 * (around(a, x, z) - a[i]) - eaten + feed * (1.0 - a[i])
			b_next[i] = b[i] + 0.16 * (around(b, x, z) - b[i]) + eaten - (feed + kill) * b[i]
	var spare := a
	a = a_next
	a_next = spare
	spare = b
	b = b_next
	b_next = spare
	steps += 1
```

The stair's step, twice: read `a` and `b`, write the next, swap.
`around()` is the neighbourhood: the mean of four, wrapped by `%`.
The block hollows into a wall: the pool.
It lifts the standing walker, then lowers it, walled in.
