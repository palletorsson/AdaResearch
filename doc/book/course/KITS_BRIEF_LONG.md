## What a kit is

A small Godot 4.6 project a learner opens, with:

- `project.godot` (name = the chapter's short name; main scene = the chapter's scene), the base's `supplied/` folder unchanged, the chapter's scene and script(s), `guests/<kit>/` (the body handed to the room), `.gitignore` (the base's);
- `TUTORIAL.md`, the lesson; `README.md` (what the kit is, how to open it, what is supplied and what is built, the commands, what was and was not checked);
- `verify.gd`, a headless SceneTree script (`godot --headless --path . --xr-mode off --script res://verify.gd`) that writes `verification.json` with a top-level `passed` and a `checks` list, built on `supplied/verify_tools.gd`;
- `sheet.gd`, a windowed script built on `supplied/sheet_tools.gd` that renders the argument's comparison sheet (`sheet.png`), the process strip (`process.png`) and `sheet.json` with the measurements;
- `FIELD_NOTE.md`, the kit's own filled field note.

No `.uid`, `.import` or `.godot/` in what you ship. Tabs for indentation in every script and every code block. LF line endings. Images under about 300 KB each.

Faults the base builder met, so you do not:

- **A guest declares no `class_name`** and names nothing outside its folder. So a guest cannot use `supplied/look.gd`: it writes the palette's hex values itself, as `guests/example/example.gd` does. Two guests with the same class name break each other in the room.
- An `--import` (and opening the editor) writes `.gd.uid` files beside every script, in `supplied/` too. Delete them before you finish; ship none.
- Never set `Look/Sun.shadow_enabled = false`: in this renderer a shadowless sun lights a face less than half as brightly, and every colour changes. To photograph a body without its shadow use `sheet_tools`' `shadows(false)`, which turns off the body's casting.
- Set a node's `position` BEFORE `add_child()`: a body added at the origin and then moved can knock another over on the way.
- `await walker.walk_ended` followed by `free()` crashed Godot. Use `await walk(...)` or `queue_free()`.
- An `Area3D` takes one physics step to find a body.
- `FileAccess.open(...).store_string(...)` followed by a read in the same function gave an empty file. Call `close()` first.
- A typed array handed through an untyped reference can be refused at run time. Declare parameters that receive a literal list as plain `Array`.
