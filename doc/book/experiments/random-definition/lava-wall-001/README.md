Initiated by Palle's 14 October 2026 request for a version of Cloudflare's lamp wall and a practical account of PRNG/TRNG use. The supplied photograph informs the shelves, tapered lamps and alternating colours. The pasted RANDOM.ORG essay is source material, not an implementation instruction or an entropy certification.

Runtime: `commons/artifacts/lava_entropy_wall/lava_entropy_wall.tscn`. Installed at map cell `(11,6)`, yaw 270, in `Random_Definition`. Ordinary registered artifact; not a hidden child of the seed bench. The existing seed bench and independently movable seed instruments retain their placements.

Read [tutorial.md](tutorial.md) to operate and reconstruct it, and [final.md](final.md) for the provisional interpretation. Either text can initiate or revise the experiment. The first 48-value pilot remains in place; this new apparatus does not declare its human research loop complete or replace the proposed hall sequence.
