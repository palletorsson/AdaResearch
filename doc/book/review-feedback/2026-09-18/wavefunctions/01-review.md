# Wavefunctions — 01 Review

Source-aware editorial and reader-experience review of the **Wavefunctions** sequence.

Basis: `wavefunctions-book(1).md`, `wavefunctions-review(1).md`, and the supplied ZIP snapshot on branch `palm-scanner-door-entry`, captured 2026-09-18. No repository code was executed.

This review uses two linked lenses:

1. **Structural / technical:** what the implemented encounter actually supports, what each return does in the sequence, and where source, metadata, map, and manuscript disagree.
2. **Reader experience:** where curiosity builds, where the visitor can discover something before it is named, where explanation arrives too early, and whether the better intervention belongs to the artifact rather than the prose.

Before proposing any cut, the review asks what technical, poetic, critical, or structural work the passage performs. Recurrence is not treated as redundancy when an oscillation returns through another record, carrier, medium, body, sampling rule, sound process, or superposition.

The strongest current sequence-level arc is:

> **returning state → recorded history → periodic rule as terrain → circular coordinates → coupled motion → modulation → periodic form in space → chance within a prepared vocabulary → struck resonance → sampled curve as route → beats → finite additive synthesis**

A second formulation is:

> **Repetition is never only “the same thing again.” What returns depends on which state is retained, how it is sampled, which coordinate carries it, which bodies receive it, and what other oscillations it meets.**

This is considerably more precise than the older sequence rhetoric “Everything oscillates” or “any signal is a sum of sines.”

### Recommendation

# 3. Reader-experience lens

## WaveFunctions Intro — Returning differently

### Curiosity

The opening is excellent:

> “The ring marks a place the bob keeps leaving.”

It gives the visitor one location before explaining state.

The centre crossing creates the key puzzle:

- position ≈ same;
- velocity sign different.

At the turning point the complementary puzzle appears:

- velocity = zero;
- position different;
- motion not finished.

### Discovery

The visitor can discover that the state needs more than position before seeing the state-update code.

Then hand release adds a second question:

> which part of a real gesture enters this one-dimensional pendulum?

The tangent projection gives a concrete answer.

### Timing

Very good.

The implementation appears only after two state ambiguities have already been felt.

The prediction trace comes later and is explicitly said to begin from another initial condition.

### Return

Forces returns here through state accumulation, but periodic return adds something new:

> a body can revisit an address while carrying another velocity.

That is the right conceptual opening for Wavefunctions.

## WaveFunctions Pendulum — Where a swing leaves its past

### Curiosity

The record is spatially strange before it is explained:

> marks drift down the hall while the bob does not.

The visitor is asked to follow one mark rather than read the whole wave immediately.

That is excellent.

### Discovery

The chapter lets the visitor discover several record policies:

- timestamp becomes depth;
- target sampling interval is quantised by physics ticks;
- fine sampling spends entry budget faster;
- coarse sampling retains more duration;
- strobe keeps one sample per measured period and can make motion appear still.

The far-end disappearance is particularly strong:

> one accessible piece of the past simply leaves the bounded record.

### Timing

The code arrives after the long-direction puzzle.

STROBE arrives only after FINE/COARSE establish what “sampling policy” means.

Excellent.

### Return

Trace returns here with another independent variable.

Trace sampled a moving hand according to movement/space.

PendulumWave samples periodic motion according to time.

That recurrence is worth keeping.

## WaveFunctions Sine Space — What a wave can hold

### Curiosity

The tray opening is strong:

> choose a hollow before releasing bodies.

The body/landscape relationship is therefore predicted before wave terminology matters.

The corridor opening similarly asks the visitor to choose a narrow place and watch it change while standing still.

### Discovery

The two experiments perform different work.

- sphere size changes which hollows matter;
- relief changes steepness while sampling addresses remain;

- freezing wall phase and walking can resemble moving walls past a stationary body;
- phase offset changes whether the pair pinches or swerves;

These are strong Ada distinctions.

Color/Transformation returns through collision versus appearance.

## WaveFunctions 3D Wave Propagation — The motion that travels

### Curiosity

The opening question is strong:

### Discovery

The visitor can compare:

- one oscillator;
- near neighbours;

- boundary cells.

This is enough to establish that collective pattern and local displacement are different accounts.

### Timing

The mechanism is explained well after observation.

The weakness is agency.

The text says coupling creates the neighbour influence, but coupling is not a visitor control. The artifact source itself calls a coupling slider “missing.”

This means the visitor can observe a coupled lattice, but cannot perform the strongest comparison:

If this hall is restored to the museum route, a simple two-state control would be high value:

> **COUPLED / INDEPENDENT**

Reset to the same initial state on change.

That would make the relation visible more effectively than another paragraph about coupling.

### Timing

Good.


every update, drawing a fresh threshold repeatedly rather than sampling one fixed “next event time.”

This hall is a deliberate seam between Wavefunctions and Randomness.

## 4.2 Rewrite the sequence tagline/objectives to match what the current artifacts actually teach

**Location:** `sequence.json` and sequence-level curriculum metadata.

### Current truth/tagline

> “Everything oscillates. Fourier shows every signal is a sum of sines. The wave is the fundamental pattern of non-rest—perpetual movement between poles.”

This is far stronger than the present book.

### Current stale objectives include

- “Rotation creates oscillation”
- “Fourier synthesis: any signal is a sum of sines”
- “From periodic to chaotic: the double pendulum transition”
- complex exponential / Fourier integration material not present in the current sequence

There is no current double-pendulum chapter.

The Synthesis Lab intentionally has only:

- five harmonics;
- nonnegative coefficients;
- integer frequency multiples;
- shared phase;
- no independent phase or negative coefficient controls.

Its source identity has already been corrected to:

> **Five nonnegative, phase-locked sine coefficients form a restricted family of sums.**

The sequence metadata should reach the same level of precision.

### Proposed editorial intention

The current intention is basically useful, but could become:

> **Follow periodic return through state, records, spatial patterns and sound; compare what phase, sampling, coupling and superposition preserve or change for different bodies and representations.**

### Proposed objectives

- Distinguish return to the same position from return to the same state.
- Compare temporal sampling policies and the histories they preserve or erase.
- Use periodic functions to assign spatial form, then distinguish visible geometry from bodily affordance.
- Relate circular coordinates to sine and cosine projections without treating that representation as the origin of every oscillation.
- Observe how coupling between local oscillators can produce collective travelling patterns.
- Compare phase modulation, struck sinusoidal resonance and additive synthesis as different ways oscillations can interact.
- Use beat frequency to make a small frequency difference visible as a slow envelope.
- Build and inspect a **finite five-harmonic sum**, including what its restricted coefficients cannot express.
- Treat chance in the Cage room as selection within an authored vocabulary, preparing the transition to Randomness.

### Reason

This removes metaphysical overclaim without making the sequence less ambitious.

The current artifacts are more interesting precisely because they expose **which periodic relation has been implemented**, rather than asserting one universal wave ontology.

## 4.3 Effect Sound — make the instrument's name match its phase-modulation implementation

**Hall / instance**

`WaveFunctions_Effect_Sound`

Primary:

`DualBallFMController:180#stand:desks#evidence:longhand`

### Current visible source

`DualBallFMController.gd::_create_title_label()` sets:

> **FM Synth**

But the audio sample is built as:

```gdscript
var modulator =
    sin(2.0 * PI * modulator_freq * t)
    * mod_index * mod_env

var output =
    sin(2.0 * PI * carrier_freq * t + modulator)
    * carrier_env
```

The modulator is added to the **phase argument**.

The manuscript already says:

> “The room calls this FM synthesis. This expression implements phase modulation, which also changes instantaneous frequency.”

That is technically responsible, but it makes the book correct the instrument.

### Artifact proposal

Prefer one of:

> **PHASE MOD SYNTH**

or, if connection to classic FM terminology is pedagogically useful:

> **PM / FM-STYLE SYNTH**

Then label the orange axes operationally as they already are:

- Mod Ratio
- Mod Index
- Mod Decay

### Source cleanup

The old identity line:

> “All timbral complexity is phase modulation of simple oscillators.”

should also go. This artifact demonstrates a restricted synthesis relation, not all timbre.

### Reason

The critical discovery should be:

> one oscillator changes another by entering its phase.

It should not be:

> the label is technically wrong and the book needs to explain why.

# 10. Overall conclusion

Wavefunctions has a stronger argument than its old manifesto suggests.

It does **not** need to claim:

> everything oscillates  
> every signal is a sum of sines  
> every wave is hidden rotation.

Its current artifacts support a more interesting and accountable argument:

> **periodic relations can be constructed, sampled, projected, coupled, modulated, superposed, embodied and listened to in different ways; similar visible repetitions can arise from different state machines, and the same mathematical periodicity can acquire different consequences depending on its carrier and receiver.**

That is enough.

The reader experience is strongest when the visitor first encounters a **partial return**:

- position returns but velocity differs;
- a history looks like a wave although the body stayed local;
- a periodic wall shapes attention without collision;
- a wave travels while oscillators remain local;
- one sound changes because another enters its phase;
- a column stores periodicity through height instead of time;
- chance changes event order without changing available vocabulary;
- a strike ends while resonance continues;
- a smooth curve still fails to guarantee a walkable route;
- two fast sources produce a slow envelope;
- five simple periodic rows produce a shape none of them owns alone.

Those are the sequence’s real discoveries.

The highest-value work now is therefore:

1. **resolve the twelve-hall versus six-hall curriculum and repair stale transitions/navigation;**
2. **rewrite the old sequence tagline/objectives to match the finite, situated experiments now in the book;**
3. **rename the Effect Sound instrument to match its phase-modulation implementation;**
4. **give coupling one direct comparison if 3D Wave Propagation returns to the spine;**
5. **delay the Synthesis Lab’s preset name until after the visitor has decomposed the arrival waveform;**
6. **clean legacy source identities in Intro, Unit Circle, Bernini, John Cage, AirMusic, Sky Stairs and TrigWalkingPath;**
7. **include `ResonatingBar.gd` in future bundles;**
8. **headset-test every bodily claim, especially grabbing the pendulum, wall passage, metallophone striking and stair continuity.**

The reader-experience principle I would carry forward from Wavefunctions is:

> **Let something return before telling the visitor what kind of repetition it is.**

And the structural principle is:

> **A periodic value does not determine its body. The same return can become state, record, terrain, sound, architecture, chance vocabulary or sum depending on where the rule is allowed to act.**
