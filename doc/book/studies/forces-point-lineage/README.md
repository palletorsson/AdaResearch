# Forces: the same point gains responses

Eleven complete lesson scripts for PointStudy inside the existing Endless Museum. Open the corresponding commons/maps/MAP/tutorial.md for the learning sequence. Shared code: doc/book/course/forces-shared-code.md. The last study requires the existing capability court receiver; all require Godot XR Tools and the museum push button.

Run `tools/probes/forces_lesson_chain.gd` in the project with Godot 4.6, headless, XR off. The probe loads these exact files. `tools/write_forces_point_lessons.py` checks that the displayed tutorial fences still match them.
