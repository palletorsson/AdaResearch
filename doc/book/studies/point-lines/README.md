# Point Lines — a relation

Open this project's `project.godot` in the prepared Godot 4.6 environment from Day Zero. `line.tscn` is the main scene. Follow TUTORIAL.md; the chapter assumes you already know how to run a project.

`line.gd` is the complete lesson. `segment.gd` is the supplied drawing helper. A, B and Readout are real nodes in the supplied scene. `base.tscn` retains the earlier floor, light and fixed camera; it is borrowed infrastructure.

Change B's initial position, or move B using the editor's Remote scene tree while running. The segment and number follow. This desktop study contains no XR player, snap manager, destruction, harm or healing system. The full museum supplies those encounters independently.

Lineage: Point Zero's once/repeated callbacks → Point One's visible marker → Coordinates' positions → two endpoints and distance → Trace's kept positions.
