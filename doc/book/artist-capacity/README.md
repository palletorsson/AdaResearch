## Use it to choose work

1. Choose the question, not merely an artist’s name or an appearance.
2. Find an operation that the student can carry from earlier work.
3. State what stays fixed and what one action changes.
4. Verify the proposed consequence in the actual hall.
5. Write the short encounter and the making exercise separately. State the apparatus each borrows.
6. Retain the source, history or relation the mechanism cannot supply.

Each match has candidates, a judgement, a smallest next study and a critical remainder. Each operation has a proposed encounter home, declared capability prerequisites, a making gate and an observable test. Each candidate has a source snapshot and exact direct active-spine placements, where present.

Three focused applications now test these decisions against existing chapter companions: [Lygia Clark — a pose left](../iterations/2026-10-01-clark-a-pose-left/index.html) follows a hinge through release and trace; [Mona Hatoum — the grid under load](../iterations/2026-10-01-hatoum-grid-under-load/index.html) distinguishes fixed array addresses from variable fragment shape, then proposes one measured row change; [Anish Kapoor — the surface that says depth](../iterations/2026-10-01-kapoor-surface-and-depth/index.html) sets the existing Boolean cavity against a proposed dark surface, separating what geometry already does from what a later shader study could ask. The deep-colour Boolean eggs are now installed in Boolean_Works; their standalone preview remains available as a lighting comparison.

**An early encounter does not require an early implementation lesson.** In the signal room a student can change a retained array using a supplied display. Rebuilding the renderer is a different task. A full hinge constraint similarly belongs later than moving one prepared hinged plate.

## Evidence boundary

This pass inspected implementation sources and scanned direct artifact keys in the interactables layers of 204 map references across the 25 active spine sequences. Fourteen candidate keys have direct tokens. No direct token does not mean unused: generated, nested, branch or dynamic placement is outside this scan. Registry descriptions are not implementation proof, and two registry entries for cloth_simulation share one scene.

No Godot runtime, headset or learner trial was run in this audit. Earlier room captures illustrate previously tested studies; they do not certify the other candidates. The tutorial graph’s nodes are proposed, so a calculated making gate does not assert that its tutorials have been completed. Main map data, sequence order and book final.md files are unchanged.

The four editorial judgements are **Existing operation**, **Combine / adapt**, **New capability needed**, and **Define the encounter first**. These are not grades of artistic value or percentages of an artist’s practice that can be reproduced.
