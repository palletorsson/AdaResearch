# The colour lands

The mounted chromatic catalyst fires toward a framed practice target. Each shot carries a randomly chosen hue. Contact tints the target and separately recolours, shrinks, rotates and shifts nearby grid visuals; their physical colliders stay unchanged. Three hits make the target disappear before returning after four seconds. The floor does not reset with it.

This closes Colour with the difference between a sent value and its receiving operation. One primary, becoming_catalyst, holds the encounter; catalyst_target is its secondary receiver. Pattern making follows with repeated elements and arrangements.
