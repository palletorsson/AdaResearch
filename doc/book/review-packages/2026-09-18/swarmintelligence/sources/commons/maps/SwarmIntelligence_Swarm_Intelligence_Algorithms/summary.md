# SwarmIntelligence_Swarm_Intelligence_Algorithms — Summary

The capstone gallery. Six swarm algorithms stand side by side — Physarum, flow fields, boids, ABM, ACO, and PSO — each in its own alcove, each running simultaneously through a unified visualization framework. The `SwarmShowcase` artifact implements a common agent interface (initialize, perceive, decide, act, update environment) that each algorithm overrides with its specific coordination logic.

The gallery enables direct comparison along three axes. Coordination mechanism: stigmergic (Physarum, ACO store messages in the environment), social (boids, PSO exchange information through direct perception or shared records), field-based (flow fields navigate pre-built infrastructure). Memory location: environmental (trail maps, pheromone), agent-internal (personal best, FSM state), or none (stateless instantaneous perception). Problem type: network formation, navigation, coordination, combinatorial optimization, or continuous optimization.

The multi-level map uses three platform heights as ecological layers — ground-level alcoves for 2D surface algorithms, mid-level for 3D spatial algorithms, upper platforms for abstract optimization. The ground floor connects everything, making the walk between alcoves a walk between paradigms of collective intelligence.

This is the final map in the Swarm Intelligence sequence. Seven maps have demonstrated one thesis: intelligence does not require centralised control. It requires a population of simple agents, a coordination mechanism, and time.

The specific mechanism determines the kind of intelligence, but the pattern is invariant. Local rules. Global behaviour. No leader, no plan. The gallery makes this invariance visible by showing that radically different algorithms share the same architecture, producing collective behaviour that no individual computed.
