Concept: Agent-based models as the universal framework — each agent carries its own state, rules, and perception, and the system-level behavior is whatever emerges from their interactions. Two raised platforms bracket an arena where agents run, collide, cooperate, and compete, making the gap between individual rules and collective dynamics physically visible.
Sequence role: Fourth map in Swarm Intelligence (14th spine sequence, integration phase), intermediate difficulty. After the specific case of boids, this map generalizes to the ABM framework: agents with arbitrary rule sets interacting in a shared environment. The arena geometry (two platforms bracketing a central ring) creates spatial structure that constrains and channels agent behavior. Connects forward to SwarmIntelligence_Ant_Colony_Optimization where agents gain a specific optimization objective; follows SwarmIntelligence_Boids_Algorithm.
Technical angle: Agent architecture with state variables (position, velocity, internal state), perception model (radius-based neighbor sensing or raycast), decision rules (finite state machine or rule-based), and environment interaction (stigmergic trail deposition, resource consumption). The simulation loop: perceive, decide, act, update environment. The two-platform geometry introduces elevation as a constraint — agents must navigate vertical transitions, adding spatial complexity to their decision-making.
Critical angle: ABM is the methodological revolution of complexity science: instead of writing equations for the system, you write rules for the individual and let the system happen. This inverts the reductionist program — you cannot derive the macro from the micro analytically, but you can simulate it. The arena is a petri dish for artificial societies, and the integration phase recognizes that intelligence, like form, is not imposed from above but emerges from below.
Key artifacts: ABMSimulation implements a general agent-based model in the two-platform arena environment, with configurable agent rules, perception models, and environment interaction mechanisms.
Gap: Needs a rule editor — an artifact that lets the learner modify individual agent rules in real time and see the macro-level behavior shift, making the micro-macro link interactive rather than observational.
