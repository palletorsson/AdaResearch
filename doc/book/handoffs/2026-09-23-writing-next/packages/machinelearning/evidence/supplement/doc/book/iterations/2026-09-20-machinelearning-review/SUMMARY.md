## Finding and editorial decision

The eight chapters already have a useful progression: selection → a chosen loss → grouping → learned weights → perception → memory → adversarial feedback → anomaly. Their recurring question is what the operation establishes, and what we add when interpreting its result. Keep that progression. There is no need to rewrite the whole sequence into a source audit.

Only **Gradient Landscape and Classification** have changed in `final.md`. The other six chapters are byte-preserved. The outside review helped identify missing comparisons, but the first repair belongs to the encounter: let the visitor change the dataset, repeat a beginning and see which parts of an apparently intelligent display actually compute something.

The sequence description now distinguishes these different operations instead of presenting all machine learning as gradient descent. The QFEP framing remains a project interpretation rather than a claim that every learning process is the same physical entropy process. Book heroes now agree with the placed primary artifacts in Evolution, Gradient, Classification and Memory. Existing supporting book entries, artifact roles and artifact families remain.
