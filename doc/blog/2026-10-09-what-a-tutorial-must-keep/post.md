A cube returns to the middle of its path. In a still image, we cannot tell whether it is rising or falling. The program knows something the picture does not: the time, the phase, and the rule that places the cube. That small difference became one of the useful questions in our work on Wavefunctions. What must an explanation keep so that someone else can do more than recognise the image?

We have been writing inside an existing world. Endless Museum already contains the objects, lights, passages and means of moving through them. The tutorial selects a construction within that world. The reflective text can follow another object or stay with a consequence the construction does not settle. Other artifacts remain part of the field without becoming compulsory exercises. Keeping these overlapping purposes distinct has been one of the hardest parts of the work.

*A native Godot capture from the previous Wavefunctions test. The learner's study occupies the museum; the surrounding exhibits remain. This is an earlier capture, not a new Randomness test.*

At first, a short piece of code could look convincing while depending on an object that had never been created. A label was assumed. A mesh waited behind a scene reference. A later chapter quietly asked for a new point when the student had already made one. These were small omissions with a large consequence: the book appeared continuous while the student's working material was interrupted.

The response has been to give the imagined student a more definite existence. Extract the code as printed. Keep the inherited files named. Run it in the declared environment. Ask for a change whose result can be checked. The ghost student then has a state: an object, a record, an available operation, and a particular set of things not yet learned.

The latest Wavefunctions rehearsal extracted thirty-two printed files across twelve halls. The existing checks passed, and twelve new variations passed thirty-seven checks after one correction to the checker. Three deliberate conceptual faults were rejected. Three representative studies were also run and photographed in the actual museum. These results support specific claims about execution. They do not tell us that an unfamiliar person has understood the lesson or that a headset encounter feels right. The assistant performing this rehearsal already knew the work.

The failed check was instructive. It expected a sample index of sixty from an expression involving division and multiplication by the audio sample rate. Floating-point arithmetic put the value just below that boundary; conversion to an integer produced fifty-nine. The program did what it said. The test had assumed exact arithmetic where it had not arranged for it. We kept the failed receipt and changed the check to sample inside the intended interval. Validation needs its own scrutiny.

That experience changes how I would describe the method. We are not stamping a whole project as true. We are making claims small enough to meet evidence. This printed program creates its own label. These two histories remain separate. Replay does not spend another random draw. A particular changed version produces the predicted difference. The claim can be inspected, challenged and revised without pretending that the rest of the museum has been certified with it.

Continuity also turned out to be more than keeping the same object. The cube returns as a moving body and later as a tread. PointBody can be a responding ball, a marker or a held control, provided the change of role is declared. Trace's list returns as timed observations and then as a score. In Synthesis, two signed contributions become a list of five amounts. Familiar constructions make new questions possible.

This gives the reflective writing something precise to lean on. A retained score raises a question about what replay preserves. A stair raises a question about what a visible invitation actually supports. A restored recipe does not restore the visitor who has already heard or seen it. The text can stay with those differences without explaining every line of the implementation again.

The next sequence is Randomness. An initial reading shows a different state of preparation: some tutorials closely explain working artifacts, while others are older sketches with missing helpers or a focus that no longer matches the hall. They should not receive the same completion label. A useful description of source code and a reconstructable lesson each have work to do, but the student needs to know which has been offered.

We can begin from what Wavefunctions has already made available. Cage chose a score and kept it for replay. Synthesis kept a recipe while its phase continued. At the first Randomness table, two pictures return from the same seed. Then one unused draw shifts the colour assignments. The number alone was never the whole recipe. This is a small enough change to understand closely and a large enough distinction to carry through the sequence.

The working plan now names one principal construction in each hall: a repeated grid, a count, an eligible set, a mark, an event record, an accumulated turn, a walk, a distribution, a population, a spatial relationship, an estimate, a feedback field, a layered sum and a sampled deadline. The wider museum remains around them. We will inspect each choice before expanding its paragraph into a lesson.

The short plan matters because it can change. It lets us see the whole route without carrying every implementation in working memory. Opening one paragraph brings back the source, the encounter and the tests that belong to it. The compressed instruction is useful when it preserves the edges: what is inherited, what is new, what is supplied and what still has to be proved.

There is a future student in these decisions, although we cannot know the conditions under which they will arrive. Their imagined difficulty has already made us preserve an object, remove an unexplained dependency, and separate a pleasing picture from a demonstrated operation. The encounter is uncertain. Its influence on the present work is concrete.

The next task is deliberately local: rebuild the first Randomness example from the printed page, inside the museum, and see whether its smallest change can carry the question we are asking of it.
