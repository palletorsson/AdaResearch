# Map: Wave Propagation: The Medium is the Message

A wave is not an object—it's a disturbance traveling through a medium. Watch waves emanate from sources, diminishing by inverse square law. Learn distance fields, phase propagation (sin(time - dist)), attenuation, and interference. Discover that identity is permeable: you are not a static entity, but a point of intersection for the world's noise.

## Learning Objectives

- Distance fields: calculating propagation from source to every point
- Wave function: sin(time * speed - dist * frequency)
- Attenuation: inverse square law (energy = 1 / (1 + dist²))
- Interference: wave summation creates peaks and cancellation
- Critical: Identity is permeable—to exist in a medium is to be distorted by it
