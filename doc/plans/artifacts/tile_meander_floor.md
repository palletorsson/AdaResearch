# Artifact: Tile Meander Floor

> a floor proving that three tile types generate infinite meander complexity

## Context

**Category:** primitives | **Complexity:** intermediate
**Tags:** 2d, pattern, mosaic, floor, meander, greek_key, majolica, san_michele, tiling | **Themes:** arrays, art, cultural_computation

Greek key meander floor built from exactly 3 tile types: field (solid blue), straight (horizontal key hook), and corner (90-degree turn). Villa San Michele blue majolica style. Each tile is a 7x7 bitmap; when tiled along all 4 borders, they form a continuous Greek key band.

*the Greek key is a tiling problem — corners and straights compose the infinite band*

## Design

- **Visual:** material: standard, animation: static
- **Scale:** [1, 1, 0] (compact)
- **Interaction:** players look down and trace the Greek key — the oldest repeating border in Western art
- **Critical Parameter:** grid_cells — resolution of the tile grid
- **What Emerges:** the insight that a meander is not drawn but TILED — 3 types suffice for any Greek key
- **Triggers:** instantiation or apply_grid_config
