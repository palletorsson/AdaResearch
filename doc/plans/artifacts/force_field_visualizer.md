# Artifact: Force Field Visualizer

> F(x) = vector at every point. The field precedes the particle. Space is not empty.

## Context

**Category:** physics | **Complexity:** intermediate
**Tags:** force_field, visualization, gravity, electric, magnetic, 3d | **Themes:** commons, mixed, physics

Visualize gravitational, electric, and magnetic force fields in 3D using arrow glyphs and particle tracers. Place sources and sinks to sculpt the field landscape, then release test particles to see how forces guide motion through space.

*Motion is reading, not deciding. The field tells the particle where to go.*

## Design

- **Visual:** material: vertex_color, animation: static
- **Scale:** [1.0, 1.0, 1.0] (compact)
- **Interaction:** To show the invisible. To make the learner see that empty space carries instructions.
- **Critical Parameter:** Field type (gravity/coulomb/dipole/vortex). Each is a different spatial grammar.
- **What Emerges:** Superposition from dipole (two sources cancel/reinforce). Curl from vortex. Convergence from gravity.
- **Triggers:** Type button → topology changes (radial vs rotational vs superposed), strength slider → arrows grow/shrink
