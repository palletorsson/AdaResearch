# Artifact: L-System String Expansion

> string(n+1) = replace_all(string(n), F, rule) — exponential rewriting made visible

## Context

**Category:** procedural | **Complexity:** advanced
**Tags:** fractal, l_system, procedural, simulation, string | **Themes:** grammar, l_systems, procedural

Visualizes the L-system rewriting process — shows how the axiom string expands through each generation, making the grammar visible as text.

*The string is the structure — the tree is just one way to read it.*

## Design

- **Visual:** material: standard, animation: static
- **Scale:** [1.0, 3.0, 3.0] (room_scale)
- **Interaction:** To show the string before the tree — stacked generations revealing how F→F[+F]F[-F]F explodes
- **Critical Parameter:** rule_to — the production rule determines the entire growth pattern of the string
- **What Emerges:** The realization that the tree was always in the string — geometry is just an interpretation of grammar
- **Triggers:** Each generation multiplies string length exponentially; truncation at 50000 chars shows the limit of display
