# Artifact: Rotating Cube Demo

> theta(t) = omega * t, displayed with circular trail and angle readout

## Context

**Category:** waves | **Complexity:** intermediate
**Tags:** animation, physics, waves | **Themes:** oscillation, physics, waves

Continuous rotation demonstration: θ += ω·dt. The simplest rotational motion—angle increases by angular velocity times delta time each frame. Ground arc shows the rotation path, direction arrow tracks the current angle. Constant spin, no oscillation.

*Rotation at constant speed is the simplest periodic motion — the mother of all oscillation.*

## Design

- **Visual:** material: shader, animation: vertex
- **Interaction:** Watch a single cube rotate at constant angular velocity with its circular path traced
- **Critical Parameter:** rotation_speed (omega) — the angular velocity in radians per second
- **What Emerges:** the connection between angular velocity, period, and the circular path
- **Triggers:** continuous time integration rotates the cube; trail mesh shows the circular orbit
