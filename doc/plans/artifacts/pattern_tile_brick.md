# Artifact: Brick Pattern Tile

> preview[px,py] = palette[grid[(py%N, px%N)]] transformed by RepeatMode/WallpaperGroup — a NxN color array tiled infinitely by a symmetry rule, with drag-and-drop colored cubes to edit the source tile

## Context

**Category:** primitives | **Complexity:** intermediate
**Tags:** 2d, pattern, primitives | **Themes:** arrays, data_structures

Tile with brick/half-drop offset. Classic masonry pattern.

*every repeating pattern in the world — from Islamic tiles to woven textiles to crystal structures — is an instance of one of the 17 wallpaper groups, and this artifact makes that classification navigable with your hands*

## Design

- **Visual:** material: generated_texture, animation: physics
- **Interaction:** to experience pattern as repetition made tangible — to place a single colored cube and watch it propagate across a carpet according to a mathematical symmetry rule, understanding that patterns are small decisions amplified by structure
- **Critical Parameter:** wallpaper_group (when in WALLPAPER mode) — the 17 mathematical wallpaper groups classify every possible way to tile a plane with a repeating motif, and switching between them changes the character of the whole carpet from a single edit
- **What Emerges:** the cursor visualization reveals that the same source cell appears multiple times in the preview — the index math (px%N, py%N) becomes physically visible as a spotlight moving across the carpet, connecting to identical tiles
- **Triggers:** placing a cube on the editor grid immediately updates the full preview; toggling symmetry_mode from LEGACY to WALLPAPER activates the 17-group system; cursor animation sweeps through the preview showing index↔source mapping
