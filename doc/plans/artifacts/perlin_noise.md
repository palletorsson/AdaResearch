# Artifact: Perlin Noise

> perlin(p) = Σᵢ amplitudeᵢ × interpolate(gradient_hash(grid_corner(frequencyᵢ × p))) — gradient noise using a permutation table to assign consistent random gradients to grid corners

## Context

**Category:** procedural | **Complexity:** intermediate
**Tags:** noise, procedural | **Themes:** probability, procedural, randomness

Interactive Perlin noise generation and visualization

*Perlin noise is organized hallucination — the algorithm enforces continuity and smoothness onto randomness, creating the illusion that chaos has intention*

## Design

- **Visual:** material: standard, animation: static
- **Scale:** [10, 3, 10] (xlarge)
- **Interaction:** to turn three sliders and watch the same mathematical recipe produce mountains, heartbeats, or alien textures — to feel that frequency, amplitude, and octaves are a complete description of organic shape
- **Critical Parameter:** octaves — each additional octave adds one more frequency layer of detail; at 1 the noise is smooth blobs, at 8 it fractures into rock-like complexity
- **What Emerges:** the learner discovers that regenerate with same octaves produces a different landscape but the same character — octaves constrain the space of possible shapes without determining which shape
- **Triggers:** animation_button toggles time-based offset that slides the noise field — revealing that Perlin noise is a 3D field being sampled in a 2D plane, and time is the third dimension
