# Artifact: Vector Addition Walk (Room Scale)

> A + B = C at body scale. You ARE inside the vector space.

## Context

**Category:** mathematics | **Complexity:** beginner
**Tags:** vectors, addition, parallelogram, room-scale, walkable | **Themes:** vectors

Player-scale 3D vector addition. Walk inside a 3m coordinate grid, grab vector endpoints at body height, see parallelogram construction and component projections in real space.

*You don't observe vector addition. You stand inside it.*

## Design

- **Visual:** material: vertex_color, animation: vertex
- **Scale:** [4, 4, 4] (xlarge)
- **Interaction:** Walk along the X-axis to feel the X-component. Addition becomes spatial, not symbolic.
- **Critical Parameter:** Grid size vs vector length — vectors must fit inside the walkable volume.
- **What Emerges:** The parallelogram from ghost arrows. Component projections along axes.
- **Triggers:** Handle grab → vectors update, preset buttons → snap configurations
