# Artifact: Random Object Spawner

> P(spawn) = P(remove) — steady-state random replacement

## Context

**Category:** unknown | **Complexity:** intermediate
**Tags:** probability, procedural | **Themes:** core, primitives

A spawning algorithm that randomly generates and places objects in the environment

*Replacement is the metabolism of randomness — the system lives by forgetting what it was.*

## Design

- **Visual:** material: standard, animation: transform
- **Scale:** [1.0, 1.0, 1.0] (compact)
- **Interaction:** watch cubes appear and disappear at random intervals, hear the wood knock of each arrival
- **Critical Parameter:** MAX_CUBES — the carrying capacity; once reached, each spawn requires a death
- **What Emerges:** a column of cubes that never grows beyond 20 but is never the same column twice
- **Triggers:** spawn_timer exceeding next_spawn_time (randomized 0.3–1.3s) triggers spawn or replace
