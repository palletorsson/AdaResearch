Book of Shaders patterns — 3 modes: classic tiling/truchet/brick, Wang tiles + Voronoi texture generation, procedural noise synthesis (simplex FBM, Worley cells, domain warp). VR slider controls per shader.

*fract() does not copy — it folds space; the pattern was always there, the function just reveals where the seams are*

## Design

- **Visual:** material: shader, animation: transform
- **Interaction:** to press the Mode button and cycle from bricks to Voronoi to domain warp — to see the same UV space fold through radically different logics
- **Critical Parameter:** grid_size — the integer that multiplies space, turning one tile into a field
- **What Emerges:** Truchet tiles from random corner flips produce labyrinths no one designed; Voronoi edge mode (F2-F1) reveals crackle patterns — structure defined entirely by boundaries
- **Triggers:** mode button cycles CLASSIC/WANG_VORONOI/NOISE; reset rebuilds current mode; aperiodic_mix slider interpolates between periodic and aperiodic Wang tiling
