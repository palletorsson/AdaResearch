# Artifact: Königsberg Bridge Problem

> 4 nodes (landmasses), 7 edges (bridges) — Euler's theorem: Eulerian path exists iff exactly 0 or 2 vertices have odd degree; all 4 vertices have degree 3 (odd), so no path exists

## Context

**Category:** algorithms | **Complexity:** beginner
**Tags:** graph_theory, euler, bridges, eulerian_path, topology, history | **Themes:** algorithms, misc

Euler's Königsberg bridge problem — can you cross every bridge exactly once? The question that birthed graph theory, proving that some problems are about structure, not calculation.

*the impossibility of the Konigsberg walk is not a failure of the walker — it is a property of the graph itself, and no amount of cleverness can overcome odd-degree parity*

## Design

- **Visual:** material: standard, animation: transform
- **Scale:** [21.0, 4.0, 21.0] (world_scale)
- **Interaction:** to walk the seven bridges yourself and feel the impossibility — each bridge you cross is an edge consumed, and you cannot complete the walk because graph theory forbids it
- **Critical Parameter:** node degree — every landmass has odd degree (3), and Euler proved that this specific parity pattern makes a complete traversal impossible
- **What Emerges:** players attempting the walk inevitably retrace a bridge, discovering Euler's proof through embodied frustration rather than abstract reasoning
- **Triggers:** educational_mode enables the analysis UI showing degree sequence, Euler's theorem, and the impossibility proof; historical bridge names and construction dates appear as Label3D nameplates
