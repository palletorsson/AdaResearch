# Artifact: VR Audio Monitor

## Context

**Category:** waves | **Complexity:** beginner
**Tags:** sound, visualization, vr, wave | **Themes:** music, oscillation, physics, waves

Standalone audio monitor display showing waveform and spectrum analysis. Place near any audio source to visualize sound. The waveform shows amplitude over time; the spectrum shows frequency content—two complementary views of the same signal.

*Sound is invisible force; the monitor makes the waveform a visible object.*

## Design

- **Visual:** material: standard, animation: static
- **Scale:** [1.0, 1.0, 1.0] (compact)
- **Interaction:** See the audio bus activity rendered as a real-time waveform monitor in VR
- **Critical Parameter:** audio_bus — selects which audio bus to monitor
- **What Emerges:** visual feedback loop between what you hear and what you see
- **Triggers:** auto_connect finds and binds to the audio system on ready
