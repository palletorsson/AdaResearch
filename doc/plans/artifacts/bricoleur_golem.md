# Artifact: Bricoleur Golem

> body = assemble(available_parts) -- asymmetric creature built from mismatched geometric primitives

## Context

**Category:** hazards | **Complexity:** beginner
**Tags:** bricolage, reconstruction, randomness, adaptation | **Themes:** education, gameplay, hazards

Asymmetric golem built from mismatched primitives. Rebuilds itself from random parts after damage — each reconstruction unique. Exhausts after 3 rebuilds. Teaches bricolage: creation from whatever is at hand.

*the bricoleur does not design -- it discovers what available parts want to become.*

## Design

- **Visual:** material: standard, animation: static
- **Interaction:** a golem that shatters and rebuilds from whatever is at hand, never the same body twice
- **Critical Parameter:** available parts inventory -- which primitives are nearby determines the next body form
- **What Emerges:** improvisation as survival -- the bricoleur's method applied to self-construction
- **Triggers:** damage causes disassembly; reassembly from local parts; each rebuild produces different geometry
