# Artifact: Pheromone Terrain

> trail(x,y) += deposit; next = argmax(pheromone[neighbors]) with P(random) = 1 - attraction — stigmergy

## Context

**Category:** emergence | **Complexity:** advanced
**Tags:** pheromone, swarm, terrain, self_organization | **Themes:** procedural, emergence

Swarm-based terrain generation where agents deposit pheromone trails that shape the landscape. Demonstrates emergent self-organization from simple local rules.

*Stigmergy is memory without a brain — the environment itself becomes the communication channel.*

## Design

- **Visual:** material: vertex_color, animation: vertex
- **Interaction:** watch random walkers leave glowing trails that attract other walkers, building ridges from nothing
- **Critical Parameter:** pheromone_attraction — the probability a walker follows pheromone vs moves randomly (0 = pure random, 1 = pure trail-following)
- **What Emerges:** path networks self-organize — walkers converge on trails they collectively created without communication
- **Triggers:** _walk_step() deposits pheromone, raises terrain, then _choose_next_position() balances attraction vs random
