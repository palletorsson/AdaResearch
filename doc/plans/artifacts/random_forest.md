## Context

**Category:** machinelearning | **Complexity:** intermediate
**Tags:** machinelearning, random-forest, ensemble, bagging, decision-tree, bootstrap, gini, classification | **Themes:** machinelearning

A forest of decision trees grows one by one, each trained on a random bootstrap sample with random feature selection. Individual trees overfit — their boundaries are jagged and noisy. But the majority vote of all trees produces a smooth, generalizing boundary. Tree columns light up as each tree joins the ensemble. The decision boundary visibly smooths with each addition. Democracy applied to prediction.

*A random forest is democracy applied to prediction. Each tree votes from its own limited perspective. The majority is usually right.*
