# Artifact: Slot Machine

> P(A∩B∩C) = P(A)·P(B)·P(C) — independent joint probability

## Context

**Category:** randomness | **Complexity:** beginner
**Tags:** slot_machine, uniform_distribution, independence, combinatorics, probability, histogram, interactive | **Themes:** probability, randomness

A classic slot machine with 3 spinning reels. Pull the VR lever to spin — reels stop one by one, left to right. Tracks a histogram of symbol frequencies showing convergence to uniform distribution. Triple matches flash gold. AUTO mode for rapid sampling.

*Independence is not absence of connection — it is the impossibility of prediction from correlation.*

## Design

- **Visual:** material: standard, animation: particle_lifecycle
- **Interaction:** pull the lever, feel anticipation as reels decelerate one by one
- **Critical Parameter:** symbols_per_reel — determines outcome space (6^3 = 216)
- **What Emerges:** histogram convergence to uniform — the longer you play, the flatter the bars
- **Triggers:** _pull_lever() → sequential reel-stop cascade via _stop_sequence_timer
