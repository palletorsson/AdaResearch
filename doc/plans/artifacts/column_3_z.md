# Artifact: column_3_z

> for i in range(4): cube.position = Vector3(0, 0, i × spacing) — four pickup cubes arranged as a linear array in the Z direction, each labeled [i]

## Context

**Category:** unknown | **Complexity:** beginner

Stacks three pickup cubes in the Z direction for spacing tests.

*an array is space made countable — column_3_z makes the abstract concept of an index into a physical position you can walk to*

## Design

- **Scale:** [1, 1, 4] (room_scale)
- **Interaction:** to walk alongside an array — to see [0], [1], [2], [3] as physical objects in space and understand that an index is a distance, that traversal is movement
- **Critical Parameter:** spacing — at 1.0 the cubes are adjacent and the array feels compact; at 2.0 they feel like separate objects; the default 1.0 makes index=position visible
- **What Emerges:** the pink label color (light pink, Color(1.0, 0.7, 0.8)) subtly codes the array as soft rather than rigid, echoing the project's queer aesthetic
- **Triggers:** picking up a cube removes it from the array visualization, making the gap visible — the array has a hole where the index used to be
