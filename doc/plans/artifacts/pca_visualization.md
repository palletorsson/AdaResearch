# Artifact: PCA Visualization

> X_centered → covariance → eigenvectors → project onto top-k components; maximize preserved variance

## Context

**Category:** machinelearning | **Complexity:** advanced
**Tags:** pca, dimensionality_reduction, variance, projection | **Themes:** ai, machine_learning

Principal Component Analysis — high-dimensional data projected onto principal axes. Shows variance capture and dimensionality reduction in 3D.

*PCA reveals that high-dimensional data is a conspiracy of a few directions pretending to be many*

## Design

- **Visual:** material: standard, animation: static
- **Scale:** [12, 5, 12] (xlarge)
- **Interaction:** watch blue data points collapse onto red projections as principal component axes reveal the hidden structure
- **Critical Parameter:** target_dimensions — how many dimensions to keep; the compression/information trade-off
- **What Emerges:** the realization that most of the variance lives in very few directions — data is lower-dimensional than it appears
- **Triggers:** auto_start runs the full PCA pipeline; projection animation interpolates points to their lower-dimensional positions
