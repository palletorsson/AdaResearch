# Artifact: Rhizomatic Structure

> recursive branching with lateral reconnection — each new node grows from a random parent with direction = lerp(random, away_from_center, 1 - growth_direction_randomness), then probabilistically connects to nearby existing nodes

## Context

**Category:** geometry | **Complexity:** intermediate
**Tags:** graph_theory, rhizome, non_hierarchical, cycles, topology, deleuze, network, alternative_geometry, critical_theory | **Themes:** geometry, non_euclidean

Grow a network that refuses root, trunk, and leaves. Recursive branching creates a scaffold, then lateral reconnections turn that scaffold into a mesh where any point can connect to any other. Adjusting reconnection probability moves the artifact between tree and rhizome, making hierarchy versus multiplicity a concrete topological choice. It brings Deleuze and Guattari into graph theory by questioning when a tree is the wrong model.

*a rhizome has no beginning and no end — only middles, and every connection is as legitimate as every other*

## Design

- **Visual:** material: standard, animation: static
- **Interaction:** to grow a structure that has no center and no hierarchy — a rhizome where any point can connect to any other point, undermining tree-shaped thinking
- **Critical Parameter:** connection_probability — at 0 the structure is a tree (hierarchical), at 1.0 every nearby node reconnects (rhizomatic), the transition is where Deleuze meets graph theory
- **What Emerges:** lateral connections create cycles in an otherwise tree-shaped growth, producing a network topology that resists reduction to any single root or trunk
- **Triggers:** generate_structure builds the node/connection arrays; draw_structure renders CylinderMesh branches between connected nodes; regenerate() clears and regrows
