## Context

**Category:** hazards | **Complexity:** intermediate
**Tags:** hazards, origami | **Themes:** gameplay, hazards

Magic-ball inspired fold shell using accordion pleats and braided ring bands; rolls compressed and deploys to fire.

*Origami is constraint that enables transformation — the same sheet becomes wheel, turret, and shield.*

## Design

- **Visual:** material: standard, animation: static
- **Interaction:** a folding origami wheel that rolls toward you, inflates to reveal a firing core, then collapses to relocate
- **Critical Parameter:** inflation_fire_bias — how compressed the shell stays during FIRE state, exposing or protecting the core
- **What Emerges:** split-face dihedral animation creates a breathing, organic quality from rigid box geometry
- **Triggers:** state machine (ROLL→DETECT→DEPLOY→AIM→FIRE→DEAD) drives fold/inflate pose via _apply_fold_pose()
