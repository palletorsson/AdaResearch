# Artifact: Y-Translation Cube

> An animated cube that moves only along the Y axis. Because the vertical coordinate changes alone, the artifact makes upward and downward displacement read differently from horizontal movement even though the operation is still translation. The result is a clean lesson in axis decomposition. It turns elevation into a coordinate fact.
