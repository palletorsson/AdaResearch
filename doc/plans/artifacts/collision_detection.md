# Artifact: Collision Detection

> Two-phase collision detection pipeline: broad phase (spatial hashing, bounding boxes) rapidly culls impossible pairs, then narrow phase (GJK/SAT algorithms) computes exact contact points, penetration depth, and collision normals. Visualizes the acceleration structures that make real-time physics possible — without them, checking every pair is O(n²) death.
