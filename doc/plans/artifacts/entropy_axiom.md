# Artifact: Entropy Axiom

> S = -Σ p_i log p_i — Shannon entropy as spatial gradient

## Context

**Category:** emergence | **Complexity:** advanced
**Tags:** 2d, chaos, compression, emergence, l_system, probability, procedural | **Themes:** emergence, probability, randomness

Visualizes the gradient from order to chaos using a 10x10x40 MultiMesh grid (4000 instances). Points transition from structured alignment to random displacement along the Z-axis.

*Entropy is not disorder — it is the number of ways a system can be without you noticing.*

## Design

- **Visual:** material: unlit, animation: static
- **Interaction:** walk along the z-axis and watch order dissolve into chaos before your eyes
- **Critical Parameter:** max_randomness — controls displacement amplitude at the chaos end
- **What Emerges:** the blue-to-red color gradient makes the arrow of entropy visible as a thermodynamic landscape
- **Triggers:** z-position of each sphere determines its entropy factor via exponential curve
