Gallery layout showcasing all parametric mathematical objects together — surfaces, knots, and topological curiosities arranged for comparison and exploration.

*Every smooth surface is a parametric function of two variables — mathematics made solid.*

## Design

- **Visual:** material: standard, animation: static
- **Interaction:** Walk past a curated gallery of parametric surfaces, each with labeled variations
- **Critical Parameter:** variations_per_object — controls how many parameter variants are shown per surface type
- **What Emerges:** a periodic table of mathematical shapes — comparison reveals what parameters do
- **Triggers:** _ready() generates the full grid of mathematical objects with labels
