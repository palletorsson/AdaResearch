# Artifact: Pickup Gate

> A blocking gate whose state depends on how many pickup cubes have crossed the threshold. Its geometry is simple, but its logic makes transformation legible as a rule: the gate is closed, then open, because enough translated objects changed the count. That turns motion into conditional infrastructure. It teaches that state change can be triggered by accumulated displacement.
