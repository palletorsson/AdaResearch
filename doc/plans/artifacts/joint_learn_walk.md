# Artifact: Joint Learn Walk (Reinforcement Learning)

> Q(s,a) ← Q(s,a) + α[r + γ·max_a' Q(s',a') - Q(s,a)] — tabular Q-learning for joint torques

## Context

**Category:** machinelearning | **Complexity:** advanced
**Tags:** reinforcement_learning, locomotion, joints, policy_gradient | **Themes:** ai, education, machine_learning

RL agent learning to walk — reward shaping, policy gradient, emergent locomotion. Joints discover coordinated movement through trial and error.

*an agent does not need to understand its body to learn to use it — reward is the only teacher*

## Design

- **Visual:** material: unlit, animation: physics
- **Interaction:** watch a random-limbed creature teach itself to walk through trial and error in VR
- **Critical Parameter:** exploration_rate (ε) — too high and the creature flails forever; too low and it gets stuck in a local gait
- **What Emerges:** locomotion gaits nobody designed — the creature discovers how to use its own body
- **Triggers:** each update_frequency tick evaluates reward (distance traveled) and updates Q-table; exploration_decay shrinks ε over time
