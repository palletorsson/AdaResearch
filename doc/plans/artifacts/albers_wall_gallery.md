*a square inside a square is not decoration — it is an experiment in how context changes the perception of every color it touches*

## Design

- **Visual:** material: vertex_color, animation: static
- **Scale:** [1.0, 1.0, 1.0] (compact)
- **Interaction:** to stand before a gallery wall and see how color relationships change when squares nest inside squares — Albers' life work, proceduralized
- **Critical Parameter:** inset_ratio — controls how quickly inner squares shrink; at 0.78 the nesting feels balanced, at extremes it collapses or barely nests
- **What Emerges:** the vertical_bias shifts inner squares downward, creating a gravity effect that makes the paintings feel grounded without explicit composition rules
- **Triggers:** palette_seed + index * 31 generates deterministic but varied palettes per canvas; no runtime interaction
