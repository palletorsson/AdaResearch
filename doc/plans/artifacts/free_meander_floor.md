# Artifact: Free Meander Floor

> the Greek key as a per-cell mathematical rule, not a repeated tile

## Context

**Category:** primitives | **Complexity:** intermediate
**Tags:** 2d, pattern, mosaic, floor, pompeii, meander, greek_key, modular_arithmetic | **Themes:** arrays, art, cultural_computation

Rule-based Greek key meander — no tiles, no turtle, no bitmap. Each cell decides its own color from ONE modular arithmetic rule applied to its global position. The entire pattern is: territory = ((pos_along + ring * band_width) % period) < half_period. Dark field interior with polka dots.

*Roman mosaicists thought in rules, not tiles*

## Design

- **Visual:** material: vertex_color, animation: static
- **Scale:** [1, 1, 0] (compact)
- **Interaction:** players see the cleanest meander yet — because it IS the rule
- **Critical Parameter:** band_width — controls the hook depth and period
- **What Emerges:** the insight that all Greek key patterns emerge from four band rules
- **Triggers:** instantiation or apply_grid_config
