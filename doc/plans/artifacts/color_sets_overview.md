# Artifact: Color Sets Overview

> palette_atlas — N palettes laid out as grabbable sticker grids, each sticker labeled with hex + nearest web color name

## Context

**Category:** color

Interactive color set grabber — explore color families, hue relationships, and palette structures through physical manipulation.

*naming a color does not capture it — but it makes the gap between name and experience visible*

## Design

- **Interaction:** to pick up a color, read its name, and carry it across the room — making color portable and personal
- **Critical Parameter:** sets_to_show — controls how many palettes are visible simultaneously, determining comparison density
- **What Emerges:** the luminance-adaptive label contrast (dark text on light stickers, light on dark) makes every color readable without explicit design per palette
- **Triggers:** none at runtime — static grabbable display; XR pickup on each sticker via grab_paper.tscn
