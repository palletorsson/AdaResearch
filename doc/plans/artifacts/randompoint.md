Drops a single draggable point inside an XY bounds and keeps its billboarded coordinate label in range.

*white noise is the null hypothesis of space — the universe before it learned to care where things go*

## Design

- **Visual:** material: standard, animation: transform
- **Interaction:** to feel the lottery of position — grab the point, release it, watch it land somewhere that has no memory of where it was
- **Critical Parameter:** area_half_extent — the size of the possible universe this point can inhabit
- **What Emerges:** the learner begins to notice that no region of space fills up faster than any other — uniformity as a lived sensation
- **Triggers:** dropping the point resets it; every drop is a new draw from the same distribution
