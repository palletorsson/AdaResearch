# Artifact: Catalyst Target

> A practice target that flashes, explodes, and respawns when struck. Its visible states change quickly, but the target remains recognizably the same object across idle, hit, destroyed, and restored phases. Movement options add patrol and orbit patterns without changing that core identity. It is a compact lesson in state transition.
