Visual representation of random forest ensemble — multiple decision trees voting on classification, showing how diversity improves accuracy.

*a forest of imperfect decision-makers can be more reliable than any single expert — this is the mathematics of collective intelligence*

## Design

- **Visual:** material: standard, animation: static
- **Scale:** [20, 9, 20] (xlarge)
- **Interaction:** watch a forest of decision trees grow, each different, each voting — democracy of weak learners producing strong predictions
- **Critical Parameter:** num_trees — more trees reduce variance; the wisdom of crowds effect
- **What Emerges:** the ensemble is wiser than any individual tree — diversity plus aggregation equals accuracy
- **Triggers:** auto_start grows trees one by one; bootstrap sampling shows how each tree sees different data; feature importance emerges
