# Artifact: Braid Meander Floor

> the Greek key derived from first principles — braid topology projected onto tiles

## Context

**Category:** primitives | **Complexity:** intermediate
**Tags:** 2d, pattern, mosaic, floor, pompeii, meander, greek_key, braid, topology | **Themes:** arrays, art, cultural_computation

Greek key meander generated TOP-DOWN from braid topology. Two strands cross at regular intervals; each crossing projects onto the grid as an angular spiral hook. The braid crossing number controls the pattern: 1 = classic Greek key, 2 = double meander. Dark field interior with polka dots.

*the meander is a braid with crossing number 1*
