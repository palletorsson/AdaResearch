# Artifact: Nested Diamonds Floor

> a floor encoding Roman depth through concentric rotated geometry

## Context

**Category:** primitives | **Complexity:** beginner
**Tags:** 2d, pattern, mosaic, floor, pompeii | **Themes:** arrays, art, cultural_computation

Pompeii mosaic floor with nested diamonds pattern. Each cell contains three concentric 45-degree rotated squares creating a bulls-eye of dark-light-dark-light zones radiating inward.

*every diamond holds a smaller copy of itself — the Romans knew about self-similarity*

## Design

- **Visual:** material: standard, animation: static
- **Scale:** [1, 1, 0] (compact)
- **Interaction:** players see how nesting the same shape at shrinking scales produces visual gravity
- **Critical Parameter:** tiles_short — number of nested-diamond cells on the short axis
- **What Emerges:** the insight that recursion was a decorative principle millennia before computers
