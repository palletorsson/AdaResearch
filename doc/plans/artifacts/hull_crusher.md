# Artifact: Hull Crusher

## Context

**Category:** hazards | **Complexity:** beginner
**Tags:** convex-hull, geometry, polyhedron, projectiles | **Themes:** education, gameplay, hazards

Morphing convex polyhedron with orbiting point-nodes. Fires points as projectiles — each launch shrinks the convex hull. Points respawn over time. Teaches computational geometry through combat.

*the hull teaches convexity by consuming itself -- structure is ammunition, geometry is finite.*

## Design

- **Visual:** material: standard, animation: static
- **Interaction:** a morphing convex hull launching its own points, shrinking with each attack
- **Critical Parameter:** vertex count / _fire_timer -- each projectile removes a vertex, hull shrinks
- **What Emerges:** convexity as self-consuming weapon -- teaches convex geometry by destroying itself
- **Triggers:** fire_timer triggers vertex ejection; hull recomputes; body shrinks as ammunition depletes
