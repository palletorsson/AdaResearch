# Artifact: Parametric L-System

> angle(depth) = base_angle * 0.95^depth + random(-var, +var) — parametric decay per branch level

## Context

**Category:** procedural | **Complexity:** advanced
**Tags:** l_system, procedural, simulation, tree | **Themes:** grammar, l_systems, procedural

L-system with continuous angle and length parameters — branch depth controls parametric decay for organic, naturalistic tree and plant forms. More organic than discrete rules.

*Randomness in the parameters, not the rules, is what makes grammar look like nature.*

## Design

- **Visual:** material: vertex_color, animation: static
- **Interaction:** To show that continuous parameters make L-systems organic — the same grammar, softer and more alive
- **Critical Parameter:** length_decay — how quickly branches shorten with depth, controlling the tree's overall proportion
- **What Emerges:** Natural-looking trees from angle randomization and length decay — no biological model, just parameter gradients
- **Triggers:** Preset switch → Bushy Tree, Willow, Fern Spray, Coral Branch — same engine, different character
