# Artifact: Spatial Voronoi

> cell(x) = argmin_i(|x - seed_i|) -- ground partitioned into Voronoi territories by nearest seed

## Context

**Category:** hazards | **Complexity:** intermediate
**Tags:** voronoi, spatial, partition, cells, seeds | **Themes:** biology, gameplay, hazards

Ground plane divided into Voronoi cells by drifting seed points. Each cell has a different danger type — safe, damage, slow, heal. Seeds drift and types shuffle, remapping the partition. Spatial decomposition as territory.

*Voronoi cells partition space by proximity -- borders between safe and lethal are always moving.*

## Design

- **Visual:** material: standard, animation: transform
- **Interaction:** drifting seed points dividing ground into territories -- safe, damage, slow, heal -- borders wander
- **Critical Parameter:** _seed_positions / _seed_types -- locations determine boundaries; types assign effects
- **What Emerges:** Voronoi partitioning as territorial hazard -- map reorganizes by nearest-neighbor geometry
- **Triggers:** seeds drift continuously; boundaries recompute; player cell type determines effect
