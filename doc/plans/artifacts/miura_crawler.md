# Artifact: Miura Crawler

> fold(t) = sin(crawl_phase) — Miura-ori corrugation drives inchworm locomotion

## Context

**Category:** hazards | **Complexity:** intermediate
**Tags:** hazard | **Themes:** gameplay, hazards

Miura-ori folding enemy - flat corrugated sheet that crawls like an inchworm. Lies flat and nearly invisible, pops up when player approaches, uses zigzag locomotion. Can squeeze through gaps when flattened.

*Miura-ori proves that a single degree of freedom — fold amount — can generate locomotion from flat material.*

## Design

- **Visual:** material: standard, animation: static
- **Interaction:** a flat sheet that ripples toward you like a living carpet, compresses to strike, then flattens to disappear
- **Critical Parameter:** _fold_amount — 0 is flat (dormant/invisible), 1 is fully corrugated (attack wind-up)
- **What Emerges:** the inchworm gait arises from sinusoidal fold cycling — no explicit leg animation, just geometry folding
- **Triggers:** state machine (DORMANT→ALERT→CRAWL→ATTACK→FLATTEN) with fold amount oscillating during crawl phase
