# Artifact: Koch Curve

> koch(segment) = [a, b, peak, d, e] where peak rises sqrt(3)/2 above the middle third. D = log(4)/log(3) ~ 1.26.

## Context

**Category:** unknown | **Complexity:** advanced
**Tags:** fractal, graph | **Themes:** generation, procedural

Koch snowflake curve fractal with recursive edge patterns

*The Koch snowflake has infinite perimeter and finite area — it is a line that wants to be a plane but never quite arrives.*

- **Visual:** material: vertex_color, animation: vertex
