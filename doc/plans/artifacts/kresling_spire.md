# Artifact: Kresling Spire

> twist(t) ∈ [0,1] — Kresling twist maps between flat disc and extended tower

## Context

**Category:** hazards | **Complexity:** beginner
**Tags:** hazards, origami | **Themes:** gameplay, hazards

Kresling origami sniper tower - twisting cylinder that extends from compact disc to tall tower. Rolls as disc to reposition, rises by untwisting to snipe from elevation, collapses rapidly to relocate.

*The Kresling fold proves that rotation and translation are coupled — to twist is to rise.*

## Design

- **Visual:** material: standard, animation: static
- **Interaction:** a disc rolls toward optimal range, twists upward into a sniper tower, fires, collapses, relocates
- **Critical Parameter:** _twist — 0 = tall tower (sniper mode), 1 = flat disc (mobile mode); single DOF controls entire behavior
- **What Emerges:** the tower seeks optimal_range — it backs away if too close, approaches if too far, creating a standoff distance
- **Triggers:** state machine (DISC→RISE→AIM→FIRE→COLLAPSE→RELOCATE) drives twist interpolation
