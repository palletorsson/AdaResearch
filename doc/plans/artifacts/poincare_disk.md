Poincaré disk model of hyperbolic geometry - where parallel lines diverge and triangles have angle sum < 180°

*infinity can be contained in a finite disk — the Poincare model proves that hyperbolic geometry is as consistent as Euclidean*

## Design

- **Visual:** material: standard, animation: vertex

- **Interaction:** see an entire infinite hyperbolic plane compressed into a finite disk — watch geodesics pulse
- **Critical Parameter:** disk_radius — contains the entire infinite geometry within a finite boundary
- **What Emerges:** the visual proof that parallel lines can diverge — multiple geodesics through a point that never meet a given line
- **Triggers:** animate_geodesics pulses geodesic arcs; the triangle displays angle sum < 180°
