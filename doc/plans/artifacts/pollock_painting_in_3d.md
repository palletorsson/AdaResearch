# Artifact: Pollock Painting in 3D

> drip(t) = position(random_walk) + color(random) + width(random) — action painting as algorithm

## Context

**Category:** procedural | **Complexity:** intermediate
**Tags:** 3d, animation, procedural | **Themes:** art, probability, procedural, randomness

Interactive 3D Jackson Pollock-inspired painting using movement-based procedural randomness

*A Pollock painting is not random — it is the trace of a body moving through a random field with intention.*

## Design

- **Visual:** material: unlit, animation: static
- **Interaction:** watch a brush cursor trace Pollock-style drip paths across a floor canvas in real time
- **Critical Parameter:** simulate_brush_motion — when true, the 3D brush follows 2D stroke paths from the SubViewport
- **What Emerges:** layered strokes create depth and complexity — the painting is never finished, only accumulated
- **Triggers:** stroke_path_generated signal from PollockPainting2D drives brush tween across canvas surface
