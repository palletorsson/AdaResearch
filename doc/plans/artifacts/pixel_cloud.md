## Context

**Category:** procedural | **Complexity:** intermediate

Builds an upward-biased self-avoiding random walk and places cubes along the path to form a pixel cloud sculpture.

*Self-avoidance is memory — and memory is the first constraint that gives randomness shape.*

## Design

- **Visual:** material: standard, animation: static
- **Scale:** [1.0, 1.0, 1.0] (compact)
- **Interaction:** see a vertical sculpture made of cubes, each placed by a walk that refuses to retrace its steps
- **Critical Parameter:** upward_bias — weight multiplier for +Y steps; higher values produce taller, thinner clouds
- **What Emerges:** the walker frequently traps itself — the sculpture is a record of how far freedom reached before constraint won
- **Triggers:** self_avoiding_walk() with weighted_random_choice(); ui_accept regenerates the structure
