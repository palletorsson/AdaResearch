# Artifact: Support Vector Machine Visualization

> max margin: min ||w||² s.t. yᵢ(w·xᵢ + b) ≥ 1; kernel trick maps to higher dimensions

## Context

**Category:** machinelearning | **Complexity:** intermediate
**Tags:** svm, support_vector, classification, margin, kernel | **Themes:** ai, machine_learning

SVM hyperplane separator with support vectors highlighted. Shows maximum margin classification and kernel trick for non-linear boundaries.

*the decision boundary depends on only a few points — most of the data is redundant once the margin is found*

## Design

- **Visual:** material: standard, animation: static
- **Scale:** [10, 6, 10] (xlarge)
- **Interaction:** see the maximum-margin hyperplane crystallize between classes, support vectors glowing gold at the boundary
- **Critical Parameter:** C_parameter — regularization; low C allows misclassification for wider margin, high C demands perfection
- **What Emerges:** support vectors — the few critical points that define the entire boundary; most data points are irrelevant
- **Triggers:** auto_start runs SMO optimization; kernel_type switches between linear, polynomial, RBF, sigmoid decision boundaries
