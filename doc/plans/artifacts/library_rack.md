# Artifact: Library Rack

> library[i] = registry.artifacts[i].scene — a physical index of computational objects

## Context

**Category:** display
**Tags:** library, collection, display, rack

Universal collection display wall. Reads any artifact registry and builds a grid of cubes, each containing a scaled-down artifact or shader. Config: #collection:shaders#cols:6#rows:4

*a library is not the objects — it is the act of organizing them so they can be found*

## Design

- **Visual:** material: shader, animation: static
- **Interaction:** stand before a wall of everything the system can make, organized and labeled
- **Critical Parameter:** the collection key — one word selects which registry to display
- **What Emerges:** a periodic table for any domain — shaders, primitives, patterns, hazards, math objects
- **Triggers:** apply_grid_config reads collection, loads registry, builds wall of instanced scenes
