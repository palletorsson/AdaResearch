# Artifact: Waterbomb Hopper

> waterbomb.compress() -> spring_release() -> hop(height) -- origami bouncing hazard

## Context

**Category:** hazards | **Complexity:** intermediate
**Tags:** hazard, origami | **Themes:** gameplay, hazards

Bouncing waterbomb tessellation enemy. Origami-themed hazard with a waterbomb base shape built from triangular faces. Bounces sinusoidally with squash-and-stretch, fold angle oscillates for a breathing effect. Patrols a rectangular path, chases on detection.

*the fold stores energy -- compression IS the spring, origami geometry IS the locomotion.*

## Design

- **Visual:** material: standard, animation: static
- **Interaction:** a waterbomb that compresses and springs upward, hopping across terrain
- **Critical Parameter:** _health / compression cycle -- compression stores energy, release drives the hop
- **What Emerges:** origami as spring -- folding geometry stores and releases elastic energy for locomotion
- **Triggers:** continuous compress-release cycle; each hop covers ground; landing zone damages player
