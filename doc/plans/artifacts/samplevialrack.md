# Artifact: Sample Vial Rack

> glow[i](t) = lerp(min, max, 0.5 + 0.5*sin(frequency*t*TAU + phase[i]))

## Context

**Category:** waves | **Complexity:** advanced
**Tags:** linear_algebra, probability, procedural, wave | **Themes:** oscillation, physics, waves

Six sample vials demonstrating phase relationships. Each vial glows with a sine wave offset by TAU/6 from its neighbor, creating a visible wave propagation effect. Modes: linear wave travel, radial expansion from center, random phases. Classic wave interference visualization.

*A row of oscillators with progressive phase offset is a traveling wave made of light.*

## Design

- **Visual:** material: standard, animation: transform
- **Interaction:** Watch a rack of sample vials pulse with phase-offset luminescence like a slow wave
- **Critical Parameter:** wave_frequency — controls the collective pulsing rate across all vials
- **What Emerges:** a visible traveling wave across the rack — phase offset makes the wave apparent
- **Triggers:** phase_mode switches between linear, radial, and random phase distribution across vials
