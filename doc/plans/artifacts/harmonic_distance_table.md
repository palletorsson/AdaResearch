# Artifact: Harmonic Distance Table

> harmonic_distance(a, b) = |shared_overtones(a, b)| — consonance as overtone overlap

## Context

**Category:** waves | **Complexity:** advanced
**Tags:** graph, interactive, sound, visualization, vr, wave | **Themes:** art, music, oscillation, physics

Tabletop artifact with 12 chromatic pitch nodes in circle-of-fifths layout. Grab nodes to hear intervals; spatial distance corresponds to harmonic consonance. Activate a node as tonal center to see all others recolor by harmonic function (tonic=green, dominant=blue, subdominant=yellow). Glowing overtone connection lines show shared harmonics between pitches. Cognitive compression: harmonic distance becomes a felt spatial relationship.

*Consonance is the degree to which two pitches share the same overtone series.*

## Design

- **Visual:** material: vertex_color, animation: particle_lifecycle
- **Interaction:** Touch pitch nodes on a circle-of-fifths layout and see overtone relationships light up
- **Critical Parameter:** base_octave — determines the frequency range for tone generation and overtone calculation
- **What Emerges:** consonance and dissonance as a visible network — more shared overtones = closer connection
- **Triggers:** selecting two notes computes shared overtone count and plays the interval
