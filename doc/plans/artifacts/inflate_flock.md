# Artifact: Inflate Flock

> vertices flock like boids to inflate/deflate a mesh — pressure pushes out, cohesion holds shape

## Context

**Category:** hazards | **Complexity:** advanced
**Tags:** fold_system, inflation, flocking, boids, vertices, sphere, organic | **Themes:** fold_system

Icosphere inflates from a point using vertex flocking — pressure pushes out, separation prevents overlap, cohesion holds shape. Organic breathing inflation. Same vertices, same faces.

*inflation is democracy. every vertex votes on where the surface should be.*

## Design

- **Visual:** material: standard, animation: static
- **Interaction:** a living membrane that breathes — inflating with organic wobble, deflating into a tight seed
- **Critical Parameter:** fold_amount — 0 is deflated (all vertices at centroid), 1 is fully inflated
- **What Emerges:** the mesh breathes because vertices negotiate position instead of following a script
- **Triggers:** each vertex feels pressure (outward), separation (don't overlap), cohesion (stay grouped)
