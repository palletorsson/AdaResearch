# Artifact: Goomba Box

> A box that walks. Stomp it flat — topology as vulnerability.

## Context

**Category:** hazards | **Complexity:** beginner
**Tags:** mario, stomp, box, patrol | **Themes:** gameplay, hazards

Folding cardboard box that patrols corridors. Stomp from above to flatten it — topology as vulnerability. Side contact deals damage.

*A box has six faces but only one is vulnerable — the top.*

## Design

- **Visual:** material: standard, animation: static
- **Interaction:** patrol corridors, bump into the player, get flattened by a stomp from above
- **Critical Parameter:** _flatten (0=walking box, 1=completely flat/stunned)
- **What Emerges:** the stomp mechanic — player learns to attack from above, not head-on
- **Triggers:** PATROL→DETECT→CHARGE→STOMPED→RECOVER→DEAD
