# Artifact: Chord Tension Spring

> tension = sum(spring_force(interval_distance)) for all pitch pairs in chord

## Context

**Category:** audio | **Complexity:** intermediate
**Tags:** chord, tension, consonance, dissonance, spring, harmony, cognitive_compression | **Themes:** audio, music_theory, physics

Four pitch nodes connected by visible springs. Consonant chord = springs relax, nodes settle. Dissonant chord = springs vibrate, nodes jitter. Drag nodes to change pitch and feel tension physically. Preset buttons for major, minor, dom7, dim, aug, sus4, tritone. Resolution IS relaxation.

*Musical tension is not metaphor — intervals exert measurable pull on perception.*

## Design

- **Visual:** material: vertex_color, animation: particle_lifecycle
- **Interaction:** Drag pitch nodes in VR and feel musical tension as physical spring resistance
- **Critical Parameter:** spring stiffness per interval — maps harmonic consonance to physical force
- **What Emerges:** the sensation of musical tension as embodied resistance — dissonance pulls harder
- **Triggers:** dragging a node recalculates all spring forces and plays the resulting chord
