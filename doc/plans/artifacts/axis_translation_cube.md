# Artifact: Axis Translation Cube

> position[axis] = start + direction * lerp(0, 1, progress) — pure single-axis translation animated

## Context

**Category:** transforms | **Complexity:** advanced
**Tags:** pattern, transforms | **Themes:** geometry, math, transforms

Configurable axis translation demonstration. Set axis export to 0 (X), 1 (Y), or 2 (Z) to change which axis the cube translates along. Shows start → wait → end → wait pattern with trail ghosts and live labels.

*translation is the additive group action on position — it changes location while preserving orientation*

## Design

- **Visual:** material: shader, animation: particle_lifecycle
- **Interaction:** learner reads the label and watches the cube traverse one axis, internalising what "X translation" means
- **Critical Parameter:** axis — X, Y, or Z; determines which coordinate changes while the others stay fixed
- **What Emerges:** the orthogonality of axes — moving on X changes nothing about Y or Z, visually confirmed
- **Triggers:** VR speed slider (slider_horizontal) adjusts lerp speed live; ghost trail shows recent positions
