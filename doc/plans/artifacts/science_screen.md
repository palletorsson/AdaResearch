# Artifact: Science Screen

> A large display that projects nearby 3D artifacts into simplified 2D abstractions. The screen keeps the structure of the source object but changes its representational state, turning embodied experience into diagram. That makes it a useful bridge between moving through a form and reasoning about it. It stages projection as a transformation with both gains and losses.
