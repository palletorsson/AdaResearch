# Artifact: colorballs

> N rigid spheres sampled from named color palettes — physics + palette = chromatic rain

## Context

**Category:** unknown | **Complexity:** beginner
**Tags:** color | **Themes:** color, perception

colorballs

*a color only becomes real when it has mass — palette theory means nothing until you can throw it*

## Design

- **Visual:** material: vertex_color, animation: physics
- **Scale:** [1.0, 3.0, 4.0] (room_scale)
- **Interaction:** to toss, scatter, and watch colored balls pool and bounce, making palette differences visceral through physics
- **Critical Parameter:** current_palette_index — switches the entire chromatic vocabulary; same physics, different visual language
- **What Emerges:** balls cluster by momentum into accidental color groupings that look curated but are pure physics
- **Triggers:** palette cycling recolors all balls instantly; falling below threshold respawns with new random palette color
