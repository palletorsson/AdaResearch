VectorFieldFlow

*A vector field is a set of instructions written in space. The particle has no memory and no plan — it only reads the local instruction.*

## Design

- **Visual:** material: standard, animation: particle_lifecycle
- **Scale:** [1.0, 1.0, 1.0] (compact)
- **Interaction:** To make an invisible flow visible — 81 arrows breathing in unison, a particle tracing the field's will.
- **Critical Parameter:** The swirl-to-radial ratio in _field_value(). It determines whether the field spirals inward, orbits, or ejects.
- **What Emerges:** Spiral trajectories from the combination of rotational swirl and inward radial pull. The particle's path is never a straight line.
- **Triggers:** Automatic — arrows oscillate vertically, particle advects continuously. R → reset particle to origin, Space → freeze velocity.
