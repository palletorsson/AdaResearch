# Artifact: Branching Growth Algorithm

> space colonization algorithm — branches grow toward attractors, each step: find closest attractor, add jitter, extend by growth_distance, mark reached attractors as consumed

## Context

**Category:** unknown | **Complexity:** intermediate
**Tags:** procedural | **Themes:** generation, procedural

Interactive visualization of branching growth patterns and algorithmic plant generation

*a tree does not plan its shape — it grows toward what attracts it, and the shape is what remains after all the reaching is done*

## Design

- **Scale:** [1.0, 1.0, 1.0] (compact)
- **Interaction:** to watch a tree grow toward light in real time — branches reaching, splitting, and filling space as attractors guide their path through 3D
- **Critical Parameter:** jitter — at 0 the growth is deterministic and straight, at high values branches wander organically, creating the difference between crystal and root
- **What Emerges:** branches competing for the same attractors create natural spacing patterns that resemble real vascular networks without any explicit spacing rule
- **Triggers:** attractor proximity (< min_branch_distance) kills an attractor and deactivates the branch; pride flag color cycling every 10 seconds shifts the visual palette
