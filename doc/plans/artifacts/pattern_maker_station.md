# Artifact: Pattern Maker Station

> symmetry_group(domain[x][y]) -> infinite_carpet — paint a small NxN grid, select one of 17 wallpaper groups, watch the GPU tile it into an infinite-seeming carpet via symmetry operators

## Context

**Category:** interactive | **Complexity:** intermediate
**Tags:** pattern, wallpaper_group, symmetry, tiling, carpet, painting | **Themes:** arrays, data_structures

Interactive wallpaper group station — paint a domain grid on an upright panel, choose from 17 symmetry groups, and watch the tiled result unfold on a large floor carpet in real time.

*structure does not emerge from complexity — it emerges from constraint applied to the almost-nothing*

## Design

- **Visual:** material: generated_texture, animation: transform
- **Interaction:** to touch cells on the upright panel with VR hands and see the floor carpet update in real time — to cycle through P1 to P6M and feel how constraint multiplies a fragment into architecture
- **Critical Parameter:** wallpaper_group — the symmetry operator that transforms a 4x4 domain into a universe; 17 groups, exactly 17, a hard constraint the universe imposes on 2D repetition
- **What Emerges:** the GPU shader carpet (wallpaper_tile.gdshader) with grout, noise distort, and aging parameters produces worn Italian mosaic effects from a handful of colored cells
- **Triggers:** palette buttons select paint color; group cycle button advances through all 17 groups; flip X/Y and rotate CW transform the domain; clear resets to blank; touch painting via Area3D collision
