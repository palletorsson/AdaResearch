## Design

- **Visual:** material: unlit, animation: static
- **Scale:** [1.0, 1.0, 1.0] (compact)
- **Interaction:** To show that territory emerges from proximity alone: scatter seeds, and boundaries appear where claims collide
- **Critical Parameter:** num_seeds — how many territories; few seeds produce large kingdoms, many produce fine-grained mosaic
- **What Emerges:** Organic spatial partitions from a single distance calculation per point
- **Triggers:** Regenerating with different seeds reorganizes all boundaries; render mode toggles faces, wireframe, and dual mesh
