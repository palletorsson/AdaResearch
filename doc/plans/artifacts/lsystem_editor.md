# Artifact: L-System Editor

> axiom → rules → string → turtle(F, +, -, [, ]) → line geometry — the full L-system pipeline interactively

## Context

**Category:** procedural | **Complexity:** intermediate
**Tags:** lsystem, grammar, procedural, plants, fractals, editor | **Themes:** commons, mixed, procedural

Edit L-system grammars in real-time and watch procedural plants, fractals, and branching structures grow from simple rewriting rules. Adjust axiom, production rules, angle, and iteration depth to explore the space of formal grammars made visible.

*Seven presets, one turtle — the grammar is the artist.*

## Design

- **Visual:** material: vertex_color, animation: static
- **Scale:** [1.0, 2.0, 1.0] (compact)
- **Interaction:** To be played with — slide between Koch, Sierpinski, Dragon, Plant, Bush, Fern, and Binary Tree in real time
- **Critical Parameter:** preset (0-6) — seven fundamentally different grammars, each a different visual universe
- **What Emerges:** The insight that one renderer + different rules = infinite variety — grammar IS the design tool
- **Triggers:** Changing angle while keeping rules → same grammar, different geometry; generation slider → growth stages
