# Artifact: Lyapunov Fractal

> Lyapunov fractal from alternating logistic map parameters — for each point (a,b) in parameter space [2,4]x[2,4], iterate x=r*x*(1-x) alternating r between a and b in pattern AABB. The Lyapunov exponent λ colors the plane: blue for stable orbits (λ<0), yellow-red for chaos (λ>0), black at the boundary. The result resembles alien calligraphy.
