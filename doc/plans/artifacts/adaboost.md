# Artifact: AdaBoost

> w(i) *= exp(alpha * err_i). Points that the last stump got wrong get heavier. The next stump focuses on the hard cases.

## Context

**Category:** machinelearning | **Complexity:** intermediate
**Tags:** machinelearning, boosting, adaboost, ensemble, weak-learner, decision-stump, classification, weighting | **Themes:** machinelearning

Watch a sequence of weak learners focus on what the previous ones got wrong. Each decision stump is simple — a single threshold on one axis. But AdaBoost weights misclassified points heavier, so each new stump specializes on the hard cases. Points that keep getting misclassified visually grow larger. The ensemble decision boundary gets progressively more sophisticated from trivially simple components.

*AdaBoost is a conversation between failure and focus. Each mistake makes the next learner pay more attention to what was missed.*
