# Artifact: SpringSuspension

> 6DOF joint with Y-axis spring, all other axes locked. Vertical bounce, nothing else.

## Context

**Category:** forces | **Complexity:** intermediate
**Tags:** physics, joints, 6dof-joint, spring, damping, suspension, vehicle, oscillation, hooke | **Themes:** physics, simulation

A car-like suspension system using a Generic6DOF joint configured as a vertical spring. A wheel hangs below a chassis, free to bounce vertically but locked in all other axes. The spring stiffness and damping create the characteristic suspension feel — press space to drop the wheel and watch it oscillate to rest. This demonstrates how a single 6DOF joint with carefully chosen axis locks and spring parameters can simulate complex mechanical behavior.

*A spring joint is a constraint that remembers where it wants to be. Damping is how fast it forgets being disturbed.*
