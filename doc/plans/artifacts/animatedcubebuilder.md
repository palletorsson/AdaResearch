# Artifact: animatedcubebuilder

> cube = 8 vertices + 12 edges + 6 faces — build it layer by layer from its components

## Context

**Category:** unknown | **Complexity:** intermediate
**Tags:** 3d, interactive, vr | **Themes:** core, primitives

Animated construction sequence that steps from vertices to edges to full cube mesh with grab handles.

*dimension accumulates — points make edges, edges make faces, faces make solids*

## Design

- **Visual:** material: shader, animation: vertex
- **Scale:** [1.0, 1.0, 1.0] (room_scale)
- **Interaction:** learner watches a cube assemble itself and understands it as an accumulation of primitives
- **Critical Parameter:** the animation sequence — vertices appear first, then edges, then faces, in order
- **What Emerges:** the pedagogical insight that a solid is constructed from lower-dimensional elements: 0D → 1D → 2D → 3D
- **Triggers:** automatically starts on ready; after full build, vertex drag handles activate for deformation
