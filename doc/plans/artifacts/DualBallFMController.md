# Artifact: Dual Ball FM Synth

> FM synthesis — carrier(t) * sin(mod_ratio * carrier * mod_index)

## Context

**Category:** waves | **Complexity:** advanced
**Tags:** hazard, sound, vr, waves | **Themes:** oscillation, physics, waves

Two-handed FM synthesis controller using ValueMapper3D balls. Blue ball controls carrier (frequency, attack, decay); orange ball controls modulator (ratio, index, decay). Classic FM synthesis—one oscillator modulating another's phase to create bells, metallic textures, electric pianos, brass. Presets for common FM patches.

*All timbral complexity is phase modulation of simple oscillators.*

## Design

- **Visual:** material: standard, animation: transform
- **Scale:** [1, 2, 1] (compact)

- **Critical Parameter:** mod_index — controls harmonic richness from pure tone to metallic chaos
- **What Emerges:** bell tones, electric pianos, brass — all from one oscillator modulating another
- **Triggers:** ball position changes map to carrier freq, attack, decay, mod ratio, mod index, mod decay
