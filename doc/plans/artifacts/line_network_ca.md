**Tags:** cellular_automata, emergence, graph | **Themes:** biology, cellular_automata, computation, emergence

Base class visualization for line-based cellular automata.

*Connect each new cell to a neighbor and a network appears — ancestry creates structure.*

## Design

- **Visual:** material: vertex_color, animation: static
- **Interaction:** To sprout tendrils in all directions, each new cell tracing a luminous thread back to its parent
- **Critical Parameter:** growth_probability — controls how aggressively the frontier expands
- **What Emerges:** Organic vascular structures — no branching logic was written, yet branches appear from random walk growth
- **Triggers:** Low growth_probability produces sparse, tree-like networks; high values create dense tangles
