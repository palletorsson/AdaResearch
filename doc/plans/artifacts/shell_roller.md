# Artifact: Shell Roller

> Kick the shell — conservation of momentum given a body.

## Context

**Category:** hazards | **Complexity:** intermediate
**Tags:** mario, kick, shell, momentum, chain-reaction | **Themes:** gameplay, hazards, physics

Icosahedron creature that retracts into a kickable shell. Kick it to send it rolling — it bounces off walls and damages other enemies on contact.

*A sphere is the shape that rolls most freely. An icosahedron is the closest polygon.*

## Design

- **Visual:** material: standard, animation: static
- **Interaction:** patrol peacefully, retract when scared, become a projectile when kicked
- **Critical Parameter:** _spin_speed (0=stopped, increases with each kick, decays over time)
- **What Emerges:** chain reactions — a kicked shell hitting another enemy teaches collision physics
- **Triggers:** PATROL→RETRACT→SHELL→KICKED→RICOCHET→RECOVER→DEAD
