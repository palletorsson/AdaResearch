# Artifact: Additive Wave Demo

> f(x) = sum(a_n * sin(n * omega * x)) — Fourier additive synthesis

## Context

**Category:** waves | **Complexity:** intermediate
**Tags:** waves, fourier, additive_synthesis, sine, frequency | **Themes:** commons, mixed, waves

Interactive demonstration of additive wave synthesis — layer sine waves of different frequencies and amplitudes to build complex waveforms. Visualizes Fourier's fundamental insight that any shape can be constructed from simple oscillations.

*Any periodic function is a sum of sines; complexity is superposition of simplicity.*

## Design

- **Visual:** material: vertex_color, animation: vertex
- **Scale:** [3, 1, 1] (standard)
- **Interaction:** Stack harmonics with VR sliders and watch complex waveforms build from pure sines
- **Critical Parameter:** harmonic_amplitudes[] — each slider adds one frequency component
- **What Emerges:** square waves from odd harmonics, sawtooth from all — Fourier theorem made tactile
- **Triggers:** slider movement updates harmonic amplitudes; waveform redraws in real-time
