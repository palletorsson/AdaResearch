# Artifact: Translation Cube Demo

> constrained_translation — move only on allowed axis; sequential constraints: first UP, then SIDEWAYS

## Context

**Category:** transforms | **Complexity:** beginner
**Tags:** transformation, translation, axis_constraint, door_puzzle, interaction, demonstration, 3d, transforms | **Themes:** geometry, math, transforms

A door-like puzzle that only permits movement along the currently allowed axis. The constraint makes translation legible by preventing every other kind of displacement, so the learner feels direction as part of the operation rather than as an afterthought. Completing the upward motion before the sideways motion also makes order matter. It is translation reduced to rule and resistance.

*a translation requires both a direction and a magnitude — constraint is what makes it meaningful*

## Design

- **Visual:** material: unlit, animation: static
- **Scale:** [2, 2, 2] (standard)
- **Interaction:** learner physically discovers that translation is axis-specific — the door will not open any other way
- **Critical Parameter:** the axis sequence constraint — UP must complete before SIDEWAYS unlocks
- **What Emerges:** the idea that translation has direction — not all displacement is allowed, only along defined axes
- **Triggers:** grabbing the knob and moving; axis deviation is corrected by projecting motion onto the allowed axis
