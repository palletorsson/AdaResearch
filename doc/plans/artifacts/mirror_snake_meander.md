# Artifact: Mirror Snake Meander

> the Greek key as mirrored self-avoiding snakes

## Context

**Category:** primitives | **Complexity:** intermediate
**Tags:** 2d, pattern, mosaic, floor, pompeii, meander, greek_key, mirror_symmetry | **Themes:** arrays, art, cultural_computation

Greek key meander via mirrored self-avoiding crossing snakes. Solve one quarter of the border, mirror X to complete each side, mirror Y to create the interlocking counter-snake. The crossings emerge automatically from the mirroring. Four depth bands where bands 0/3 and 1/2 are mirrors produce the classic Pompeii hook pattern.

*mirror the quarter and the Greek key builds itself*
