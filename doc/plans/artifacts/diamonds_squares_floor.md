# Artifact: Diamonds in Squares Floor

> a floor encoding the Roman fascination with nested geometry

## Context

**Category:** primitives | **Complexity:** beginner
**Tags:** 2d, pattern, mosaic, floor, pompeii | **Themes:** arrays, art, cultural_computation

Pompeii mosaic floor with diamonds-in-squares pattern. Each cell contains a 45-degree rotated diamond inscribed in a square, alternating dark/light in a checkerboard arrangement.

*a diamond is just a square that refused to align with the grid*

## Design

- **Visual:** material: standard, animation: static
- **Scale:** [1, 1, 0] (compact)
- **Interaction:** players see how rotating a square inside a square produces visual rhythm
- **Critical Parameter:** tiles_short — number of diamond-square cells on the short axis
- **What Emerges:** the insight that checkerboard logic operates at multiple scales simultaneously
- **Triggers:** instantiation or apply_grid_config
