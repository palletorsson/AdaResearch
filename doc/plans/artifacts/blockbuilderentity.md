# Artifact: Block Builder Entity

> eat(grid_cell) -> extrude(block) -- creature that consumes and rebuilds the grid environment

## Context

**Category:** hazards | **Complexity:** intermediate
**Tags:** builder, grid, constructive | **Themes:** gameplay, hazards

A creature that builds with blocks — constructing and deconstructing grid structures as it moves. The world-shaping hazard that treats the grid as raw material.

*when the creature eats the environment and rebuilds it, hazard and level design become the same thing.*

## Design

- **Visual:** material: standard, animation: physics
- **Scale:** [1.0, 1.0, 1.0] (compact)
- **Interaction:** a block-eating, block-extruding entity that reshapes the map as it moves through it
- **Critical Parameter:** navigation_agent pathfinding -- determines which grid cells to consume and where to build
- **What Emerges:** the environment is not static scenery but edible/buildable material -- creature IS architecture
- **Triggers:** proximity to grid cells; pathfinding decisions; build/consume cycle timer
