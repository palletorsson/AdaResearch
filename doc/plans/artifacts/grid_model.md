# Artifact: Grid Model

> a miniature 1:10 scale interactive diorama of the current map's grid — layout_data[z][x] = height rendered as stacked cubes you can grab, move, and stack to reshape the terrain in real time

## Context

**Category:** interactive | **Complexity:** beginner
**Tags:** arrays, 2d_array, grid, data_structure, map_editing | **Themes:** arrays, data_structures, spatial_computing

Miniature interactive model of the map grid — grab cubes to reshape terrain. Teaches layout_data[z][x] = height as a physical 2D array.

*a map is a 2D array made walkable — this artifact reverses the abstraction, letting you hold the array and write to it by moving blocks*

## Design

- **Visual:** material: shader, animation: interactive
- **Interaction:** to make the 2D array that defines every map touchable — to hold the data structure in your hands, see indices as spatial coordinates, and feel that editing an array cell is moving a physical block
- **Critical Parameter:** max_model_size — the model dynamically scales so any map fits within this bounding dimension (default 1.0m); a 10×10 map = 0.1m cells, a 20×15 map = 0.05m cells
- **What Emerges:** students discover that the map IS a 2D array — every column is an address [x,z], every height is a value, and reshaping terrain is just writing to array cells
- **Triggers:** dropping a GridModelCube fires cube_dropped → GridModel calls structure_component.stack_remove(from) + stack_add(to) → the real terrain rebuilds; structure_component.cube_changed updates the model back
