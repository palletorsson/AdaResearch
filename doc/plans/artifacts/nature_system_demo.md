# Artifact: Nature System Demo

## Context

**Category:** nature_system | **Complexity:** advanced
**Tags:** nature_system, critter_dna, evolution, transmutation, haraway, qfep, procedural_mesh, lsystem, flower, tree, creature, fungus, hybrid, cross_kingdom, interactive | **Themes:** biology, nature, qfep, simulation

Visual test scene for the Q-FEP Nature System. Spawns critters from all 4 kingdoms (tree, creature, flower, fungus) in a grid. Keyboard controls: 1-4 spawn by kingdom, R randomize DNA, E evolve, L cycle LOD, H toggle hybrids, SPACE reset grid.

*A kingdom is not a boundary — it is a region in a continuous morphospace.*

## Design

- **Visual:** material: standard, animation: transform
- **Scale:** [3, 7, 14] (xlarge)
- **Interaction:** spawn creatures from 4 kingdoms, watch them evolve, toggle hybrid mode to break taxonomy
- **Critical Parameter:** _hybrid_mode — when true, body_type floats between kingdoms, dissolving categories
- **What Emerges:** cross-kingdom breeding produces forms no single kingdom template could generate
- **Triggers:** _evolution.evolve_step() runs selection + crossover + mutation across the population
