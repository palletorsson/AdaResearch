## Context

Triptych of classic space-filling curves — Hilbert, Peano, and Moore — generated via L-system rules and turtle graphics on a floor display. Curves that visit every point in a 2D region.

*Three grammars, one goal — every point touched, no crossing, each path a different philosophy of exhaustion.*

## Design

- **Visual:** material: generated_texture, animation: static
- **Interaction:** To lay three space-filling curves side by side on the floor — walk over them, compare their strategies for visiting every point
- **Critical Parameter:** iteration count per curve — controls density and visual complexity of each panel
- **What Emerges:** Visual comparison reveals that different grammars can achieve the same goal (space-filling) through different strategies
- **Triggers:** Each curve fills its panel differently — Hilbert (recursive quadrants), Peano (9-fold), Moore (closed loop Hilbert variant)
