# Artifact: Curvature Slider

> K ∈ [-1, +1] — Gaussian curvature as continuous parameter

## Context

**Category:** geometry | **Complexity:** beginner
**Tags:** curvature, non_euclidean, slider, interactive, alternative_geometry | **Themes:** geometry, non_euclidean

VR slider controlling Gaussian curvature from negative (hyperbolic) through zero (flat/Euclidean) to positive (elliptic). Emits curvature_changed signal for linked surfaces.

*flat space is not the default — it is the singular boundary between two infinite families of geometries*

## Design

- **Visual:** material: standard, animation: static
- **Scale:** [1, 1, 1] (compact)
- **Interaction:** slide between hyperbolic, flat, and elliptic geometry with one hand
- **Critical Parameter:** curvature — the ONE number that determines the entire geometry
- **What Emerges:** the intuition that geometry is not fixed — it is a parameter you can vary
- **Triggers:** slider movement emits curvature_changed signal, updates label with geometry type
