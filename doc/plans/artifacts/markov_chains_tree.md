# Artifact: Markov Chains Tree

> Markov chain state machine growing a 3D tree — branch, grow, curve, or terminate as probabilistic state transitions

## Context

**Category:** procedural_generation | **Complexity:** advanced
**Tags:** markov, tree, growth, procedural, organic, grammar | **Themes:** formal_languages, grammar

A tree grown by Markov chain decisions — each branch point is a state transition. Branch/terminate/grow probabilities shape the form. Randomness parameter tunes order vs chaos. Bark, leaves, animated growth.

*A tree does not follow a blueprint — it walks a probability space, and the walk becomes wood.*

## Design

- **Visual:** material: standard, animation: vertex
- **Scale:** [10, 11, 1] (world_scale)
- **Interaction:** To show that a tree is a random walk through growth states: each branch tip rolls dice to decide its next move
- **Critical Parameter:** branch_probability — the chance of forking; low values grow poles, high values grow bushes
- **What Emerges:** Organic branching structure from eight Markov states — the tree shape is its transition matrix made spatial
- **Triggers:** High terminate_probability produces bonsai; high vertical_bias produces columnar; balanced produces naturalistic crown
