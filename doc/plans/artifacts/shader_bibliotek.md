# Artifact: Substrate Bibliotek

> for i in N: wall[i] = load_shader(catalog[i]) — a physical library of computational substrates

## Context

**Category:** shaders | **Complexity:** intermediate
**Tags:** shaders, substrate, library, showcase, wall, catalog | **Themes:** shaders, visual, substrate, library

Freestanding wall of cubes — each cube showcases a different shader from across the project. A physical library catalog of computational substrates.

*a substrate is not decoration — it is the physics of a surface, the rules that light follows when it meets matter*

## Design

- **Visual:** material: shader, animation: transform
- **Interaction:** to stand before a wall where every cube is a different world — voronoi, rothko, velvet, slime — and understand that "material" is just a function from position to color
- **Critical Parameter:** the catalog itself — which 12 shaders stand for all 218? curation IS the argument
- **What Emerges:** the wall becomes a periodic table of visual computation — each cube a different element
- **Triggers:** _ready builds the wall, loads one shader per cube, adds labels and slow spin
