# Artifact: Transformation Workbench

> Interactive VR learning tool for understanding transformations. Grabbable cube shows live 4x4 matrix updates, ghost position for comparison, and mode buttons to switch between Translate (T), Rotate (R), and Scale (S). Rotation snaps to 90° increments and shows coordinate swap notation. Matrix cells highlight based on current transformation mode.
