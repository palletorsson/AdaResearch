## Context

**Category:** machinelearning | **Complexity:** intermediate
**Tags:** neural_network, activations, weights, forward_pass, layers | **Themes:** ai, machine_learning

Layered neural network with visible activations, weights as line thickness, forward pass animation. See how information transforms through layers.

*a neural network does not learn rules — it learns a continuous function that happens to approximate them*

## Design

- **Visual:** material: standard, animation: static
- **Interaction:** see neurons glow as activations flow forward, weights shimmer as gradients flow backward, error graph descend
- **Critical Parameter:** learning_rate — the step size that makes the difference between convergence and oscillation
- **What Emerges:** feature representation in hidden layers — the network discovers its own internal language
- **Triggers:** auto_train drives mini-batch gradient descent; activation function selection changes the nonlinearity; error history builds the 3D graph
