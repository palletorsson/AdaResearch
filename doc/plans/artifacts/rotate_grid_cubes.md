# Artifact: Rotate Grid Cubes

> A grid of cubes rotated in repeating row-based patterns. The lattice stays fixed while orientation changes propagate across it, making the difference between flat and tilted sections immediately readable. Animation exposes rotation as a patterned field rather than a single isolated action. It shows how a transformation can be distributed across a structure.
