## Design

- **Visual:** material: standard, animation: static
- **Scale:** [20.0, 20.0, 20.0] (world_scale)
- **Interaction:** To throw balls at things and watch them break differently — each destructible teaching a different algorithm for decomposing geometry under impact.
- **Critical Parameter:** The velocity of the thrown ball at impact. It triggers destruction thresholds and determines fragment ejection speeds. Faster throw = more dramatic break.
- **What Emerges:** Cantor boxes splitting into 4, then each quarter splitting again (recursive fractal destruction). Voronoi spheres cracking along Voronoi cell boundaries. Each method feels different.
- **Triggers:** VR grab + throw → ball hits destructible, each type responds differently (instant/health/recursive-split/voronoi-crack/prism-shatter), stats track throws and destroys
