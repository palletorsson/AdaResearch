# Artifact: Firework Launcher

> launch → ascend → explode(N particles) → each: v += g, v *= drag, life -= dt, fade. One event becomes sixty trajectories.

## Context

**Category:** physics | **Complexity:** intermediate
**Tags:** firework, particles, emission, gravity, drag, lifetime, explosion, color, statistical | **Themes:** particles, emission, lifetime, forces_on_many

Launch rockets that climb, then explode into showers of glowing particles — each one a tiny body under gravity, drag, and fading lifetime. Four color presets (classic, ocean, garden, ring pattern) create distinct particle distributions. Shows particle emission, statistical spread, force application to many bodies, and emergent visual patterns from simple rules.

*A firework is a population explosion. One event becomes many independent trajectories, each obeying the same law, each taking a different path.*

## Design

- **Visual:** material: vertex_color, animation: particle_lifecycle
- **Interaction:** To launch a rocket and watch it bloom — sixty glowing particles inheriting random velocities from a single explosion point, then falling under gravity and drag.
- **Critical Parameter:** burst_force (1.0-8.0) — the initial speed of exploded particles. It sets the bloom radius. Higher = wider, more dramatic, longer airtime before gravity wins.
- **What Emerges:** Ring patterns from constrained emission (horizontal only). Sphere patterns from uniform random direction. Particle trails tracing parabolas. The moment of bloom as maximum expansion.
- **Triggers:** Auto-launch every 2.5s, FIRE button → manual launch, preset buttons → color palettes (classic/ocean/garden) and patterns (sphere/ring), burst slider → controls explosion force
