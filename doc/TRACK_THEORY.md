# Track Theory — What Makes a Track?

A framework for understanding, evaluating, and generating coherent electronic/game music tracks.

---

## Core Definition

A track is not "a song." A track is a **coherent, repeatable audio object** with:

| Property | Description |
|----------|-------------|
| **Identity** | A recognizable signature (motif, palette, rhythm DNA, harmonic color) |
| **Internal Logic** | Implied rules: what changes, what stays constant, how energy moves |
| **Delivery Format** | Stereo master, loopable stems, adaptive layers, interactive states |
| **Listening Contract** | Must survive repetition, sit under SFX/VO, signal narrative/emotion |

**A track is not content — it's a designed system that behaves predictably.**

---

## The "Perfect" Track

Perfection ≠ max quality. Perfection = **max fitness for purpose**.

A perfect electronic/game track optimizes:

| Dimension | Goal |
|-----------|------|
| **Cohesion + Novelty** | Stable identity, enough variance to resist fatigue |
| **Energy Control** | Macro arc + micro motion |
| **Mix Translation** | Works on laptop, headphones, big system |
| **Masking Discipline** | Doesn't kill VO/SFX |
| **Loop Durability** | Survives the "10th listen problem" |
| **Implementation Ready** | Stems, loop points, transitions |

## Three-Layer Evaluation Framework

### Layer A: Composition (Structure, Theme, Meaning)

#### 1. Theme & Motif Integrity

**Questions:**
- Can I hum the motif or identify the signature in 1-2 seconds?
- Does the track *return* to itself (anchor), or just drift?

**Tests:**
- **Signature Test**: Play 5s from 3 random timestamps. Can you identify it as the same track?
- **Motif Recurrence**: How many times does the central idea return, transformed?

#### 2. Form & Pacing (Macro)

Game "epic electronic" typically uses **modular form**:

```
A (0:00-0:30)  → Identity establishment
B (0:30-1:15)  → Expansion or contrast  
C (peak)       → Payoff (combat/intensity state)
Return         → Re-anchor + exit / loop seam
```

**Metric: Arc Legibility** — Can a listener sketch energy over time after one listen?

#### 3. Tension & Release Grammar

Tension channels in electronic/epic:
- Harmonic density (more notes/partials)
- Rhythmic subdivision (8ths → 16ths)
- Brightness (filter opening)
- Distortion/saturation
- Spatial lift (wider + more reverb tail)

**Metric: Tension Channel Count** — How many channels active simultaneously? >3 = "trailer cliché" risk.

---

### Layer B: Production (Sound Design, Frequency, Dynamics, Space)

#### 4. Palette Coherence (Timbre Identity)

A track becomes "a track" when its sound world is constrained:

| Slot | Description |
|------|-------------|
| 1-2 core synths | Signature voices |
| 1 bass identity | Even if notes change |
| 1 percussion identity | Rhythmic fingerprint |
| 1 air/space identity | Noise bed, reverb type, texture |

**Metric: Palette Count** — Number of distinct timbral families. Too many = collage, not identity.

#### 5. Frequency Strategy (Spectral Allocation)

Frequency is **allocation**, not EQ. Define **who owns what**:

```
SUB (20-60Hz)      → Kick tail OR sub bass (one boss)
BASS (60-200Hz)    → Bass body + low percussion
LOW-MID (200-500)  → Danger zone (mud/box) - keep sparse
MID (500-2kHz)     → Musical intelligibility
PRESENCE (2-5kHz)  → Attack/clarity (⚠️ VO conflict zone)
AIR (8-16kHz)      → Sheen/space/noise
```

**Tests:**
- **Mute Test**: Mute bass — does track still read? Mute lead — does identity remain?
- **Band-Pass Scan**: Listen narrow-band to detect clutter vs meaning

#### 6. Dynamics & Impact

Impact ≠ loudness. Impact = **contrast** + **envelope discipline**.

**Checklist:**
- Short-term transients are clean (kick/snare/impacts)
- Midrange doesn't stay pinned at one density
- Loud sections are earned by quieter moments

**Metrics:**
- **Micro Contrast**: Busy vs sparse moments (arrangement density)
- **Macro Contrast**: Intro vs peak (density + brightness + loudness)

#### 7. Space Design (Depth & Staging)

A track's "world" is defined by:
- One main reverb character (room/cathedral/plate)
- One delay character (tempo sync or atmospheric)
- Controlled width (wide elements, mono anchors)

**Game Rule:** Reserve 2-5kHz clarity for gameplay cues and VO.

**Tests:**
- **Mono Collapse**: Does track keep identity in mono?
- **Center Clarity**: Is there a stable center (kick/bass/lead focus)?

---

### Layer C: Game-Readiness (Looping, Adaptivity, Implementation)

#### 8. Loop Durability (The 10th Listen)

A good loop is not "invisible" — it's **non-irritating**.

**Techniques:**
- Avoid long melodic statements that restart obviously
- Use evolving texture that can reset without feeling like a reset
- Write phrases whose endings imply beginnings

**Tests:**
- **Hard Loop Test**: Loop 20x while doing something else. Notice the seam? Feel fatigue?
- **Attention Spike Test**: Identify what repeatedly steals attention (hats, arps, bright motifs)

#### 9. Stem Logic (Interactive Mixing)

Think **layers**, not "one track":

| Layer | Purpose |
|-------|---------|
| Bed | Atmos/texture |
| Rhythm | Drums/percussion |
| Harmonic | Pads/chords |
| Lead/Motif | Melodic identity |
| Impacts | Transitions |

**Rule:** Each layer should have a reason to exist AND a reason to disappear.

#### 10. Transition Grammar (States)

For exploration → combat → exploration:
- Use risers/downers, filtered versions, rhythmic thinning
- Keep the **same identity token** across states (chord color, motif interval, noise profile)

## The 10-Point Rubric

Score each 1-5:

| # | Dimension | Question |
|---|-----------|----------|
| 1 | **Identity Token** | Can I recognize it in 2 seconds? |
| 2 | **Cohesion** | Do sounds belong together? |
| 3 | **Controlled Variation** | Not static, not chaotic? |
| 4 | **Energy Arc** | Is macro shape legible? |
| 5 | **Frequency Allocation** | Nothing fights unnecessarily? |
| 6 | **Dynamic Contrast** | Does impact feel earned? |
| 7 | **Spatial Clarity** | Depth without smear? |
| 8 | **Loop Durability** | Seam + fatigue acceptable? |
| 9 | **Implementation Ready** | Stems/transitions viable? |
| 10 | **Emotional Truth** | Does it *feel* like the scene? |

**Note:** A "perfect" game track isn't 5/5 everywhere — it's high on dimensions that matter for its role.

## Practical Methods

### Reference Triangulation

Pick 3 references (don't copy one track):
- **Ref A**: Rhythm/drive
- **Ref B**: Texture/world
- **Ref C**: Emotional arc

Extract **principles**, not sounds:
- "A has a motif every 12-16 seconds"
- "B keeps low-mids empty"
- "C saves brightness until late"

### Track Brief (One Page)

```markdown
## Track Brief: [Scene Name]

**Scene**: What player is doing
**Emotion**: 3 adjectives
**Identity Token**: What makes it itself
**Do-Not-Do**: Clichés to avoid
**Deliverables**: Loop length, stems, transitions
**References**: 3 tracks (rhythm / texture / arc)
```

### Constraint-First Building

Winning constraint sets:
- Only 6 sound families total
- One scale + one bass register
- One reverb, one delay
- One "weird" element (signature) only

**Constraints create identity.**

## Evaluation Probes (For Automated Analysis)

| Probe | Purpose | Implementation |
|-------|---------|----------------|
| **Identity Probe** | How strongly does one parameter cluster define the sound? | Spectral fingerprint consistency |
| **Variation Probe** | How many parameters move over time (and at what rate)? | Parameter flux analysis |
| **Fatigue Probe** | Detect repetitive high-frequency transients | Hi-freq onset density + variance |
| **VO Safety Probe** | Measure energy in 2-5kHz | Presence band monitoring |
| **Loop Seam Probe** | Detect discontinuity at loop point | Cross-correlation at boundaries |
| **Mono Collapse Probe** | Identity preservation in mono | Stereo vs mono spectral comparison |
