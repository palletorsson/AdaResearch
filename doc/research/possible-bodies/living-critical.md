# A change that has no address

The Depth control makes a modest but exact argument. Four numerical edits leave the compiled instruction and resulting branch geometry unchanged. The fifth changes the generation count. The program groups distinct raw settings into one operative value. A category is being made inside the conversion.

That grouping is useful. A rewrite runs a whole number of times, and a stable control is easier to learn than an arbitrary transformation at every tremor. Yet the grouping also establishes which differences count for this operation. The book can make that decision inspectable instead of attributing stillness to the player's failure or the tree's nature.

The same caution applies to the apparent generosity of eight sliders. The controls allow many bodies, but they select the dimensions along which variation is available. Branching angle has an address; reconnecting a branch into a loop does not. This is a specific limit of the current grammar, not evidence that the desired body is impossible. The absence can become a proposal for another rule or representation.

A queer reading can begin with pleasure in these bodies and continue when a desired relation does not fit the supplied variation. It need not label every irregular tree queer or demand endless novelty. Holding a form steady is also an available action. The witness and placed specimen allow refusal of the next edit, comparison and attachment without requiring a winner.

The export repair makes this concrete. A live reference and a snapshot are different commitments. Previously an exported DNA reference could change when the source was edited. A deep copy now preserves a particular state. The local placed geometry remains with it. Neither behavior is intrinsically the more ethical one; each distributes continuity and authority differently, and an interface should make that consequence clear.

At high settings the representation budget adds another boundary. The interpreter draws a prefix of the sentence and stops after its command allowance. A crown can look complete at a cutoff. Counting requested commands helps expose this without treating more computation as a measure of freedom or biological richness. The hall measures neither entropy nor ecological fitness.

Finally, the raised terrain is authored map data. It can support or obstruct a visitor, but it is not a forest that emerged from these rules. Keeping that distinction lets us ask a future question honestly: what would need to connect a growing body to the space it changes? Soil exchange, collision, load, branching contact and persistence are different mechanisms to investigate, not effects supplied by calling the room Living.
