Where should sine enter?

BEND shifts X with spatial Z. SINE shifts the required birth count by up to two neighbours according to Y and time. One changes the architecture around a held state; the other changes the next state. Both are available on the console.

Rules, cuts and the limits of this material
# Growth rule: read 26 neighbours from the previous volume.
next_cell = neighbours >= 4 if current_cell else neighbours == 4

# Turnover rule changes both survival and birth conditions.
next_cell = (4 <= neighbours and neighbours <= 7) if current_cell else neighbours == 5

# Optional shift applied to the birth condition only.
shift = int(floor(2 * sin(TAU * y / 13 + generation * PI / 4) + 0.5))

# Optional coordinate bend. The cell state remains intact.
x = x + 1.5 * sin(TAU * z / 26)

The numerical boundary is fixed at 13³; neighbours beyond it are empty. Each cell spans 2 m. Geometry is held while you walk and can change only after stepping outside the marked domain. The workshop floor supports the visitor; it is not a row of protected living cells. There is no simulated gravity or structural engineering in the cellular material.

CUT removes the negative-X part of the displayed geometry, retains the cellular state and reports how many cells remain visible. It is an inspection opening, not an opening that evolved. REPLAY reconstructs the current generation from the same seed, rule and sine setting. FIRST returns to G0. No cells are held alive by either rule.

The instrument counts connected components through shared faces. The CA reads all 26 neighbours. Cells can therefore influence one another diagonally while belonging to separate face-connected components. Neither count alone proves a continuous route for a body.

What did the room inherit?

A block stands in your way. Its addresses are occupied. You press FRAME. The number does not fall, but the way opens.

The cell was never the concrete. It was a decision we gave a body to.

Put panels back on the frame. Some openings remain. You enter one and find another surface ahead. From outside, the object looked porous. From here, porosity has a direction and a distance.

Now return to the beginning and change the rule. Two steps later, nothing remains. The empty space did not need a door. It also lost the thing that could have sheltered you.

From chosen rules to learned rules

The paper you brought in learns probabilistic cellular transitions from examples of 3D shapes. Its shape representation uses surface voxels. That is a later comparison for this workshop: what changes when we choose training examples as well as a starting state? Zhang et al., Learning to Generate 3D Shapes with Generative Cellular Automata.

This laboratory uses two explicit, hand-authored rules. It has not trained or reproduced the paper's model. The official repository contains GCA and its later continuous extension: authors' implementation.
