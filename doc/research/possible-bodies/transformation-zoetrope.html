How much difference must you keep before you can say that something happened?

A pose is not the time it took.

A plain cube occupies the same geometry after a quarter-turn about Y. An unequal tetrahedron does not. A uniformly coloured ideal sphere has no preferred orientation to reveal. These are different kinds of sameness before the sampling clock enters the argument.

At one sample every four seconds, all four studies are observed at the same phase of their motion. The held view can look still while the sampled timestamp advances. Same geometry, same image and same time are different claims. A mark changes what the image can distinguish. It adds a relation you can follow, without changing the body's silhouette.

These four comparisons are a sample-and-hold illustration: the last observation stays visible until the next one. A physical 3D zoetrope exposes successive poses through viewing intervals. These held views borrow that question about motion and stillness; they do not simulate literal flashing or retinal perception. The separate perspective drum above uses an actual parent rotation.

Read the four operations and the sampling rule
period = 4 seconds
theta = 2 * PI * time / period

offset.x = 0.6 * sin(theta)
angle.y  = theta
size     = 1 + 0.3 * sin(theta)

combined_point = offset + rotate_y(size * point, angle.y)

sample_time = floor((time + 1e-9) / interval) * interval
held_pose   = pose_at(sample_time)

The sampling grid begins at time zero. Changing the interval takes the latest sample on the new grid; it does not restart the clock. The twelve small views always show the twelve equally spaced poses of one complete cycle. Rose ticks mark the phases the selected interval visits; the rose frame marks the pose currently held.

The cube has edge length 0.55. The sphere has radius 0.32. The tetrahedron's four unequal vertices make orientation visible. Camera, illumination, object colour and reference frames remain fixed. A fixed tessellation depicts the ideal sphere so its rendering mesh does not add an unintended rotating pattern.
