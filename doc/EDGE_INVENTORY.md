# Edge Inventory

> *Every rule that holds this museum together refuses something. This is the list of the refusals, what escapes each one, and whether the escape currently survives.*

Companion to [EDGES_OF_ALGORITHM.md](EDGES_OF_ALGORITHM.md), which catalogues the thirteen **conceptual** edges (A–M) the late spine teaches. This file catalogues the **material** edges: the ones with a line number.

**59 edges**, swept 2026-09-23 across eight regions of the corpus by 75 agents, every candidate adversarially verified against the file it cites (66 candidates, 57 confirmed, 9 refuted). Three added by hand.

What becomes of the remainder: **38 dropped**, 12 partial, 9 kept. **36** could spill to the `LeakData` bus today.

## How this was made

`Workflow` run `wf_0ba1f8c4-d74`, 23 September 2026. Eight sweep agents (primitives, artifacts a–l, artifacts m–z, grid and museum infrastructure, algorithms, life-and-death systems, the project's own instruments, and one reading only the prose), then one adversarial verifier per candidate instructed to refute it and to default to refuted when uncertain, then a completeness critic. 75 agents, no errors.

Two cautions carried over from that run:

- **Read the scene, not the script.** `draw_dot.gd` declares `trail_max_points = 1024` and `min_segment_distance = 0.01`; `draw_dot.tscn` ships 4096 and 0.005. An inventory built from script defaults is wrong.

- **Do not count the remainder.** `LeakData` deliberately exposes no total, no score and no ordering by size, and a probe asserts their absence. A remainder with a number attached gets optimised, and then this project has built the scoreboard it argues against.
