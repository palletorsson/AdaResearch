## Recommended spine — one best per concept

A suggested pick per concept for the comprehensive sequence (lean embodied/console where possible; the alternatives above are the bench).

 1. **Coordinate system** → `CoordinateSystem3M` — the clean 3-axis coordinate frame
 2. **Vector basics** → `VectorBasics` — the canonical 'what is a vector' scene
 3. **Magnitude / length** → `length_lantern` — magnitude made embodied (a lantern that grows)
 4. **Unit vector / normalize** → `vector_normalize_demo` — normalize to length 1
 5. **Addition** → `vector_add` — the dual-pad console — drag two tips, resultant live
 6. **Subtraction** → `vector_sub` — same console, op=subtract (a−b = a+(−b))
 7. **Dot product** → `dot_aligner` — aim·foe = cos θ, the turret that befriends on alignment
 8. **Projection / reflection** → `projection_shadow` — the sun-cast shadow = (a·n̂)
 9. **Cross product / torque** → `torque_crank` — r×F spins the flywheel
10. **Vector field / flow** → `weather_vector_field` — a walkable flow field
11. **Motion / velocity** → `launch_arc` — velocity bent into a parabola
12. **Work (F·d)** → `force_mower` — push the mower; W = F d cos θ live
13. **Friction / drag** → `drag_lane` — F = −b·v, glide to dead-stop
14. **Projectile / launch** → `launch_arc` — range peaks at 45° (shared with Motion)
15. **Centripetal** → `circle_train` — a = v²/r, the train leans into the curve
16. **Gravity / orbit** → `orbit_pair` — F = Gm₁m₂/r², barycenter slides with mass
17. **Spring / Hooke** → `spring_bob` — F = −kx, period 1/√k
18. **Pendulum** → `pendulum_swing` — T = 2π√(L/g), restoring = mg sin θ
19. **Momentum / collision** → `momentum_cradle` — Newton's cradle, p = mv conserved
20. **Restitution / bounce** → `bounce_well` — h' = e·h, decaying bounces
21. **Lever / balance** → `lever_balance` — τ = F·d; calder_mobile as the showpiece
22. **Wind / weather** → `weather_vane` — wind drag ∝ v², the flag snaps horizontal
23. **Force field (zone)** → `force_field_zone` — a force you stand inside (+ vector_machine)
24. **General force / pad** → `force_pad` — the launch pad — impulse made bodily
