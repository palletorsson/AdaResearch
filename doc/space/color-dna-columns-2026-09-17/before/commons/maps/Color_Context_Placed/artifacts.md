# Colour joins the primitives - artifacts

Two primary artifact families, seventeen placed instances and twenty-three physical columns. Enter at (11,2), proceed toward increasing Z, exit at (11,40). All plates face the entrance. Grid cells are metres.

| Encounter | Placements | What changes |

## chroma_stack

The early columns contain five primitive pieces. Four later stacks contain 6-8 pieces with explicit proportions, offsets, turns and chosen paint (`rule:composed`). Fixed poses keep the base and height stable, rotating successive levels by 22.5 degrees and/or reducing XZ scale by 0.15 per level. Geometry and collision boxes share those transformations. Default pose:aligned preserves existing configurations elsewhere.

## chroma_translation

Each placement contains four fixed copies and a rail. The hall compares colour assignment after translation; it does not animate transport or ask the visitor to operate a control panel.
