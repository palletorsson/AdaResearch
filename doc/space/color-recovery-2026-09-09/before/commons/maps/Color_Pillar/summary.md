# Color_Pillar - Map Summary

## Overview
Color_Pillar creates a gauntlet of color interaction stations. Pillar collections, grabbable color sticks, a flashlight demo, and visual color mixing transform color from passive observation to active manipulation. Players gather colors, observe additive mixing, and understand color as light rather than pigment.

## Spatial Layout
- **Dimensions**: 12×22 columned runway
- **Architecture**: Walled corridor with evenly spaced light pairs
- **Height**: Single level with 2-high boundary walls
- **Structure**: Linear progression through interaction stations

## Key Elements

### Interactables
- **pillarcolorcollection:0:-0.5** - Primary color collection pillar
- **visual_color_mixing:0:-0.4:0.9** - Additive color demonstration
- **flashlight_demo** - Light-based color revelation
- **grabcolorcollection:90:1** (×8) - Grabbable color stick stations
- **grabcolorcollection:-90:1** (×4) - Opposing color sticks
- **SpectrumVisualizer** - Spectrum display at terminus
- **dark_sphere** - Ambient dome

### Utilities
- **Extra lights** (el) - Repeating corridor illumination (×16)
- **Spawn point** (s) and annotation (an:90)
- **Teleporter** (t) with score point (sp)

## Atmosphere
- **Lighting**: Cool ambient with warm directional
- **Background**: Sky blue
- **Mood**: Interactive, educational, exploratory

## Learning Sequence
1. Player enters columned runway
2. Approaches pillar color collection
3. Grabs color sticks from side stations
4. Observes flashlight demo (light creating color)
5. Experiments with visual color mixing
6. Collects colors from multiple stations
7. Views SpectrumVisualizer at end
8. Exits via teleporter

## Design Intent
The map makes color **interactive and collectible**. By grabbing color sticks and observing mixing, players learn additive color (how light combines) rather than subtractive color (how paint mixes). The flashlight demo reveals that color emerges from light, not surface.

## Connection to Sequence
- **Position in color sequence**: 4/6
- **Follows**: Color_Rainbow (spectrum immersion)
- **Establishes**: Color mixing, light-based color, collection mechanics
