# Colour joins the primitives - artifacts

Two primary artifact families, fifteen placed instances and twenty-seven physical columns. Enter at (11,2), proceed toward increasing Z, exit at (11,40). All plates face the entrance. Grid cells are metres.

| Encounter | Placements | What changes |
|---|---|---|
| Same column, different colour rules | Four chroma_stack instances at row 6 | One colour, shape category, local height, neighbouring colour |
| Different primitive combinations | Three chroma_stack instances at row 12 | Bauhaus, turned and cut alphabets; colour by shape held constant |
| Static transformation | Four chroma_stack instances at row 18 | Aligned, successive Y turns, narrowing in X/Z, then both together |
| Translation and colour | Four chroma_translation instances at rows 26 and 35 | Kept colours, colour by displacement, colour by copy index, diagonal displacement with colours kept |

## chroma_stack

Five primitive pieces per column. Fixed poses keep the base and height stable, rotating successive levels by 22.5 degrees and/or reducing XZ scale by 0.15 per level. Geometry and collision boxes share those transformations. Default pose:aligned preserves existing configurations elsewhere.

## chroma_translation

Each placement contains four fixed copies and a rail. The hall compares colour assignment after translation; it does not animate transport or ask the visitor to operate a control panel.
