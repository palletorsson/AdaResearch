The entire L-system pipeline in one room. Axiom becomes rules. Rules become string. String becomes tree.

Start with a single character — F. Apply one production rule: F rewrites to F[+F]F[-F]F. Do it again. The string doubles, triples, explodes. The expansion is visible: each generation laid out as text, the grammar growing before your eyes. Then the turtle reads the string and walks — forward, turn, branch, return — and a tree appears. Seven presets wait in the editor: Koch, Sierpinski, Dragon, Plant, Bush, Fern, Binary Tree. Adjust the angle. Add generations. Watch the same rule produce wildly different architectures.

One sentence contains a forest. The grammar doesn't describe the tree — it *is* the tree. Description and structure are the same object.
