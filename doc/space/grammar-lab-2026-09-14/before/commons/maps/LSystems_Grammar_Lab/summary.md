# LSystems_Grammar_Lab — Summary

The entire L-system pipeline in one room. An axiom string F is rewritten through production rules, expanded generation by generation, and interpreted by a turtle-graphics renderer that maps characters to movement, rotation, and branching commands. The result: trees, curves, and fractal structures from a single sentence.

The `lsystem_editor` artifact exposes seven presets — Koch, Sierpinski, Dragon, Plant, Bush, Fern, Binary Tree — each demonstrating how different production rules applied to the same rewriting mechanism produce radically different geometries. The `fractal_lsystem_string` visualizes the raw string before any rendering, making visible that the string *is* the structure; the tree is one interpretation. The `lsystem_tree` renders the turtle's walk.

This is the first map in the L-Systems sequence. It establishes the pipeline that every subsequent map refines: axiom to rules to string to shape. The learner needs no prior L-system knowledge — only the recursive intuition from earlier fractal sequences. The room's argument is that grammar is not description but generation. A two-rule system can produce a forest. The gap between symbol and form is bridged by iteration alone.

The map is an 8x10 compact lab with a raised teaching platform at north (height 2) and a demonstration floor at south, leading to a teleporter into LSystems_Growth.
