Concept: Noise moves to the GPU — shader-based procedural generation using hash functions and parallel computation. What ran as sequential CPU loops now executes simultaneously across millions of fragments, and the wall displays six octaves of fractal Brownian motion as real-time procedural texture.
Sequence role: Fifth map in the Noise sequence; the advanced implementation pivot. After four maps of conceptual and CPU-side noise, this map reframes noise as a shader problem — massively parallel, hash-driven, resolution-independent. The six-octave wall is both pedagogy and proof: each octave contributes detail at a different scale, and the GPU renders all of them in real time. Connects forward to Noise_Inside_Noise's domain warping (which also runs on GPU) and backward to Noise_One's octave layering (now hardware-accelerated); follows Noise_Voxel.
Technical angle: GPU noise via hash functions replacing gradient lookup tables — integer hashing of grid coordinates to produce pseudo-random gradients without texture memory. Shader implementations of Perlin/Simplex noise operating per-fragment in parallel. The shader_noise_space artifact displays procedural textures generated entirely on the GPU, with no pre-computed data — every pixel computed from its coordinate and a hash chain. Six octaves of fBM layered in a single fragment shader pass.
Critical angle: Moving noise to the GPU is not merely optimization — it changes the ontology. CPU noise is computed point by point, sequentially, with the programmer choosing where to sample. GPU noise is computed everywhere simultaneously, the entire field evaluated in parallel. The hash function replaces the gradient table, and with it the last vestige of stored state disappears: noise becomes pure computation, no memory, just function. This is entropy as algorithm — stateless, reproducible, infinite.
Key artifacts: shader_noise_space is the six-octave wall itself — a real-time procedural texture surface demonstrating GPU noise generation, hash-based gradient computation, and fractal layering in a single shader program; dark_sphere persists, its surface a potential target for the same shader techniques, contrasting procedural texture with geometric form.
Gap: An interactive shader editor letting the learner modify the hash function or octave weights and see the wall update instantly would transform observation into authorship — the difference between reading noise and writing it.
