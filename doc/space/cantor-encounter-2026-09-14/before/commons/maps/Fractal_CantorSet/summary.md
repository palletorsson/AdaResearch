# Fractals_3 - Circular Fractals

## Overview
Fractals_3 explores radial self-similarity through recursive circles. Where trees branch linearly, circles branch radially—spawning smaller circles around their circumference. This produces spiraling, mandala-like patterns that converge toward infinitely small centers.

## Spatial Layout
- **Dimensions**: 9×12 grid
- **Architecture**: Central void surrounded by walkable perimeter, creating a viewing gallery around the fractal
- **Height**: Single level with raised viewing platform

## Key Elements

### Interactables
- **Fractal Recursion Circles** (4,4) height 8m, 40 iterations - Central recursive circle visualization
- **Dark Sphere** (3,2) - Ambient lighting element

### Utilities
- **Teleporter** (7,10) - Exit to Fractals_4

## Atmosphere
- **Background**: Sky blue [0.2, 0.3, 0.7]
- **Lighting**: Warm directional with cool ambient
- **Mood**: Meditative, spiral, mandala-like contemplation

## Learning Sequence
1. Player enters and sees central void
2. Observes the recursive circles suspended above the void
3. Walks around perimeter, viewing from different angles
4. Notes how smaller circles reproduce the pattern of larger ones
5. Recognizes radial vs. linear recursion
6. Contemplates the convergence toward center
7. Exits to explore the Cantor set

## Design Intent
The map demonstrates that **recursion operates in multiple geometries**. Linear recursion (trees) and radial recursion (circles) produce different aesthetic qualities but share the same mathematical principle. The central void emphasizes the **infinite inward** direction—where trees grow outward, circles can spiral forever inward.
