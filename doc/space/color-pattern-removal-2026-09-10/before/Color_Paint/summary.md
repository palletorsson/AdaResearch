# A painting already in progress

The existing wet-paint canvas now makes automatic strokes before the visitor touches it. A visible pigment ball follows two differently timed oscillations while its hue changes. Thirty grabbable pigment balls remain available for manual marks; the Albers wall gallery provides a second encounter with colour context.

The recovered source footprint is preserved inside a new perimeter wall. See `museum_recovery.md` for historical provenance and placement exceptions.
