# Borrow an address

Noise_Inside_Noise develops the existing noisesphere into an opt-in coordinate study, retaining the independent dark_sphere. A matched pair of spheres, two sampled image plates and a direct/displaced coordinate grid share one explicit sampler. WARP selects 0, .35, .8 or 1.4; ZERO returns immediately to direct sampling; SAMPLE selects a witness; RELIEF separately converts the same values into radial mesh displacement.

The base is single-octave FastNoiseLite Value noise (seed 4, frequency 1.2). Two single-octave Perlin fields (seeds 19 and 47, frequency .45) provide the coordinate displacement. The result is N(p + amount × displacement(p)). All comparison state is static between actions. The two sphere geometries remain identical in SKIN mode, and zero warp restores identical field samples and relief geometry.

The instrument now has a floor, an approach and a narrow museum apron. All original structure cells and utilities remain; an added east boundary contains the stage, and museum-only floor declarations bridge the approach and exit threshold. One new ground row wraps around the preserved exit wall. The sphere's legacy scene and shader remain available when stand:warp is absent. This stage uses a new explicit CPU sampler, not the original dome shader's field realization.

Two primary book passages: noisesphere, then dark_sphere. The hall is reconnected after Noise_6_Wall in the museum plan, matching its already declared place in the book sequence. Noise_Space_10 is the next hall to develop; its museum connection remains part of that later pass.
