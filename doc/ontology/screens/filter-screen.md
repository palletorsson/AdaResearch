# The Filter Screen — Projection as Primitive

**Lens:** Dimensionality collapse — *What is lost when 3D becomes 2D?*

**Status:** Ontology pending — needs discussion

## Discussion

Every screen you've ever looked at performs 3D to 2D projection. Your eye
does it. A camera does it. The Filter Screen makes this operation visible
as an object you can walk around in VR.

## QFEP Connection

Projection is erasure made systematic. What the camera cannot see, the
viewer cannot know. The filter screen names what is lost.

## Open Questions

- What information is destroyed in projection? (Depth)
- Can you reconstruct the 3D from the 2D? (Only with multiple views — stereoscopy)
- Is understanding itself a projection? (Reducing complexity to a viewable surface)

## Connections

- **Science Screen** — the filter screen projects; the science screen abstracts — complementary operations
- **Triangle** — projection maps 3D triangles onto 2D screen triangles
- **Coordinate System** — the camera's coordinate system determines what is projected where
