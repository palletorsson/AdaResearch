# Audio Effect Box Research - AdaResearch

Date: 2026-02-05

## Scope
This report focuses on special effect (SFX) sounds for AdaResearch and the Effect Box tooling. It covers:
- What SFX are already available in the codebase
- What SFX are missing for core interaction moments
- Refinements to make the existing SFX feel more distinct and readable

## Gaps (Effects AdaResearch Still Needs)
These are not explicitly represented as dedicated effect sounds yet, but they are important interaction cues:
- Data ping / scan tick (short, bright, non-musical confirmation)
- Error buzz / denial (brief dissonant burst)
- Portal whoosh (broadband sweep with transient)
- Algorithm step tick (subtle clocked tick for algorithm iteration)
- Gravity drop / weight shift (low pitch drop)
- Activation sparkle (short, high, harmonic shimmer)
- Map unlock chime (distinct from power_up_jingle)
- Time dilation / slowdown (pitch-bent wash)

## Recommended Additions (Minimal New Sound Types)
If we add a small set of new effect sounds, these would cover most missing cues:
- data_ping: sine + short FM burst, 80-120 ms
- error_buzz: square or saw burst with fast decay + slight detune
- portal_whoosh: filtered noise sweep + sub transient
- algorithm_tick: noise click + short resonant bandpass
- gravity_drop: low sine with pitch fall, 300-600 ms
- activation_sparkle: high sine clusters + short reverb

These can be implemented as new `CustomSoundGenerator` entries if you want them as first-class SoundTypes.

## Refinements Applied to Existing Effects
Adjusted defaults to make effects more distinct and readable in context:
- teleport_drone: longer fade, deeper modulation, less noise
- laser_shot: sharper attack, higher start frequency, more harmonics
- explosion: heavier low end, less high sizzle, longer low decay
- shield_hit: stronger ring modulation, clearer impact
- ambient_wind: softer cutoff, slower gusts, lower amplitude

See these files for the new defaults:
- commons/audio/parameters/basic/teleport_drone.json
- commons/audio/parameters/basic/laser_shot.json
- commons/audio/parameters/basic/explosion.json
- commons/audio/parameters/basic/shield_hit.json
- commons/audio/parameters/basic/ambient_wind.json

## Effect Box Coverage
To surface more special effects in the Effect Box, the following are now loaded via the parameter loader:
- parameters/space_pop/*.json
This brings glitch_chaos, wavetable_morph, industrial_clank, space_sub_drone, etc into the selectable set.
