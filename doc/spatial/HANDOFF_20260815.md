## The chain, and who owns what

```
spatial_contract.resolve(token)  →  body_m, posture, venue          [python]
spatial_floorplan.from_museum()  →  the tile as a plan (WALL_H from em_detail)
spatial_negotiation.negotiate()  →  Placement (slot / court / bay / REJECT)
spine_run.py spine --write-plan  →  ada_run/em_plan.json  (v2: plans[])
                                    ~10 MIN, isosurfaces alone 257 s — never
                                    wrap it in a short timeout; CHECK THE MTIME
export_museum_plan.py            →  rows in TILE coords (apron subtracted HERE)
endless_museum.gd                →  builds from the plan; TAB = editor      [gdscript]
  em/em_detail.gd    WALL_H 4.5 — THE ONE OWNER of height; everything derives
  em/em_lighting.gd  reads em_detail
  em/em_props.gd     reads em_detail; mount_defaults() + prop_wall_rules.json
  em/em_plinths.gd   viewing band; band() reads standing_rules.json
  em/em_editor.gd    stateless helpers; rulings → ada_run/em_overrides.json
```

**Authorship rule (non-negotiable):** the plan is the ONE author of placement.
Everything the hand does is a RULING recorded in a file and re-applied at
build where the thing is created — never a scene transform the builder does
not know about. Every fault this week was two authors holding one number.
