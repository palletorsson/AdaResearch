## Question and experiment

What shape can several simple returns make together? A visitor meets a sawtooth already assembled on a board above a bench, with the five sines it is made from drawn as rows beneath. Taking the four lower sliders down one at a time leaves a sine; H1 ALONE does it at once; BASELINE puts the five amounts back on every slider. HOLD stops the board's drift so one place on it, marked by an amber line, can be read on every row and on the sum: the plate on the bench prints each row's value there, adds them, and prints the drawn total beside the sum. The last line names which coefficients differ from the arrival. With the baseline held, five harmonics visibly fail to make the sawtooth's cliff.

## Design decision

The staging is an opt-in axis (`stand: bench`); `none` is the shipped behaviour and the artifact's ten other placements are untouched in what they show (the draw loops now pass through one emitter, `_emit_strip`, which writes the same line strip when the ribbon half-thickness is 0 — a shared refactor with identical output, flagged for Astra). The comparison is R1 (BASELINE against any change, `differs:` naming it) with a housed readout (R2) whose arithmetic is the display's own — `display_values(i)` uses the same loop and the same phase the meshes are built from — and HOLD, without which "a place on the sum" moves half a metre every second. No audio, no sixteen-slider bank, no application of the sum to a surface (the card's optional item 3): five clear contributions, held still, are the experiment.
