# Addons

Godot editor plugins used by Ada Research. Mix of project-owned tools and vendored third-party addons.

## Project-Owned

| Addon | Purpose |
|-------|---------|
| `audio_catalog_editor` | Browse and edit procedural sound presets with live preview |
| `element_editor` | 3D grid-based element placement for VR racks and audio systems |
| `infoboard_text_editor` | Edit InfoBoard JSON content (axioms, code, poetic text) |
| `map_sequence_editor` | Manage map sequences — reorder maps, edit descriptions, save |
| `prezi_mindmap` | JSON-based 2D mind map editor with zoom/pan and node/edge editing |
| `procedural_degradation` | Multi-layer procedural wear and surface degradation system |
| `tissue_gd` | Computational tessellation tools (Tissue-like) for mesh generation |
| `tutorial_text_editor` | BBCode editor for tutorial_text.json with live preview |
| `warning_dumper` | Scans GDScript files for potential warnings, exports to file |
