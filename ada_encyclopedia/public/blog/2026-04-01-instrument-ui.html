The Instrument UI: Green Screens That Glow in the Dark

The Science Screen started as a white coordinate grid. It worked on the web. In VR, it was invisible — dark pixels on a dark surface in a dark room. Today we rebuilt it as a glowing green instrument, and added the layout to make it useful for all 100+ artifacts in the spine.

The Three Surfaces

Every visualization exists on three surfaces simultaneously:

SurfaceTechnologyWhere
Web 2DHTML Canvas, JavaScriptBrowser at /primitives/point
Godot 2DSubViewport + Control._draw()768x576 texture rendered in engine
Godot 3DPlaneMesh + emission materialFloating screen in VR space

The web is the design surface. Godot 2D reproduces it at viewport resolution. Godot 3D projects it onto a physical screen with 4x emission energy and a green OmniLight. Same data, three contexts.

Why Dark Screens Don't Work in VR

The first version used a white background with light gray grid lines. On a monitor it looked clean. In VR, a SubViewport renders to a texture which gets mapped onto a 3D surface. Dark colors in the texture emit almost no light. The screen was technically there but effectively invisible.

The fix required three things: Brighter panel fills (green-tinted, not black). Higher emission energy (4x multiplier). And an OmniLight casting green light into the room — because a screen that doesn't illuminate its surroundings doesn't look like a screen.

The Instrument Aesthetic

We settled on a clean instrument look: oscilloscope, not HUD. Green-on-dark, monospace text, corner brackets, no decorative elements. The palette:

Three-Panel Layout

The screen now has the same structure as the web pages:

+--HEADER----------------------------------+ | POINT POSITION P=(x,y) SCORE 003 | +---------------------+---DATA PANEL-------+ | | X POSITION | | [VISUALIZATION] | +0.000 | | coordinate grid | Y POSITION | | with trail, dots | +0.000 | | targets, lines | DISTANCE | | | 1.42 | | | TRAIL | | | 100 pts | +---------------------+-------------------+ | INFO BAR | | Before the point, infrastructure. | | The origin is not a point but a pre... | +------------------------------------------+

The info bar cycles through sentences from the map's blurb.md and intent.md every 6 seconds. In VR, you read philosophy while you drag points. The text comes from the map's own documentation — no hardcoded messages.

Scaling to 100+ Artifacts

The current 3 modes (point, line, trace) cover the primitives sequence. The full spine has 19 sequences with ~100 artifacts. We identified 7 reusable visualization types that cover all of them:

ModeShowsSequences
xyPoint/trail on gridprimitives, forces, transformation
lineTwo endpoints + measurementsprimitives, springs
traceDrawing path with auto-zoomprimitives
grid2D cell heatmapcellular automata, WFC, arrays
waveTime-series line graphwavefunctions, Fourier, oscillation
fieldArrow/intensity mapnoise, forces, morphogenesis
scatterMany dots/agentsswarm, particles, ML

Any map adds a Science Screen with one config key: science_screen:180:1.5#mode:wave. The screen loads its text from the map's markdown files. The data panel shows whatever the tracked artifact exposes. Same green glowing instrument, different visualization inside.
