# Fetish Torus

A minimal primitives artifact that serves as a placeholder or base node. The script extends `Node` with no additional logic.

## Concept Taught

**Minimal node structure** -- demonstrates the simplest possible GDScript file as a base node that can be extended or composed with other nodes in a scene tree.

## How It Works

The script contains only `extends Node`, providing a bare node with no custom behavior. It can be used as a root for a scene that relies entirely on child nodes or external composition for its functionality.
