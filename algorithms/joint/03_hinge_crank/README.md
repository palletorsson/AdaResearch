# Hinge Crank

Rotating mechanism using HingeJoint3D — converting rotation to reciprocating motion.

## QFEP

Hinge constrains to 1 axis (F); motor drives rotation (E). Crank converts continuous rotation to back-and-forth — λ as mechanical transformation.

## Joint: HingeJoint3D

1 rotational degree of freedom. Motor-driven.
