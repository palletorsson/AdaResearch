# Pendulum (Pin Joint)

Simple pendulum using PinJoint3D — the foundation of harmonic motion.

## QFEP

Pendulum: gravity (F) drives oscillation (E). Energy converts between potential and kinetic. Period depends only on length, not mass. Pure λ — predictable chaos.

## Joint: PinJoint3D

3 rotational degrees of freedom (ball socket).

## Parameters

Adjust mass, length, damping to change behavior.
