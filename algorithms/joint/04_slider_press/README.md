# Slider Press

Linear motion using SliderJoint3D — constrained translation for piston/press mechanics.

## QFEP

Slider allows 1 translational axis (F); force drives motion (E). Pure linear constraint — no rotation allowed. λ as directed force.

## Joint: SliderJoint3D

1 translational degree of freedom.
