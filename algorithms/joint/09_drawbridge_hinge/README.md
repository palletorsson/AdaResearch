# Drawbridge Hinge

Castle drawbridge using HingeJoint3D — raising/lowering mechanism.

## QFEP

Hinge at one end (F, pivot point); gravity and motor control the swing (E). The bridge can only rotate around the hinge axis — constraint enabling function.

## Joint: HingeJoint3D

1 rotational DOF with motor and limits.
