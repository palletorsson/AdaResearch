# Cone Twist Bag

Punching bag using ConeTwistJoint3D — limited rotation within a cone.

## QFEP

Cone defines allowed angles (F, boundary); impact creates motion within that space (E). Real punching bags swing but don't flip over — biological constraints made mechanical.

## Joint: ConeTwistJoint3D

Rotation limited to cone angle + twist. Good for limbs, bags, pendants.
