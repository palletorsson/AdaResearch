# Spring Suspension

Damped spring using Generic6DOFJoint3D — oscillation with energy absorption.

## QFEP

Springs store energy (F, potential); damping dissipates it (E, entropy). Over time, oscillation decays to equilibrium. λ as energy flow between order and dissipation.

## Joint: Generic6DOFJoint3D

Configurable constraints with spring/damper parameters.
