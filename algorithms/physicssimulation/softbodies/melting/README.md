# Melting Geometry

A level-set method simulation that teaches **implicit surface representation, heat diffusion, phase transitions, and marching cubes mesh extraction**. A solid shape (initialized as a sphere) melts in response to heat sources placed in the scene. The surface is tracked as a signed distance field on a 3D grid, and the mesh is reconstructed each frame using a simplified marching cubes algorithm.

## How It Works

### Level Set Method

The solid is represented as a 3D scalar field (`level_set_grid`) where negative values are inside the object and positive values are outside. The zero-crossing of this field defines the surface.

1. **Initialization** -- A sphere is written into the grid by computing the signed distance `distance_to_center - radius` for every voxel.

2. **Heat diffusion** -- A second 3D grid (`temperature_grid`) stores temperature. Each frame:
   - Interior voxels (level set <= 0) diffuse heat via a 6-neighbor finite-difference Laplacian.
   - Heat sources inject temperature into a spherical radius around their positions, with falloff proportional to distance.

3. **Melting** -- Where temperature exceeds `melt_threshold`, the level set advances outward (value increases) at a rate proportional to the temperature excess and the gradient magnitude. This erodes the surface from the inside.

4. **Reinitialization** -- Every 10 frames, the level set is reinitialized to maintain the signed distance property. This uses an iterative PDE approach with upwind differences, running 5 iterations of the reinitialization equation `phi_t + sign(phi) * (|grad(phi)| - 1) = 0`.

### Mesh Extraction

A simplified **marching cubes** pass sweeps through the grid. For each cell, the 8 corner values determine a configuration bitmask. When a cell straddles the zero-crossing, edge intersection points are computed by linear interpolation and assembled into triangles. Normals are generated by `SurfaceTool`.

### Demo Scene

`melting.gd` provides a complete demo: it instantiates the melting geometry at resolution 32, adds a heat source at `(1, 0, 0)` with a glowing red marker sphere, sets up a camera and light, and offers mouse-click heat source placement and keyboard speed controls.

## Parameters

### MeltingGeometry
| Export | Type | Default | Description |
|--------|------|---------|-------------|
| `resolution` | int | 64 | Grid size in each dimension |
| `melt_speed` | float | 0.5 | Rate of level set advancement |
| `heat_sources` | Array[Vector3] | `[]` | World-space positions of heat emitters |
| `ambient_temperature` | float | 0.0 | Starting temperature of all voxels |
| `melt_threshold` | float | 0.5 | Temperature above which melting begins |

### Demo Scene
| Control | Effect |
|---------|--------|
| Left click | Add heat source at clicked position |
| Key 1 | Set melt speed to 0.5 (slow) |
| Key 2 | Set melt speed to 1.0 (normal) |
| Key 3 | Set melt speed to 2.0 (fast) |
| Key R | Reset geometry to initial sphere |

## Features

- Full 3D level set representation on a regular grid.
- Signed distance field initialization from analytic sphere.
- 6-neighbor heat diffusion with configurable diffusion rate.
- Spherical heat source injection with distance-based falloff.
- Temperature-driven melting with gradient-magnitude weighting.
- Upwind reinitialization to maintain signed distance property.
- Simplified marching cubes mesh extraction with linear edge interpolation.
- Auto-generated normals via `SurfaceTool`.
- World-to-grid and grid-to-world coordinate conversion.
- Public API for adding / removing heat sources and adjusting speed.
- Demo scene with camera, lighting, interactive heat placement, and speed controls.
