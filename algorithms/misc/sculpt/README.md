# Sculpt

A procedurally generated decorative sculpture artifact that teaches **constructive solid geometry** and **procedural mesh generation**. The sculpture assembles a base of stepped blocks, metallic posts, a rippling torus crown, catenary ropes, and fairy lights -- all built entirely from code at runtime with no imported models.

## How It Works

1. **Stepped base** -- A row of box meshes is laid out along the X axis, with every pair of blocks dropping slightly to create a stepped silhouette.
2. **Metallic posts** -- Three cylinder meshes rise from the base, evenly spaced, with high metallic / low roughness materials.
3. **Rippling torus** -- A `TorusMesh` sits atop the posts. A custom vertex shader displaces the surface along normals using a sine wave, and a fragment shader paints alternating pink-and-dark stripes blended by a layered sine function.
4. **Catenary ropes** -- Two ropes droop from the torus to the base. Each rope is a procedural `ArrayMesh` tube generated by sweeping a circular cross-section along a quadratic Bezier curve. Vertices, normals, UVs, and triangle indices are computed analytically.
5. **Fairy lights** -- A `MultiMesh` of tiny emissive spheres is distributed along a Bezier curve spanning the posts, giving the appearance of a string of glowing bulbs.

## Features

- Fully procedural -- the entire sculpture is built in `_ready()` with no external assets.
- Custom `ArrayMesh` tube generator that sweeps a circular cross-section along a Bezier spline, computing vertices, normals, UVs, and indices.
- Inline GLSL vertex + fragment shader for the torus that combines sine-wave vertex displacement with a striped color pattern.
- `MultiMesh` instancing for fairy lights distributes dozens of emissive spheres along a Bezier curve in a single draw call.
- Quadratic Bezier helper function used by both ropes and lights.
