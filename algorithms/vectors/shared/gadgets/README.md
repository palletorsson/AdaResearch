# Vectors Shared — Gadgets

Reusable physics gadget scripts shared across vector algorithm demonstrations. Each gadget extends `gadget_base.gd` and provides a hands-on mechanical device for exploring vector concepts in VR.

## Contents

- `gadget_base.gd` — Abstract base class defining the gadget interface (setup, reset, force application).
- `balance_beam_gadget.gd` — Beam balancing on a fulcrum, demonstrating torque and moment arms.
- `catapult_gadget.gd` — Catapult launching projectiles, showing force vectors and trajectories.
- `gyroscope_gadget.gd` — Spinning gyroscope demonstrating angular momentum and precession.
- `hinge_panel_gadget.gd` — Hinged panel showing rotational constraints.
- `paddle_wheel_gadget.gd` — Paddle wheel driven by force vectors.
- `piston_gadget.gd` — Piston demonstrating linear force conversion.
- `spring_scale_gadget.gd` — Spring-based scale showing Hooke's law and force measurement.

See the parent [Vectors Shared README](../README.md) for how gadgets integrate with the vector demonstrations.
