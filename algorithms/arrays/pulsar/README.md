# Pulsar Visualizers

This folder contains array-based pulsar artifacts used as dynamic reference objects in tutorial maps.

## Files
- `pulsar_visualizer.tscn` / `pulsar_visualizer.gd`: Main tutorial-facing pulsar artifact.
- `pulsar_glass_tubes.tscn` / `pulsar_glass_tubes.gd`: Alternate visual treatment.
- `pulsar_data.gd`: Shared pulsar pattern data and helpers.

## Used By
- `Tutorial_2D_Build` via `pulsar_visualizer`.
