# Slap Test

Soft body impact testing — watching deformable objects respond to collision forces.

## QFEP Connection

Slapping is **impulsive force meeting compliance**. The impact (E, sudden energy) deforms the body; internal forces restore shape (F, elastic return). The wobble is λ — the oscillation between deformation and recovery.
