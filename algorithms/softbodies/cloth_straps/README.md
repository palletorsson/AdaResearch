# Cloth Straps

Soft body cloth simulation with strap-like constraints — fabric physics for ribbons and bands.

## QFEP Connection

Cloth is **constraint between flexibility and structure**. Straps maintain length (F, stretch resistance) while bending freely (E, flex). The ratio determines whether it acts like rope, ribbon, or rigid band.
