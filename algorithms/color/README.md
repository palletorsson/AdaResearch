# Color Algorithms

Perception, mixing, spaces, and glitch. Color as both physics (wavelength) and qualia (experience).

## QFEP Connection

Color exists at the boundary between objective physics and subjective perception. **Metamerism** (different spectra appearing identical) and **simultaneous contrast** (context changing perception) demonstrate that color is not "out there" but constructed — a queer phenomenon par excellence.

## Key Concepts

1. **Color spaces** — RGB (additive), CMYK (subtractive), HSV (perceptual), LAB (perceptually uniform)
2. **Metamerism** — Different spectral compositions producing identical color perception
3. **Simultaneous contrast** — Adjacent colors affecting perception of each other
4. **Color quantization** — Reducing palette while preserving appearance (k-means, median cut)
5. **Glitch aesthetics** — Intentional corruption revealing underlying representation
