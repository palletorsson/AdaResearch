# Pillar Color Collection

## Purpose
Generates a palette-driven field of colored pillars for comparative color exploration.

## Key Files
- `res://algorithms/color/pillarcolorcollection/pillarcolorcollection.tscn`
- `res://algorithms/color/pillarcolorcollection/pillarcolorcollection.gd`

## VR Notes
- Spawns pillar instances once and assigns color materials at setup.
- Supports palette cycling to refresh the color set without reloading the map.
