# Grab Color

## Purpose
Palette and color-set interactables built from grabbable sticker/paper primitives.

## Key Files
- `res://algorithms/color/grabcolor/color_sets_overview.tscn`
- `res://algorithms/color/grabcolor/color_sets_overview.gd`

## VR Notes
- Uses grabbable paper instances for direct hand interaction.
- Labels are generated at runtime to keep each color swatch readable.
