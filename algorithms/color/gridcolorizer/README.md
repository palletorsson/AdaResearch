# Grid Colorizer

## Purpose
Applies palette and gradient patterns to the grid `MultiMesh` via per-instance colors.

## Key Files
- `res://algorithms/color/gridcolorizer/gridcolorizer.tscn`
- `res://algorithms/color/gridcolorizer/gridcolorizer.gd`

## VR Notes
- Designed to run against `GridMultiMesh` and can auto-cycle or respond to next-cube events.
- Keep debug logging disabled during VR playtests.
