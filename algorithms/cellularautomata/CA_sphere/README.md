# CA Sphere

Cellular automata on spherical surface — rules adapted for non-Euclidean topology.

## QFEP Connection

Spherical CA demonstrates **topology matters**. Same rules, different space — no edges, wraparound everywhere. Patterns that would hit boundaries on a plane continue around the sphere. λ as the shape of space itself.
