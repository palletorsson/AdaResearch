# Cellular Automata (Core)

Base implementations and utilities for cellular automata systems.

## QFEP Connection

CA are **parallel local computation**. Every cell updates simultaneously based on neighbors (F, synchronous rules); global patterns emerge from local interactions (E, emergence). The simplest path from rules to complexity.

## Core Concepts

- Grid of cells with states
- Neighborhood (Moore, von Neumann)
- Transition rules
- Synchronous update
