# CA Growth Network

Cellular automata creating network-like growth patterns — branching structures from local rules.

## QFEP Connection

Network growth emerges from **local decisions**. Each cell decides based on neighbors (F, rules); global network structure emerges (E, pattern). No cell knows the whole — yet coherent networks form. λ as emergence.
