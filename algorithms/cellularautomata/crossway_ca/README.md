# Crossway CA

Cellular automata with crossing/intersection rules — patterns that create path-like structures.

## QFEP Connection

Crossway rules generate **network topology**. Cells become paths; rules determine crossings (F, intersection logic); road-like networks emerge (E, connected structure). Order from local connectivity rules.
