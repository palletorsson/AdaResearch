# Ecosystem Simulation 2 — Components

Primitive mesh scenes used as visual building blocks for ecosystem entities.

## Contents

- `cone.tscn` — Cone mesh component.
- `cube.tscn` — Cube mesh component.
- `cylinder.tscn` — Cylinder mesh component.
- `sphere.tscn` — Sphere mesh component.
- `torus.tscn` — Torus mesh component.

These are instanced by the simulation to represent organisms with distinct shapes based on species or role.

See the parent [Ecosystem Simulation 2 README](../README.md) for the full simulation architecture.
