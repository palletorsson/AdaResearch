# Evolutionary Algorithms 2

## Folder Summary

The `Evolutionary Algorithms 2` module provides a 3D sandbox for exploring the ideas behind the Evolutionary Algorithms 2 workflows. It invites visitors to tune parameters, watch spatial feedback evolve in real time, and connect the algorithm's theory to an intuitive scene.

It ships with scene files like `scenes/creature.tscn` and `scenes/evolved_creatures.tscn` and controller scripts such as `scripts/creature.gd` and `scripts/evolved_creatures.gd`.
