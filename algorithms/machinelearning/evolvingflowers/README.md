# Evolving Flowers

## Folder Summary

The `Evolving Flowers` module provides a 3D sandbox for exploring the ideas behind the Evolving Flowers workflows. It invites visitors to tune parameters, watch spatial feedback evolve in real time, and connect the algorithm's theory to an intuitive scene.

It ships with the scene file `evolvingflowers.tscn` and the controller script `evolvingflowers.gd`.
