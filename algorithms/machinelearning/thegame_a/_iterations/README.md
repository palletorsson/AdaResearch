# The Game A — Iterations (Archived)

Archived test iteration scripts from the development of The Game A. These were used during iterative prototyping and are kept for historical reference.

## Contents

- `README_AXIOM_GARDEN.md` — Design notes for the Axiom Garden concept.
- `test_full_playthrough.gd` — End-to-end playthrough test.
- `test_iteration_1.gd` through `test_iteration_9.gd` — Sequential iteration test scripts, each capturing a snapshot of the game logic at that development stage.

These scripts are not actively used. The current entry point is in the parent folder.

See the parent [The Game A README](../README.md) for the active implementation.
