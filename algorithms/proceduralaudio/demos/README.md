# Procedural Audio — Demos

Demo scenes for the procedural audio algorithms.

## Contents

- `EuclideanDemo.tscn` — Demo scene for the Euclidean rhythm generator. Euclidean rhythms distribute a given number of onsets as evenly as possible across a number of steps, producing rhythmic patterns found in world music traditions (e.g., 3 onsets in 8 steps = tresillo).

See the parent [Procedural Audio README](../README.md) for the full list of synthesis and audio processing algorithms.
