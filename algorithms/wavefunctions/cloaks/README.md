# Live Cloak

A flowing cloak effect generated by sweeping a `CSGPolygon3D` profile along an animated `Path3D` curve. The path points follow a helical base shape modulated by wave functions, producing fabric-like rippling motion. The artifact teaches how **parametric curves and wave functions** can simulate soft, organic surfaces without a full physics simulation.

## Concept Taught

**Wave-based procedural animation** demonstrates that complex organic motion can be synthesized from simple mathematical functions. The cloak's shape at any moment is a helix whose radius varies from top to bottom, displaced by sine and cosine waves whose amplitude increases toward the hem. This teaches the principle that `position = base_shape + wave_displacement(t, frequency, amplitude)` can produce convincing fabric motion.

## How It Works

1. The script runs in `@tool` mode for editor preview.
2. A `Path3D` with a `Curve3D` of `segments + 1` points defines the cloak's spine.
3. Multiple `CSGPolygon3D` layers are created in `MODE_PATH`, each following the same path but with a slightly wider rectangular cross-section (`layer_spacing` offset), creating layered thickness.
4. Each layer gets a translucent, double-sided, emissive `StandardMaterial3D`.
5. Every frame, `_animate_curve()` updates each curve point:
   - **Base position**: A slowly spinning helix with radius interpolated from `radius_top` to `radius_bottom`.
   - **Wave displacement**: `sin` and `cos` functions at `wave_frequency` produce horizontal perturbation. A quadratic modifier (`t^2`) makes the bottom ripple more than the top.
6. The `speed` parameter controls how fast the wave and spin evolve over time.

## Parameters

| Export | Type | Default | Description |
|--------|------|---------|-------------|
| `height` | float | `2.0` | Vertical extent of the cloak |
| `radius_top` | float | `0.4` | Helix radius at the top (collar) |
| `radius_bottom` | float | `0.8` | Helix radius at the bottom (hem) |
| `segments` | int | `20` | Number of curve sample points |
| `layers` | int | `3` | Number of CSGPolygon3D layers for thickness |
| `layer_spacing` | float | `0.05` | Width offset between layers |
| `speed` | float | `2.0` | Overall animation speed |
| `wave_frequency` | float | `3.0` | Frequency of the ripple waves |
| `wave_amplitude` | float | `0.15` | Peak displacement of the ripple |
| `spin_force` | float | `0.5` | Rotational drift of the helix base |
| `layer_color` | Color | Translucent cyan | Base color and emission for all layers |
| `emission_strength` | float | `0.5` | Emission energy multiplier |

## Features

- `@tool` script: animated cloak visible in the Godot editor.
- CSGPolygon3D in path mode for smooth mesh extrusion along a curve.
- Multi-layer construction for volumetric appearance.
- Wave-function animation with configurable frequency, amplitude, and speed.
- Quadratic amplitude modifier: calm at the top, rippling at the hem.
- Translucent double-sided material with emission for ethereal look.

## Files

- `LiveCloak.gd` -- Main script: curve construction, wave animation, CSG layer management.
- `LiveCloak.tscn` -- Scene file (contains the Path3D node).
