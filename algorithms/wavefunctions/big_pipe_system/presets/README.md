# Big Pipe System — Presets

Pre-built pipe network configurations demonstrating different topologies.

## Contents

- `pipe_demo_gallery.tscn` — Gallery scene displaying all presets side by side.
- `pipe_demo_gallery.gd` — Controller for the preset gallery.
- `straight_run.tscn` — Linear pipe run.
- `l_bend.tscn` — Single L-shaped bend.
- `t_distribution.tscn` — T-junction distribution network.
- `cross_manifold.tscn` — Four-way cross manifold.
- `serpentine.tscn` — Serpentine (S-curve) pipe layout.
- `vertical_bypass.tscn` — Vertical pipe bypass routing.
- `industrial_branch.tscn` — Industrial-style branching network.

See the parent [Big Pipe System README](../README.md) for the parametric pipe segment system.
