# CosHLea -- Hyperbolic Cosine Helicoid Surface

A parametric 3D surface generated by evaluating a helicoid-like equation that uses the hyperbolic sine function (`sinh`). The surface is built from a UV parameter grid and rendered as a triangle mesh using `SurfaceTool`. The artifact teaches **parametric surface construction** and how hyperbolic functions create smooth, saddle-like geometry distinct from ordinary trigonometric surfaces.

## Concept Taught

**Parametric surfaces** define 3D geometry by mapping two parameters (u, v) to (x, y, z) coordinates via mathematical functions. The surface here uses:

```
x = sinh(v) * sin(u)
y = 3 * u
z = -sinh(v) * cos(u)
```

The `sinh` (hyperbolic sine) function produces exponential growth in the radial direction, creating a surface that flares outward rapidly. Combined with `sin(u)` and `cos(u)` for the angular component and a linear `y = 3u` for height, the result is a helicoid -- a surface that looks like a twisted ramp or corkscrew. This teaches how different function families (trigonometric vs. hyperbolic) produce fundamentally different geometric character.

## How It Works

1. A UV grid is constructed with `u_steps + 1` columns and `v_steps + 1` rows, spanning `[u_min, u_max]` by `[v_min, v_max]`.
2. Each grid point evaluates the parametric equations and is scaled by `scale_factor`.
3. `SurfaceTool` is used to emit triangles: each grid cell produces two triangles with face normals computed via cross products.
4. A smooth blue-white `StandardMaterial3D` with low roughness is applied.
5. The resulting `ArrayMesh` is assigned to a dynamically created `MeshInstance3D`.

## Parameters

| Export | Type | Default | Description |
|--------|------|---------|-------------|
| `u_min` | float | `-PI` | Minimum u parameter |
| `u_max` | float | `PI` | Maximum u parameter |
| `v_min` | float | `0.0` | Minimum v parameter |
| `v_max` | float | `4.0` | Maximum v parameter |
| `u_steps` | int | `64` | Subdivisions along the u axis |
| `v_steps` | int | `128` | Subdivisions along the v axis |
| `scale_factor` | float | `1.0` | Uniform scale applied to all vertices |

## Features

- Parametric surface evaluation using hyperbolic sine for radial flare.
- High-resolution triangle mesh built with `SurfaceTool` and per-face normals.
- Configurable parameter domain and resolution for exploring different regions of the surface.
- Smooth, low-roughness material for clear surface curvature visibility.
- Static geometry generated once at `_ready()` for zero per-frame cost.
