# Hybrid Complex

Combined procedural generation techniques — mixing multiple methods for richer results.

## QFEP Connection

Hybrid systems combine **complementary strengths**. L-systems provide structure (F); noise adds variation (E); constraint solvers ensure validity. The combination produces results no single method could achieve. λ as synthesis of techniques.

## Combinations

- L-system + noise = organic variation
- WFC + physics = stable generation
- Growth + constraints = bounded development
- Multiple noise octaves = multi-scale features
