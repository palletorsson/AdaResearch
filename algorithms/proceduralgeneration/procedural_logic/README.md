# Procedural Logic

Logic-based procedural generation — formal rules producing content.

## QFEP Connection

Procedural logic uses **deduction as generation**. Axioms and inference rules (F) derive new content (E as exploration of logical space). Valid outputs are provable; invalid ones are contradictions. λ as logical derivation.

## Methods

- Rule engines
- Logical inference
- Constraint propagation
- Answer set programming
