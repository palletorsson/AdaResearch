# Penteract Double Projection

A visualization of the 5-dimensional hypercube (penteract) projected twice -- first from 5D to 4D, then from 4D to 3D -- to produce a viewable wireframe. This artifact teaches how higher-dimensional geometry can be understood through successive projections, the same way a 3D cube casts a 2D shadow. It introduces 5D coordinate systems, rotation planes in higher dimensions, and the difference between perspective and orthographic projections.

## How It Works

1. **Vertex generation**: The 32 vertices of a penteract are generated by iterating over all 5-bit binary combinations, mapping each bit to +1 or -1 along the X, Y, Z, W, and V axes, then scaling by `penteract_size`.
2. **5D rotation**: Vertices are rotated in the VW plane (the unique rotation plane involving the 5th dimension) using a standard 2D rotation matrix applied to the V and W coordinates.
3. **First projection (5D to 4D)**: Each 5D vertex is projected down to 4D. In perspective mode, a scaling factor `dist / (dist - v)` simulates depth from the V axis. In orthographic mode, the V coordinate is simply dropped.
4. **4D rotations**: The resulting 4D vertices are rotated in the XW, YW, and ZW planes -- three independent rotation planes unique to 4D space.
5. **Second projection (4D to 3D)**: Each 4D vertex is projected to 3D using the same perspective/orthographic choice, this time collapsing the W dimension.
6. **Edge detection**: The 80 edges of a penteract connect vertex pairs that differ by exactly one bit (Hamming distance 1).
7. **Rendering**: Edges are drawn as colored lines using `ImmediateMesh`, with color interpolated between inner, middle, and outer based on each edge's average V-coordinate depth.

Four projection modes are available: both perspective, both orthographic, or mixed combinations.

## Parameters

| Export | Type | Default | Description |
|--------|------|---------|-------------|
| `projection_mode` | ProjectionMode | PERSPECTIVE_BOTH | Projection method for each step |
| `penteract_size` | float | 2.0 | Scale of the 5D hypercube |
| `projection_distance_5d` | float | 4.0 | Eye distance for 5D perspective projection |
| `projection_distance_4d` | float | 4.0 | Eye distance for 4D perspective projection |
| `rotation_5d_vw` | float | 0.0 | Rotation angle in the VW plane |
| `rotation_4d_xw` | float | 0.0 | Rotation angle in the XW plane |
| `rotation_4d_yw` | float | 0.0 | Rotation angle in the YW plane |
| `rotation_4d_zw` | float | 0.0 | Rotation angle in the ZW plane |
| `animate_rotation` | bool | true | Auto-animate all rotation angles |
| `rotation_speed` | float | 0.3 | Speed of animated rotations |
| `inner_color` | Color | red | Color for edges near V=-1 |
| `middle_color` | Color | green | Color for edges near V=0 |
| `outer_color` | Color | blue | Color for edges near V=+1 |
| `edge_thickness` | float | 0.02 | Line thickness |
| `emission_strength` | float | 1.5 | Glow intensity |

## Features

- **True 5D geometry** -- 32 vertices, 80 edges, generated from binary vertex enumeration
- **Double projection pipeline** -- demonstrates the chain of dimensional reductions (5D to 4D to 3D)
- **Custom Vector4D and Vector5 classes** -- inner classes for 4D and 5D vector math
- **Four projection modes** -- perspective/orthographic combinations for each projection step
- **Depth-coded coloring** -- edge color reveals position along the 5th dimension
- **Demo controller** -- full UI with sliders for all rotations, projection distances, colors, and a randomize button
- **Camera orbit** -- auto-rotating camera for continuous viewing

## Files

- `penteract_double_projection.gd` -- Core algorithm: 5D vertex generation, VW rotation, double projection, edge detection, ImmediateMesh rendering, Vector4D/Vector5 classes
