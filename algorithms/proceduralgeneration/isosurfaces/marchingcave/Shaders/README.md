# Marching Cave — Shaders

Shader files for the marching cubes cave terrain rendering.

## Contents

- `glass_wireframe.gdshader` — Spatial shader rendering the isosurface mesh as a translucent glass wireframe, useful for inspecting the triangle structure.
- `TerrainVisual.tres` — Shader material resource applying terrain visual effects to generated meshes.

See the parent [Marching Cave README](../README.md) for the full isosurface pipeline.
