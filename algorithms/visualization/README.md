## Rorschach

Symmetric, ambiguous patterns that invite interpretation:

```
    ╱╲    ╱╲
   ╱  ╲  ╱  ╲
  │    ╲╱    │
  │    ╱╲    │
   ╲  ╱  ╲  ╱
    ╲╱    ╲╱
```

Generated through symmetric noise or fluid simulation, 
these patterns are objectively random but subjectively meaningful —
a perfect demonstration of pattern-seeking cognition.

## QFEP Connection

Rorschach tests reveal how we impose **F (structure)** onto **E (noise)**.
The pattern has no inherent meaning; meaning emerges from the observer.
This is QFEP in perception: we are F-minimization machines,
finding order even where none exists.
