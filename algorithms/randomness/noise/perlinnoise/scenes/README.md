# Perlin Noise — Scenes

Scene files for the Perlin noise terrain and wave visualizations.

## Contents

- `perlin_noise_terrain.tscn` — Heightmap terrain generated from Perlin noise.
- `NeonWaveGrid.tscn` — Neon-styled wave grid driven by Perlin noise.
- `neon_wave_grid.gd` — Script controlling the neon wave grid animation.
- `random_edge_noise_profile.tscn` — Edge profile distortion using noise.

See the parent [Perlin Noise README](../README.md) for the noise generation details.
