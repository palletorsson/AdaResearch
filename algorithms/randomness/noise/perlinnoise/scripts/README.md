# Perlin Noise — Scripts

GDScript implementations for the Perlin noise visualizations.

## Contents

- `terrain_generator.gd` — Generates heightmap terrain meshes from Perlin noise fields.
- `random_top_noise_edge_modifier.gd` — Applies noise-based distortion to edge profiles.

See the parent [Perlin Noise README](../README.md) for the noise generation details.
