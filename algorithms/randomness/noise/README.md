# Noise Algorithms

Implementations of noise functions used for procedural generation — terrain, clouds, textures, and organic variation.

## Contents

| Subfolder | Description |
|-----------|-------------|
| `cellularnoise/` | Cellular (Worley) noise — distance-to-nearest-point patterns for stone, water, and biological textures |
| `cloudvolume/` | Volumetric cloud rendering using 3D noise fields |
| `perlinnoise/` | Classic Perlin noise — gradient-based coherent noise for terrain and textures |
| `perlinvolume/` | Perlin noise in 3D volumetric form (fog shader) |
| `scatter/` | Instancing scatter — random point distribution for placing objects across surfaces |

Several subfolders have their own READMEs with detailed documentation.

See the parent [Randomness README](../README.md) for an overview of all randomness categories.
