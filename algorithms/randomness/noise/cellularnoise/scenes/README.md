# Cellular Noise — Scenes

Scene files and supporting scripts for the cellular noise (Worley noise) visualization.

## Contents

- `cellshader.tscn` — Scene applying the cellular noise shader to a mesh surface.
- `pool_hole_noise.tscn` — Variant scene using cellular noise to create pool/hole-like patterns.
- `pool_hole_noise.gd` — Script driving the pool hole noise variant.

See the parent [Cellular Noise README](../README.md) for the noise algorithm details.
