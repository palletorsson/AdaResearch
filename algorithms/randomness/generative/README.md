# Generative Randomness

Algorithms that use randomness as a creative tool to generate visual structures.

## Contents

### Ten Print / Ant Maze

`tenprintantmaze/` — A 3D take on the classic "10 PRINT" one-liner pattern (random diagonal lines filling a grid) combined with ant-maze generation. The algorithm fills a grid with randomly chosen forward-slash or backslash tiles, producing an emergent maze-like pattern.

See its own [README](tenprintantmaze/README.md) for details.
