# Procedural Randomness

Techniques for applying randomness to different domains of 3D scene construction — geometry, movement, transforms, and particle systems.

## Contents

| Subfolder | Description |
|-----------|-------------|
| `geometrybased/` | Randomized geometry generation: cave systems, kitbashing, procedural moss, cloud forms, random plant structures |
| `movementbased/` | Random movement patterns and procedural animation |
| `objecttransforms/` | Randomized position, rotation, and scale of scene objects |
| `particlerandomness/` | Particle system randomness: emergent behavior, evolutionary algorithms, extreme randomness |

Each subfolder contains scenes and scripts demonstrating how randomness at different levels of the scene hierarchy produces distinct visual effects — from subtle organic variation (transform jitter) to fully generative structures (cave systems).

See the parent [Randomness README](../README.md) for an overview of all randomness categories.
