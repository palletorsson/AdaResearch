# Geometry-Based Randomness — Scripts

GDScript implementations for geometry-driven randomness demonstrations.

## Contents

- `ico_sphere_distort.gd` — Vertex-level random displacement on an icosphere mesh.
- `random_edge_profile_set_parameters.gd` — Parameterized random edge profile generation.
- `random_object_spawner.gd` — Spawns objects with randomized position, rotation, and scale.
- `random_top_edge_modifier.gd` — Applies random modifications to top-edge geometry.

See the parent [Geometry-Based README](../README.md) for the randomness techniques.
