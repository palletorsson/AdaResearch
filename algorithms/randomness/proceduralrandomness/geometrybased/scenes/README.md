# Geometry-Based Randomness — Scenes

Scene files demonstrating randomness applied to geometric forms.

## Contents

- `ico_sphere_distorted.tscn` — Icosphere with randomized vertex displacement.
- `random_edge_profile.tscn` — Single random edge profile.
- `random_edge_profile_collection.tscn` — Collection of varied edge profiles.
- `random_edge_profile_grabable.tscn` — VR-grabbable edge profile variant.
- `random_object_spawner.tscn` — Spawns objects with randomized transforms and properties.

See the parent [Geometry-Based README](../README.md) for the randomness techniques.
