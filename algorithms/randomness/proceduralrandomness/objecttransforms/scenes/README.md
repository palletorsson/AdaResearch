# Object Transforms — Scenes

Scene files demonstrating randomness through object transform variation.

## Contents

- `spawn_randomcubes.tscn` — Scene spawning cubes with randomized transforms (position, rotation, scale).
- `spawn_randomcubes.gd` — Script applying random transforms to spawned cube instances.

See the parent [Object Transforms README](../README.md) for the randomness techniques.
