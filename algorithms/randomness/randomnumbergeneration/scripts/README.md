# Random Number Generation — Scripts

GDScript implementations for the random number book page visualizations.

## Contents

- `random_number_book_page_1995.gd` — Generates and renders random number tables on a 3D book page surface.
- `random_color_book_page_1955.gd` — Maps random numbers to color swatches on a book page.

See the parent [Random Number Generation README](../README.md) for the generation algorithms.
