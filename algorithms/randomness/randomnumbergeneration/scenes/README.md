# Random Number Generation — Scenes

Scene files visualizing random number and color generation as physical book pages.

## Contents

- `random_number_book_page_1955.tscn` — Book page displaying random number tables (inspired by RAND Corporation's 1955 publication).
- `random_number_book_page_collection.tscn` — Collection of multiple random number pages.
- `random_color_book_page_1955.tscn` — Book page mapping random numbers to colors.
- `random_color_book_page_collection.tscn` — Collection of random color pages.

See the parent [Random Number Generation README](../README.md) for the generation algorithms.
