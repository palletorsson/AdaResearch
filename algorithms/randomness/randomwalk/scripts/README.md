# Random Walk — Scripts

GDScript implementations for the random walk visualizations.

## Contents

- `random_walk.gd` — Core random walk: step generation, trail drawing, and statistics.
- `random_walk_manager.gd` — Manages multiple concurrent random walks.
- `crystal_random_walk.gd` — Walk constrained to crystal lattice bond directions.
- `crystal_demo_controller.gd` — Demo controller for the crystal walk scene.
- `tessellation_lattice_walk.gd` — Walk on tessellated lattice structures (hexagonal, triangular).
- `tessellation_demo_controller.gd` — Demo controller for the tessellation walk scene.

See the parent [Random Walk README](../README.md) for the walk algorithms.
