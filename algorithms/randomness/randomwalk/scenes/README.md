# Random Walk — Scenes

Scene files for random walk and lattice walk visualizations.

## Contents

- `random_walk.tscn` — Basic random walk visualization.
- `random_walk_collection.tscn` — Multiple simultaneous random walks for comparison.
- `random_walk_grab_paper.tscn` — VR-grabbable paper showing walk traces.
- `crystal_random_walk.tscn` — Random walk constrained to crystal lattice geometry.
- `crystal_random_walk_demo.tscn` — Full demo scene for the crystal walk.
- `tessellation_lattice_demo.tscn` — Random walk on tessellated lattice structures.
- `place_me.gd` — Helper script for object placement in walk scenes.

See the parent [Random Walk README](../README.md) for the walk algorithms.
